S3 · 第二课（L3-02） 45 分钟 受控源模型 · 两条规则 · 四种基本电路

运放作为电路元件：虚短虚断与四种基本电路

前面学的元件都能用一两条 VCR 描述。这节课解决一件事：运放内部成千上万晶体管，能不能完全不管内部、只靠两条简单规则就把各种运放电路（反相、同相、跟随、相加）的输出算出来？这两条规则从哪里来、为什么成立、又在什么情况下会失效？

核心问题→ 理想化·两规则→ 反相→ 同相·跟随→ 加法器→ 实验台→ 练习/过关
0 · 核心问题与预测 1（先别算，凭直觉判断）

先看运放的图形符号。它有两个输入端 + / − 和一个输出端。注意：+ / − 只是区分两种输入端性质的标志，不是电压极性——这是今天第一大误读。

师：从电路分析角度，我们只关心它端子上的表现：输出受两个输入端电压之差控制，u_o=A(u_+−u_-)，A 是很大的开环增益；差分输入记作 u_d=u_+−u_-。运放是单向器件——输出受输入控制，输入不受输出影响。

图中两个输入端：+ 是同相端（电压 u_+）、− 是反相端（电压 u_-）。三角形指向反映"单向"。

图① · 运放符号与差分输入（自包含示意，不引用书内图号）。

先预测 1：A 很大（比如 10 万倍），但输出电压被电源卡在 ±13 V 之间。假如运放停在线性放大（输出没顶到底、是个有限值），那两个输入端的电压差 u_d 大概是多少？选定后才解锁揭晓。

提示一下：u_o = A·u_d，A 极大而 u_o 有限。先自己选，公布只到"u_d 有多大"这一层，还不给规则的名字。

选"几乎为零"。输出 u_o=A·u_d 停在一个有限值，而 A 极大，所以 u_d=u_o/A≈0，两输入端电压几乎相等；又因为输入电阻极大，输入端几乎不取电流。

这一层只确认现象：u_d≈0、输入端电流≈0。至于这两条现象叫什么、凭什么敢用，下一步才给。

师：把这个思想实验正式化——增益 A→∞、输入电阻 R_i→∞、输出电阻 R_o→0，且工作在线性区，就称理想运放。三条极限直接换来两条规则。

图②：两条规则与它们的边界。虚断来自 R_i→∞，虚短来自 A→∞ 且输出有限。两个"虚"字都要盯住"不是真的"：虚短≠真短路（电流为零）、虚断≠真开路（电压可不为零）。

关键追问：A→∞ 意味着差一点点就把输出顶到饱和，凭什么还能停在线性区？——靠负反馈：把输出经电阻接回反相端，输出偏高就压低 u_d=u_+−u_-，把输出拉回来。所以 线性区 + 负反馈是前提；一旦饱和，虚短失效。

图② · 两条规则与边界（自包含示意）。
陈述时刻 ① · 理想运放、虚短与虚断
全称/命名：理想运算放大器（ideal op-amp）及两条分析规则——虚短、虚断。
一句定义：满足 A→∞、R_i→∞、R_o→0 且工作在线性区（输出不饱和、有负反馈）的运放称为理想运放；由此得到两条规则——虚断：两输入端电流为零 i_+=i_-=0（因 R_i→∞），但输入端电压可不为零，不是真开路；虚短：两输入端电压相等 u_+=u_-（因 A→∞ 且 u_o 有限），但输入端电流为零，不是真短路。一端接地时另一端也≈0，称"虚地"。适用前提：线性区 + 负反馈；饱和时 u_d 不再≈0，虚短失效。
符号式：i_+=i_-=0；u_+=u_-（即 u_d=u_+−u_-=0）。〔邱 §5-1 p.114–116、§5-3 p.118–119〕

2 · 反相比例器（陈述时刻② · 揭晓预测 2）
师：同相端接地，输入 u_i 经 R₁ 接反相端，R₂ 从输出接回反相端——这就是负反馈。先看电路，再猜输出与输入同号还是反号。

图上 R₂ 是反馈电阻，把输出接回反相端；同相端接地。先只盯住"输出升高时，反馈把反相端电压怎么拉"。

图③ · 反相比例器（自包含示意，不引用书内图号）。

先预测 2：这个电路里，输出 u_o 和输入 u_i 是同号还是反号？选定后才解锁揭晓。

选"反号"。同相端接地 u_+=0，虚短给反相端 u_-=0（虚地）；虚断使输入端不取电流，对反相端节点列 KCL：u_i/R₁ + u_o/R₂ = 0 → u_o=−(R₂/R₁)u_i。

u_o = −(R₂ / R₁) · u_i　（负号来自虚地节点的电流求和）
陈述时刻 ② · 反相比例器（倒向放大器）
全称/命名：反相比例器（inverting amplifier）。
一句定义：同相端接地、输入经 R₁ 接反相端、R₂ 从输出反馈到反相端的电路；由虚短得反相端为"虚地"，在反相端节点列 KCL 即得输出电压与输入电压成固定比例、符号相反，比例只由外部电阻 R₂/R₁ 决定，与运放本身参数几乎无关。
符号式：u_o=−(R₂/R₁)u_i；负号来自虚地节点电流求和 u_i/R₁+u_o/R₂=0。〔邱 §5-2 p.117–118〕

精确式（§5-2）算出比值几乎只由 R₂/R₁ 决定、与 A 几乎无关——这就是工程上敢用理想模型的原因；精确式不要求记。

3 · 同相比例器与电压跟随器（陈述时刻③ · 揭晓预测 3）
师：把输入改接到同相端，反相端经 R₁ 接地、R₂ 仍从输出反馈回来。这次增益还是 −R₂/R₁ 吗？先猜。

先预测 3：输入改接同相端后，输出大概是输入的什么范围？选定后才解锁揭晓。

选"大于 1 的正数"。虚断使反相端不取电流，R₁、R₂ 就是普通分压；虚短给 u_-=u_+=u_i，故 u_i=R₁/(R₁+R₂)·u_o → u_o=(1+R₂/R₁)u_i（恒 >1、为正）。

u_o = (1 + R₂ / R₁) · u_i　；　R₂=0 时 u_o = u_i（跟随器，增益 1）
陈述时刻 ③ · 同相比例器与电压跟随器
全称/命名：同相比例器（non-inverting amplifier）与电压跟随器（voltage follower）。
一句定义：输入接同相端、反相端经 R₁ 接地并由 R₂ 反馈的电路，增益为 1+R₂/R₁（恒大于 1、输出与输入同号）；当 R₂=0（R₁→∞）时退化为电压跟随器 u_o=u_i，增益 1，因输入电阻无限大不取电流，插在信号源与负载之间可隔离负载效应、保持原定分压值。
符号式：同相 u_o=(1+R₂/R₁)u_i；跟随器 u_o=u_i。〔邱 §5-3 p.119–120〕

图④：同相比例器与跟随器隔离。左边同相增益恒 >1；右边跟随器把输出直接接回反相端（u_o=u_i），靠 R_i→∞ 不取电流，使负载接上来也不拉低原来的分压比。增益只有 1，价值却在"隔离"。

图④ · 同相比例器与跟随器隔离（自包含示意）。
4 · 加法器（陈述时刻④ · 揭晓预测 4）
师：两个输入各经一个电阻接反相端，同相端接地，反馈电阻 R_f。分析这个电路时，能不能像以前一样，也给输出节点列一条 KCL？这是今天最容易踩的坑，先表态。

图上两路输入 u₁、u₂ 分别经 R₁、R₂ 汇到反相端节点，R_f 从输出接回该节点。先想想：输出那根线上的电流，你能提前写出来吗？

图⑤ · 反相加法器（自包含示意，不引用书内图号）。

先预测 4：分析这个电路时，能不能也给输出节点列一条 KCL 方程？选定后才解锁揭晓。

选"不能"。输出电流由运放内部的受控源提供、事先未知，无法在输出节点写一条确定的 KCL；只能在输入（反相）节点列方程。虚地 u_-≈0 下：u₁/R₁ + u₂/R₂ + u_o/R_f = 0 → u_o=−R_f(u₁/R₁+u₂/R₂)；等阻时 u_o=−(u₁+u₂)。

u_o = −R_f ( u₁/R₁ + u₂/R₂ )　→　等阻 R₁=R₂=R_f=R：u_o = −(u₁+u₂)
陈述时刻 ④ · 加法器与输出节点纪律
全称/命名：反相加法器（summing amplifier）与运放电路的分析纪律。
一句定义：多路输入各经电阻接反相端、同相端接地、反馈电阻 R_f 的电路，因反相端虚地，各输入电流在输入节点汇合后经 R_f 流向输出，输出为各输入的加权和取负；分析运放电路时只在输入节点列 KCL，不对输出节点列 KCL（输出电流未知）。
符号式：u_o=−R_f(u₁/R₁+u₂/R₂+…)；等阻 R₁=…=R_f=R → u_o=−(u₁+u₂+…)。〔邱 §5-3 p.120–121〕

全课宪法

上一课会解出稳态相量 Ū、İ；本课把二者"相乘"：p=ui 展开后分成恒定分量（真耗能）与可逆分量（往返交换），于是有 P、Q、S、λ。
因果顺序：p=ui → P/Q → S/λ → 复功率打包 → 并联补偿 / 共轭匹配。不是时间安排。

正弦稳态功率与功率因数

L2-06 已经能把稳态的电压、电流相量解出来。但把两个相量"相乘"到底发生什么？这节课只解决一个问题：正弦稳态下电压、电流都是相量，为什么功率不能简单写成 UI，而要写成 P=UIcosφ？那个不干活的"无功 Q"究竟在交换什么、多个负载的功率怎么结算、又怎样用并联电容让电源少送无效电流、让负载拿到最大功率？

核心问题→ p=ui → P/Q→ S 与 λ→ 复功率守恒→ 并联补偿→ 共轭匹配→ 练习
上方链条是因果顺序：先看见功率里有一半在往返，才需要 P 与 Q；再由容量引出 S 与 λ；三种功率太散才用复功率打包；最后谈两个"调一调"的工程应用。不是时间安排。
0 · 核心问题与预测 1（先别算，凭直觉选）

某感性负载接在 220 V 交流电源上，电流表读 10 A（有效值），但瓦特表只读 1500 W——不是 220×10=2200 W。为什么？先猜，第 2 环节推导出 P=UIcosφ 后才揭晓。

先预测 1：① 电表坏了；② 电压电流不同相，要乘 cosφ；③ 有功能量被无功抵消掉了。

选定后，第 2 环节给出功率因数定义才揭晓；现在不公布。

1 · 从 p=ui 推出 P 与 Q（揭晓预测 2）

不引入任何新东西，就从最朴素的瞬时功率 p(t)=u(t)i(t) 出发。设电流为参考：i=√2 I cosωt、u=√2 U cos(ωt+φ)（关联参考方向，φ=φ_u−φ_i，感性时 φ>0）。相乘并用积化和差 cosα cosβ=½[cos(α−β)+cos(α+β)]：〔邱 §9-4〕

p = UI cosφ [1 + cos(2ωt)] − UI sinφ · sin(2ωt)

功率的频率是电压电流的 2 倍，而且分成两块：第一项有恒定分量 UIcosφ（无源一端口时 ≥0），是不可逆部分，真正被电阻吃掉；第二项是纯波动、一周期均值为零，是储能元件与外电路往返交换的可逆部分，振幅 UIsinφ。

符号说明：这里以电流为参考才得到负号；若以电压为参考，第二项写成正号，二者等价。恒定分量 UIcosφ 与可逆分量振幅 |UIsinφ| 与参考选择无关——这才是要记住的物理量。（以电流为参考与邱 §9-4 一致。）

代入数值检验：U=100、I=1、φ=30°、ωt=45° 时，直接算 p=u·i≈136.6 W，上式也给出 136.6 W；若把第二项符号写反就变成 36.6 W，立刻露馅。

先预测 2：纯电感接正弦电源，一周期平均功率 P 是多少？① UI；② 0；③ UI/2。定义给出前先选。

选定后解锁下面的定义与揭晓。

陈述时刻 ① · 有功功率（average / active power）P（正式定义 + 条件）：一端口一周期内吸收的平均功率，等于瞬时功率不可逆部分的恒定分量 P=(1/T)∫₀ᵀp dt = UI cosφ，单位 W。条件：同频正弦稳态、U/I 为有效值、电压电流关联参考方向、φ=φ_u−φ_i。
陈述时刻 ② · 无功功率（reactive power）Q（正式定义 + 条件）：瞬时功率可逆部分的振幅 Q = UI sinφ，衡量储能元件与外电路往返交换的规模，单位 var（乏）。条件：同上；φ>0（感性、电流滞后）时 Q>0，φ<0（容性、电流超前）时 Q<0。"无功"不是"没做功"，而是这部分能量在往复中不被消耗。

李下 §9-3 给出 Q 的物理意义：Q_L=+ωLI²=+2ωW̄_L、Q_C=−ωCU²=−2ωW̄_C——Q = 2ω × 储能平均值（电感正、电容负）。储能越多、往返规模越大，Q 越大。能量平均值与时间无关，可以直接相加，于是有无功守恒 ΣQ=0。

元件φ有功 P无功 Q口诀
电阻 R0I²R=U²/R0只吃 P
电感 L+90°0+ωLI²=U²/(ωL)吃正 Q
电容 C−90°0−ωCU²=−I²/(ωC)"吐"负 Q

电容 Q 的坑：用电压写是 −ωCU²，用电流写是 −I²/(ωC)（因为 U=I/(ωC)，两式相等），不能写成 −ωCI²——那是 OCR 常见的误识，量纲和数值都不对。〔李下 §9-3 式 9-17〕

选②，P=0，但 Q=+UI≠0。纯电感瞬时功率是均值为零的波动（前半周吸能、后半周吐能），一周期净耗能为零，所以平均功率为零；但它和电源之间有大规模能量往返，这个规模正由 Q=+UI=ωLI² 衡量。**"不耗能"不等于"没有功率交换"**——这是后面理解并联补偿的支点。

2 · 视在功率、功率因数，揭晓预测 1

发电机、变压器是按额定电压和额定电流设计的，关心的是"电压×电流"的整体规模，于是定义视在功率 S=UI（单位 V·A）。由 P=Scosφ、Q=Ssinφ 得直角三角形：

S = √(P² + Q²)　，　λ = cosφ = P / S
陈述时刻 ③ · 视在功率（apparent power）S 与功率因数（power factor）λ（正式定义 + 条件）：S=UI 是电源需提供的功率容量（V·A）；λ=P/S=cosφ 是有功占容量的比例；S≥|P|、S≥|Q|。条件：正弦稳态有效值。对不含独立源的无源一端口，|φ|≤90°，P≥0、λ≥0；因 cosφ 对 ±φ 同值，必须补注"感性（滞后）"或"容性（超前）"才知道电路性质。含受控源时可能 |φ|>90°、P<0（发出有功），此时按定义 λ=P/S<0，"功率因数非负"的说法不适用，须直接看 P 的符号。〔邱 §9-4、李下 §9-4〕

功率三角形把三个功率画成直角三角形：横边 P、竖边 Q、斜边 S，夹角 φ。图中用 3-4-5 整比参数 P=36 W、Q=−48 var、S=60 V·A、φ=−53.13°、λ=0.6，对应容性负载（Q 向下为负）。

看三角形就明白两件事：① S 是斜边，不是 P+Q 的算术和；② λ=横边/斜边，是有功"打了几折"。容性时 Q 在下方，但 λ 仍为正——性质要看 Q 的符号或文字标注。

自包含示意图：功率三角形。斜边 S 才是"容量"，横边 P 才是"真做功"。

选②，电压电流不同相，要乘 cosφ。P=UIcosφ=220×10×cosφ=1500 W，所以 cosφ=1500/2200≈0.682（感性）。S=UI=2200 V·A 才是"220×10"，它比 P=1500 W 大。

选③错在哪：把 P 与 Q 当成正负标量相减。它们相位差 90°，在功率三角形里是两条直角边，合成用勾股定理 S=√(P²+Q²)，不是加减。无功不会"抵消"有功。

3 · 复功率与守恒（揭晓预测 3）

P/Q/S 三套公式太散，能不能装进一个复数？用极坐标一步就够：Ū=U∠φ_u、İ=I∠φ_i，取共轭得 İ*=I∠−φ_i，于是

S̃ = Ū İ* = UI∠(φ_u − φ_i) = UIcosφ + j UIsinφ = P + jQ

实部是 P、虚部是 Q、模是 S、辐角是 φ——三种功率与功率因数全部统一进一个复数。为什么必须取电流共轭：不取共轭就会得到 φ_u+φ_i，实部不再是 P。〔邱 §9-5〕

陈述时刻 ④ · 复功率（complex power）S̃（正式定义 + 条件）：S̃=Ūİ*=P+jQ，等价写法 S̃=Z|İ|²=|Ū|²Y*（Y*=G−jB；串联用前者、并联用后者）。条件：必须取电流共轭；S̃ 不是相量、不对应任何时域正弦量（乘积 Ūİ 没有物理意义）；吸收或发出由端口参考方向决定。单位 V·A，实部 W、虚部 var。

李下 §9-5~§9-6 把节点方程乘以节点电压后相加，从 KCL/KVL 严格证出 ΣŪ_k İ_k* = 0，即

Σ S̃ = 0　⇒　ΣP = 0 且 ΣQ = 0

注意：这里说的是复功率守恒。视在功率 S 是否也能相加？先别看答案，自己判断。

先预测 3：既然复功率守恒、P 与 Q 都守恒，多个元件各自的视在功率相加，是否等于总视在功率？① 一定等于；② 一般不等于；③ 都不守恒。选定后才揭晓。

选定后解锁下面的带做与揭晓；现在不公布。

带做（形态 A）· 李下例 9-12：2300 V 母线上并接两负载——负载 1：10 kW、λ₁=0.8（容性）；负载 2：15 kW、λ₂=0.6（感性）。求总复功率、线电流与总功率因数。

S̃₁ = P₁ − j P₁ tan(arccosλ₁) = 10000 − j7500 V·A
S̃₂ = P₂ + j P₂ tan(arccosλ₂) = 15000 + j20000 V·A
ΣS̃ = 25000 + j12500 = 27951∠26.56° V·A
λ = ΣP / |ΣS̃| = 25000 / 27951 ≈ 0.894（感性）；　I = |ΣS̃| / U = 27951 / 2300 ≈ 12.15 A

揭晓：选②，一般不等于。ΣS̃=0 保证 P、Q 分别守恒（实部、虚部各自相加），但视在功率 S 是复功率的模，模不满足线性相加：

ΣS件 = 12.5 k V·A + 25 k V·A = 37.5 k V·A　≠　|ΣS̃| = 27.95 k V·A

两个负载的视在功率相加是 37.5 k V·A，实际总线只需提供 27.95 k V·A——因为容性负载的负 Q 与感性的正 Q 在复功率里抵消了一部分，但各自的视在功率（模）都是正的，加起来自然偏大。选①错在把模当成可加的量；选③错在以为 P、Q 也不守恒。

工程含义：设备容量按总视在功率选，而不是各负载容量之和——理解复功率守恒能省下真实投资。〔李下 §9-5~§9-6〕

4 · 并联电容提高功率因数（揭晓预测 4）

先预测 4：给感性负载并联电容把功率因数提高后，电源提供的电流如何变？① 变大；② 变小；③ 不变（因为电容不耗能）。推导前先选。

选定后解锁下面的补偿推导与揭晓。

感性负载 Q₁>0，电源得来回送这部分无功、电流白流。电容 Q_C=−ωCU²<0，两者符号相反，可以就地抵消。关键在"并联"：并联在负载两端 ⇒ 端电压 U 不变 ⇒ 负载自身的 P₁、Q₁ 与工作状态完全不变；变的只是电源少送的那部分无功。

S̃ = S̃₁ + S̃_C　⇒　P = P₁ = UIcosφ，　Q = Q₁ − ωCU²

两式相除：tanφ = tanφ₁ − ωCU²/P，解出电容：

C = P (tanφ₁ − tanφ) / (ω U²)
陈述时刻 ⑤ · 并联电容提高功率因数（正式定义 + 条件）：在感性负载端并联电容，以电容的负无功抵消负载的正无功，使总功率因数由 λ₁ 提到 λ，而负载工作状态不变；所需电容 C=P(tanφ₁−tanφ)/(ωU²)，其中 φ₁=arccosλ₁、φ=arccosλ。条件：① 负载为感性且电容并联（串联会改变负载电压，不是同一回事）；② 只提高 λ、不改变负载 P；③ 工程通常提到 0.9 左右而非 1——过补偿会变容性，且需更大电容、不经济。〔邱 §9-5 例 9-10〕

带做：50 Hz、380 V，感性负载 P=20 kW、λ₁=0.6 提到 λ=0.9。φ₁=53.13°、φ=25.84°、ω≈314.16 rad/s，得 C≈374 μF（书 374.51 μF，tan 取值舍入微差）。电源电流由 I₁=P/(Uλ₁)≈87.7 A 降到 I=P/(Uλ)≈58.5 A——同样送出 20 kW，线路电流小了三分之一，损耗下降、设备利用率上升。

相量图看"电流为什么变小"：以端电压 Ū 为水平参考。感性负载电流 İ₁ 滞后 U；电容电流 İ_C 超前 U 恰好 90°。总线电流 İ = İ₁ + İ_C——电容电流抵消了 İ₁ 的滞后分量，于是合成电流更短、与 U 的夹角更小（λ 提高）。

看图就懂：电容不耗有功，但它提供的这个向上的无功分量让电源不必再从远处送同样多的无功电流。这就是"不耗能也能减小电流"的真相。

自包含示意图：并联补偿相量图。电容电流向上抵消滞后分量。

选②，电流变小。电容虽不耗 P，却提供负 Q；电源不必再往返送这部分无功，于是同样 P 下总电流变小（87.7 A → 58.5 A）。I=P/(Uλ)，λ 提高、电流自然下降。

选③错在哪：把"不耗能"等同于"对电源电流没贡献"。电容不耗有功，但它的无功电流是真实流过电源与线路的——正因为这份电流在负载端就地提供，干路才少了一部分。

5 · 最大功率传输与共轭匹配

另一类"调一调"不是调电源侧的电容，而是调负载自己。通信、信号电路里功率很小、不计效率，只关心负载拿到多少。把 L2-05 的戴维南等效搬来：电源 U_oc、内阻抗 Z_o=R_o+jX_o，负载 Z=R+jX。

P = I² R = U_oc² R / [(R_o+R)² + (X_o+X)²]
  1. 先固定 R 看 X：X 只在分母里，取 X=−X_o 把总电抗消成纯电阻，分母最小。
  2. 再对 R 求极值：此时 P=U_oc²R/(R_o+R)²，令 dP/dR=0 得 R=R_o。
  3. 合并：Z=Z_o*（共轭匹配），最大功率 P_max=U_oc²/(4R_o)（诺顿形式为 Y=Y_o*）。
陈述时刻 ⑥ · 正弦稳态最大功率传输（共轭匹配）（正式定义 + 条件）：当负载 Z=Z_o*（即 R=R_o、X=−X_o）时，负载获得最大有功功率 P_max=U_oc²/(4R_o)（U_oc 为有效值）。条件：给定戴维南电源、R 与 X 可独立调整；此时负载与内阻各分一半电压、效率 50%，只适合小功率信号场景，不适于电力传输；若负载阻抗角固定、仅模可变，只能取次优而非此极值。〔邱 §9-6、李下 §9-7〕

与直流的区别：直流最大功率只有 R=R_o；交流多了一条 X=−X_o，因为电抗不耗能却进分母，必须先抵消掉。

P–R_L 曲线（保持 X_L=−X_o）：只有一个峰，落在 R_L=R_o。左右两侧都下降——想多拿功率，负载电阻既不能太大也不能太小，必须和电源内阻"门当户对"。

默认 U_oc=12 V、Z_o=2+j4 Ω：匹配时 Z_L=2−j4 Ω、P_max=18 W。若只把 R_L 调到 4 Ω 而不消电抗，功率掉到 16 W；若只把 X_L 调到 0 而保留 R_L=2 Ω，掉到 9 W——两个条件缺一不可。

自包含示意图：P–R_L 曲线，峰值在共轭匹配处。

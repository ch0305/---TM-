全课宪法

正弦激励的稳态响应与激励同频，只剩"有效值 U + 初相 ψ"两个未知量。相量就是把这两个数装进一个复数；换到复数域做加减乘除，再换回来。
因果顺序：稳态只剩两数 → 同频运算封闭 → 复数正好装两数 → 欧拉公式做翻译 → 微分变 jω → KCL/KVL 照搬。不是时间安排。

正弦量与相量法基础

上一课看的是"换路后怎么从一种稳态走到另一种稳态"，过渡项 e−t/τ 最终会消失。若接的是正弦电源，留下来的稳态仍是同频正弦波。这节课只解决一个问题：已知几个同频正弦电压/电流——有时给时域表达式、有时给相量图——怎么不被三角函数拖住，像学直流电路那样用 KCL/KVL 加复数代数算出未知的正弦量，并且说清谁超前谁？

两个同频正弦波相加，峰值是不是直接相加？u₁=20cos(ωt−30°)、u₂=40cos(ωt+60°)——它们的峰值分别在不同时刻出现。先猜，后面的推导会给你答案。

先预测 1：u₁+u₂ 是什么？① 60cos(ωt+…)（幅值直接加）；② 幅值约 44.7cos(ωt+…)；③ 不是正弦波了。

1 · 正弦稳态：过渡结束后为什么只剩两个数

上一课 RC 接正弦电源，全响应 = 瞬态项 Ke−t/τ + 稳态正弦项。过 (4~5)τ 瞬态衰减掉，留下来的稳态与激励同频；频率 ω 是已知的，未知的只剩幅度和初相。可书里求这两个量要展开 cos(ωt+ψ) 解待定系数，很繁〔李下 §8-1〕。

陈述时刻 ① · 正弦稳态（全称 + 一句定义 + 符号式，可抄笔记）：线性电路在单一频率正弦激励下，过渡过程结束后所有电压、电流都是与激励同频率的正弦量，它们只在有效值（或振幅）与初相上不同〔邱 §8 导读；李下 §8-1〕。
符号式：x(t)=√2 X cos(ωt+ψx)。

图里两条虚线是衰减的过渡包络，绿色曲线是留下来的稳态正弦。大约 4~5τ 之后包络贴平，波形就是纯正弦了——这正是相量法能上场的地方。

自包含示意图：过渡项衰减，稳态留下一个同频正弦波。
2 · 三要素、相位差与有效值

Im 是波峰；ω=2πf=2π/T 是相位变化的角速度（工频 50 Hz → ω≈314 rad/s）；ψ 是 t=0 时的相位，参考方向一反，ψ 加 180°。同频时相位差 φ=ψ₁−ψ₂ 是与时间无关的常数，φ>0 说"前者超前"〔邱 §8-2；李下 §8-1〕。

有效值不是"峰值打折"的规定，是算出来的：把 i=Imcos(ωt+ψ) 代入均方根定义，用 cos²θ=(1+cos2θ)/2，一个周期内 cos2θ 积分为 0，得 I=Im/√2≈0.707Im。铭牌与交流表读数都是有效值〔邱 §8-2 式(8-2)〕。

陈述时刻 ② · 有效值（均方根值）（全称 + 定义 + 符号式）：周期量的有效值等于瞬时值平方在一个周期内平均值的平方根，即 I=√[(1/T)∫0T i²(t) dt]；对正弦量有 I=Im/√2〔邱 §8-2 式(8-2)〕。
边界：均方根定义对任何周期量成立，Im/√2 只对正弦波成立。

封闭性（换语言的前提）：同频正弦量乘常数、微分、积分、代数和，结果还是同频正弦量〔邱 §8-2〕。所以换到复数域不会把问题变成另一种波形。

先预测 2：u=220√2 sin(314t−20°) V。若用"有效值作模、余弦为基准时的初相"这两个数来记它，该选哪一组？（此时还没学极坐标记号与相量，先只用"模/初相"想。）

先选；第 4 环节才给出相量写法并揭晓。

3 · 为什么能换语言：复数工具

复数的模装有效值，辐角装初相：F=a+jb=|F|(cosφ+j sinφ)=|F|ejφ=|F|∠φ，其中 |F|=√(a²+b²)，φ=atan2(b,a)。若只写 arctan(b/a)，当 a<0 时必须按象限修正 ±180°——例如 −4.33+j2.5 的辐角是 150° 而不是 −30°〔邱 §8-1；李下 §8-3〕。

加减用直角坐标：实部/虚部分别相加减　·　乘除用极坐标：模相乘除、角相加减

先预测 3：复数乘以 j，在复平面上是什么效果？（旋转规则还没讲，先猜。）

作答后，下面的旋转规则与示意图才会出现。

答案是 B。j=1∠90°=ej90°，乘 j 就是模不变、辐角加 90°（逆时针转 90°）；除以 j 等于乘 −j，顺时针转 90°。这就是"旋转因子"〔邱 §8-1〕。

下一环节的 jω 正是同一件事：模乘 ω、角加 90°。先在这里把旋转看熟，后面就不会觉得 jω 突然冒出来。

自包含示意图：乘 j = 模不变、角加 90°。

4 · 欧拉公式做翻译：相量与 jω（揭晓预测 2）

ejωt=cosωt+j sinωt ⇒ cosωt=Re[ejωt] ⇒ u(t)=√2 U cos(ωt+ψ)=Re[√2·U ejψ·ejωt]=Re[√2 Ū ejωt]，其中 Ū=U∠ψ。√2 不能丢：相量的模是有效值，时域振幅是它的 √2 倍。振幅相量 Ūm=Um∠ψ 是另一口径（u(t)=Re[Ūmejωt]），两种口径差 √2，不可混用〔邱 §8-3；李下 §8-4〕。

陈述时刻 ③ · 相量（phasor）（全称 + 定义 + 符号式）：与正弦量 x(t)=√2 X cos(ωt+ψx) 对应的复数是 Ẋ=X∠ψx，其模为有效值、辐角为初相；翻译式为 x(t)=Re[√2 Ẋ ejωt]〔邱 §8-3；李下 §8-4〕。
三条纪律：相量不等于时间函数；相量不含频率 ω，反变换必须补 √2 与 ω；相量运算只在同频正弦量之间成立。

选 B（模 220、初相 −110°）。sin θ=cos(θ−90°)，先统一成余弦：u=220√2 cos(314t−110°) V ⇒ Ū=220∠−110° V。A 把振幅当模又漏了 −90°，C 只漏了 sin→cos 的 −90°。这就是相量写法第一次出场：模放有效值，角放余弦基准下的初相。

dx/dt = d Re[√2 Ẋ ejωt]/dt = Re[√2·jω Ẋ ejωt]，所以微分把相量乘 jω（模乘 ω、角加 90°），积分则除以 jω。微分方程因此真的变成了复代数方程——这就是下一课 ZL=jωL、ZC=1/(jωC) 的直接来源〔邱 §8-3 例8-3〕。

陈述时刻 ④ · 微分/积分的相量对应（符号式 + 条件）：若 x(t) ↔ Ẋ，则 dx/dt ↔ jωẊ，∫x dt ↔ Ẋ/(jω)（积分常数另计）。条件：同频正弦稳态。

5 · KCL/KVL 相量形式与相量图（揭晓预测 1）

时域 KCL Σ ik(t)=0，各支路同频 ⇒ Σ Re[√2 Īkejωt]=Re[√2(ΣĪk)ejωt]=0 ⇒ ΣĪk=0（相量的线性性质）。KVL 同理。参考方向的正负号完全照时域规定，只是加减的数变成复数〔李下 §8-5；邱 §8-4 结论句〕。

陈述时刻 ⑤ · KCL/KVL 的相量形式（全称 + 符号式 + 条件）：正弦稳态下，任一节点同频正弦电流相量的代数和为零 ΣĪ=0；任一回路同频正弦电压相量的代数和为零 ΣŪ=0。条件：全部正弦量同频；正负号按各自参考方向。

带做例题 A（揭晓预测 1，选 B）〔李下 §8-5 例8-4〕：u₁=20cos(ωt−30°)、u₂=40cos(ωt+60°)。有效值相量 Ù₁=14.14∠−30°=12.25−j7.07，Ù₂=28.28∠60°=14.14+j24.50；Ù=26.39+j17.42=31.62∠33.43°；回时域 u=√2×31.62 cos(ωt+33.43°)=44.72cos(ωt+33.43°) V。不是 60：因为两波峰不在同一时刻。

带做例题 B（KCL，节点求第三支路）〔李下 §8-5 例8-5〕：两支路 i₁=10√2 cos(ωt+60°)、i₂=5√2 sin ωt 流入，求流出的 i₃。Ī₁=10∠60°=5+j8.66；i₂ 先化余弦 =5√2 cos(ωt−90°)，Ī₂=5∠−90°=−j5；Ī₃=Ī₁+Ī₂=5+j3.66=6.2∠36.2° A ⇒ i₃=6.2√2 cos(ωt+36.2°) A。

相量图怎么读超前/滞后：把 Ī₁、Ī₂ 当邻边作平行四边形，对角线就是 Ī₃。复平面上逆时针方向为相位超前：从 Ī₂（−90°）转到 Ī₃（36.2°）是逆时针，所以 Ī₃ 超前 Ī₂ 126.2°。同频时相量图静止，夹角在任何时刻不变，不必再画波形图。

自包含示意图：平行四边形对角线 = 相量和。
6 · 独立练习（8 题，覆盖核心难点，非例题近邻复制）

先独立作答再点"看依据"；数值题按顺序填空，概念题选择。每题判定后给出依据提示。

练习 1（sin 化 cos）：u=220√2 sin(314t+120°) V，有效值相量的模 = ____ V，初相 = ____ °。

220 V，30 °。sin(314t+120°)=cos(314t+30°)，模取有效值 220。错因：直接把 120° 当初相，或把振幅 220√2 当模。〔我编的题〕

练习 2（相量回时域）：Ū=100∠−45° V、f=50 Hz，写回时域 u=____√2 cos(____ t−45°) V（填两个数）。

100，314（≈314.16）：u=100√2 cos(314t−45°) V，ω=2πf=314.16 rad/s。错因：漏 √2，或把 50 Hz 直接当 ω（差一个 2π）。〔我编的题〕

练习 3（复数乘除，面板默认值的迁移）：C=3−j4=5∠−53.1°、D=2∠60°。C·D 的模 = ____、辐角 = ____ °；C/D 的模 = ____、辐角 = ____ °。

C·D=10∠6.9°（模 5×2=10、角 −53.1+60=6.9°）；C/D=2.5∠−113.1°（模 5/2=2.5、角 −53.1−60=−113.1°）。错因：把角也做除法，或忘记负象限。〔我编的题〕

练习 4（KVL 相减 + 负角 sin，核心难点）：回路 u₁=u₂+u₃，u₁=10√2 cos(ωt+30°)、u₂=8√2 sin(ωt−45°) V。求 u₃ 的有效值 = ____ V、初相 = ____ °；u₃ 超前 u₂ ____ °。

Ù₁=10∠30°=8.660+j5.000；u₂=8√2 cos(ωt−135°) ⇒ Ù₂=8∠−135°=−5.657−j5.657；Ù₃=Ù₁−Ù₂=14.317+j10.657=17.85∠36.66°。故有效值 17.85 V、初相 36.7 °，u₃=17.85√2 cos(ωt+36.7°)；超前 u₂ 约 171.7 °。错因：u₂ 漏化 cos 的 −90°，或把相减做成相加。〔我编的题〕

练习 5（频率边界）：uₐ=cos ωt、ub=cos 2ωt，能否把二者画进同一相量图做复数相加？

B，不能。频率不同，相位差随时间变，相量图不会静止，二者相加也不是单一正弦量，相量代数失效。错因：只看到"都是余弦"就动手加。〔我编的题〕

练习 6（微分 ↔ jω）：i=2√2 cos(100t+60°) A，di/dt 相量的模 = ____ A/s、辐角 = ____ °。

jωĪ：模 ω·I=100×2=200 A/s，角 60+90=150 °（时域 di/dt=200√2 cos(100t+150°)）。错因：只加 90° 忘了乘 ω，或把 ω 写成 f。〔我编的题〕

练习 7（相量里没有的信息）：相量 Ū=100∠30° V 不含下列哪项？

C。相量只装有效值与初相；ω 是反变换时必须另给的公共参数。错因：以为角频率藏在"∠30°"里。〔我编的题〕

练习 8（读相量图，形态 B）：下图给出同频两相量 Ūₐ=10∠−75° V、Ūb=5∠35° V。不计算，从图上回答：____ 超前 ____，超前 ____ °。
相量图：逆时针为超前。

Ū_b 超前 Ūₐ，110 °：35−(−75)=110°。相量图上逆时针方向为超前，Ū_b 在第一象限、Ūₐ 在第四象限。错因：按模大小判超前（模大不代表超前），或把角度相加。〔我编的题〕

讲什么 / 不讲什么（本课边界）

讲：正弦稳态；三要素、ω=2πf、初相与相位差；有效值均方根定义与正弦特例；同频运算封闭性；复数直角/极坐标与四则、j 是旋转因子、辐角象限修正；欧拉公式与有效值相量、振幅相量差 √2；相量三条纪律；微分 ↔ jω、积分 ↔ 1/(jω)；KCL/KVL 相量形式；相量图读超前滞后；频率不同方法失效。

不讲：元件 VCR 相量形式 ZR=R、ZL=jωL、ZC=1/(jωC) 与阻抗/导纳（L2-05）；用相量模型完整解电路、戴维南推广（L2-06）；正弦稳态功率 P/Q/S（L2-07）；暂态求解细节（L2-03 已学）；傅里叶与非正弦稳态。H&H 未做正文摘录，本课不引用其章节号。

学习目标（学完能独立做什么）
  1. 把同频正弦量在时域与相量之间双向转换（sin 先化 cos、补 √2 与 ω）。
  2. 用复数四则算同频正弦量的和/差/微分，并说清每一步为什么用直角或极坐标。
  3. 用 KCL/KVL 相量形式求未知支路的正弦表达式。
  4. 从相量图判断谁超前谁、超前多少度。
  5. 看到不同频率立即判定相量法不适用。

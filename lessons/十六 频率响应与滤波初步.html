频率响应与滤波初步

L2-07 之前我们都把正弦频率 ω 当成"给定的一个数"。这节课只解决一个问题：如果让频率从低到高连续变化，同一个 RC 电路的输出大小和相位为什么会跟着变？怎样用一个 H(jω) 把这种变化算出来、画成"频率—输出"的关系图，并凭它判断电路是"放行"还是"挡掉"某些频率？

核心问题→ H(jω)→ 低通 |H|/φ→ ω_c 半功率→ 高通对偶→ 分贝/波特图→ 四类滤波/练习
0 · 核心问题与预测 1（先别算，凭直觉选）

场景只有一个：RC 串联电路，输出取在电容 C 两端，输入正弦电压幅度固定不变，只把频率从很低慢慢升到很高。先不翻公式，预测输出幅度怎么变。

先预测 1：输入幅度固定、频率从低升高，电容两端的输出幅度会？① 基本不变；② 越来越小；③ 越来越大。选定后才解锁揭晓。

选定后才解锁第 2 环节的揭晓；现在不公布。若你想答"取决于 R、C"——趋势与具体值无关，R、C 只决定"在哪儿开始降"。

1 · 网络函数 H(jω)（陈述时刻 ①）

用 L2-05 学过的电容阻抗 Z_C=1/(jωC) 看两端：

ω=0 → Z_C→∞（C 开路）→ Ū_o ≈ Ū_i　；　ω→∞ → Z_C→0（C 短路）→ Ū_o ≈ 0

不需要新公式就看见：输入没变，光是频率变了，输出就从"几乎等于输入"掉到"几乎没有"。这才逼出下一个问题——要把这种变化精确算出来，得有一个以 ω 为自变量的函数。

定义网络函数 H(jω) = 响应相量 / 激励相量。本课取同一对端口的电压比 H(jω)=Ū_o/Ū_i（转移电压比）。关键性质：它由电路结构与参数决定，与输入幅值无关；输入同端口时就是阻抗/导纳（驱动点函数），不同端口时是转移函数。

它是复数——模 |H(jω)| 是"输出幅度是输入的几倍"，辐角 φ(ω)=arg H(jω) 是"输出相对输入移了多少相"。

陈述时刻 ① · 网络函数（network function）H(jω) 与幅频 / 相频特性（正式定义 + 条件）：H(jω)=Ū_o/Ū_i（输出相量与输入相量之比），是描述正弦稳态下电路传输特性的复函数；其模 |H(jω)| 与 ω 的关系叫幅频特性，辐角 φ(ω)=arg H(jω) 与 ω 的关系叫相频特性，二者合起来就是电路的频率响应。条件：线性时不变、正弦稳态、输入输出须同为电压（或同为电流）相量；H 与输入幅值无关，只随 ω 变。〔邱 §11-1、李下 §10-2〕

由 H 求响应的配方（李下 §10-2）：Ū_o=H(jω)Ū_i，即 U_o=|H|U_i、ψ_o=φ+ψ_i（有效值相量写时域式时再乘 √2）。

图①：RC 低通电路与它的两条曲线。左图输出取在电容两端；右上 |H| 从 1 缓慢降到 0，右下 φ 从 0° 单调降到 −90°（输出始终滞后输入）。这里先看形状，下一环节才把两条曲线的公式推出来。

图是自包含的：横轴都是 ω 从低到高；不引用书内图号，不必翻书也能看懂。

自包含示意图：RC 低通电路 + 幅频 / 相频形状。
2 · 推出低通 H，带做例 10-3，揭晓预测 1

输出取电容两端，用分压（Z_C=1/(jωC)）：

H_LP = Z_C / (R + Z_C) = (1/jωC) / (R + 1/jωC) = 1 / (1 + jωRC)

令 x = ω/ω_c、ω_c = 1/RC，则 ωRC = x，于是

H_LP = 1/(1+jx) = [1/√(1+x²)] ∠ [−arctan x]
|H| = 1/√(1+x²)　，　φ = −arctan x

陈述时刻 ① 的符号式在此落地：|H| 随 x 单调下降，φ 从 0° 趋向 −90°——正是图①的形状。这两个公式是推出来的，不是背的。

τ=RC=10⁻³ s ⇒ ω_c=1/τ=1000 rad/s。输入 u_i=2.5√2cos(500πt+30°) V，ω=500π≈1571 rad/s，x=1.571。

|H| = 1/√(1+1.571²) ≈ 0.537（书取 0.54）　；　φ = −arctan 1.571 ≈ −57.5°（书取 −57°）
U_o = |H|U_i ≈ 0.537 × 2.5 ≈ 1.34 V（书 1.35 V）　；　ψ_o = φ + ψ_i ≈ 30° − 57.5° ≈ −27.5°（书 −27°）
u_o ≈ 1.35√2 cos(500πt − 27°) V

小数口径：书的 0.54/−57°/1.35/−27° 是"由图或式得"的读数与截断（30−57=−27），精确值 0.537/−57.5°/1.34/−27.5° 与它在图示读数精度内一致；不要把 57.5° 先四舍五入成 58° 再相减（那会得到 −28°）。〔李下 §10-3〕

选②，越来越小。|H|=1/√(1+x²) 随 x 单调下降：ω=0 时输出最大且等于输入，ω→∞ 时输出→0——低频易通过、高频被抑制，这就是 RC 低通（滞后网络）。

选③错在把它和高通搞反了：输出取在电容端才是低通；若改从电阻端取，才是频率越高输出越大（第 4 环节）。

3 · 截止频率与半功率点（揭晓预测 2）

从公式读三个点：x=0 → |H|=1；x=1 → |H|=1/√2≈0.707；x→∞ → |H|→0。x=1（即 ω=ω_c）正是幅频从"近乎 1"转入"明显下降"的分界点；相频在 x=1 处 φ=−45°，并随 x 从 0 到 ∞ 单调从 0° 趋向 −90°。

那么"半功率点"到底指什么减半？先别看答案——功率 ∝ 电压平方这件事第 3 环节刚用过。

先预测 2：已知 ω=ω_c 处输出幅度已降到 1/√2≈0.707。那么输出功率降到输入的多少？① 1/2；② 1/√2；③ 1/4。选项中不含答案注解，选定后才揭晓。

选定后解锁下面的定义与揭晓；现在不公布。

陈述时刻 ② · 截止频率（cut-off frequency）ω_c 与半功率点（正式定义 + 条件）：ω_c=1/RC=1/τ，是低通电路幅频降到 |H|=1/√2≈0.707（相移 −45°）处的频率；因平均功率 ∝ 电压有效值平方，P_o/P_i=|H|²=1/2，故又称半功率点；0~ω_c 定为通频带（通带）。条件：一阶 RC 低通；对高通 ω_c 同式、|H(ω_c)| 仍 0.707（高通的相移留到第 4 环节预测 3 揭晓后再给出，此处不预告）；τ=RC 正是 L2-03 一阶暂态时间常数，ω_c=1/τ 是它在频域的倒数。〔李下 §10-3〕

揭晓：选①，功率降到 1/2。因为功率 ∝ 电压²，P_o/P_i=|H|²=(1/√2)²=1/2——"半功率点"由此得名，指的是功率减半而不是幅度减半。

选②错在把功率当成幅度（1/√2 是幅度比）；选③错在以为幅度先降到 1/2 再平方（实际幅度是 1/√2）。

4 · 高通对偶（揭晓预测 3）

先预测 3：低通在 ω=ω_c 相移是 −45°；若把输出改从电阻 R 取（C 串在信号通路里）构成高通，同一频率 ω_c 下输出相位是？① −45°；② 0°；③ +45°。选定后才揭晓相移推导。

先推幅值（不含相位结论）；选定后才解锁揭晓块里的相移推导。

输出取 R 上，仍用分压：

H_HP = R / (R + 1/jωC) = jωRC / (1 + jωRC) = jx / (1 + jx)

这一步只取模：|H_HP| = x/√(1+x²)。极端值 x=0 → |H|=0；x→∞ → |H|→1；x=1 → |H|=0.707——与低通共用同一个 ω_c、同一条 0.707，幅频互补。相移留到揭晓块里再算。

图②：低通 / 高通幅频对比。一条递减、一条递增，在 x=1 处相交于 |H|=0.707——这就是"共用同一个截止频率"的几何图像。

幅值互补已经看得见；相位是否也"互补"，正是预测 3 要盲测的内容。

自包含示意图：低通（黄）与高通（蓝）幅频互补，交于截止点。

相移推导（+45° 在此首次出现）：H_HP=jx/(1+jx) 的分子 jx 相角是 90°、分母 1+jx 相角是 arctan x，故

φ = 90° − arctan x　→　x=1 时 φ = 90° − 45° = +45°

x→0 时 φ→+90°，x→∞ 时 φ→0°。低通 φ=−arctan x、高通 φ=90°−arctan x，在 x=1 分别是 −45°、+45°——相位也互补。

陈述时刻 ③ · RC 高通电路（超前网络）（正式定义 + 条件）：输出取在电阻端的一阶 RC 电路，H_HP=jωRC/(1+jωRC)，|H|=x/√(1+x²)、φ=90°−arctan x，ω_c=1/RC 处 |H|=0.707、φ=+45°；高频易通过、低频被抑制，输出超前输入，故又称超前网络。条件：一阶 RC、输出取 R；与低通共用同一个 ω_c，幅频互补、相移一负一正。〔李下 §10-3〕

揭晓：选③。+45°。选①错在以为换输出端不影响相位；选②错在忽略电容引入的 90° 相移。

频响计算台 A 的"RC 高通"标签已解锁，可用默认参数核对 0.707 / +45° / 3.54 V。

5 · 分贝与一阶波特图（揭晓预测 4）

直接画 |H|−ω，ω 从 1 到 10⁵ rad/s 时低频段全挤在左端。工程上换尺子（邱 §11-5）：横轴用对数频率 lg ω（每十倍频等距），纵轴用分贝 L(ω)=20lg|H|。|H|=1 → 0 dB；|H|=0.707 → −3 dB（因为 20lg 0.707≈−3）；ω_c 正是 −3 dB 点。

为什么是 20 而不是 10（可见地推一遍）：第 3 环节已建立 P∝U²，即功率比 P_o/P_i=|H|²。分贝的定义本来针对功率比取 10lg，于是

L = 10lg(P_o/P_i) = 10lg(|H|²) = 20lg|H|

系数 20 来自"电压平方就是功率比"，不是要背的新规则。

先预测 4：一阶低通在 ω>ω_c 之后，幅度按每十倍频程下降多少 dB？① −20 dB/dec；② −3 dB/dec；③ −40 dB/dec。选定后才解锁斜率推导与揭晓。

斜率规则就在下一个揭晓块里；先选再翻。

一阶折线推导：H_LP=1/(1+jx)。x≪1 时 |H|≈1 → L≈0 dB（水平线）；x≫1 时 |H|≈1/x → L≈−20lg x，即每十倍频降 20 dB（−20 dB/dec）。两段在 x=1 相交，真值 −3 dB 比折点低 3 dB（折线是近似）。相频在 0.1ω_c~10ω_c 之间近似以 −45°/dec 从 0° 过渡到 −90°。

陈述时刻 ④ · 分贝与一阶波特图渐近线（正式定义 + 条件）：幅频波特图纵轴 L(ω)=20lg|H(jω)|（单位 dB），横轴为对数频率 lg ω；一阶因子 1/(1+jω/ω_c) 的幅频渐近线在 ω<ω_c 为 0 dB、ω>ω_c 为 −20 dB/dec，折点 ω_c 处真值 −3 dB；相频渐近线在 0.1ω_c~10ω_c 以 −45°/dec 过渡。条件：一阶因子；20lg 用于幅值比、源于 10lg(P_o/P_i)=10lg|H|²=20lg|H|（功率比本身用 10lg）；渐近线是近似，折点附近须用真值修正。〔邱 §11-5〕

揭晓：选①，−20 dB/dec。原因：x≫1 时 |H|≈1/x，20lg(1/x)=−20lg x，x 每乘 10 就降 20 dB。选②把折点的 −3 dB 误当斜率；选③是二阶因子的斜率（本课不讲，L2-09 后再说）。

6 · 滤波器四类、独立练习与过关

能"按频率筛选"的网络叫滤波器：希望保留的频段是通带、希望抑制的是阻带。物理根据是 L 与 C 互补——Z_L=jωL 随 ω 增大，Z_C=1/(jωC) 随 ω 减小，搭配起来就能选频。

陈述时刻 ⑤ · 滤波器（filter）与四种类型（正式定义 + 条件）：滤波器是具有选频功能的网络，使通带内的频率分量顺利通过、阻带内被抑制；按通带位置分为低通、高通、带通、带阻四类。条件：本课只定量处理一阶 RC 低通 / 高通；带通 / 带阻要等 L2-09 讲了谐振才能理解其"附近"的含义；工程上 LC 无源滤波体积大，实际常用运放构成 RC 有源滤波器实现集成（邱 §11-6，设计细节不讲）。

图④：四类滤波器的通带位置。横轴是频率从低到高（对数轴），绿色=通带、暗色=阻带。一类只改"绿带放在哪儿"：

  • 低通：0~ω_c 通过（本课已定量）；
  • 高通：ω_c~∞ 通过（本课已定量）；
  • 带通：只过谐振点附近（L2-09 后再量化）；
  • 带阻：只挡谐振点附近。
自包含示意图：四类滤波器只改变通带的位置。

下一课钩子：一阶 RC 的选频是"平缓的"——幅频从 0 dB 慢慢拐下去。若把 L 和 C 一起放进来，会在某一个特定频率出现阻抗抵消、响应冲出尖峰（或陷谷），"平缓选择"升级为"尖锐选频"。下一课讲谐振入门与二阶直觉。

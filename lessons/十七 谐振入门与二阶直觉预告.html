全课宪法

上一课让频率连续变化，看到一阶 RC 的输出平缓下降。本课把 L 和 C 放一起，问：为什么偏偏某一个频率让电路突然像纯电阻、电流或电压冲到极大？

三条纪律（违反就错）

① 谐振的共同判据是端口电压电流同相；串联表现为电抗为零、并联表现为电纳为零，不是"L、C 电压为零"。

谐振入门与二阶直觉预告

L2-08 让频率连续变化，看到一阶 RC 的输出平缓下降。这节课只解决一个问题：把 L 和 C 放进同一个电路，为什么偏偏在某一个特定频率上，电路突然表现得像一个纯电阻、电流或电压冲到极大？这个频率由什么决定，冲得多高、多"尖"又由什么决定？

核心问题→ ω₀ 过零→ 串联四特征/Q→ 并联对偶→ 带宽/选择性→ 稳态 vs 暂态→ 练习/过关
0 · 核心问题与预测 1（先别算，凭直觉选）

场景只有一个：RLC 串联电路接在频率可调的正弦电压源上，R、L、C 固定，只把频率从很低慢慢升到很高。先用 L2-05 学过的 Z_L=jωL、Z_C=1/(jωC) 预判总电抗怎么变——先不写出任何谐振频率公式。

先预测 1：总电抗 X=ωL−1/ωC 随 ω 从低到高会怎样？① 一直增大；② 一直减小；③ 先为负、中间过零、再为正。选定后才解锁揭晓。

若你想答"看 L、C 谁大"——肯定这个直觉：低频时 1/ωC 占优、高频时 ωL 占优。追问一句：从低到高连续变化时，中间那一点一定存在吗？选定后才解锁揭晓，现在不公布。

1 · 谐振条件与 ω₀（陈述时刻 ① · 揭晓预测 1）

用学过的两个阻抗看两端：

ω 很低 → 1/(ωC) 占优 → X ≈ −1/(ωC) < 0（容性）　；　ω 很高 → ωL 占优 → X ≈ ωL > 0（感性）

X(ω) 连续，从负到正必然过零。不需要任何新公式就能预判：存在唯一一点让感抗与容抗完全抵消。这才逼出"那个特定频率"的问题。

选③。写出输入阻抗 Z(jω)=R+j(ωL−1/ωC)（邱 §11-2、李下 §10-6），令电抗为零：

X(jω₀)=ω₀L − 1/(ω₀C)=0 ⇒ ω₀²=1/(LC) ⇒ ω₀=1/√(LC)，f₀=1/(2π√(LC))

选①错在只看高频段，选②错在只看低频段。关键点：ω₀ 只由 L、C 决定，与 R 无关——R 管谐振峰有多高、多尖，不管峰在哪。

陈述时刻 ① · 谐振（resonance）与谐振频率 ω₀（正式定义 + 条件）：端口电压与电流同相的工作状态称为谐振；串联时表现为总电抗为零，并联时表现为总电纳为零（环节 3 才展开，此处只记住"电压电流同相"这一共同判据）。发生谐振的角频率 ω₀=1/√(LC)、频率 f₀=1/(2π√(LC))，只由 L、C 决定，与 R 无关，故又称电路的固有频率。条件：理想串联 RLC、线性元件、正弦稳态，外施频率须与 ω₀ 相同（"合拍"）。实际电感线圈带损耗电阻时，并联谐振频率会偏移（ω₀=√(1/LC−R²/L²)，邱 §11-4 点名不推导）、"端电压最大"判据也不再严格成立——本课一律按理想元件计算。〔邱 §11-2、李下 §10-6〕

图①：串联 RLC 与电抗过零。左为电路；右为 X(jω)=ωL−1/ωC 随频率的走向——低频在容性区（负），高频在感性区（正），虚线标出的过零点就是 ω₀。图自包含，不引用书内图号。

过零处 X=0、Z=R，电路"像纯电阻"——谐振。
2 · 串联谐振四特征与 Q（陈述时刻 ② · 揭晓预测 2）

把 X=0 代进去，四条特征逐条落下来（邱 §11-2、李下 §10-6）：

#特征为什么
①电压电流同相φ=arg Z=0
②Z(jω₀)=R 是 |Z| 极小 → 电流极大|Z|=√[R²+X²] 在 X=0 取最小，I_max=U/R
③U_L+U_C=0、L、C 串联端相当于短路ω₀L=1/(ω₀C)，两个电抗电压等大反相、各自不为零
④无功 Q_L+Q_C=0能量在 L、C 间往复交换；故串联谐振又称电压谐振

第③条最反直觉：总和为零不等于各自为零。那各自有多大？先预测。

先预测 2：取 R=2 Ω、L=25 mH、C=10 µF、U_s=10 V、ω=2000 rad/s（正好是 ω₀）。电感电压 U_L 相对外施 U_s=10 V 会？① 等于 10 V；② 小于 10 V（被电阻分走）；③ 远大于 10 V（可达很多倍）。选定后才解锁揭晓，选项不含放大倍数的数值。

别用电阻分压的直觉套电抗电压：L、C 上的电压与电流差 90°，不是简单按 R 分。

选③。现场复算（李下例 10-10）：

X_L = ω₀L = 2000 × 0.025 = 50 Ω　；　X_C = 1/(2000 × 10×10⁻⁶) = 50 Ω　→ 相消
Z = 2∠0° Ω　；　İ = U_s/R = 10/2 = 5∠0° A
U̇_L = İ(j50) = j250 V　；　U̇_C = İ(−j50) = −j250 V　→　u_L=250√2cos(2000t+90°) V，u_C=250√2cos(2000t−90°) V

比值 U_L/U_s=250/10=25。选①错在把"总和为零"当成"各自为零"；选②错在用电阻分压直觉。

Q ≡ ω₀L/R = 1/(ω₀CR) = U_L/U_s = U_C/U_s　⇒　U_L = U_C = Q·U_s
陈述时刻 ② · 串联谐振、品质因数 Q 与电压谐振（正式定义 + 条件）：RLC 串联谐振时 Z=R 最小、I=U/R 最大，U_L 与 U_C 等大反相而抵消、但各自可达外施电压的 Q 倍，故又名电压谐振；品质因数 Q=ω₀L/R=1/(ω₀CR)，是谐振时 L（或 C）电压与外施电压之比，刻画电压放大与峰的尖锐程度。条件：正弦稳态、ω=ω₀、理想元件；Q>1 才过电压（电力防患、无线电利用）。此 Q 无量纲，是品质因数，不是 L2-07 的无功功率 Q（var）；字母相同、含义不同，不可混用。〔邱 §11-2、李下 §10-6〕

图②：串联谐振的电压相量。U_L 向上、U_C 向下，各 250 V、正好抵消；只剩同相的 U_R=U_s=10 V。这就是"局部高压不违反能量守恒"的相量图像：L、C 储能此消彼长，电源只补 R 的损耗。

相量长度不按比例（否则 10 V 会缩成一点），数值以标注为准；图自包含。

3 · 并联对偶（陈述时刻 ③ · 揭晓预测 3）

先预测 3：把电路改成 GLC 并联、用正弦电流源驱动，频率调到环节 1 求出的那个谐振频率 ω₀。端口阻抗 |Z| 与串联情况相比会？① 和串联一样是最小；② 反而变成最大；③ 始终不变。选定后才解锁，作答阶段不出现任何并联导纳公式。

选②。把串联阻抗式逐项对偶（R↔G、L↔C、jωL−1/(jωC)↔jωC−1/(jωL)）就得到并联导纳，不是新公式：

Y(jω)=G+j(ωC − 1/(ωL))　；　谐振条件 ωC−1/(ωL)=0 ⇒ ω₀=1/√(LC)

Y(jω₀)=G 最小 ⇒ Z(jω₀)=1/G=R 最大 ⇒ 电流源驱动时端电压最大。选①错在把串联照搬。

支路电流 I_L=U/(ω₀L)=I_s/(ω₀LG)、I_C=Uω₀C=I_s(ω₀C/G)，用 ω₀²=1/(LC) 得 1/(ω₀LG)=ω₀C/G，二者等大反相而抵消、可远大于外施电流：电流谐振。

Q_并 = ω₀C/G = 1/(ω₀LG)　；　I_L = I_C = Q·I_s
陈述时刻 ③ · 并联谐振与电流谐振（正式定义 + 条件）：理想 GLC 并联电路在 ω₀=1/√(LC) 处电纳虚部为零、Y=G、Z=R 最大；L、C 支路电流等大反相而抵消、各自可达外施电流的 Q_并=ω₀C/G 倍，故又名电流谐振。条件：正弦稳态、ω=ω₀、理想元件（电感无损耗）；与串联共用同一个 ω₀，但"极大"落在阻抗而非电流上，低频/高频性质与串联相反；Q 仍不是无功功率。实际线圈并联见陈述①的条件说明，本课不计算。〔邱 §11-4、李下 §10-6〕

图③：串 / 并联对偶对照。同一个 ω₀=1/√(LC)，但"极大"落点正好相反：串联是阻抗最小 → 电流极大 → 电压谐振；并联是阻抗最大 → 端电压极大 → 电流谐振。低频/高频性质也相反（串联：低容高感；并联：低感高容），因为串联看电抗 ωL−1/ωC、并联看电纳 ωC−1/ωL。

4 · 选择性与带宽（陈述时刻 ④ · 揭晓预测 4）

Q 不只管"冲多高"，还管"峰多尖"。沿用 L2-08 的半功率尺子：谐振曲线上电流降到 I_r/√2（功率减半、−3 dB）的两个频率记为 ω₁、ω₂，二者之差就是通频带 BW。Q 大的曲线更尖、带外抑制更强，但通频带更窄、带内信号易失真——这是工程权衡（邱 §11-3）。先不写出 BW 公式。

先预测 4：保持 ω₀ 不变，把品质因数 Q 调大（比如减小串联电阻 R），通频带 BW 会？① 变宽；② 变窄；③ 不变。选定后才解锁揭晓。

选②。从已学过的电流式推起（李下 §10-6）：I=U/√[R²+(ωL−1/ωC)²]、I_r=U/R。令 I=I_r/√2 ⇔ |Z|=√2 R ⇔ ωL−1/ωC=±R，解得：

ω₁ = −R/(2L)+√[(R/(2L))²+1/(LC)]　；　ω₂ = +R/(2L)+√[(R/(2L))²+1/(LC)]

两式相减 BW=ω₂−ω₁=R/L；相乘 ω₁ω₂=1/(LC)=ω₀² ⇒ ω₀=√(ω₁ω₂)。于是

Q = ω₀L/R = ω₀/(R/L) = ω₀/BW　⇒　BW = ω₂−ω₁ = R/L = ω₀/Q（f 域：BW_f=f₀/Q）

选②：Q 越大 → BW 越窄，与"选择性越强"是同一件事的两面；选①记反了，选③忽略了半功率点随 Q 移动。

画选择性曲线时才首次引入相对频率 η=ω/ω₀（邱 §11-3 归一化坐标）：把上式除以 I_r，用 ω₀L=1/(ω₀C) 改写 (ωL−1/ωC)/R=(ω₀L/R)(η−1/η)=Q(η−1/η)，得

I/I_r = 1/√[1 + Q²(η−1/η)²]

η=1 时取 1（峰），I/I_r=1/√2 正是两个半功率点。这只是已推电流式的改写，不是要背的新公式。

陈述时刻 ④ · 品质因数 Q、通频带 BW 与选择性（正式定义 + 条件）：BW=ω₂−ω₁=R/L=ω₀/Q（串联），半功率点满足 I=I_r/√2（−3 dB），且 ω₀=√(ω₁ω₂)；Q 越大曲线越尖、选择性越强、通频带越窄，Q 越小带宽越宽、带内失真越小。条件：RLC 串联谐振、半功率定义；并联由对偶得 BW=G/C=ω₀/Q（电导 G 越小 → Q 越大 → BW 越窄）。Q 越大 BW 越窄是推出来的核心关系，不是死记。〔邱 §11-3、李下 §10-6〕

带做（形态 B，李下例 10-12）：f₀=10 kHz、BW_f=100 Hz、总 R=25 Ω ⇒ Q=f₀/BW_f=100、ω₀=2π×10⁴≈62832 rad/s、L=QR/ω₀≈39.8 mH、C=1/(ω₀²L)≈6360 pF、f₁,₂≈f₀(1∓1/(2Q))=9950/10050 Hz。下面的面板 B 就是这条设计链。

5 · 稳态谐振 vs 暂态振铃（陈述时刻 ⑤）

邱 §11-4 末段专门提醒：稳态谐振的过压/过流，与换路后动态电路的过冲机理完全不同。并排看：

稳态谐振过压/过流暂态振铃过冲
起因外施正弦源频率调到 ω₀，L、C 反复交换能量t=0 换路，储能重新分配的自由响应
是否持续参数与激励频率不变就一直存在随时间衰减，最终到新稳态
用什么工具相量 / 阻抗 / Q（本课）二阶微分方程、阻尼分类（L3-03）
陈述时刻 ⑤ · 稳态谐振与暂态振铃的区别（正式定义 + 条件）：正弦稳态谐振是与外施频率"合拍"后由外部持续供能的强迫响应，过压/过流在参数不变时持续存在；暂态振铃是换路瞬间 L、C 储能重新分配的自由响应，随时间衰减。条件：前者只在 ω=ω₀ 的正弦稳态下讨论，后者属二阶暂态（L3-03 主课）。本课的 Q 只用于前者，不能套到暂态振铃。〔邱 §11-4〕

下一课 L2-10 把时域暂态工具与正弦稳态工具放在一起，问"给定问题该用哪一套"；L3-03 再定量讲二阶阶跃响应形态（振铃、过冲、稳定时间）。本课先把两条线分开。

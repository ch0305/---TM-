## 一、这节课要解决的核心问题

> **一个节点上汇了三条支路，一个回路里串着两个电阻。为什么我随手把电流箭头、电压极性和绕行方向一标，写下的 `Σi = 0` 和 `Σu = 0` 就自己成立？如果这些方向是别人标好贴在题上的，我又该照着它怎么列方程？**

> 【开场先把记号点名，别让学生带着问号听课】`Σ` 是希腊字母 sigma，读作“连加”——`Σi = 0` 就是“把接到这个节点上的电流全加起来等于零”的缩写，`Σu = 0` 同理；“**绕行方向**”就是你沿回路走一圈的方向。**现在只要在黑板上认得这三个记号，不要求会用**；环节 2、3 会现场讲清它们怎么用。

整节课回答这一个问题，覆盖两种任务形态：**自己指定参考方向去列方程** / **读别人已标好的参考方向去列方程**。走出教室时学生应能：

1. 认出支路、节点、回路；知道用理想导线连在一起的点算**同一个节点**；
2. 说出 KCL 来自电荷守恒（节点不积累电荷）、KVL 来自电压的路径无关性（电位单值）——**不是背规则**；更深一层，两者分别是电荷守恒、能量守恒的运用（放页尾）；
3. 能在推导后**明确说出并写出**两条定律：**基尔霍夫电流定律（KCL）**——在集总电路中，任一时刻，对任一节点，所有支路电流的代数和恒等于零（`Σi=0`）；**基尔霍夫电压定律（KVL）**——在集总电路中，任一时刻，沿任一回路，所有支路电压的代数和恒等于零（`Σu=0`）；
4. 解释“为什么任意参考方向下方程仍成立”：项前的 ± 由参考方向决定，物理约束对实际方向成立；**翻电流箭头、翻电压极性、翻绕行方向**都只改符号，方程等价；能按给定参考方向列 KCL（含把一小块电路当“大节点”）和 KVL，并区分**项前符号**与**数值符号**；KCL 统一采用“流出为正”，并知道“流进为正”完全等效；
5. 说出适用前提：集总假设；并知道两定律与元件性质无关，所以电阻、二极管都照用。

## 二、讲什么 / 不讲什么

**讲**：支路/节点/回路的识别；VCR 与拓扑约束的分工；KCL 从电荷守恒推出、KVL 从“电位单值 → 电压与路径无关”推出（因果链可见，只用第一课的电位差概念）；两套约定与其等效性；两套符号；绕行方向任意性；广义节点一句；两定律与元件性质无关；集总假设的边界；KCL + KVL + VCR 的最小合用。

**不讲**（今天故意留白）：

- 受控源、含受控源电路的严格处理（**L1-06**）：邱 §1-7 p.21 今天不摘、不提公式；例题里出现源也只当“已知电压的元件”。
- KCL/KVL 的独立方程数、`n−1`、网孔数、节点法与网孔法（**L1-06**）：李 §1-9 p.45–46 今天只取“拓扑约束 vs 元件约束”这一层，**不讲独立方程数**；网孔只在板书上认个名字。
- 功率、能量与额定值（**L1-03**）。**主线完全不出现功率记号**：KVL 直接由“两点间电压与路径无关”推出，只借第一课的电位差概念。教材里从能量守恒（Σ*w*=0 → Σ*p*=0 → 按电流分组 → Σ*u*=0）推出 KVL 的完整推导，移到页尾折叠区；那里才第一次交代 *p* 是功率（元件吸收能量的快慢，算法是 *p*=*ui*），**不要求掌握，也不进练习**。
- 串并联、分压分流（**L1-04**）；电源等效（**L1-05**）。
- 分布参数电路的严格理论（**S13**）：今天只给 100 MHz/1 m 这个边界反例，不展开。
- 图论术语（有向图、树、割集）：P3，不引入新词增加负担。
- 理想源的最小引入：只说“电压源两端电压就是给定的 `U_S`，电流由外电路决定”〔邱 p.19〕，**不展开伏安特性、开路短路、电流源**。

## 三、概念依赖链（决定讲解顺序，不决定页面分节）

```
第一课：一个电阻，u=Ri 靠参考方向定正负；u_AB = V_A − V_B 是两点间电位差
   ↓ 但元件接在一起后，VCR 只管元件自己，管不了“在节点碰头”
邱 p.10/p.22：变量受两类约束 —— 元件约束(VCR) + 连接带来的几何/拓扑约束
   ↓ 要说清“连接”，先得会认连接
邱 p.22 / 李 p.12：支路 → 节点（理想导线相连 = 同一节点）→ 回路
   ↓ 在一个节点上，物理事实是什么？
电荷守恒 + 节点不可能积累电荷（李 p.13）⇒ dq/dt=0 ⇒ Σi=0  ← KCL
   ↓ 预测 1：翻一支路箭头，方程还成立吗？⇒ 项前符号跟着翻，物理不变 ⇒ 成立
李 p.13 的“流进为正”与邱 p.23 的“流出为正”乘 −1 互转 ⇒ 等效，本课统一“流出为正”
   ↓ 在一个回路上，物理事实是什么？
电位单值 → 两点间电压与路径无关（邱 p.24）⇒ 绕一圈回原点，电位净变化为 0 ⇒ Σu=0  ← KVL
   （更深的根子是能量守恒：李 p.15–17 的完整推导只放页尾，主线不借功率）
   ↓ 预测 2：绕行方向反过来 / 翻一个电压极性，矛盾吗？⇒ 整体变号或成对变号，等价 ⇒ 不矛盾
两套符号：项前 ±（参考方向决定） vs 数值 ±（解出来才知道）
   ↓ 那“随手标就成立”的底气到底在哪？
邱 p.24 / 李 p.45–46：两定律只与连接方式有关，与元件性质无关（拓扑约束）
   ↓ 什么时候不成立？
李 p.4–5：集总假设是前提（100 MHz / 1 m 反例）
   ↓ 下一课的钩子
电流电压都定下来了 → 谁供能、谁耗能、元件扛不扛得住 → L1-03 功率
```

**关键**：每一步都是因为**上一步不够用了**才引入，不是因为大纲里有这个词。

## 四、教学主线（逐环节脚本）

### 环节 0｜开场：两个“凭什么”（4′）

板书核心问题，画一个小电路（节点 O 汇三条支路；下方另一个回路里两个电阻串在一个源上），**先不标任何电流箭头、电压极性、绕行方向**。按 §一说明在黑板角落认一下 `Σ` 的读法和“绕行方向”的字面意思，随即问学生：

> “如果我现在随手在这三条支路上各画一个电流箭头，写下‘流入 = 流出’——我凭什么相信它成立？”
> “如果我再随手把回路的绕行方向一指，写下‘两个电阻的电压降加起来等于电源电压’——又凭什么？”
> “如果这些箭头和方向是别人画好贴在题上的，我又该怎么照着读？”

**教师动作**：不给答案，也不说“这是基尔霍夫定律”。把问题留在黑板上，说“今天就把这两个‘凭什么’找出来”。

〔邱 p.10 的引入逻辑：VCR 只管元件自己，元件的相互连接带来另一类约束。这里用问题复现了这一步。〕

### 环节 1｜先认清“连在哪里”：支路、节点、回路（6′）

〔邱 p.22〕先说为什么需要新概念：

> “第一课我们只盯着一个电阻。现在元件接在一起了，每个元件自己的 `u=Ri` 还是对的，但它管不了‘三条支路在同一个点上碰头’这件事。书上说，变量受到两类约束：一类来自元件特性——就是第一课那个 `u=Ri`，书里叫 **VCR**（电压电流关系）；另一类来自元件的相互连接，叫几何约束或**拓扑约束**，‘拓扑’就是连接关系的意思。”

板书两行：**VCR → 管元件自己**；**KCL / KVL → 管连接方式**。

〔李 p.12〕给定义，并当场拆掉最常见的坑：

> “把每一个二端元件看作一条**支路**；支路的连接点叫**节点**。注意：图里 a 点和 b 点用理想导线连着，从电的角度看它们是**同一个端点**，只能算一个节点——初学者最容易把它们数成两个。”
> “由支路构成的闭合路径叫**回路**。”

补两句〔通识〕：手算时也常把几个串联元件合并成一条支路；支路怎么划是人为的，但一旦划好，节点和回路就跟着定了。今天只要**会认**，不要求数回路个数。

〔李 p.12〕网孔只在板书角落写个名字：“回路内部不包别的回路叫网孔，今天不数，L1-06 再拿它列方程。”

**即时识别**（口头，不写答案）：给一幅图，问“这儿有几条支路、几个节点？a 和 b 是一个节点还是两个？”

> 【铺垫】顺手交代一句：“我们这门课讨论的是**集总电路**——先记住这个名字，收尾时讲它成立的前提。”不要在这里展开波长。

QA 锚点：`QA:stage-1` 可挂“为什么 a、b 用导线连着就算一个点”。

### 环节 2｜KCL：为什么“流入 = 流出”不是口诀（12′）

**先预测 1**（此时学生还不知道 KCL 的代数表述，只知道第一课的“正负反映实际方向”）：

> 板书：节点 O 汇三条支路。**本课统一约定“流出为正”**——它就是大家熟悉的“流入 = 流出”，两者的等效性推导完就讲。三条支路的参考箭头：①号朝内、②号朝外、③号朝外。实际电流是①号 3 A 流入、②号 1 A 流出、③号 2 A 流出，都和各自箭头同向，所以 *i*₁ = +3 A、*i*₂ = +1 A、*i*₃ = +2 A；按流出为正在黑板上写出 −*i*₁ + *i*₂ + *i*₃ = −3 + 1 + 2 = 0。
> 现在把③号的参考箭头改成朝内（其他都不动），我照旧按流出为正写 Σ*i* = 0，方程还成立吗？
> 先猜“成立 / 不成立”，说理由，**先别算**。

收集答案，**不评判**。

**再推导**（〔李 p.12–13〕，因果链要可见）：

> 电荷守恒：电荷既不能创造也不能消灭。而节点只是理想导体的汇合点，**不可能积累电荷**，所以电荷随时间的变化率 d*q*/d*t* = 0。流进节点电荷的速率，就是各支路电流按参考方向带符号相加：d*q*/d*t* = *i*₁ + *i*₂ − *i*₃。于是 *i*₁ + *i*₂ − *i*₃ = 0。

板书三步：**电荷守恒 → 节点不积累电荷 → Σ*i* = 0**。

**陈述时刻（推导后立刻命名）**〔邱 p.22–23〕：

> “这就是**基尔霍夫电流定律（Kirchhoff's Current Law，KCL）**：在集总电路中，任何时刻，对任一节点，所有支路电流的代数和恒等于零。记作 Σ*i* = 0。”

> 【铺垫】回扣开场：`Σ` 就是刚才认过的“连加”，这里第一次正式用它；d*q*/d*t* 是“节点上电荷的多少随时间变化的快慢；今天只要知道它等于 0 就行。”

〔邱 p.23〕给符号规则：

> “若流出节点的电流前面取 ‘+’ 号，则流入节点的电流前面取 ‘−’ 号；电流是流出节点还是流入节点，**均根据电流的参考方向判断**。”

**两套约定，完全等效**（这是本环节的第二个关键点，必须当场讲破）：

> “注意：李瀚荪 p.13 刚才是按‘**流进为正**’推出 *i*₁ + *i*₂ − *i*₃ = 0；邱关源 p.23 这里是按‘**流出为正**’写 Σ*i* = 0。把其中一式两边乘 −1 就得到另一式——书上的原话：‘以上两种说法是等效的。’〔李 p.13〕李 p.15 还专门验算过：改用流入为正，结果完全一样。**本课接下来统一用‘流出为正’**；你若用‘流进为正’做题也完全正确，只要从头到尾别混。‘流入 = 流出’不是第三套约定，它就是 Σ*i* = 0 的口语说法。”

强调〔通识〕：这里的 ± 是**项前符号**，由参考方向决定；不是电流本身的正负。

**此刻公布预测 1**（推导之后才揭晓）：

> 成立。③号箭头改朝内后，同一个“2 A 流出”的物理事实，代数值从 *i*₃ = +2 A 变成 *i*₃′ = −2 A；方程里那一项也从“+*i*₃”（箭头朝外）改写成“−*i*₃′”（箭头朝内），而 −(−2) = +2，和原来一模一样。变的只是两套标记（项前符号、数值符号），物理没变，方程仍成立。

**即时检查**（〔我编的题〕，口头，配自包含节点示意图，不引用书内图号）：按本课统一的“流出为正”，节点 O 接三条支路——*i*₁、*i*₂ 的参考箭头流入节点，*i*₃ 的参考箭头流出。给 *i*₁ = 2 A、*i*₂ = 3 A，列 Σ*i* = 0 求 *i*₃，并说出实际方向。（方程：−*i*₁ − *i*₂ + *i*₃ = 0 ⇒ *i*₃ = 5 A；参考箭头朝外、数值为正，所以实际有 5 A 流出节点。）

**广义节点一句**（〔邱 p.23〕）：KCL 对包围几个节点的闭合面也适用——把三个节点圈成一个“大节点”，内部支路电流在相加时一正一负抵消了，剩下的就是穿过边界的电流。〔通识〕这叫电流的连续性，本质是电荷守恒。**今天只认这个图，不练。**

QA 锚点：`QA:stage-2` 可挂“为什么翻个箭头方程还成立”。

### 环节 3｜KVL：为什么“绕一圈加起来为零”（14′）

**先预测 2**（此时学生还不知道绕行方向的符号规则）：

> 板书一个矩形回路，并让电源符号**第一次出现就当场解释**〔邱 p.19：“电压源两端电压就是给定的 *U*_S，电流由外电路决定；今天只要这一层。”〕：
> **左边**是理想电压源 *U*_S，参考极性标为上 + 下 −；**上边**是电阻 *R*₁，电压 *u*₁ 的极性左 + 右 −；**右边**是电阻 *R*₂，电压 *u*₂ 的极性上 + 下 −；**下边**是理想导线。
> 回扣开场：**绕行方向就是你沿回路走一圈的方向**。我先选顺时针——从左上角出发，先沿上边向右走。
> 沿顺时针写出 −*U*_S + *u*₁ + *u*₂ = 0。现在把绕行方向改成逆时针，方程变成 +*U*_S − *u*₁ − *u*₂ = 0。
> 这两个方程矛盾吗？还是同一件事？先猜。

收集答案，**不评判**。

**推导**（主线只用第一课的电位差，不碰功率；依据〔邱 p.24〕）：

> “第一课我们用过 *u*<sub>AB</sub> = *V*<sub>A</sub> − *V*<sub>B</sub>——两点间的电压就是两点电位的差。书上说得很直接〔邱 p.24〕：‘④、③两节点之间的电压是单值的，不论沿支路 3 或沿支路 4、1、2 构成的路径，此两节点间的电压值是相等的。’ 换句话说：**每个节点有确定的电位，两点的电压只由这两个电位决定，跟你走哪条路无关。**”
> “现在沿任一回路绕一圈：从某点出发又回到**同一个点**，电位绕一圈回到原值，净变化只能是 0。把沿途每一小段的电位差带符号加起来，就是 **Σ*u* = 0**。”

**关键**：黑板上必须可见地走完这四步——**电位单值 → 电压与路径无关 → 绕一圈回原点 → Σ*u* = 0**。让学生看到这条公式是从第一课已会的电位差概念长出来的，不是新背的规定。

**陈述时刻（推导后立刻命名）**〔邱 p.23–24〕：

> “这就是**基尔霍夫电压定律（Kirchhoff's Voltage Law，KVL）**：在集总电路中，任何时刻，沿任一回路，所有支路电压的代数和恒等于零。记作 Σ*u* = 0。”

〔邱 p.24 脚注：“实质上，是能量守恒和转换定律的反映。”教材里从 Σ*w*=0 → Σ*p*=0 → 按电流分组 → Σ*u*=0 的完整推导**放页尾折叠区**，那里才第一次交代 *p* 是功率（*p*=*ui*）；主线不出现功率记号。〕

〔邱 p.24〕给表述与符号规则：

> “在集总电路中，任何时刻，沿任一回路，所有支路电压的代数和恒等于零。” 绕行方向**任意指定**；支路电压的参考方向与绕行方向一致取 “+”，相反取 “−”。

**此刻公布预测 2**：不矛盾。逆时针时每一项都变号，等于整个方程乘了 −1；电压降的物理事实没变。

**第三种“随手标”：翻电压极性**（补上核心问题承诺的第三样，〔通识〕）：

> “除了翻电流箭头、翻绕行方向，还能翻**电压极性**：把某个电阻的 +/− 对调，同一个物理电压的代数值变号（+3 V 变 −3 V）；而它的参考方向相对绕行方向也反了，**项前符号同时变号**。两次变号成对出现、互相抵消，方程照旧成立。独立练习第 (4) 问会亲手做一遍。”

〔邱 p.24〕取同一回路里两条路径，可见地推一次：

> *u*₁ + *u*₂ − *u*₃ + *u*₄ = 0　⇒　*u*₃ = *u*₁ + *u*₂ + *u*₄

点破：“③、④两点之间的电压是单值的，走支路 3 还是走支路 1、2、4，算出来一样——这就是 KVL。”〔邱 p.24 脚注：实质上是能量守恒和转换定律的反映。〕

**两套符号**（〔李 p.15〕，本环节第二个重点）：

> “在运用 KCL 时常需和两套符号打交道：其一是方程中各项前的正、负符号，其正、负取决于电流参考方向对节点的相对关系；另一是电流本身数值的正、负号。两者不要混淆。”

板书并排：**项前 ±（由参考方向决定）** vs **数值 ±（解出来才知道）**。告诉学生：今天的独立练习就在考这个区分。

QA 锚点：`QA:stage-3` 可挂“绕行方向反了，方程到底算不算变了”。

### 环节 4｜两定律合用与自检（6′）

**教师示范**（〔邱 p.24 例 1-2〕，think-aloud，2′）：

> 电路：两个回路共用一条支路，那条支路电压是 *u*₆；待求电压是 *u*_x。已知 *u*₁ = *u*₃ = 1 V，*u*₂ = 4 V，*u*₄ = *u*₅ = 2 V。
> “先别找答案。第一条回路顺时针写：−*u*₁ + *u*₂ + *u*₆ − *u*₃ = 0。第二条回路也顺时针写：−*u*₆ + *u*₄ + *u*₅ − *u*_x = 0。
> 注意 *u*₆ 在两式里一次是 ‘+’、一次是 ‘−’——不是我写错了，是两个回路的绕行方向在 *u*₆ 这条支路上相反。两式相加，*u*₆ 抵消，得 *u*_x = −*u*₁ + *u*₂ − *u*₃ + *u*₄ + *u*₅ = 6 V。”

**学生独立练习**（〔我编的题〕，3′，不提示；答案在文末）：完整题面见 §5。它不是例 1-2 的换数：它要求**照着别人标好的方向列方程**，并且**亲手翻电流箭头、翻绕行方向、翻电压极性各一次验证方程仍成立**——正是核心问题的两种形态。

**讲评 1′**：只问一句“翻方向、翻极性之后，物理变了没有？”答：没有，变的是项前符号和数值符号，两者成对变化、互相抵消。三种“随手标”都验证过了。

### 环节 5｜收尾：回答“凭什么”（3′）

板书一句话回答开场问题：

> **因为 `Σi = 0` 和 `Σu = 0` 不是关于“哪个方向算正”的规定，而是关于“电荷不积累、电位单值（电压与路径无关）”的事实——更深一层，分别是电荷守恒与能量守恒的运用。项前的 ± 只是把参考方向翻译成代数语言；你随手怎么标，物理不变，方程就仍然成立。别人标的方向，照着它的参考方向翻译即可。**

补适用条件一句〔李 p.4–5〕：KCL/KVL 成立的前提是**集总假设**。100 MHz 的信号波长 3 m，接一根 1 m 的线就不能当集总电路——今天不要求算，但边界要记住（S13 再学）。

补一句“与元件无关”〔邱 p.24、李 p.46〕：这两个定律只看**怎么连**，不管元件是线性还是非线性。所以例题里换成二极管，KCL/KVL 照样写。

留钩子（不复述、不说教）：“电流、电压都被方程定下来了。下次该问：谁供能、谁耗能、元件能扛多大——第三课，功率、能量与额定值直觉。”

## 五、预测题与练习题（**前端必须先隐藏答案**）

> **实现约束**：以下问题先只显示题干；学生作答后才展开答案区。不要把答案和题目并列放在同一屏。
> **顺序约束**：预测 1 必须在环节 2 推导 KCL **之前**提出，推导后才公布；预测 2 必须在环节 3 讲绕行方向符号规则**之前**提出，推导后才公布；翻电压极性的验证在环节 3 公布预测 2 之后点破，练习 (4) 才让学生亲手做。答案区默认折叠。

**预测 1**（环节 2 开头）：节点 O 汇三条支路，统一按“流出为正”。参考箭头：①号朝内、②号朝外、③号朝外。实际电流为①号 3 A 流入、②号 1 A 流出、③号 2 A 流出，故 *i*₁ = +3 A、*i*₂ = +1 A、*i*₃ = +2 A，−*i*₁ + *i*₂ + *i*₃ = −3 + 1 + 2 = 0。现在把③号参考箭头改成朝内，其他不动，照旧写 Σ*i* = 0，方程还成立吗？先猜“成立 / 不成立”，说理由，先别算。〔我编的题〕

**预测 2**（环节 3 开头）：矩形回路——左边电压源 *U*_S（上 + 下 −），上边电阻电压 *u*₁（左 + 右 −），右边电阻电压 *u*₂（上 + 下 −），下边理想导线。先说明“绕行方向＝沿回路走一圈的方向”，选顺时针（从左上角沿上边向右）。顺时针写 −*U*_S + *u*₁ + *u*₂ = 0；改逆时针写 +*U*_S − *u*₁ − *u*₂ = 0。两式矛盾吗？先猜。〔我编的题〕

**即时识别**（环节 1）：给图，数支路与节点；判断用理想导线相连的两点该算一个还是两个节点。

**即时检查**（环节 2）：按流出为正，节点 O 接三条支路，*i*₁、*i*₂ 参考箭头流入、*i*₃ 参考箭头流出；*i*₁ = 2 A、*i*₂ = 3 A，列 Σ*i* = 0 求 *i*₃ 并说实际方向。〔我编的题〕

**教师示范题**（环节 4，学生看着走一遍）：邱 p.24 例 1-2 原题与数值。〔书〕

**学生独立练习**（环节 4，本课唯一独立计算题）：

> 下面是**别人已经标好方向**的电路，请照着它做题。
> ① 节点 O 汇三条支路，参考箭头已标：*i*₁ 指向 O（流入），*i*₂ 离开 O（流出），*i*₃ 指向 O（流入）。已知 *i*₁ = +4 A，*i*₂ = +6 A。
> ② 另一个回路画成矩形，四边从左上角起顺时针依次是：**上边**电阻 *R*₁，电压 *u*₁ 的参考极性为左 + 右 −；**右边**电阻 *R*₂，电压 *u*₂ 的参考极性为上 + 下 −；**下边**是理想导线；**左边**电压源 *U*_S，参考极性为上 + 下 −。绕行方向已用虚线箭头指定为**顺时针**（即从左上角先沿上边向右走）。已知 *u*₁ = +3 V，*u*₂ = +5 V。
> (1) 按别人标的方向，用本课统一的“流出为正”列 KCL，求 *i*₃，并说出实际电流方向。
> (2) 按别人标的极性和绕行方向列 KVL，求 *U*_S。
> (3) 把 *i*₃ 的箭头翻成“流出 O”，把绕行方向改成逆时针，重新列这两个方程；它们还成立吗？*i*₃ 和 *U*_S 的值变了吗？
> (4) 把绕行方向恢复顺时针，再把 *u*₁ 的参考极性翻成“右 + 左 −”（物理上仍是左端比右端高 3 V），重新列 KVL；*U*_S 还是 8 V 吗？〔我编的题〕

## 六、答案区（`<!-- 前端：默认折叠 -->`）

- **预测 1**：成立。③号箭头改朝内后，同一个“2 A 流出”的物理事实，代数值从 *i*₃ = +2 A 变成 *i*₃′ = −2 A；方程里那一项也从“+*i*₃”（箭头朝外）改写成“−*i*₃′”（箭头朝内），而 −(−2) = +2 与原来相同。变的只是项前符号和数值符号两套标记，物理没变，方程仍成立。〔KCL 的完整推导已在环节 2 现场完成，这里不重复。〕
- **预测 2**：不矛盾。逆时针绕行时每一项都变号，等于整个方程乘了 −1；电压降的物理事实没变。
- **即时识别**：按具体图作答；核心判据是“理想导线相连的点算同一个节点”。
- **即时检查**：−*i*₁ − *i*₂ + *i*₃ = 0 ⇒ *i*₃ = 5 A；参考箭头朝外、数值为正，所以实际有 5 A 流出节点。
- **教师示范题**：−*u*₁ + *u*₂ + *u*₆ − *u*₃ = 0；−*u*₆ + *u*₄ + *u*₅ − *u*_x = 0；两式相加消去 *u*₆，得 *u*_x = −1 + 4 − 1 + 2 + 2 = 6 V。*u*₆ 在两式中符号相反，是因为两回路绕行方向在该支路上相反。
- **独立练习**：
  - (1) 流出为正：−*i*₁ + *i*₂ − *i*₃ = 0 ⇒ −4 + 6 − *i*₃ = 0 ⇒ *i*₃ = +2 A。参考箭头指向 O、数值为正，所以实际是 **2 A 流入 O**。
  - (2) 顺时针绕行：−*U*_S + *u*₁ + *u*₂ = 0 ⇒ *U*_S = 3 + 5 = 8 V。
  - (3) *i*₃ 箭头翻成流出后，代数值变成 *i*₃′ = −2 A；方程改写为 −*i*₁ + *i*₂ + *i*₃′ = 0 ⇒ −4 + 6 + (−2) = 0，仍成立。逆时针绕行：+*U*_S − *u*₁ − *u*₂ = 0 ⇒ *U*_S = 8 V，也成立。*i*₃ 的数值符号变了（因为它自己的参考箭头变了），但物理事实没变——仍是 2 A 流入 O；*U*_S 完全没变。
  - (4) *u*₁ 极性翻成右 + 左 − 后，同一个“左端高 3 V”的物理事实，代数值变成 *u*₁′ = −3 V；顺时针沿上边走变成从 − 端进、+ 端出，那一项写成 −*u*₁′ = +3。方程：−*U*_S − *u*₁′ + *u*₂ = 0 ⇒ −*U*_S + 3 + 5 = 0 ⇒ *U*_S = 8 V。项前符号与数值符号成对变号、互相抵消，物理和答案都没变。至此三种“随手标”（电流箭头、电压极性、绕行方向）全部验证过。

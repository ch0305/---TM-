# L3-04 教案：拉普拉斯变换与 s 域直觉（选学强化）

> S3 第四课（选学强化）· 前置 L3-03（二阶响应形态与工程直觉）· 45 分钟预算（因果链完整前提下）· 教案先行，独立审核通过前不得写 HTML。
> 本课把 L3-03"看特征根预判二阶性格"升级成一套**系统求解语言**：把时域微分方程变 s 域代数方程、初值自动带入、把特征根 `p` 变成能四则运算的复频率 `s`。**只做方法论认知 + s 域阻抗 + 系统求解流程；变换对细表与复杂反变换技巧"了解即可"（P3），网络函数零极点与频率响应留后续、不引章节号。**

## 一、核心问题（一个，贯穿全篇）

**L3-03 里我们靠"看特征根 p"就预判了二阶电路的性格，但每次都要先列微分方程、再求根、还要把电感电流/电容电压的初值换算成各阶导数的初值——又慢又容易错。能不能换一种"运算"方式：直接把微分方程变成代数方程、把初始状态自动带进去、还能让那个特征根变成一个可以像电阻一样做四则运算的量，从而用同一套电阻电路方法系统求解任意阶线性动态电路，并且从结果里一眼看出响应由哪些指数衰减成分（衰减快慢、振荡频率）组成？**（"拉普拉斯变换""象函数 F(s)""复频率 s=σ+jω""运算阻抗 sL/1/(sC)""部分分式""分母根=模态"等术语与符号在对应预测揭晓时才给出；开场只用"换一个域""把微分变代数""自动带初值""像电阻一样算"这类待解描述，不点出术语。）

这句话覆盖本课两种任务形态：

- **形态一 · 把电路/微分方程翻译成 s 域代数问题并求解**：给一个含初值的动态电路（或给微分方程），用微分/积分性质写出 s 域方程（运算电路），解出象函数 F(s)，再用"查表 + 部分分式"反变换回时域。核心是"时域微分方程 → s 域代数方程 → 反变换回时域"的迁移链，不要求手算复杂展开。
- **形态二 · 用 s 域语言读响应、并与 L3-03 对上号**：给象函数 F(s) 或 s 域方程，从分母根看出响应里的衰减率/振荡频率（模态），认出"把 jω 换成 s"就是 L2-05 阻抗法的升级，分清**来自 Z(s)=0 的根（=特征根 p=瞬态模态）**与**激励引入的极点（=稳态强迫分量）**、以及零状态/非零状态。核心是"从 s 域结构读时域行为"，且知道"jω→s"只在零初始条件下成立。

学生学完应能自己说出："这节课解决的是——用拉氏变换把微分方程变成代数方程、初值自动带进去；电感变 sL、电容变 1/sC，零初始时就是把相量法的 jω 换成 s，所以电阻电路那套方法照搬；解出来的 F(s) 分母里来自 Z(s)=0 的根就是 L3-03 的特征根 p，决定瞬态里 e^(−at) 或衰减振荡的模态（激励另带来的极点只对应稳态分量）。"（这句是学习目标，放页尾折叠区，不在开场显示。）

## 二、讲什么 / 不讲什么（边界与留白）

**讲**：
1. 经典法困难：n 阶方程要各阶导数的初值，而电路只给 i_L(0₋)、u_C(0₋)（§14-1 导读）；
2. 拉氏变换定义 `F(s)=∫₀₋^∞ f(t)e^(−st)dt`、`s=σ+jω`（复频率）、象函数/原函数；与相量法同属"变换域方法"（§14-1、李下 §12-1）；
3. 线性性质 + 微分性质 `L[df/dt]=sF(s)−f(0₋)`：微分变乘 s、初值 `f(0₋)` 自动带入；KCL/KVL 运算形式 `ΣI(s)=0`、`ΣU(s)=0`（§14-2、李下 §12-1）；
4. 运算电路：元件 s 域模型 `Z_R=R`、`Z_L=sL`、`Z_C=1/sC`，非零初值折算为附加电源；广义阻抗 `Z(s)=U(s)/I(s)`；**"零初始时把 jω 换成 s"**（§14-4、李下 §12-3）；
5. 运算法求解流程：画运算电路 → 用节点/网孔/叠加/戴维南列 s 域代数方程解出 F(s) → 部分分式 + 查表反变换 → 时域全响应 = 瞬态 + 稳态（§14-5、李下 §12-3 例12-8）；
6. 认知支点：`F(s)` 分母的根 = 响应的模态（每个根给一项 `e^(s_i t)`）；其中来自 `Z(s)=0` 的根才是 L3-03 的特征根 p、决定瞬态，激励引入的极点是稳态分量；实部决定衰减率、虚部决定振荡频率（P1 直觉，不靠背）。

**不讲**（留白，钩子）：
- 拉氏变换的复变反演积分 `f(t)=(1/2πj)∫F(s)e^(st)ds`（只提一句"存在但不用"，不做）；
- 变换对细表、各种复杂部分分式展开技巧（**P3 了解即可**：给常用对，复杂展开只要求"看得懂对应"，不要求手算）；
- 网络函数 H(s)、零极点图、极点零点与冲激响应/频率响应（邱 §14-6~§14-9，**本课不摘、不引章节号**，留后续与 L2-08 呼应）；
- 电路方程的矩阵形式、状态方程（邱 §15，不引）；
- 收敛域的严格数学讨论（邱 §14-1 一句"σ 为收敛因子"带过，不展开）。

**下一课钩子**：L3-05（若排）将用 s 域的系统视角看传递函数/网络函数，把本课"分母根=模态"升级成"零极点→频响"，与 L2-08 的频率响应呼应；本课先把"域变换 + 运算阻抗 + 分母根读模态"这三件事立住。

## 三、概念依赖链（每一步"因为上一步不够用"才引入）

1. **L3-03 的成就与痛点**：已经能用特征根 p 预判二阶性格 → 但列微分方程 + 求根 + 初值换算仍繁琐，且"两个储能元件 + 多电源"时直接解微分方程很困难。→ **引入：换一个域，让微分变代数（预测 1）**。
2. **拉氏变换定义与复频率 s（§14-1、李下 §12-1）**：`F(s)=∫₀₋^∞ f(t)e^(−st)dt`，s=σ+jω。与相量法类比：相量把正弦量换成复数、s 把任意时间函数换成复频率函数；s 比 jω 多一个实部 σ，所以能描述衰减/增长而不只是等幅正弦。**【陈述时刻 1】** 但"换个域"本身还不够，必须证明微分真的变简单了。
3. **微分性质与初值自动带入（§14-2）**：`L[df/dt]=sF(s)−f(0₋)` → 微分变成乘 s，而唯一需要的初值是 `f(0₋)` 本身，恰是电路给的 i_L(0₋)、u_C(0₋)。**预测 2** 问：为什么这个性质正好治了经典法"要各阶导数初值"的病？揭晓后线性性质顺带给出 KCL/KVL 运算形式。**【陈述时刻 2】** 但只知道"微分变乘 s"还不会画电路——元件的 s 域长什么样？
4. **运算电路与 jω→s（§14-4、李下 §12-3）**：由微分/积分性质推出 `Z_L=sL`、`Z_C=1/sC`、`Z_R=R`，广义阻抗 `Z(s)=U(s)/I(s)`；非零初值折算成附加电源。**预测 3** 问：相量法里 `Z_L=jωL`、`Z_C=1/jωC`，s 域对应该是什么？揭晓"把 jω 换成 s"，解锁面板 B 迁移台。**【陈述时刻 3】** 现在能列 s 域方程了——解出来的分母根意味着什么？
5. **反变换与分母根=模态（§14-3/§14-5、李下 §12-3 例12-8）**：解出 F(s) 后部分分式 + 查表反变换。**预测 4** 问：F(s) 分母的根和 L3-03 的特征根 p、和响应里的 e^(−at)/衰减振荡是什么关系？揭晓：分母根 s_i 就是响应模态 e^(s_i t) 的指数，实部=衰减率、虚部=振荡频率；其中来自 `Z(s)=0` 的根才是 L3-03 的特征根 p，例12-8 里 `2s+8=0 → s=−4` 对应瞬态 `e^(−4t)`，而激励引入的 `±j3` 不是特征根、对应稳态。全响应 = 瞬态 + 稳态。**【陈述时刻 4】** 面板 A 解锁"翻译台"。

链条的驱动力始终是"上一步只解决了表象、还没解决这个新痛点"，不是把定义、性质、运算电路、反变换并列摆出。

## 四、逐环节脚本（教师说什么 / 板书什么 / 问什么 / 何时揭示）

### 环节 0 · 开场核心问题 + 预测 1（约 7′）

- **师**："上一课我们看一眼特征根 p 就知道电路是振铃还是单调——但要先列微分方程、求根，初值还得从 i_L、u_C 换算成各阶导数的初值。今天换一种玩法：把整个问题搬到一个新'域'里，让微分方程直接变成代数方程，初值自己跳进来。"
- **板书**：核心问题（第一节那句话）；画"时域 → 变换域 → 解代数 → 反变换回时域"的四步流程图（页内自包含 SVG）。**明确：只出现"换一个域/微分变代数/自动带初值/像电阻一样算"这类描述词，不出现任何术语符号。**
- **师**："你们已经用过一次'换域'了——正弦稳态里把正弦量换成相量，微分变 jω 乘，电路变成复数电路。拉氏变换是同一招的升级版。"
- **问（预测 1，先想后揭）**："拉氏变换和我们学过的相量法，你觉得是什么关系？（A 完全无关的两种东西 / B 同一类'换域简化'的方法，拉氏更一般 / C 拉氏只能算正弦稳态）"
- **揭示条件**：学生先选后才揭晓；揭到"同属变换域方法、s=σ+jω 比 jω 多一个实部 σ、能描述衰减/振荡而不只是等幅正弦"这一层，陈述时刻 1 才给"拉普拉斯变换/复频率/象函数"的定义名。
- **揭晓要点**：给常用对 δ(t)↔1、ε(t)↔1/s、e^(−at)↔1/(s+a)、sin ωt↔ω/(s²+ω²)、cos ωt↔s/(s²+ω²)（"查表即可，少数记住"，不要求推导）。**此处只揭定义与类比，不写微分性质、不写运算阻抗、不提分母根。**

### 环节 1 · 拉氏变换定义 + 微分性质（约 10′）

- **【陈述时刻 1 · 拉普拉斯变换与复频率 s】**：全称、一句定义、符号式（见答案区）。
- **师**："换域本身不值钱，值钱的是微分在新域里变简单了。先别看公式——猜一猜。"
- **问（预测 2，先想后揭，公式出现前提出）**："相量法里微分变成乘 jω；猜拉氏域里微分会变成什么运算？经典法最烦的'各阶导数初值'，在新域里会不会自己冒出来？线性性质下 KCL/KVL 搬到 s 域又是什么样？"（学生先表态，此时黑板上没有 `L[f']` 公式）
- **揭晓（陈述时刻 2，公式此时才板书推导）**：**板书推导（可见地被推出来）**：分部积分 `L[f']=∫₀₋^∞ f'(t)e^(−st)dt = [f e^(−st)]₀₋^∞ + s∫₀₋^∞ f e^(−st)dt = sF(s) − f(0₋)`。**强调 `−f(0₋)` 这一项：微分一次只需 f 自己在 0₋ 的值，初值自动进来了**（元件在 s 域长什么样、是否出现 sL，留到预测 3 揭晓，此处不写）。微分一次→乘 s 减 f(0₋)，微分两次→s²F−s f(0₋)−f'(0₋)；线性性质给出 `ΣI(s)=0`、`ΣU(s)=0`，与相量形式一模一样。**【陈述时刻 2】**
- **师**："既然 KCL/KVL 照搬，那电阻电路那套节点/网孔/戴维南是不是也能照搬？差就差在元件的 s 域长相。"

### 环节 2 · 运算电路与 jω→s（约 10′）

- **师**："电阻 u=Ri 取变换还是 U=RI。电感、电容靠微分/积分性质推出新长相——先猜长相，再对答案。"
- **问（预测 3，先想后揭，公式出现前提出）**："相量法里 `Z_L=jωL`、`Z_C=1/(jωC)`；猜 s 域对应的运算阻抗长什么样？如果把 s 取成纯虚数 jω（σ=0），它们会不会退回相量值？"（学生先表态，此时黑板上没有 `sL`/`1/sC` 答案）
- **揭晓（陈述时刻 3，公式此时才板书）**：**板书**：`Z_R=R`；电感 `U(s)=sL I(s)−L i(0₋)` → 运算阻抗 sL + 附加电压源 `−L i(0₋)`；电容 `U(s)=(1/sC)I(s)+u_C(0₋)/s` → 运算阻抗 1/sC + 附加电压源 `u_C(0₋)/s`。广义阻抗 `Z(s)=U(s)/I(s)`（零状态元件）。结论 `Z_L=sL`、`Z_C=1/sC`、`Z_R=R`——**把 jω 换成 s**，零初始时相量模型直接变 s 域模型；非零初始再加附加电源。解锁面板 B，令 σ=0 即数值退化为相量阻抗（面板可验）。**【陈述时刻 3】**
- **师**："现在能照搬整套电阻电路方法列 s 域代数方程了。可解出来的 F(s) 是一堆分式，怎么读回时域、它的分母藏着什么？"

### 环节 3 · 反变换、分母根=模态（约 10′）

- **板书（预测 4 提出前只写 ①②）**：运算法前两步：① 画运算电路（含初值电源）→ ② 用节点/网孔/叠加/戴维南解出 `F(s)`（s 的有理分式）。**师**："解出 F(s) 后，怎么读回时域？它的分母里藏着什么？"（第 ③ 步"部分分式 + 查表反变换"、常用对与 P3 说明一律等预测 4 揭晓后才板书，此处不出现）
- **问（预测 4，先想后揭）**："邱例14-6 的 `F(s)=(2s+1)/(s³+7s²+10s)` 分母根是 0、−2、−5；李下例12-8 的 `I(s)=60/((s²+9)(s+4))` 分母根含 −4 与 ±j3。这些分母根，和 L3-03 讲的特征根 p、和响应里的常数项/e^(−2t)/衰减振荡，是什么关系？"
- **揭晓（陈述时刻 4，此时才板书第 ③ 步）**：**板书第③步：部分分式展开 + 查表反变换得 f(t)；给常用对；复杂展开 P3 了解即可。** F(s) 分母的每个根 s_i 对应部分分式的一项 `K_i/(s−s_i)`，反变换就是 `K_i e^(s_i t)` 这个**模态**——实部决定衰减率（−4 → e^(−4t)，τ=1/4），虚部决定振荡频率；共轭复根成对出现就合成衰减振荡（对应 L3-03 欠阻尼）。**注意**：只有来自 `Z(s)=0` 的根才是 L3-03 的特征根 p（决定瞬态），激励引入的极点（例12-8 的 `±j3`，来自 `U(s)=120/(s²+9)`）不是电路特征根、只对应稳态强迫分量。例12-8 全响应 `i(t)=[2.4e^(−4t)+4sin(3t−37°)]ε(t)`：第一项瞬态（由 s=−4 定）、第二项稳态（相量法可核对）。**【陈述时刻 4】** 解锁面板 A 翻译台。
- **师**："记住：s 域分母的根，就是时域响应的脾气。"

### 环节 4 · 双实验台 + 独立练习（约 6′）

- 面板 A（s 域翻译台）：滑块 R/L/C → 显示时域微分方程、s 域方程、归一化分母多项式、根 s₁/s₂、响应模态形式、形态判定（复用 L3-03 词汇）。
- 面板 B（jω→s 迁移台）：相量域 vs s 域元件阻抗对照，滑块 σ/ω/R/L/C；令 σ=0 数值退化为相量阻抗；并读例12-8 的 `Z(s)=2s+8` 与根 s=−4。
- 再做 8 题（4 数值/形式 + 2 选择 + 2 文字/辨析），覆盖两形态，强调不是例题近邻复制。

### 环节 5 · 收尾与钩子（约 2′）

- 回扣核心问题："换域把微分变代数、初值自动进；电感 sL、电容 1/sC，零初始就是把 jω 换成 s；F(s) 分母根 = 模态，其中 Z(s)=0 的根 = L3-03 特征根 p（定瞬态），激励极点是稳态分量。" 抛下一课 s 域系统视角/网络函数钩子。

### 预测题答案（每题单独折叠，按提出时机解锁）

<details><summary>预测 1 揭晓（含陈述时刻 1）</summary>

**② 同一类"换域简化"的方法，拉氏更一般。** 相量法把正弦量换成复数相量、微分变 jω 乘，从而把正弦稳态问题变成复数代数方程；拉氏变换把任意时间函数换成 s 域象函数、微分变乘 s，把动态电路的微分方程变成 s 域代数方程——两者都是"换域 → 简化运算 → 换回"的变换域方法。区别在 `s=σ+jω` 比 `jω` 多一个实部 σ，所以 s 域既能描述等幅正弦（σ=0），也能描述衰减振荡（σ<0，对应 L3-03 欠阻尼）、单调衰减与增长。常用对查表：δ(t)↔1、ε(t)↔1/s、t↔1/s²、e^(−at)↔1/(s+a)、sin ωt↔ω/(s²+ω²)、cos ωt↔s/(s²+ω²)。

> **【陈述时刻 1 · 拉普拉斯变换与复频率 s】**
> **全称/命名**：拉普拉斯变换（Laplace transform）、象函数（image function）、原函数（original function）、复频率（complex frequency）。
> **一句定义**：定义在 [0,∞) 的函数 f(t) 的拉普拉斯变换为 `F(s)=∫₀₋^∞ f(t)e^(−st)dt`，其中 `s=σ+jω` 为复数（复频率）；F(s) 叫 f(t) 的象函数，f(t) 叫 F(s) 的原函数。积分下限取 0₋ 可计及 t=0 的冲激。它与相量法同属变换域方法，但 s 的实部 σ 使它可描述衰减/增长，不局限于正弦稳态。
> **符号式**：`F(s)=∫₀₋^∞ f(t)e^(−st)dt`；`s=σ+jω`；常用对 `ε(t)↔1/s`、`e^(−at)↔1/(s+a)`、`sin ωt↔ω/(s²+ω²)`。

〔邱 §14-1 / p.320–321；李下 §12-1 / PDF 202–204〕

</details>

<details><summary>预测 2 揭晓（含陈述时刻 2）</summary>

分部积分给出 `L[f']=∫f'e^(−st)dt=[f e^(−st)]₀₋^∞+s∫f e^(−st)dt=sF(s)−f(0₋)`。关键在 `−f(0₋)`：微分一次只用到 f **自己在 0₋ 的值**，不是它的导数值；微分两次 `s²F−s f(0₋)−f'(0₋)` 里的 f'(0₋) 也可由电路的 i_L/u_C 初值推出，不需另测各阶导数——这正是经典法的痛点。线性性质又让 KCL/KVL 直接搬过来：`ΣI(s)=0`、`ΣU(s)=0`，与相量形式一样。

> **【陈述时刻 2 · 微分性质、初值自动带入与 KCL/KVL 运算形式】**
> **全称/命名**：拉氏变换的微分性质（differentiation property）、基尔霍夫定律的运算形式。
> **一句定义**：若 `L[f(t)]=F(s)`，则 `L[df/dt]=sF(s)−f(0₋)`——时域微分变成 s 域乘 s 再减去初值 `f(0₋)`，只需 f 自己在 0₋ 的值；微分两次 `s²F−s f(0₋)−f'(0₋)` 的高阶初值由低阶初值递推。在后面写出的 s 域元件 VCR 里只出现 i_L(0₋)、u_C(0₋)（电路给的初始状态），不必像经典法那样换算回路电流各阶导数初值。由线性性质，KCL/KVL 在 s 域仍是各支路电流的象函数和为零、各支路电压的象函数和为零：`ΣI(s)=0`、`ΣU(s)=0`。
> **符号式**：`L[f']=sF(s)−f(0₋)`；`L[f'']=s²F−s f(0₋)−f'(0₋)`；`ΣI(s)=0`、`ΣU(s)=0`。（元件 VCR 的 s 域形式与 sL/1/sC 留陈述时刻 3。）

〔邱 §14-2 / p.322–324；李下 §12-1 / PDF 204–205〕

</details>

<details><summary>预测 3 揭晓（含陈述时刻 3）</summary>

相量域 `Z_L=jωL`、`Z_C=1/jωC`，s 域对应 `Z_L=sL`、`Z_C=1/sC`（电阻不变 `Z_R=R`）——**把 jω 换成 s** 即可。`s=σ+jω`，令 σ=0 则 s=jω，s 域阻抗数值退回相量阻抗（面板 B 可验）。非零初始时，电感串一个附加电压源 `−L i(0₋)`、电容串 `u_C(0₋)/s`，运算阻抗部分仍是 sL、1/sC。广义阻抗定义为零状态元件（或无独立源单口）`Z(s)=U(s)/I(s)`。

> **【陈述时刻 3 · 运算阻抗、运算电路与"jω→s"】**
> **全称/命名**：运算阻抗（operational impedance）/广义阻抗（generalized impedance）、运算电路（operational circuit）、拉普拉斯阻抗。
> **一句定义**：由微分/积分性质，元件 VCR 的 s 域形式为 `U(s)=Z(s)I(s)+初值源`：电阻 `Z_R=R`，电感 `Z_L=sL`（附加源 `−L i(0₋)`），电容 `Z_C=1/sC`（附加源 `u_C(0₋)/s`）；零状态时 `Z(s)=U(s)/I(s)` 称广义阻抗。**零初始条件下，把相量模型里的 jω 换成 s 就得到 s 域运算电路**，所以相量法的节点/网孔/叠加/戴维南可原样搬到 s 域；非零初始须另加初值电源。
> **符号式**：`Z_R=R`、`Z_L=sL`、`Z_C=1/(sC)`；`s=σ+jω`，σ=0 时退化为相量阻抗。

〔邱 §14-4 / p.331–334；李下 §12-3 / PDF 215–216〕

</details>

<details><summary>预测 4 揭晓（含陈述时刻 4）</summary>

`F(s)` 若有单根 s_i，部分分式含一项 `K_i/(s−s_i)`，反变换是 `K_i e^(s_i t)`；共轭复根 `α±jω` 两项合并成 `e^(αt)(A cos ωt+B sin ωt)` 衰减振荡；根 0 对应常数项（不衰减/稳态）。所以**分母根 s_i = 响应模态 e^(s_i t) 的指数**：实部=衰减率（s=−4 → e^(−4t)，τ=1/4），虚部=振荡频率；**其中只有来自 `Z(s)=0` 的根才是 L3-03 的特征根 p**（p 是写在时域特征方程里的同一批根），**激励引入的极点（如例12-8 的 ±j3）不是电路特征根、对应稳态分量**。例12-8 `Z(s)=2s+8=0 → s=−4`，瞬态项 `2.4e^(−4t)`；稳态项 `4sin(3t−37°)` 由相量法核对；全响应 = 瞬态 + 稳态。**复杂部分分式展开只要求看得懂"根↔模态"的对应，不要求手算（P3 了解即可）。**

> **【陈述时刻 4 · 反变换、分母根=模态（其中 Z(s)=0 的根=特征根 p）、全响应】**
> **全称/命名**：部分分式展开（partial fraction expansion）、反变换（inverse transform）、模态（mode）、全响应（complete response）= 瞬态响应 + 稳态响应。
> **一句定义**：运算法解 s 域代数方程得象函数 F(s)（s 的有理分式）后，用部分分式展开 + 查表反变换得时域解；F(s) 分母的每个根 s_i 对应一项 `K_i e^(s_i t)`（共轭复根合成为衰减振荡），即一个响应模态——实部决定衰减率、虚部决定振荡频率。**注意适用条件**：只有来自网络自身 `Z(s)=0`（齐次/无源方程）的根才是 L3-03 的特征根 p，决定瞬态（固有）响应；激励引入的极点不是电路特征根，对应稳态（强迫）响应。以例12-8 的 `I(s)=60/((s²+9)(s+4))` 为例：分母有两类根——`s=−4` 来自 `Z(s)=2s+8=0`，是特征根、给出瞬态 `2.4e^(−4t)`；`s=±j3` 来自激励 `U(s)=120/(s²+9)`，不是特征根、给出稳态 `4sin(3t−37°)`。电路的全响应 = 瞬态（固有）响应 + 稳态（强迫）响应。
> **符号式**：`K_i/(s−s_i) ↔ K_i e^(s_i t)`；`s=−4 → e^(−4t)`、`τ=1/4`；`i(t)=2.4e^(−4t)+4sin(3t−37°)`（例12-8）。

〔邱 §14-3 p.327–330、§14-5 p.334–336；李下 §12-2~§12-3 例12-8 / PDF 208–217〕

</details>

### 陈述时刻汇总（供页面做显式化定义卡，均在对应揭晓之后出现）

1. **拉普拉斯变换 / 复频率 s**：`F(s)=∫₀₋^∞ f(t)e^(−st)dt`、`s=σ+jω`；与相量法同类，s 多实部能描述衰减/增长。〔邱 §14-1；李下 §12-1〕
2. **微分性质 / 初值自动带入 / KCL-KVL 运算形式**：`L[f']=sF(s)−f(0₋)`；`ΣI(s)=0`、`ΣU(s)=0`。〔邱 §14-2；李下 §12-1〕
3. **运算阻抗 / 运算电路 / jω→s**：`Z_R=R`、`Z_L=sL`、`Z_C=1/sC`；零初始时"把 jω 换成 s"，非零初始加附加源。〔邱 §14-4；李下 §12-3〕
4. **反变换 / 分母根=模态（Z(s)=0 的根=特征根 p，激励极点=稳态）/ 全响应**：`K_i/(s−s_i)↔K_i e^(s_i t)`；实部衰减率、虚部振荡频率；全响应=瞬态+稳态。〔邱 §14-3/§14-5；李下 §12-2/§12-3〕

  - 例12-8 读根卡（揭晓后出现）：`Z(s)=2s+8=0 → s=−4` → 瞬态 `e^(−4t)`、`τ=0.25s`；稳态幅值 4∠−36.87°。**此卡在预测 4 揭晓后才解锁。**

### 独立练习答案

1. `L[f']=sF(s)−f(0₋)=s/(s+2)−1=(s−s−2)/(s+2)=−2/(s+2)`；验算 `f'=−2e^(−2t)`、`L[f']=−2/(s+2)` ✓。
2. 响应形式 `f(t)=K₀+K₁e^(−2t)+K₂e^(−5t)`（根 0→常数项、−2→e^(−2t)、−5→e^(−5t)）；根 0 对应常数/不衰减项 `0.1`（稳态）；根 −5 对应 `−0.6e^(−5t)`（衰减最快的模态）。
3. `Z(s)=s·1+2+1/(s·1)` → 分母 `s²+2s+1=(s+1)²=0` → `s=−1` 重根 → 临界阻尼；模态 `e^(−t)`、`t e^(−t)`。
4. s=−4；τ=1/4=0.25s；稳态幅值 4A（相量核对 `Z=8+j6=10∠36.87°`、`I=40/10=4∠−36.87°`）。
5. ②。①否认同族关系错；③拉氏不仅算正弦稳态；④s 实部可为任意值（正是它比 jω 强的点）。
6. `sL`；`1/sC`；零初始状态（零状态）。非零初始时还要加初值电源，不能只换阻抗。
7. ②。初值折算成附加电压源（电感 `−L i(0₋)`、电容 `u_C(0₋)/s`）。
8. 不对（只对一半）——部分分式每项 `K_i/(s−s_i)` 反变换为 `K_i e^(s_i t)`，s_i 实部=衰减率、虚部=振荡频率；但只有来自 `Z(s)=0` 的根才是特征根 p（定瞬态），激励引入的极点（如例12-8 的 ±j3，来自 `U(s)=120/(s²+9)`）对应稳态强迫分量、不是电路特征根。s=σ+jω 有实部 σ 能表达衰减/增长/暂态；jω 只有虚部，只能表达等幅正弦稳态。

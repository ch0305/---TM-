# L3-03 教案：二阶电路响应形态与工程直觉

> S3 第三课 · 前置 L2-03（一阶暂态/三要素）、L2-09（谐振/二阶直觉预告）、L2-10（二阶形态分类定性钩子）· 45 分钟预算（因果链完整前提下）· 教案先行，独立审核通过前不得写 HTML。
> 本课把 L2-10 只做定性钩子的二阶形态正式展开：LC 能量往返 → 二阶微分方程与特征根 → 四种阻尼形态 → 阶跃响应里的过冲/振铃/稳定时间工程直觉。**拉氏变换系统求解留 L3-04（选学），本课不碰。**

## 一、核心问题（一个，贯穿全篇）

**同样是 RLC 电路，为什么有的响应单调回落、有的却来回振铃甚至冲过稳态值？能不能只看 R、L、C 三个参数就预判电路的"性格"，并把波形里看到的"振铃、过冲、迟迟不稳"跟阻尼对上号、说出工程上该怎么取舍？**（"特征根""过阻尼/欠阻尼/临界/等幅""过冲/振铃""阻尼比"等术语与公式在对应预测揭晓时才给出；开场只用"电路的性格""振铃、过冲"这类现象词作待解问题，不点出四种形态的名字。）

这句话覆盖本课两种任务形态：

- **形态一 · 给参数预判形态 + 读响应形式**：给 R/L/C（或给特征根），先算临界电阻 `R_c=2√(L/C)` 或衰减系数 `α` 与固有频率 `ω₀`，判断过阻尼/临界/欠阻尼/等幅，写出响应形式、定性画出波形。核心是"参数 → 形态 → 波形"的预判链，不必先解出完整时域函数。
- **形态二 · 工程现象反推与边界取舍**：给一个波形（在稳态附近来回摆动、或峰值超过稳态）或一句说法（"电阻越大越不易振铃""临界阻尼永远最好"），反推阻尼状态，辨清振铃/过冲/稳定时间与阻尼的关系，知道串联 RLC 与并联 GCL 的对偶边界，按需求选阻尼。核心是"现象 → 阻尼 → 工程决策"，且知道结论的适用条件。

学生学完应能自己说出："这节课解决的是——RLC 二阶电路的性格由 R、L、C 三个参数决定，用临界电阻或 α 与 ω₀ 的比较就能预判它是单调还是振铃；欠阻尼会过冲、振铃，电阻越小过冲越大、越难稳；工程上按能否容忍过冲来选阻尼。"（这句是学习目标，放页尾折叠区，不在开场显示。）

## 二、讲什么 / 不讲什么（边界与留白）

**讲**：
1. LC 电路的能量在电场/磁场之间往返转移 → 等幅振荡（§7-1），储能 `W=½Li²+½Cu²` 恒定；
2. RLC 串联零输入响应的二阶微分方程 `LC u_C''+RC u_C'+u_C=0`（§7-2）与特征方程 `LCp²+RCp+1=0`、特征根 `p=−α±√(α²−ω₀²)`，`α=R/(2L)`、`ω₀=1/√(LC)`；
3. 四种特征根 → 四种形态：不等负实根过阻尼、相等负实根临界、共轭复根欠阻尼、共轭虚根等幅；临界电阻 `R_c=2√(L/C)`（§7-5 + 李上阻尼电阻 `R_d`）；
4. 四种响应形式（不要求学生背待定常数求解，只认形式与波形）；
5. 二阶阶跃响应：欠阻尼出现**过冲（overshoot）/振铃**、稳定时间概念（§7-7、李上 §7-3 例7-5 的"上冲 300V→516V"）；
6. 工程取舍：R 越小过冲越大、振铃越久；临界无过冲、稍欠阻尼更快；串联 RLC 与并联 GCL 的对偶边界（一句认知）。

**不讲**（留白，钩子）：
- 拉氏变换、s 域阻抗、传递函数的系统求解（L3-04 选学强化）；
- 二阶阶跃超调量/调节时间的解析推导（**面板会按公式计算并显示过冲百分比、峰值、峰值时刻的具体数值供观察趋势，但不讲 `M_p=e^(−απ/ω_d)` 的推导、不要求学生背这个解析公式**；学生只需知道 ζ 越大过冲越小的定性趋势）；
- 用初始条件解待定常数 A₁/A₂ 的完整代数（P3 繁复求解细节，例题里一步带过，不进练习）；
- 并联 GCL 的数值求解（只做"有对偶版本、方向如何"的定性辨析）；
- 冲激响应的求解（邱 §7-8 只做边界认知，页尾一句话带过）；
- 非线性二阶、状态平面（邱 §17-6 等，不引为教案依据）。

**下一课钩子**：L3-04 拉氏变换与 s 域直觉。今天我们靠"看特征根"就预判了二阶性格，但每次都要先列微分方程再求根仍嫌麻烦；下一课用拉氏变换把微分方程变成代数方程，把今天的 `p` 变成一个可以四则运算的 `s`，这是后面学传递函数、滤波器、控制系统的语言。

## 三、概念依赖链（每一步"因为上一步不够用"才引入）

1. **一阶暂态（L2-03）**：一个储能元件 → 一条一阶微分方程 → 一个 τ → 单调指数。→ 但 RLC 有**两个**储能元件，能量会在 L、C 之间交换，一阶的"单调指数"经验不够用了。**引入：先看没有电阻的 LC（预测 1）**。
2. **LC 能量往返（§7-1）**：电容初始储能 → 放电、电流增长 → 能量转入电感 → 电流不能突变、又给电容反向充电 → 能量回到电容……周而复始。储能 `W=½Li²+½Cu²` 恒定 → **等幅振荡**。【陈述时刻 1】但真实电路总有电阻，能量会被耗掉 → 振荡不会等幅。→ **引入电阻 R，列二阶方程**。
3. **二阶方程与特征根（§7-2/§7-5）**：KVL 得 `LC u_C''+RC u_C'+u_C=0`；沿用一阶"设 `e^(st)`"的经验 → 特征方程 `LCp²+RCp+1=0` → `p=−α±√(α²−ω₀²)`。**预测 2** 问：根号里 `α²−ω₀²` 的正负一变，根的性质会怎样？揭晓四种根 → 四种形态 + 临界电阻 `R_c=2√(L/C)`。【陈述时刻 2】
4. **只改一个 R 看形态演变（李上例7-1~7-4）**：`L=1H, C=1F` 时 `R_d=2Ω`，`R=3/2/1/0` 分别得不等实根/重根/共轭复根/共轭虚根 → 波形从单调、振荡与非振荡的分界、衰减振荡、到等幅。揭晓陈述时刻 2 后开面板 A，让学生用四个预设亲眼对比"R 从大调到小，波形怎么变"。【陈述时刻 2 的应用延伸，不是独立预测题，编号与第五节预测表一致：预测 3 是阶跃过冲、预测 4 是工程取舍】
5. **阶跃输入下的过冲（§7-7、李上例7-5）**：前面是"初始储能自己放电"（零输入），工程里更常见"突然加电源"（阶跃）。**预测 3**问：欠阻尼 RLC 加阶跃，输出峰值会不会超过稳态值？揭晓：会——这就是**过冲（overshoot）**，伴随振铃，随后进入稳定时间；给 `300V→516V` 的直观数。【陈述时刻 3】
6. **工程取舍与边界（预测 4）**：既然欠阻尼会过冲，是不是把 R 加到过阻尼就万事大吉？揭晓：过阻尼虽无过冲但恢复慢，临界是"无过冲中最快"，常允许少量过冲换更快响应；并点出"电阻越大越不易振铃"只在**串联 RLC** 成立，并联 GCL 要看电导 `G`（`α=G/2C`），别把结论用错场合。【陈述时刻 4】

链条的驱动力始终是"上一步在这个新场景不够用了"，不是把四种形态并列摆出。

## 四、逐环节脚本（教师说什么 / 板书什么 / 问什么 / 何时揭示）

### 环节 0 · 开场核心问题 + 预测 1（约 6′）

- **师**："前面一阶电路，一个电容或一个电感，响应是一条单调的指数曲线。今天电路里放**两个**储能元件——电感加电容。它们之间会互相'倒腾'能量，响应就不再单调了。先看一个极端：只有 L 和 C、没有电阻。"
- **板书**：核心问题（第一节那句话）；画一个 LC 回路草图（页内自包含 SVG：电容 C 与电感 L 成环，标初始 `u_C(0)`、`i_L(0)=0`）。**明确：先看零输入（无外施电源，靠初始储能）。**
- **师**："电容一开始存了能量、电感没有。电容放电、电流增长，能量搬到电感；电感电流不能突变，又反过来给电容充电……"
- **问（预测 1，先想后揭）**："没有电阻、没有能量损耗，这个来回倒腾会怎样？（A 幅度越来越小最后停下 / B 幅度不变、永远来回振荡 / C 单调降到零不再回来）"
- **揭示条件**：学生先选后才揭晓；揭到"能量在电场/磁场往返、`W=½Li²+½Cu²` 恒定、振幅不衰减 → 等幅振荡"这一层，陈述时刻 1 才给"二阶电路/等幅振荡"的定义名。
- **揭晓要点**：每一步能量转移用 SVG 配图讲清；`W(t)=W(0)` 说明无损耗 → 振幅不减。**此处只揭"等幅、按正弦规律往复、振幅不变"的现象层，不写出 `u_C=U₀cos(ω₀t)`、`ω₀=1/√(LC)` 的符号式**（`ω₀` 的定义放陈述时刻 1 给出，与预测表"陈述时刻 1 才给 ω₀"口径一致）。

### 环节 1 · 等幅振荡的定义 + 引入电阻（约 6′）

- **【陈述时刻 1 · 二阶电路与 LC 等幅振荡】**：全称、一句定义、符号式（见答案区）。
- **师**："等幅振荡是理想情况——真实电路里导线、电感线圈都有电阻，能量会被一点点耗掉。把电阻 R 串进来，会怎样？"
- **板书**：RLC 串联电路（页内自包含 SVG：R、L、C 串联，标 `u_C` 为求解量、电压源 `u_s`）。KVL 逐步写：`u_R+u_L+u_C=u_s`，`u_R=Ri=RC·du_C/dt`、`i=C·du_C/dt`、`u_L=L di/dt=LC·d²u_C/dt²` → **`LC u_C''+RC u_C'+u_C=u_s`**。零输入时右端为 0。
- **师**："这是二阶微分方程。沿用一阶的经验，猜解是 `Ke^(pt)`。"

### 环节 2 · 特征根与四种形态（约 12′）

- **板书推导（可见地被推出来）**：把 `u_C=Ke^(pt)` 代入齐次方程 → `(LCp²+RCp+1)Ke^(pt)=0` → **特征方程 `LCp²+RCp+1=0`**；令 `α=R/(2L)`、`ω₀=1/√(LC)` → **`p=−α±√(α²−ω₀²)`**。
- **问（预测 2，先想后揭）**："答案全在根号 `α²−ω₀²` 里。如果 α>ω₀、α=ω₀、α<ω₀、以及 R=0（α=0），根各是什么数、波形大概什么样？"（先让学生按四种情况表态，不揭晓）
- **揭晓（四种形态，陈述时刻 2）**：
  - `α>ω₀`（`R>R_c`）：根号为正 → 两个不等负实根 → 两个衰减指数相加 → **过阻尼**，单调回落不振荡；
  - `α=ω₀`（`R=R_c`）：重根 `p=−α` → `(A₁+A₂t)e^(−αt)` → **临界阻尼**，不振荡（它与过阻尼同为"非振荡"，是振荡与非振荡的分界；"快不快、过不过冲"的工程评价留预测 4 揭晓）；
  - `α<ω₀`（`R<R_c`）：共轭复根 `−α±jω_d` → `e^(−αt)(A cos ω_d t+B sin ω_d t)` → **欠阻尼**，衰减振荡/振铃；
  - `R=0`（`α=0`）：共轭虚根 `±jω₀` → 等幅正弦 → **等幅振荡**（回到预测 1）。
  - 临界电阻 `R_c=2√(L/C)`（由 `α=ω₀` 解出）。
- **面板 A 解锁**：形态预判台（滑块 R/L/C → `R_c`、`α`、`ω₀`、`α²−ω₀²`、特征根、形态判定、响应形式）。
- **李上例证**：`L=1H,C=1F → R_d=2Ω`，`R=3/2/1/0` 四个预设按钮分别演示四种形态（与面板默认值呼应）。

### 环节 3 · 二阶阶跃响应与过冲（约 12′）

- **师**："前面都是'电容自己带着初始能量放电'。工程里更常见的是'一开始没能量，突然合上开关加电源'——这叫**阶跃激励**。"
- **板书**：RLC 串联接直流阶跃 `u_s=U_s`（t>0），方程右端为常数 `U_s`；解 = 特解（稳态 `U_s`）+ 齐次通解（刚才那四种形态之一）。**形态仍由特征根定，与激励无关；阶跃只决定稳态值。**
- **问（预测 3，先想后揭）**："欠阻尼 RLC 加上阶跃，输出 `u_C` 从 0 往稳态值 `U_s` 爬。它会温和地爬到 `U_s` 停住，还是会冲过 `U_s` 再荡回来？"（冲过 / 不冲过 / 看情况）
- **揭晓（陈述时刻 3）**：欠阻尼会**冲过稳态值**——峰值高出稳态的部分叫**过冲（overshoot）**，随后在稳态附近来回衰减振荡叫**振铃（ringing）**，最后进入并稳定在稳态附近所需的时间叫**稳定时间**。给李上例7-5：`U_s=300V`，欠阻尼时峰值约 `516V`、上冲约 `216V`（定性认知，不重算其 ω）。
- **引入阻尼比 ζ（为量化过冲，学生第一次见，必须先定义）**："过冲多大，可以用一个无量纲的数来刻画，叫**阻尼比 ζ（damping ratio）**，定义为衰减系数与固有角频率之比 `ζ≡α/ω₀`。它把 R、L、C 三个参数合成一个数：ζ<1 欠阻尼、ζ=1 临界、ζ>1 过阻尼——和前面 `α` 与 `ω₀` 的比较是一回事。**本面板固定 `L=C=1`，故 `ω₀=1`、`ζ=α=R/2`**（这是面板特例；一般串联 RLC 用 `ζ=R/R_c`，练习 6 用的正是一般式，`ζ=R/2` 不是要背的结论）。" ζ 越大越接近临界、过冲越小。
- **面板 B 解锁**：阶跃响应过冲台（滑块 R、稳态值 U∞ → ζ、过冲百分比、峰值、峰值时刻、定性波形），默认 `L=1H,C=1F,R=1Ω,U∞=10V` → `α=0.5`、`ζ=α/ω₀=0.5`、过冲 `16.3%`、峰值 `11.63V`、峰值时刻 `3.63s`。
- **师拖动 R**：R 调小 → 过冲变大、振铃更久、稳定更慢；R 调到 2Ω（临界）→ 过冲消失（面板数值可直接读出；"这样是不是最好"留预测 4 揭晓，此处不下工程结论）。

### 环节 4 · 振铃的工程影响与边界（约 6′）

- **问（预测 4，先想后揭）**："既然过冲、振铃可能有害，那是不是把 R 加到过阻尼（不振荡）就一定最好？还有，'电阻越大越不易振铃'这句话，放到并联 RLC 也对吗？"（表态）
- **揭晓（陈述时刻 4）**：
  - 过阻尼无过冲但**恢复慢**；临界是"无过冲中最快"；工程常允许**少量过冲**（稍欠阻尼，ζ≈0.5~0.8）换更快的响应——看需求（能否容忍过冲/振铃、稳定时间要求）取舍，没有"永远最好"。
  - 边界："电阻越大越不易振铃"只在**串联 RLC**（`α=R/2L`）成立；**并联 GCL** 的一阶系数是电导 `G`（`α=G/2C`），**G 越大越阻尼**（等价于并联电阻 `R_p=1/G` 越小越阻尼）。把串联的结论原样搬到并联会出错。
- **师**："记住：先判共振形态，再谈工程好坏；形态由参数定，好坏由需求定。"

### 环节 5 · 实验台 + 独立练习（约 8′，形态一 + 形态二）

- 面板 A（形态预判台）四预设 + 拖动；面板 B（阶跃过冲台）拖动 R 看过冲/振铃变化。
- 再做 8 题（4 数值/形式 + 2 选择 + 2 文字），覆盖两形态、含特征根读形态、工程现象反推、对偶边界、取舍辨析，强调不是例题近邻复制。

### 环节 6 · 收尾与钩子（约 1′）

- 回扣核心问题："性格由 R、L、C 定——算 `R_c` 或比 `α` 与 `ω₀` 就能预判；欠阻尼过冲振铃、R 越小越明显；工程按需求选阻尼、注意串并联方向相反。" 抛 L3-04 s 域钩子。

### 独立练习（8 题，覆盖两形态，非近邻复制）

**形态一 · 给参数预判形态 + 读响应形式（例题给了 `L=1,C=1,R=3/2/1/0`，练习换参数/换给定量）**

1. RLC 串联 `L=1H, C=0.25F, R=5Ω`，求临界电阻 `R_c` 并判形态。（答 `R_c=2√(1/0.25)=4Ω`，`R>R_c` → 过阻尼）
2. 已知特征根 `p₁,₂=−3±j4`，判形态并写响应形式（填：形态 + "是否衰减振荡"）。（答：负实部共轭复根 → 欠阻尼，`u=e^(−3t)(A cos4t+B sin4t)`，衰减振荡/振铃）
3. `L=2H, C=2F, R=2Ω`，求 `R_c`、判形态并写出 `α`。（答 `R_c=2√(2/2)=2Ω=R` → 临界，`α=R/(2L)=0.5`，形式 `(A+Bt)e^(−0.5t)`）
4. `R=0, L=4H, C=1F`，判形态并求振荡角频率 `ω₀`。（答：无阻尼等幅振荡，`ω₀=1/√(4×1)=0.5 rad/s`）

**形态二 · 工程现象反推与边界取舍（例题没有的问法）**

5. 选择：某二阶阶跃响应在稳态值附近来回摆动、幅度越来越小，这是？①过阻尼 ②临界 ③欠阻尼 ④等幅。（答 ③）
6. 一个欠阻尼串联 RLC，把串联电阻 R 调小：过冲会变大还是变小？振铃持续更久还是更短？（答：R 小 → ζ 小 → 过冲更大、振铃持续更久、稳定更慢）
7. 选择：关于串联 RLC 与并联 GCL 的阻尼，正确的是？① 串联 R 越大越易振铃；② 并联 G 越大越易振铃；③ 串联 `R_s` 越大、并联电导 G 越大都让阻尼变大（并联电阻 `R_p=1/G` 越小越阻尼）；④ 两者完全相同。（答 ③）
8. 辨析（文字两空）："临界阻尼无过冲，所以工程上永远选临界最好"，对吗？说出一条理由；若系统允许少量过冲、追求更快响应，应选略偏哪种形态？（答：不对——临界是"无过冲中最快"，但允许过冲时稍欠阻尼上升更快，好坏看需求；应选略偏欠阻尼）

**过关线**：形态一 4 题至少对 3 题、形态二 4 题至少对 3 题，且第 2、7、8 题（特征根读形态、串并联对偶、工程取舍辨析）不得选错——那三题是把"形态由参数定、好坏由需求定、方向看串并联"真正内化的关键。

## 六、答案区（默认折叠；揭晓只到当前知识能解释的程度）

### 预测题答案（每题单独折叠，按提出时机解锁）

<details><summary>预测 1 揭晓（含陈述时刻 1）</summary>

**幅度不变、永远来回振荡（等幅振荡）**。无电阻即无能量损耗：电容放电把电场能转成电感的磁场能，电感电流不能突变又给电容反向充电，能量在两者间往返，储能 `W(t)=½Li²+½Cu²=W(0)` 恒定，所以振幅不衰减。`u_C=U₀cos(ω₀t)`，`ω₀=1/√(LC)`。

> **【陈述时刻 1 · 二阶电路与 LC 等幅振荡】**
> **全称/命名**：二阶电路（second-order circuit）；LC 等幅振荡（undamped / sustained oscillation）。
> **一句定义**：含两个独立储能元件（L 与 C）、需用二阶微分方程描述的电路叫二阶电路；只由 L、C 组成且无电阻时，储能在电场与磁场间往返转移而总量 `W=½Li²+½Cu²` 恒定，电压电流按正弦规律周而复始、振幅不衰减，称为等幅振荡。
> **符号式**：`W=½Li²+½Cu²=常数`；`ω₀=1/√(LC)`；`u_C=U₀cos(ω₀t)`。

〔邱 §7-5 印刷 p.154；李上 §7-1 / PDF 300–302〕

</details>

<details><summary>预测 2 揭晓（含陈述时刻 2）</summary>

四种情况对应四种根、四种形态：
- `α>ω₀`（`R>R_c`）：根号正 → 不等负实根 `p₁,p₂` → `u=A₁e^(p₁t)+A₂e^(p₂t)` → **过阻尼**（单调、不振荡）；
- `α=ω₀`（`R=R_c`）：重根 `p=−α` → `u=(A₁+A₂t)e^(−αt)` → **临界阻尼**（不振荡，振荡与非振荡的分界；工程快慢评价见陈述时刻 4）；
- `α<ω₀`（`R<R_c`）：共轭复根 `−α±jω_d`（`ω_d=√(ω₀²−α²)`）→ `u=e^(−αt)(A cos ω_d t+B sin ω_d t)` → **欠阻尼**（衰减振荡/振铃）；
- `R=0`（`α=0`）：共轭虚根 `±jω₀` → `u=A sin(ω₀t+β)` → **等幅振荡**。
临界电阻 `R_c=2√(L/C)`（即李上的阻尼电阻 `R_d`，由 `α=ω₀` 解出）。

> **【陈述时刻 2 · 特征根、四种阻尼形态与临界电阻】**
> **全称/命名**：特征方程/特征根（characteristic equation / roots）、四种阻尼形态、临界电阻（critical resistance）。
> **一句定义**：把 `u=Ke^(pt)` 代入二阶齐次方程得到的 `LCp²+RCp+1=0` 叫特征方程，其根 `p=−α±√(α²−ω₀²)`（`α=R/(2L)`、`ω₀=1/√(LC)`）叫特征根，只由 R、L、C 决定、与激励和初始储能无关；按 `α` 与 `ω₀` 的比较分为**过阻尼**（`α>ω₀`，不等负实根、单调）、**临界**（`α=ω₀`，重根、不振荡，是振荡与非振荡的分界）、**欠阻尼**（`α<ω₀`，共轭复根、衰减振荡/振铃）、**等幅**（`α=0`，共轭虚根、无衰减正弦）；分界电阻 `R_c=2√(L/C)`。（工程评价见陈述时刻 4，此处只判形态。）
> **符号式**：`p=−α±√(α²−ω₀²)`，`α=R/(2L)`，`ω₀=1/√(LC)`，`R_c=2√(L/C)`。

〔邱 §7-5 印刷 p.154–162；李上 §7-2 式 7-13/7-14/7-15、例7-1~7-4 / PDF 303–310〕

</details>

<details><summary>预测 3 揭晓（含陈述时刻 3）</summary>

**会冲过稳态值再荡回来（欠阻尼）**。阶跃响应的解 = 稳态特解 `U_s` + 齐次通解；欠阻尼的齐次项是衰减振荡，所以 `u_C` 边往 `U_s` 爬边围绕它摆动，第一次峰值超过 `U_s`——高出部分叫**过冲（overshoot）**，之后的来回衰减摆动叫**振铃（ringing）**，进入并保持在稳态附近所需时间叫**稳定时间**。李上例7-5：`U_s=300V`，峰值约 `516V`、上冲约 `216V`。

> **【陈述时刻 3 · 二阶阶跃响应、过冲与振铃、阻尼比】**
> **全称/命名**：二阶阶跃响应（step response）、过冲（overshoot）、振铃（ringing）、稳定时间（settling time）、阻尼比（damping ratio）。
> **一句定义**：二阶电路对直流阶跃激励的零状态响应 = 稳态特解 + 由特征根决定的齐次通解；欠阻尼时齐次项为衰减振荡，输出会**冲过稳态值**（峰值高出稳态的部分为过冲/上冲），并在稳态附近来回衰减摆动（振铃），经过一段稳定时间后进入并保持在稳态附近。**形态仍由特征根定、与激励无关，阶跃只决定稳态值。** 为量化过冲，定义**阻尼比 ζ≡α/ω₀**（无量纲）：ζ<1 欠阻尼、ζ=1 临界、ζ>1 过阻尼，与 α 和 ω₀ 的比较等价；ζ 越大过冲越小。
> **符号式**：`u(t)=稳态值 + e^(−αt)(A cos ω_d t+B sin ω_d t)`（欠阻尼）；过冲量 = 峰值 − 稳态值；`ζ=α/ω₀`（面板固定 `L=C=1` 时 `ζ=R/2`）。

〔邱 §7-7 印刷 p.166–169；李上 §7-3 例7-5 / PDF 312–314〕

</details>

<details><summary>预测 4 揭晓（含陈述时刻 4）</summary>

**不是永远最好；那句话只对串联成立**。过阻尼不振荡但恢复慢，临界是"无过冲中最快"，若系统允许少量过冲，稍欠阻尼响应更快——按需求取舍。而"电阻越大越不易振铃"只在**串联 RLC**（`α=R/2L`，R 大则阻尼大）成立；**并联 GCL** 一阶系数是电导 G（`α=G/2C`），G 越大越阻尼（并联电阻 `R_p=1/G` 越小越阻尼），把串联结论照搬会出错。

> **【陈述时刻 4 · 阻尼的工程取舍与串并联边界】**
> **全称/命名**：阻尼的工程取舍；串联 RLC 与并联 GCL 的对偶（duality）。
> **一句定义**：过阻尼无过冲但恢复慢、欠阻尼快但有过冲振铃、临界是"无过冲中最快"；工程上按能否容忍过冲/振铃与稳定时间要求选阻尼，常取稍欠阻尼折中，没有"永远最好"。串联 RLC 的阻尼由 `α=R/(2L)` 决定（R 越大越阻尼）；对偶的并联 GCL 由 `α=G/(2C)` 决定（电导 G 越大越阻尼，等价于并联电阻 `R_p=1/G` 越小越阻尼）——"电阻越大越不易振铃"只适用于串联，不能照搬到并联。
> **符号式**：串联 `α=R/(2L)`；并联 `α=G/(2C)=1/(2R_p C)`。

〔李上 §7-3 例7-5、§7-4 式 7-17 / PDF 314、317；邱 §7-7（过阻尼过渡）印刷 p.168–169；工程取舍为〔通识〕〕

</details>

### 陈述时刻汇总（供页面做显式化定义卡，均在对应揭晓之后出现）

1. **二阶电路 / LC 等幅振荡**：`W=½Li²+½Cu²` 恒定、`ω₀=1/√(LC)`、`u_C=U₀cos ω₀t`。〔邱 §7-5；李上 §7-1〕
2. **特征根 / 四种形态 / 临界电阻**：`p=−α±√(α²−ω₀²)`，四形态判据，`R_c=2√(L/C)`。〔邱 §7-5；李上 §7-2〕
3. **阶跃响应 / 过冲 / 振铃 / 稳定时间 / 阻尼比 ζ**：`u=稳态+e^(−αt)(A cos ω_d t+B sin ω_d t)`，过冲=峰值−稳态；`ζ=α/ω₀`，ζ<1 欠阻尼、ζ=1 临界、ζ>1 过阻尼（面板固定 L=C=1 时 ζ=R/2）。〔邱 §7-7；李上 §7-3〕
4. **工程取舍 / 串并联对偶**：临界无过冲最快、稍欠阻尼折中；串联 `α=R/2L`、并联 `α=G/2C`。〔李上 §7-3/§7-4；通识〕

### 实验台默认数值（自编，已独立验算自洽）

- **面板 A（形态预判台）**：滑块 R(Ω)、L(H)、C(F)；显示 `R_c=2√(L/C)`、`α=R/(2L)`、`ω₀=1/√(LC)`、`Δ=α²−ω₀²`、特征根 `p₁,p₂`、形态、响应形式。
  - 默认 `L=1H, C=1F, R=3Ω` → `R_c=2Ω`、`α=1.5`、`ω₀=1`、`Δ=1.25>0` → `p=−1.5±√1.25=−0.382/−2.618` → **过阻尼**，形式 `A₁e^(p₁t)+A₂e^(p₂t)`。（对应李上例7-1）
  - 预设 R=2 → `Δ=0`、`p=−1` 重根 → 临界；R=1 → `α=0.5`、`ω_d=√0.75≈0.866`、`p=−0.5±j0.866` → 欠阻尼；R=0 → `α=0`、`p=±j` → 等幅。
  - 拖动任意滑块按同一组公式联动；改 L/C 会改变 `R_c`。
- **面板 B（阶跃响应过冲台）**：`L=1H, C=1F` 固定，滑块 R(Ω, 0.2~2)、U∞(V, 稳态值)。欠阻尼（`R<2`）时：`ω₀=1`、`α=R/2`、`ζ=α/ω₀=R/2`、`ω_d=√(1−α²)`、过冲 `M_p=e^(−απ/ω_d)×100%`、峰值时刻 `t_p=π/ω_d`、峰值 `=U∞(1+M_p)`；`R≥2` 无过冲。
  - 默认 `R=1Ω, U∞=10V` → `α=0.5`、`ζ=0.5`、`ω_d=√0.75≈0.866`、`M_p=e^(−0.5π/0.866)≈16.3%`、`t_p≈3.63s`、峰值 `≈11.63V`。
  - 联动校验：R=0.4 → `ζ=0.2`、`M_p≈52.7%`、峰值≈15.27V；R=1.6 → `ζ=0.8`、`M_p≈1.5%`；R=2 → 临界、过冲 0。**面板按上述公式计算并显示过冲百分比/峰值/峰值时刻的具体数值（供学生观察 ζ 与过冲的趋势），但不展示 M_p 解析式、不要求学生记公式。**

### 独立练习答案

1. `R_c=2√(L/C)=2√(1/0.25)=4Ω`；`R=5Ω>R_c` → 过阻尼。
2. `p=−3±j4` 为负实部共轭复根（`α=3`、`ω_d=4`）→ 欠阻尼；`u=e^(−3t)(A cos4t+B sin4t)`，衰减振荡/振铃。
3. `R_c=2√(2/2)=2Ω=R` → 临界；`α=R/(2L)=2/4=0.5`；形式 `(A+Bt)e^(−0.5t)`。
4. `R=0` → 无阻尼等幅振荡；`ω₀=1/√(LC)=1/√4=0.5 rad/s`。
5. ③（欠阻尼）。摆动且幅度衰减是欠阻尼的特征；过阻尼/临界不摆动，等幅幅度不衰减。
6. R 调小 → `ζ=α/ω₀=R/R_c`（一般串联 RLC；面板 L=C=1 时 `R_c=2`，即 `ζ=R/2`）变小 → 过冲变大、振铃持续更久（稳定更慢）。（本题不依赖面板特定数值，用一般式 `ζ=R/R_c` 判趋势即可。）
7. ③。串联 `α=R/2L`（R 大→阻尼大）；并联 `α=G/2C`（G 大→阻尼大，即 `R_p=1/G` 小→阻尼大）。①把串联方向说反、②把并联方向说反、④忽略对偶差异。
8. 不对：临界是"无过冲中最快"，但允许过冲时稍欠阻尼上升更快，好坏看需求（能否容忍过冲/振铃、稳定时间）；应选略偏**欠阻尼**。

## 八、给前端的实现约束

1. **开场只显示核心问题 + 预测 1**；学习目标、节奏、来源台账、P1/P2/P3 标签放页尾折叠区；**不出现"特征根、过阻尼/欠阻尼、α、ω₀、R_c、p=−α±…、过冲/振铃定义、对偶"等术语与符号**。
2. **严格揭示顺序**：预测 1（揭能量往返/等幅 → 陈述时刻 1）→ 预测 2（推特征根四形态、`R_c` → 陈述时刻 2，解锁面板 A）→ 预测 3（阶跃过冲/振铃 → 陈述时刻 3，解锁面板 B）→ 预测 4（工程取舍/对偶边界 → 陈述时刻 4）→ 练习。每个预测先选定才解锁揭晓；四个陈述卡一律在对应揭晓**之后**才出现（gated），绝不提前显示。此顺序与第四节脚本、第五节预测表三者一致。
3. **四个陈述时刻显式化**：全称 + 一句可抄写定义 + 符号式；陈述时刻 2 必须写清四形态判据与"特征根只由 R/L/C 定、与激励初值无关"，且**此处不得出现"临界最快/无过冲最快"等工程评价**（那是陈述时刻 4 的内容，提前出现会泄预测 4 的底）；陈述时刻 3 必须写"形态与激励无关、阶跃只定稳态值"，并给出**阻尼比 ζ=α/ω₀ 的显式定义**（ζ 首次出现须当堂定义，面板固定 L=C=1 时 ζ=R/2）；陈述时刻 4 必须写对偶方向（串联 `α=R/2L`、并联 `α=G/2C`）与"没有永远最好"。
4. **图示自包含**：至少 5 张页内 SVG——① LC 能量往返（电容↔电感四阶段，配 `W` 恒定）；② RLC 串联电路 + KVL 推二阶方程；③ 四种形态波形对照（单调/临界/衰减振荡/等幅，同坐标示意）；④ 二阶阶跃响应过冲示意（稳态线、峰值、过冲、振铃、稳定时间标注）；⑤ 串联 RLC 与并联 GCL 对偶对照（R/G 位置与阻尼方向）。不引用书内图号（书内图号只可在页尾来源说明出现）。
5. **图示版式**：文字/操作在左、示意图在右并排（窄宽自动换行）；按信息量用 sm/md/lg 档，最大 ≤520 px，图中文字清晰可读；波形 SVG 用简洁曲线示意、不追求精确比例。
6. **实验台**：A 面板 R/L/C 滑块 → `R_c/α/ω₀/Δ/特征根/形态/响应形式` 联动 + 四预设（R=3/2/1/0）；B 面板 R/U∞ 滑块 → `ζ/过冲%/峰值/峰值时刻/定性波形` 联动，`R≥2` 显示"无过冲"。默认值按第六节（A 过阻尼 `p=−0.382/−2.618`；B `R=1,U∞=10`→过冲 16.3%/峰值 11.63V），改滑块按同一公式联动、口径一致。
7. **练习判定**：8 题（4 数值/形式 + 2 选择 + 2 文字），多空题全填才判定；进度计数 8/8；错题 `fb bad`；`resetFlow` 重锁 4 个预测门并清空反馈/输入/选项/面板与预设状态。
8. **疑问锚点**：7 个环节预留 `QA:stage-0..6` 标记对；真实卡点（无电阻为何等幅、`α²−ω₀²` 正负为何决定形态、临界为何"无过冲最快"、阶跃为何只定稳态值、过冲/振铃与 R 的关系、并联 GCL 方向为何相反）才挂标签，不预置凑数问答。

## 一 · 核心问题（贯穿全篇，只有一个）

**前七课我们都把正弦频率 ω 当成"给定的一个数"来算功率、算相量；可如果让这个频率从低到高连续变化，同一个 RC 电路的输出大小和相位为什么会跟着变？我们怎样用一个 `H(jω)` 把这种变化算出来、画成"频率—输出"的关系图，并凭它判断这个电路是"放行"还是"挡掉"某些频率？**

学生学完要能自己复述这句话，并覆盖两种任务形态：

- **形态 A（由 H 定量求响应）**：给出 RC 电路（R、C）和输入正弦信号的频率与初相，写出网络函数 `H(jω)`，求截止频率 `ω_c=1/RC`、幅值比 `|H|`、相移 `φ`，再用配方 `U_o=|H|U_i`、`ψ_o=φ+ψ_i` 写出输出时域式。（李下例 10-3）
- **形态 B（读频响/波特图作判断）**：给一条幅频曲线、一个 `H(jω)` 表达式或一张波特图，判断它是低通还是高通、截止频率在哪、某个频率下输出是被通过还是被抑制、相位是超前还是滞后；并能说出"−3 dB 点""−20 dB/dec"分别指什么。（邱 §11-5、§11-6）

## 二 · 讲什么 / 不讲什么

**讲（P1 必会）**：频率响应（幅频/相频）的定义；网络函数 `H(jω)=响应相量/激励相量`（与输入幅值无关，只随 ω 变）；RC 低通 `H_LP=1/(1+jωRC)=1/(1+jx)`（`x=ω/ω_c`）、`|H|=1/√(1+x²)`、`φ=−arctan x`；RC 高通 `H_HP=jωRC/(1+jωRC)`、`|H|=x/√(1+x²)`、`φ=90°−arctan x`；截止频率 `ω_c=1/RC`（`|H(ω_c)|=0.707`、`φ(ω_c)=∓45°`、半功率点）；由 H 求响应配方 `U_o=|H|U_i`、`ψ_o=φ+ψ_i`；分贝 `L(ω)=20lg|H|`、`−3 dB` 点；一阶幅频渐近线 `0 dB` 平台 + `−20 dB/dec`，相频 `0°→−90°` 过渡。

**讲（P2 应会）**：通带 / 阻带 / 截止频率的工程含义；低通 / 高通 / 带通 / 带阻四类滤波器的频率位置地图；"滞后网络（低通）"与"超前网络（高通）"的相位标签；`τ=RC ↔ ω_c=1/τ` 与 L2-03 一阶暂态时间常数的对偶；用对数频率作横轴的动机（宽频段压缩与折线化）。

**不讲**：RLC 串联/并联谐振条件、品质因数 Q、选择性与带宽、谐振时过电压过电流（L2-09 主课，本课只用"谐振=尖锐选频"作钩子）；二阶因子 `±40 dB/dec`、`±90°/dec` 与多因子波特图叠加细节（邱 §11-5 后半，留到 L2-09 后）；傅里叶级数与非正弦周期信号的完整分解、多频叠加的数值求法（L3-05）；滤波器逼近与有源滤波器设计细节（邱 §11-6 只给工程地图，不设计）。

**下一课钩子**：本课的一阶 RC 频率选择是"平缓的"——幅频从 0 dB 慢慢拐下去。若把 L 和 C 一起放进来，会在某一个特定频率上出现阻抗抵消、响应突然冲出一个尖峰（或陷谷），"平缓选择"升级成"尖锐选频与放大"。下一课讲谐振入门与二阶直觉。

## 三 · 因果顺序（不是时间安排）

L2-07 在**固定频率**下把相量和功率算清了。next question：**让频率 ω 自己变，同一个电路的响应会怎么变？** 推理链：

1. 先建立物理直觉（李下 §10-2）：一个 RC 串联电路，输出取在电容两端——直流（`ω=0`）时 C 开路，`Ū_o≈Ū_i`；频率极高时 C 近似短路，`Ū_o≈0`。**学生先看见"频率真的能改变输出"，才有动机引入描述它的函数**。（不需要新公式，用 L2-05 学过的 `Z_C=1/(jωC)` 即可。）
2. 要把"随频率变"说清楚，需要一个以 ω 为自变量的函数：网络函数 `H(jω)=响应相量/激励相量`（邱 §11-1）。**关键性质**：它是电路结构与参数决定的，与输入幅值无关；它是复数——模是幅值比、辐角是相移（邱 §11-1、李下 §10-2）。陈述时刻 ①。
3. 用分压把低通的 H **推出来**（不让学生背）：`H_LP=Z_C/(R+Z_C)=1/(1+jωRC)`；令 `x=ω/ω_c`、`ω_c=1/RC`，化成 `H=1/(1+jx)`，得 `|H|=1/√(1+x²)`、`φ=−arctan x`（李下例 10-3）。再由 H 求响应的配方 `U_o=|H|U_i`、`ψ_o=φ+ψ_i`，带做李下例 10-3（`τ=10⁻³ s`、`u_i=2.5√2cos(500πt+30°)` → `u_o≈1.35√2cos(500πt−27°)`）。预测 1 在此揭晓（低通：频率越高输出越小）。
4. 观察 `|H|` 曲线：`x=0` 时 1、`x=1` 时 0.707、`x→∞` 时 0。**为什么偏偏是 0.707？** 因为功率∝电压²，`0.707²≈0.5`，这个点是"半功率点"。陈述时刻 ②：截止频率 `ω_c=1/RC`。预测 2（半功率点处**功率**降到多少）在此揭晓。
5. **对偶一步**：把输出改从电阻 R 取（C 串在通路里），`H_HP=jωRC/(1+jωRC)`，`x=0` 时 0、`x→∞` 时 1、`x=1` 时仍 0.707——无 gate 部分**只推幅值互补**。接着先提出预测 3（高通在 `ω_c` 的相位），选定解锁后**才在揭晓块内**推相移 `φ=90°−arctan x`、`x=1 → +45°`（超前），并给出陈述时刻 ③：高通 / 超前网络。低通高通共用同一个 `ω_c`、同一条 0.707，只是"倒过来"——这是本课的第二个支点。
6. **为什么要波特图**：直接画 `|H|−ω`，ω 跨几个数量级时低频段挤在一起看不清。改用对数横轴 `lg ω` + 分贝纵轴 `20lg|H|`（邱 §11-5），宽频段被压缩、一阶曲线还能用折线逼近：折点前 `0 dB`、折点后 `−20 dB/dec`，折点真值比渐近线低 `3 dB`。陈述时刻 ④：分贝与一阶波特图渐近线。预测 4（一阶斜率 −20 dB/dec）在此揭晓。
7. 最后给工程地图：通带 / 阻带 / 四类滤波器（邱 §11-6），用 L、C 互补的频率特性解释"为什么能选频"。陈述时刻 ⑤：滤波器分类。`τ=RC ↔ ω_c=1/τ` 在此回扣 L2-03。

**为什么先低通、后高通、再波特图**：低通把 `H→|H|/φ→ω_c→配方` 这条主线完整走一遍；高通只做"对偶迁移"，学生能自己推出，训练迁移而非再背一遍；波特图是"换一把尺子看同一条曲线"，必须在学生已经理解 `|H|` 曲线之后引入，否则会变成机械折线规则。

## 四 · 教学环节（预测先提后揭；每环节写明"提出—推导—揭晓"顺序）

### 环节 0：核心问题与预测 1（约 3′）

- 开场只写核心问题。给场景：同一个 RC 串联电路，输出取在电容两端，输入正弦电压幅度固定不变，只把频率从很低慢慢升到很高。
- **先预测 1（只收选项，不公布）**：输出幅度会怎么变？① 基本不变；② 越来越小；③ 越来越大。**选定后才解锁揭晓**，现在别翻答案。
- 明确电路的取法（输出在 C 上），避免"RC 电路"指代不清导致答案不唯一。
- 【QA 锚点】若学生答"取决于 R、C"，肯定其直觉（确实取决于 ω_c 在哪），但强调趋势与 R、C 具体值无关——真实卡点，不预置。

### 环节 1：网络函数 H(jω)（约 8′）

- 铺垫（无 gate，板书可见）：用 `Z_C=1/(jωC)`（L2-05 已学）看极端——`ω=0` 时 `Z_C→∞`（C 开路）输出≈输入；`ω→∞` 时 `Z_C→0`（C 短路）输出≈0。**频率真的在改变输出。**
- 引入：要精确描述"输出随频率怎么变"，需要 `H(jω)=响应相量/激励相量`（邱 §11-1）。它只由电路结构与参数决定，**与输入幅值无关**；输入同端口时就是阻抗/导纳（驱动点函数），不同端口时是转移函数，本课聚焦转移电压比 `Ū_o/Ū_i`。
- 陈述时刻 ①：**网络函数（network function）H(jω) 与幅频 / 相频特性**——`H(jω)=Ū_o/Ū_i`（输出相量与输入相量之比），是描述正弦稳态下电路传输特性的复函数；其模 `|H(jω)|` 与 ω 的关系叫**幅频特性**，辐角 `φ(ω)=arg H(jω)` 与 ω 的关系叫**相频特性**，二者合起来就是电路的**频率响应**。条件：线性时不变、正弦稳态、输入输出须同为电压（或同为电流）相量；H 与输入幅值无关，只随 ω 变。
- 由 H 求响应的配方（李下 §10-2）：`Ū_o=H(jω)Ū_i`，即 `U_o=|H|U_i`、`ψ_o=φ+ψ_i`（有效值相量写时域式时乘 `√2`）。页内 SVG ① 给出 RC 低通电路与它的 |H|、φ 曲线示意。

### 环节 2：推出低通 H，带做例 10-3，揭晓预测 1（约 10′）

- 推导（无 gate，板书可见）：`H_LP=Z_C/(R+Z_C)=(1/jωC)/(R+1/jωC)=1/(1+jωRC)`；令 `x=ω/ω_c`、`ω_c=1/RC`，则
  `H_LP=1/(1+jx)=[1/√(1+x²)]∠[−arctan x]`，故 `|H|=1/√(1+x²)`、`φ=−arctan x`。
- **陈述时刻 ① 的符号式在此落地**（复述 `|H|=1/√(1+x²)`、`φ=−arctan x` 与默认曲线）。
- 带做（形态 A，李下例 10-3）：`τ=RC=10⁻³ s` ⇒ `ω_c=1000 rad/s`；输入 `u_i=2.5√2cos(500πt+30°) V`，`ω=500π≈1571 rad/s`，`x=1.571`，`|H|≈0.537`、`φ≈−57.5°`（书取 `0.54`、`−57°`）；`U_o≈1.34 V`（书 `1.35 V`）、`ψ_o=30°−57.5°≈−27.5°`（书 `−27°`），故 `u_o≈1.35√2cos(500πt−27°) V`。**明确**：书的 `0.54/−57°/1.35/−27°` 是"由图或式得"的读数与截断（`30°−57°=−27°`），精确值 `0.537/−57.5°/1.34/−27.5°` 与之**在图示读数精度内一致**；不要把 `57.5°` 先四舍五入成 `58°` 再相减（那会得到 `−28°`）。
- 揭晓 gate（预测 1）：选②。`|H|=1/√(1+x²)` 随 x 单调下降，`ω=0` 时输出最大且等于输入，`ω→∞` 时输出→0——低频易通过、高频被抑制，这就是**RC 低通（滞后网络）**。选③错在把它和高通搞反。
- 互动面板 A 在此使用（"低通/高通"两标签，"RC 低通"为默认）。

### 环节 3：截止频率与半功率点，揭晓预测 2（约 7′）

- 观察（无 gate）：`x=0 → |H|=1`；`x=1 → |H|=1/√2≈0.707`；`x→∞ → |H|→0`。`x=1`（即 `ω=ω_c`）是幅频从"近乎 1"转入"明显下降"的分界点。相频在 `x=1` 处 `φ=−45°`，并随 `x` 从 0 到∞ 单调从 `0°` 趋向 `−90°`（输出始终滞后输入）。
- **先预测 2（在命名"半功率点"之前提出，不揭晓）**：已知 `ω=ω_c` 处输出**幅度**已降到 `1/√2≈0.707`。那么输出**功率**降到输入的多少？① 1/2；② 1/√2；③ 1/4。**选项中不含答案注解**；作答阶段一律不公布正确答案，选定后才解锁揭晓块。
- 陈述时刻 ②：**截止频率（cut-off frequency）ω_c 与半功率点**——`ω_c=1/RC=1/τ`，是低通电路幅频降到 `|H|=1/√2≈0.707`（相移 `−45°`）处的频率；因平均功率 ∝ 电压有效值平方，`P_o/P_i=|H|²=1/2`，故又称半功率点；`0~ω_c` 定为通频带（通带）。条件：一阶 RC 低通；对高通 `ω_c` 同式、`|H(ω_c)|` 仍 0.707（**高通的相移留到环节 4 预测 3 揭晓后再给出，此处不预告**）；`τ=RC` 正是 L2-03 一阶暂态时间常数，`ω_c=1/τ` 是它在频域的倒数。
- 揭晓 gate（预测 2）：选①，功率降到 `1/2`。因为功率 ∝ 电压²，`P_o/P_i=|H|²=(1/√2)²=1/2`——"半功率点"由此得名，指的是**功率**减半而不是幅度减半。选②错在把功率当成幅度（1/√2）；选③错在以为幅度先降到 1/2 再平方（实际幅度是 1/√2）。

### 环节 4：高通对偶，揭晓预测 3（约 7′）

- **先预测 3（在推出高通相移之前提出，不揭晓）**：低通在 `ω=ω_c` 相移是 `−45°`；若把输出改从电阻 R 取（C 串在信号通路里）构成高通，同一频率 `ω_c` 下输出相位是？① `−45°`；② `0°`；③ `+45°`。选定后解锁揭晓。
- 幅值推导（无 gate，板书可见；**此处只推模，不出现任何相移结论**）：输出取 R 上，`H_HP=R/(R+1/jωC)=jωRC/(1+jωRC)=jx/(1+jx)`，取模得 `|H_HP|=x/√(1+x²)`。极端：`x=0 → |H|=0`；`x→∞ → |H|→1`；`x=1 → |H|=0.707`。页内 SVG ② 并排对比低通/高通**幅频**曲线（一条递减、一条递增，交于 `x=1, |H|=0.707`）——幅值互补已经看得见，相位留到揭晓。
- **揭晓 gate（预测 3）块内（选定后才可见）——`+45°` 在此首次出现**：
  - 相移推导（板书可见）：`H_HP=jx/(1+jx)` 的分子 `jx` 相角是 `90°`、分母 `1+jx` 相角是 `arctan x`，故 `φ=90°−arctan x`。`x=1` 时 `φ=90°−45°=+45°`，故选③；`x→0` 时 `φ→+90°`，`x→∞` 时 `φ→0°`。低通 `φ=−arctan x`，高通 `φ=90°−arctan x`，在 `x=1` 分别是 `−45°`、`+45°`——相位也互补。选①错在以为换输出端不影响相位；选②错在忽略电容引入的 90° 相移。
  - 陈述时刻 ③：**RC 高通电路（超前网络）**——输出取在电阻端的一阶 RC 电路，`H_HP=jωRC/(1+jωRC)`，`|H|=x/√(1+x²)`、`φ=90°−arctan x`，`ω_c=1/RC` 处 `|H|=0.707`、`φ=+45°`；高频易通过、低频被抑制，输出超前输入，故又称**超前网络**。条件：一阶 RC、输出取 R；与低通共用同一个 `ω_c`，幅频"互补"、相移一负一正。
- 互动面板 A 的"RC 高通"标签**在预测 3 揭晓后才解锁**（作答阶段标签禁用，避免提前暴露 `+45°`）；解锁后默认值 `R=1kΩ/C=1µF/ω=ω_c` → `|H|=0.707`、`φ=+45°`，作为揭晓后的验证工具。

### 环节 5：分贝与一阶波特图，揭晓预测 4（约 8′）

- 铺垫（无 gate）：直接画 `|H|−ω`，ω 从 1 到 10⁵ rad/s 时低频段全挤在左端。工程上换两把尺子（邱 §11-5）：横轴用对数频率 `lg ω`（每十倍频等距），纵轴用分贝 `L(ω)=20lg|H|`。`|H|=1 → 0 dB`；`|H|=0.707 → −3 dB`（因为 `20lg0.707≈−3`）；`ω_c` 正是 `−3 dB` 点。
  - **为什么是 20 而不是 10（此处可见地推一遍）**：环节 3 已建立 `P∝U²`，即功率比 `P_o/P_i=|H|²`。分贝的定义本来是针对**功率比**取 `10lg`，于是 `L=10lg(P_o/P_i)=10lg(|H|²)=20lg|H|`——系数 20 来自"电压平方就是功率比"，不是要背的新规则。（过关自检⑤要学生说出的正是这条链。）
- **先预测 4（在给出斜率规则之前提出，不揭晓）**：一阶低通在 `ω>ω_c` 之后，幅度按每十倍频程下降多少 dB？① `−20 dB/dec`；② `−3 dB/dec`；③ `−40 dB/dec`。选定后解锁揭晓。
- 推导（板书可见）：`H_LP=1/(1+jx)` 的一阶折线——`x≪1` 时 `|H|≈1 → L≈0 dB`（水平线）；`x≫1` 时 `|H|≈1/x → L≈−20lg x`，即每十倍频降 `20 dB`（`−20 dB/dec`）。两段在 `x=1` 相交，真值 `−3 dB` 比折点低 3 dB（**折线是近似**）。相频在 `0.1ω_c~10ω_c` 之间近似以 `−45°/dec` 从 `0°` 过渡到 `−90°`。页内 SVG ③（在面板 B 内）画一阶低通幅频渐近线 + 真值曲线。
- 陈述时刻 ④：**分贝与一阶波特图渐近线**——幅频波特图纵轴 `L(ω)=20lg|H(jω)|`（单位 dB），横轴为对数频率 `lg ω`；一阶因子 `1/(1+jω/ω_c)` 的幅频渐近线在 `ω<ω_c` 为 `0 dB`、`ω>ω_c` 为 `−20 dB/dec`，折点 `ω_c` 处真值 `−3 dB`；相频渐近线在 `0.1ω_c~10ω_c` 以 `−45°/dec` 过渡。条件：一阶因子；`20lg` 用于幅值比、源于 `10lg(P_o/P_i)=10lg|H|²=20lg|H|`（功率比本身用 `10lg`）；渐近线是近似，折点附近须用真值修正。
- 揭晓 gate（预测 4）：选①，`−20 dB/dec`。原因：`x≫1` 时 `|H|≈1/x`，`20lg(1/x)=−20lg x`，x 每乘 10 就降 20 dB。②把折点的 `−3 dB` 误当斜率；③是二阶因子的斜率（本课不讲，L2-09 后再说）。
- 互动面板 B 在此使用（"波特图 / 分贝"台）。

### 环节 6：滤波器分类与过关（约 7′）

- 工程地图（邱 §11-6）：能"按频率筛选"的网络叫滤波器，希望保留的频段是**通带**、希望抑制的是**阻带**。四类：低通（`0~ω_c` 通过）、高通（`ω_c~∞` 通过）、带通（只过谐振点附近）、带阻（只挡谐振点附近）。物理根据：L 的阻抗 `jωL` 随 ω 增大、C 的阻抗 `1/(jωC)` 随 ω 减小，二者互补，搭配即可选频。页内 SVG ④ 画四类通带示意。
- 陈述时刻 ⑤：**滤波器（filter）与四种类型**——滤波器是具有选频功能的网络，使通带内的频率分量顺利通过、阻带内被抑制；按通带位置分为低通、高通、带通、带阻四类。条件：本课只定量处理一阶 RC 低通/高通；带通/带阻要等 L2-09 讲了谐振才能理解其"附近"的含义；工程上 LC 无源滤波体积大，实际常用运放构成 RC 有源滤波器实现集成（邱 §11-6，设计细节不讲）。
- 独立练习 9 题（全部换参数或换问法，非例题近邻复制）+ 过关自检。
- 下一课钩子：一阶 RC 的选频是平缓的；引入 L 与 C 一起，会在某特定频率出现阻抗抵消的尖峰/陷谷——谐振与二阶直觉。

## 六 · 答案区（默认折叠，不提前泄露后续推导）

- 预测 1：②，低通 `|H|=1/√(1+x²)` 随 ω 单调下降；选③与高通混淆。
- 预测 2：①，功率降到 `1/2`（`P_o/P_i=|H|²=(1/√2)²`）；②误把功率当成幅度，③误以为幅度先降到 1/2。
- 预测 3：③，高通 `φ=90°−arctan x`，`x=1` 时 `+45°`。
- 预测 4：①，一阶 `−20 dB/dec`（`|H|≈1/x → 20lg=−20lg x`）；②误把 −3dB 当斜率，③是二阶。
- 练习：1 ①（输出取 R 端→高通，频率升高输出增大）；2 `2000/1/0.707/7.07`；3 `0.447/−63.43/4.47/−33.43`；4 `1000/低`；5 `0.707/+45/3.54`；6 `−20.04/−20`；7 ②；8 `0.707/−45/1.41/低`；9 `高/0.447/+63.43`（`RC=1ms`、`ω_c=1000`、`x=0.5`，高通 φ=90°−arctan0.5）。

# L3-02 教案：运放作为电路元件（电阻电路视角）

> S3 第二课 · 前置 L1-E（S1 阶段考核，电阻电路 / 节点法 / 受控源已过关）· 45 分钟预算（因果链完整前提下）· 教案先行，独立审核通过前不得写 HTML。
> 本课只把运放当成**用受控源建模的多端电路元件**，在已学的电阻电路框架里分析它；不碰器件内部、不碰频率特性。

---

## 一、核心问题（一个，贯穿全篇）

**运算放大器内部有成千上万个晶体管，能不能完全不管它的内部、只靠"两条简单规则"就把各种运放电路（反相放大、同相放大、跟随、相加）的输出算出来？这两条规则从哪里来、为什么成立、又在什么情况下会失效？**（"虚短 / 虚断"是这两条规则的名字，正式术语与定义在预测 1 揭晓时才给出；开场只用"两条简单规则"这一待解问题本身，不出现术语。）

这句话覆盖本课两种任务形态：

- **形态一 · 读图列式与计算**：给一张画好的运放电路（电阻标好），用两条规则 + 在**输入节点**列 KCL，算出输出电压与增益。核心是"看懂电路，列对方程，算对数值与符号"。
- **形态二 · 需求反推与适用边界辨析**：给一个需求（"要增益 −3，怎么选电阻""分压后面带重负载，插什么电路不拉低分压比"）或一个陷阱说法（"虚短就是两输入端真的短接，有电流流过""不管什么情况都能用虚短"），自己选组态、反推电阻、辨清"两条规则只在**线性区 + 负反馈**下成立，饱和时失效"。核心是"没有现成电路也能设计，且知道规则什么时候不能用"。

学生学完应能自己说出："这节课解决的是——把运放当元件，用理想化换来的虚短虚断两条规则，在分析各种电阻-运放电路时列式算输出、按需求选电路，并知道饱和时这两条规则不能用。"（这句是学习目标，放页尾折叠区，不在开场显示。）

## 二、讲什么 / 不讲什么（边界与留白）

**讲**：
1. 运放的外部特性与受控源模型（VCVS：输出受差分输入控制、单向器件）；为什么从电路分析角度"只看外部、不看内部"（§5-1）；
2. 差分输入关系 `u_o=A(u_+−u_-)`、外特性（线性区 vs 饱和）；
3. 理想运放三条件 `A→∞、R_i→∞、R_o→0` 与线性区（闭环负反馈）→ **虚断 `i_+=i_-=0`、虚短 `u_+=u_-`**（本课 P1 核心，陈述时刻 1）；
4. 两条规则 + 在**输入节点**列 KCL 的分析方法（输出节点不列 KCL 的纪律）；
5. 四种组态增益：反相 `−R₂/R₁`、同相 `1+R₂/R₁`、跟随器 `1`（隔离作用）、加法（等电阻）`−(u₁+…+u_n)`（P1 落点）；
6. 饱和只做"认知 + 边界"提示：虚短虚断的适用前提是线性区（输出不饱和）。

**不讲**（留白，钩子）：
- 运放内部晶体管电路、偏置电源的细节（§5-1 一句话带过存在，不展开）；
- 频率特性、带宽、压摆率、失调与温漂（P3，本课是纯电阻视角，信号视为直流 / 低频）；
- 精确式 `u_o=−A R₂ R_i /[R_i(R₁+R₂)+R_o(R₁+R_i)+A R₁R_i] u_i`（§5-2）只口头说明"它证明比值与外部电阻有关、与 A 几乎无关"，不要求记、不进练习；
- 积分 / 微分运算电路、有源滤波器（涉及动态元件，L3 后续与 S4）；
- 非线性应用（比较器、施密特触发器、正反馈 / 饱和工作，邱 ＊§17-6），本课只把饱和当边界提示，不做定量设计。

**下一课钩子**：L3-03 二阶电路响应形态。今天我们用"理想化条件"换来运放的虚短虚断；前面的 L2-10 已经预告过二阶形态——下一课把 RLC 二阶方程的特征根与过阻尼/欠阻尼/等幅形态系统解出来，同样是"抓住模型的关键参数，就抓住电路的性格"。

## 三、概念依赖链（每一步"因为上一步不够用"才引入）

1. **电阻电路 + 节点法 + 受控源**（L1-E 已学）：已经会列节点方程、会用 VCVS。→ 但运放是一个有 5 个端子的新器件、内部成千晶体管，若逐个晶体管列方程根本没法算。**引入：只看外部特性，把运放建成 VCVS 模型**（§5-1）。
2. **受控源模型** `u_o=A(u_+−u_-)`，带三个参数 A（增益）、R_i（输入电阻）、R_o（输出电阻）。→ 列节点方程要带着这三个参数一起算，式子很繁。实际参数又非常极端（A≈10⁵~10⁷、R_i 极大、R_o 很小）。→ 能不能把它们推到极限来简化？**引入思想实验：预测 1**。
3. **预测 1 揭晓**：A→∞ 且输出有限（`u_o` 受电源限制在 ±U_sat 内）→ 逼出 `u_d=u_+−u_-→0`，即 `u_+≈u_-`；R_i→∞ → `i_+=i_-=0`。**引入理想化三条件 + 两条规则** →【陈述时刻 1】。但立刻追问：A→∞ 意味着差一点就把输出顶到饱和，凭什么输出还能"有限、停在线性区"？→ 靠**负反馈**（把输出经电阻接回反相端，输出升高就压低差分输入，自我刹车）。**引入前提：线性区 + 负反馈**；饱和时虚短失效。
4. **用两条规则分析反相比例器**：同相端接地 + 虚短 → 反相端"虚地" `u_-≈u_+=0`；虚断 → 输入端不取电流；对**反相端节点**列 KCL → `u_o=−(R₂/R₁)u_i`。→【陈述时刻 2】。此处先让学生预测输出与输入同号还是反号（**预测 2**），揭晓时推导并落定义。
5. **换接法：同相比例器**：输入改接同相端 → 虚短给 `u_-=u_+=u_i`；虚断使 R₁、R₂ 分压支路不受输入电流影响 → `u_-=R₁/(R₁+R₂)u_o` → `u_o=(1+R₂/R₁)u_i`（恒 >1、为正）。→【陈述时刻 3】。R₂=0 得**电压跟随器** `u_o=u_i`（增益 1、隔离负载）。先让学生预测增益范围（**预测 3**）。
6. **多路输入 + 一条操作纪律**：两个输入各经电阻进反相端 → 虚地 → 对输入节点列 KCL 求和 → `u_o=−R_f(u₁/R₁+u₂/R₂)`，等阻退化为 `−(u₁+u₂)`。**预测 4** 问"能否对输出节点也列 KCL" → 揭晓：不能，输出电流由运放内部提供、事先未知，只对输入节点列方程。→【陈述时刻 4】。

链条的驱动力始终是"上一步在这个新器件 / 这个接法下不够用了"，不是把四种组态并列摆出。

## 四、逐环节脚本（教师说什么 / 板书什么 / 问什么 / 何时揭示）

### 环节 0 · 开场核心问题 + 预测 1（约 5′）

- **师**："前面我们学的所有元件——电阻、电源、受控源、RLC——都能用一两条 VCR 方程描述。今天来一个新器件：运算放大器。它里面有成千上万个晶体管，如果一个个列方程，这课就没法上了。但工程上大家却能用几条简单规则把运放电路算得飞快。今天就来弄明白：那几条规则是什么、凭什么能用。"
- **板书**：核心问题（第一节那句话）；画一个三角形运放符号草图（页内自包含 SVG），标出两个输入端 `+ / −`、输出端、差分输入 `u_d`。**明确点明：`+/−` 只是区分输入端性质的标志，不是电压极性**（学生第一大误读）。
- **师**："从电路分析角度，我们只关心它端子上的表现。它的输出受两个输入端电压之差控制：`u_o=A(u_+−u_-)`，A 是很大的增益。"
- **问（预测 1，先想后揭）**："A 很大（比如 10 万倍），但输出电压被电源卡在 ±13 V 之间。假如运放工作在**线性放大**（输出没顶到底、停在某个有限值），那两个输入端的电压差 `u_d` 大概是多少？"（选：很大 / 几乎为零 / 等于输出电压）
- **揭示条件**：学生先选后才揭晓；只揭到"A→∞ 且输出有限 → `u_d→0`、`u_+≈u_-`，且输入端不取电流"这一层，**不给"虚短 / 虚断"的名字**（名字在揭晓的陈述时刻 1 里给，属当前知识能解释的范围）。
- **揭晓要点**：因为 `u_o=A·u_d` 有限而 A 极大，所以 `u_d=u_o/A≈0`；因为输入电阻极大，输入端几乎不取电流。

### 环节 1 · 理想化三条件 + 虚短虚断 + 负反馈前提（约 10′）

- **师**："把刚才的思想实验正式化：给运放三个条件——增益 A→∞、输入电阻 R_i→∞、输出电阻 R_o→0，并且让它工作在线性区。这样的运放叫**理想运放**。"
- **板书三条件**，然后逐条推：`R_i→∞` → `i_+=i_-=0`（虚断）；`A→∞ + u_o 有限` → `u_d=0` → `u_+=u_-`（虚短）。
- **追问（关键边界，防"无条件真理"误解）**："A→∞ 意味着哪怕差一点点就要把输出顶到电源上限。凭什么输出还能停在线性区、让 u_d≈0 成立？" → 引出**负反馈**：把输出经电阻接回**反相端**，输出偏高就使 `u_d=u_+−u_-` 变小、把输出拉回来，自我刹车，稳定在线性区。板书一句话："**虚短虚断的前提：线性区 + 负反馈；一旦饱和（输出顶到 ±U_sat），u_d 不再≈0，虚短失效。**"
- **【陈述时刻 1 · 理想运放与虚短虚断】**：全称、三条件、两条规则、符号式、适用前提（见第六节答案区）。
- **强调两个"虚"字**：虚短 ≠ 真短路（两端电压相等但电流为零）；虚断 ≠ 真开路（电流为零但电压可以不为零）。

### 环节 2 · 反相比例器（约 9′）

- **师**："先看第一个电路：同相端接地，输入 `u_i` 经 R₁ 接反相端，R₂ 从输出接回反相端（这就是负反馈）。"
- **板书电路**（页内自包含 SVG）。
- **问（预测 2，先想后揭）**："输出 `u_o` 和输入 `u_i` 是同号还是反号？（同号 / 反号 / 不确定）"——先选再揭。
- **揭晓（推导）**：同相端接地 `u_+=0`，虚短 → 反相端 `u_-=u_+=0`（**虚地**）；虚断 → `i_-=0`，输入电流不进运放；对**反相端节点**列 KCL：
  `(u_i−u_-)/R₁ + (u_o−u_-)/R₂ = 0`，代入 `u_-=0` → `u_i/R₁ + u_o/R₂ = 0` → **`u_o = −(R₂/R₁)u_i`**（反号，负号来自虚地节点的电流求和）。
- **【陈述时刻 2 · 反相比例器】**：全称、增益式、虚地、符号来源（见答案区）。
- **工程一句话**：精确式（§5-2）算出比值几乎只由 R₂/R₁ 决定、与 A 几乎无关——这就是敢用理想模型的原因（不要求记精确式）。

### 环节 3 · 同相比例器与电压跟随器（约 8′）

- **师**："把输入改接到同相端，反相端经 R₁ 接地、R₂ 仍从输出反馈回来。"
- **板书电路**（页内自包含 SVG）。
- **问（预测 3，先想后揭）**："这次增益还是 `−R₂/R₁` 吗？输出电压大概是输入的什么范围？"（小于 1 的正数 / 大于 1 的正数 / 负数）
- **揭晓（推导）**：虚断 → 反相端不取电流，R₁、R₂ 就是普通分压；虚短 → `u_-=u_+=u_i`，故 `u_i=R₁/(R₁+R₂)·u_o` → **`u_o=(1+R₂/R₁)u_i`**（恒 >1、为正）。
- **【陈述时刻 3 · 同相比例器与电压跟随器】**：全称、增益式、跟随器特例（见答案区）。
- **跟随器**：R₂=0（或 R₁→∞）时 `u_o=u_i`，增益 1。师："增益只有 1，有什么用？" → 因 `R_i→∞` 不取电流，插在信号源和负载之间能把负载"隔离"，分压比不被重负载拉低（画一个分压+跟随器隔离的示意 SVG）。

### 环节 4 · 加法器与输出节点纪律（约 7′）

- **师**："两个输入各经一个电阻接到反相端，同相端接地，反馈电阻 R_f。"
- **板书电路**（页内自包含 SVG）。
- **问（预测 4，先想后揭）**："分析这个电路时，能不能像以前一样，也给输出节点列一条 KCL 方程？"（能 / 不能 / 看情况）——这是独立练习的真难点，先让学生表态。
- **揭晓（推导）**：同相端接地 + 虚短 → 反相端虚地 `u_-≈0`；虚断 → 对反相端节点列 KCL：
  `u₁/R₁ + u₂/R₂ + u_o/R_f = 0` → **`u_o = −R_f(u₁/R₁ + u₂/R₂)`**；等阻 `R₁=R₂=R_f=R` → `u_o=−(u₁+u₂)`。
  **输出节点纪律**：输出电流由运放内部（受控源）提供、事先未知，所以**不对输出节点列 KCL**，只在输入节点列。
- **【陈述时刻 4 · 加法器与操作纪律】**：全称、加法式、纪律（见答案区）。

### 环节 5 · 实验台 + 独立练习（约 4′，形态一 + 形态二）

- 页面实验台：A 面板切反相/同相/跟随、拖 R₁/R₂/u_i 看 u_+、u_-、u_o、增益；B 面板拖 u₁/u₂/R_f 看加法器输出。
- 再做 8 题（5 数值 + 1 选择 + 2 文字），覆盖两形态、含负数与需求反推，强调不是例题近邻复制。

### 环节 6 · 收尾与钩子（约 2′）

- 回扣核心问题："两条规则从哪来？A→∞、R_i→∞ 的理想化 + 线性区负反馈；什么时候失效？饱和。"给"理想化条件 → 模型适用边界"主线，抛 L3-03 二阶钩子。

### 独立练习（8 题，覆盖两形态，非近邻复制）

**形态一 · 读图列式与计算（例题算过同型，练习换参数 / 换符号 / 多空）**

1. 反相比例器 R₁=2 kΩ、R₂=10 kΩ、u_i=1 V，求 u_o。（答 −5 V）
2. 同相比例器 R₁=2 kΩ、R₂=8 kΩ、u_i=1 V，求 u_o。（答 5 V）
3. 电压跟随器 u_i=3 V，求 u_o 与同相端输入电流 i_+ 两空。（答 3 V / 0 A）
4. 加法器 R₁=R₂=R_f=10 kΩ，u₁=2 V、u₂=−3 V（含负数），求 u_o。（答 1 V）

**形态二 · 需求反推与适用边界辨析（例题没有的问法）**

5. 要一个增益为 −3 的反相比例器，R₁=10 kΩ，反馈电阻 R₂ 应取多少 kΩ？（答 30 kΩ）
6. 选择：关于虚短虚断，下列说法正确的是？① 虚短表示两输入端真的短接、有电流流过；② 虚断表示输入端真的开路、电压必为零；③ 虚短是 u_+=u_- 而输入电流为零（虚断），前提是线性区 + 负反馈，饱和时不成立。（答 ③）
7. 辨析（文字两空）：反相比例器里反相端"虚地"u_-≈0，流入反相端的电流去了哪里（经哪条元件到哪）？为什么分析时不对输出节点列 KCL？（答：电流经反馈电阻 R₂ 流向输出端、不进运放；输出电流由运放内部提供、事先未知，故只列输入节点 KCL）

## 六、答案区（默认折叠；揭晓只到当前知识能解释的程度）

### 预测题答案（每题单独折叠，按提出时机解锁）

<details><summary>预测 1 揭晓（含陈述时刻 1）</summary>

**几乎为零**。输出 `u_o=A·u_d` 停在一个有限值，而 A 极大，所以 `u_d=u_o/A≈0`，两输入端电压几乎相等；又因输入电阻极大，输入端几乎不取电流。

> **【陈述时刻 1 · 理想运放、虚短与虚断】**
> **全称/命名**：理想运算放大器（ideal op-amp）及两条分析规则——虚短、虚断。
> **一句定义**：满足 `A→∞、R_i→∞、R_o→0` 且工作在**线性区（输出不饱和、有负反馈）**的运放称为理想运放；由此得到两条规则——**虚断**：两输入端电流为零 `i_+=i_-=0`（因 R_i→∞），但输入端电压可不为零，**不是真开路**；**虚短**：两输入端电压相等 `u_+=u_-`（因 A→∞ 且 u_o 有限），但输入端电流为零，**不是真短路**。一端接地时另一端也≈0，称"虚地"。**适用前提：线性区 + 负反馈；饱和时 u_d 不再≈0，虚短失效。**
> **符号式**：`i_+=i_-=0`；`u_+=u_-`（即 `u_d=u_+−u_-=0`）。

〔邱 §5-1 p.114–116、§5-3 p.118–119 / 李上 §2-3（PDF 105–107）交叉佐证〕

</details>

<details><summary>预测 2 揭晓（含陈述时刻 2）</summary>

**反号**。同相端接地 `u_+=0`，虚短给反相端 `u_-=0`（虚地）；虚断使输入端不取电流，对反相端节点列 KCL：`u_i/R₁ + u_o/R₂ = 0` → `u_o=−(R₂/R₁)u_i`。

> **【陈述时刻 2 · 反相比例器（倒向放大器）】**
> **全称/命名**：反相比例器（inverting amplifier）。
> **一句定义**：同相端接地、输入经 R₁ 接反相端、R₂ 从输出反馈到反相端的电路；由虚短得反相端为"虚地"，在反相端节点列 KCL 即得输出电压与输入电压成固定比例、符号相反，比例只由外部电阻 R₂/R₁ 决定，与运放本身参数几乎无关。
> **符号式**：`u_o = −(R₂/R₁)·u_i`；负号来自虚地节点电流求和（`u_i/R₁ + u_o/R₂ = 0`）。

〔邱 §5-2 p.117–118、§5-3 p.119 / 李上 §2-3 例（PDF 108）〕

</details>

<details><summary>预测 3 揭晓（含陈述时刻 3）</summary>

**大于 1 的正数**，不再是 `−R₂/R₁`。虚断使反相端不取电流，R₁、R₂ 构成分压；虚短给 `u_-=u_+=u_i`，故 `u_i=R₁/(R₁+R₂)·u_o` → `u_o=(1+R₂/R₁)u_i`。

> **【陈述时刻 3 · 同相比例器与电压跟随器】**
> **全称/命名**：同相比例器（non-inverting amplifier）与电压跟随器（voltage follower）。
> **一句定义**：输入接同相端、反相端经 R₁ 接地并由 R₂ 反馈的电路，增益为 `1+R₂/R₁`（恒大于 1、输出与输入同号）；当 R₂=0（R₁→∞）时退化为电压跟随器 `u_o=u_i`，增益 1，因输入电阻无限大不取电流，插在信号源与负载之间可隔离负载效应、保持原定分压值。
> **符号式**：同相 `u_o=(1+R₂/R₁)u_i`；跟随器 `u_o=u_i`。

〔邱 §5-3 p.119–120 / 李上 §2-3 例 2-11、2-12（PDF 109–110）〕

</details>

<details><summary>预测 4 揭晓（含陈述时刻 4）</summary>

**不能**。输出电流由运放内部的受控源提供、事先未知，无法在输出节点写一条确定的 KCL；只能在**输入（反相）节点**列方程。虚地 `u_-≈0` 下：`u₁/R₁ + u₂/R₂ + u_o/R_f = 0` → `u_o=−R_f(u₁/R₁+u₂/R₂)`，等阻时 `u_o=−(u₁+u₂)`。

> **【陈述时刻 4 · 加法器与输出节点纪律】**
> **全称/命名**：反相加法器（summing amplifier）与运放电路的分析纪律。
> **一句定义**：多路输入各经电阻接反相端、同相端接地、反馈电阻 R_f 的电路，因反相端虚地，各输入电流在输入节点汇合后经 R_f 流向输出，输出为各输入的加权和取负；分析运放电路时只在输入节点列 KCL，**不对输出节点列 KCL**（输出电流未知）。
> **符号式**：`u_o = −R_f(u₁/R₁ + u₂/R₂ + …)`；等阻 `R₁=…=R_f=R` → `u_o = −(u₁+u₂+…)`。

〔邱 §5-3 p.120–121 / 李上 §2-3 练习题 2-11、2-12（PDF 111）〕

</details>

### 陈述时刻汇总（供页面做显式化定义卡，均在对应揭晓之后出现）

1. **理想运放 / 虚短 / 虚断**：三条件 `A→∞、R_i→∞、R_o→0` + 线性区负反馈；`i_+=i_-=0`（虚断，非真开路）、`u_+=u_-`（虚短，非真短路），一端接地为虚地；饱和时虚短失效。〔邱 §5-1 p.114–116、§5-3 p.118–119〕
2. **反相比例器**：`u_o=−(R₂/R₁)u_i`，反相端虚地，负号来自输入节点 KCL，比值与外部电阻有关、与 A 几乎无关。〔邱 §5-2 p.117–118〕
3. **同相比例器 / 跟随器**：`u_o=(1+R₂/R₁)u_i`（恒 >1）；跟随器 `u_o=u_i`，增益 1、隔离负载。〔邱 §5-3 p.119–120〕
4. **加法器 / 输出节点纪律**：`u_o=−R_fΣ(u_k/R_k)`，等阻 `u_o=−Σu_k`；只在输入节点列 KCL，不对输出节点列。〔邱 §5-3 p.120–121〕

### 实验台默认数值（自编，已独立验算自洽）

- **A 面板（比例器族，模式：反相 / 同相 / 跟随）**：R₁、R₂ 单位 kΩ，u_i 单位 V。
  - 默认**反相**：R₁=2 kΩ、R₂=10 kΩ、u_i=1 V → `u_+=u_-=0`（虚地）、`i_+=i_-=0`、`u_o=−(10/2)×1=−5 V`、增益 `A_v=−5`。
  - 切**同相**（同参数）：`u_+=u_-=u_i=1 V` → `u_o=(1+10/2)×1=6 V`、增益 `A_v=+6`。
  - 切**跟随**：`u_o=u_i=1 V`、增益 `A_v=1`。
  - 拖动 R₁/R₂/u_i 后按对应模式公式联动；反相模式 u_+=u_-=0，同相/跟随模式 u_+=u_-=u_i；i_+=i_-=0 始终成立。
- **B 面板（加法器）**：R₁=R₂=10 kΩ 固定，u₁、u₂ 单位 V，R_f 单位 kΩ。电阻统一用 kΩ，故 `R_f/R₁`、`R_f/R₂` 都是无量纲比值。默认 u₁=2 V、u₂=−3 V、R_f=10 kΩ → `u_-≈0`、`u_o=−(R_f/R₁)u₁−(R_f/R₂)u₂=−(10/10)×2−(10/10)×(−3)=−2+3=1 V`。拖动 u₁/u₂/R_f 按此式联动（例：R_f=20 kΩ → `u_o=−2×2−2×(−3)=−4+6=2 V`）。

### 独立练习答案

1. `u_o=−(R₂/R₁)u_i=−(10/2)×1=−5 V`。
2. `u_o=(1+R₂/R₁)u_i=(1+8/2)×1=5 V`。
3. 跟随器 `u_o=u_i=3 V`；虚断 `i_+=0 A`。
4. 等阻加法 `u_o=−(u₁+u₂)=−(2+(−3))=1 V`。
5. `−R₂/R₁=−3` → `R₂=3R₁=30 kΩ`。
6. ③。①错：虚短是电压相等、电流为零，不是真短路；②错：虚断是电流为零、电压可不为零（如反相端虚地时 u_-=0，但同相端可接任意 u_i）；③对：标明线性区+负反馈前提、饱和失效。
7. 流入反相端的电流不进运放（虚断 i_-=0），经反馈电阻 R₂ 流向输出端；不对输出节点列 KCL，因为输出电流由运放内部受控源提供、事先未知，只能在输入（反相）节点列 KCL。
8. 插入**电压跟随器**；靠输入电阻 `R_i→∞`（不取电流、不拉低分压比），增益 1 把输入电压原样送到负载。

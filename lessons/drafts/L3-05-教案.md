# L3-05 教案：三相电路与非正弦周期量（工程认知）

> S3 第五课（工程认知）· 前置 L2-07（正弦稳态功率与功率因数）· 45 分钟预算（因果链完整前提下）· 教案先行，独立审核通过前不得写 HTML。
> 本课把 L2-07 学会的"单一频率正弦稳态 + 功率"工具搬到两类工程现实：① 电网用**三路错开三分之一周期的正弦**一起供电（三相）；② 整流/方波/信号**根本不是正弦**（非正弦周期量）。核心动作都是"按相/按频率分开算，再合起来"。**只建工程图景与边界：复杂傅里叶系数手算与不对称联立求解为 P3「了解即可」，邱 §13-5~§13-7 不摘、不引章节号。**

## 一、核心问题（一个，贯穿全篇）

**前几课我们只会算"一幅正弦波"的电路；可现实里电网是三路错开三分之一周期的正弦一起供电，很多波形（整流、方波）又根本不是正弦——能不能把已经学会的相量法和功率工具，按"哪一路"或按"哪一种快慢"分开算、再合起来，既算得清这种多路供电的电压电流与功率，又看得懂非正弦波里各份贡献，并且说清这些简化在什么条件下才成立？**（"对称三相""相序""相电压/线电压""√3""一相计算""中性点位移""二瓦计法""傅里叶级数""直流分量/基波/谐波""频谱""有效值平方和""同频配对""谐波分析法"等术语与结论，都在对应预测揭晓时才给出；开场只用"三路错开三分之一周期""按哪一路分开算""按哪一种快慢分开算""合起来"这类待解描述，不点出术语。）

这句话覆盖本课两种任务形态：

- **形态一 · 多路供电的对称系统（三相）**：给一套三路错开 120° 的正弦源与对称负载，求线/相电压电流与功率；用"和为零 → 归结为一相"的简化，并守住 √3/±30° 只在"对称 + 定相序 + 定参考方向"下成立、功率公式里 φ 是阻抗角、中线在不对称时不可省这些边界。
- **形态二 · 非正弦周期量（按频率拆分）**：给一个非正弦周期波形，用傅里叶分解看出直流/基波/各次谐波，算有效值与平均功率（只有同频配对才产生平均功率），并用"逐频相量求解 + 时域叠加"的谐波分析法搭电路；守住"不同频率不能合并成一个相量""直流分量按 ω=0 单独处理"这些边界。

学生学完应能自己说出："这节课解决的是——把相量/功率工具搬到两类工程现实：多路供电按'相'算（三相差 120° 相加为零，所以能只算一相、线值是相值的 √3 倍、功率 √3 U_l I_l cos φ），非正弦按'频率'算（分解成直流+基波+谐波，只有同频才产生平均功率，逐频算完时域相加），而且这些简化都有适用条件。"（这句是学习目标，放页尾折叠区，不在开场显示。）

## 二、讲什么 / 不讲什么（边界与留白）

**讲**：
1. 对称三相电源：三路相差 120°、`U̇_A+U̇_B+U̇_C=0`、`u_A+u_B+u_C=0`（由 `cos θ+cos(θ−120°)+cos(θ+120°)=0` 可见地推出）；相序、Y/△ 联结、相电压/线电压命名（§12-1；李下 §9-8）。
2. 线值与相值：Y 形 `U̇_AB=U̇_A−U̇_B=√3 U̇_A∠30°`（可推导）；Y 形 `U_l=√3 U_p`、△ 形 `U_l=U_p`；Y 形 `I_l=I_p`、△ 形 `I_l=√3 I_p∠−30°`；**只在对称 + 定相序 + 定参考方向下成立**（§12-2；李下 §9-8）。
3. 对称 Y-Y 归结为一相：`U̇_N'N=0`、中线电流为零、中线可省；不对称时中性点位移、中线保证各相独立与安全（§12-3/§12-4；李下 §9-9）。
4. 三相功率：对称时瞬时功率恒定 = 平均功率、`P=√3 U_l I_l cos φ`（**φ 是负载阻抗角**）；二瓦计法 `P₁+P₂=P`、单独一表无意义、|φ|>60° 时一表可为负（§12-5；李下 §9-8）。
5. 非正弦周期量：傅里叶级数 = 直流 + 基波 + 各次谐波、离散线频谱、收敛快慢看波形光滑度（§13-2）。
6. 有效值 `U=√(U₀²+U₁²+…)`、平均功率 `P=U₀I₀+ΣU_kI_k cos φ_k`（**只有同频配对才贡献**）、谐波分析法：逐频相量求解 + 时域叠加、不同频率不可合并相量、直流按 ω=0 单独处理（§13-3/§13-4；李下 §10-4/§10-5）。

**不讲**（留白，钩子）：
- 复杂傅里叶系数的积分手算与更多项展开（**P3 了解即可**：给公式、看得懂分解，不要求手算系数）；
- 邱 §13-5~§13-7（对称三相高次谐波、指数形式、傅里叶积分）——**本课不摘、不引章节号**；
- 不对称三相电路的完整联立求解细节（只给定性结论 + 中线电流非零 + 某相电压低至 60 V 这些可复核数值，不引用有争议的相角细节）；
- 非周期信号的傅里叶变换、非正弦电路里的暂态过程（P3 了解即可）；
- 相量的"跨频率相加"（明确错误，作为反例讲，不作为方法）。

**下一课钩子**：L3-06「传输线边界：从集总到分布」——本课看到"波形越陡、需要的谐波越多"，高频分量一多，导线就不再只是导线：什么时候必须启动信号完整性（SI）思维，留给下一课。本课先把"按相/按频率分开算再合起来"和它们的边界立住。

## 三、概念依赖链（每一步"因为上一步不够用"才引入）

1. **L2-07 的成就与不就够了**：已经会算单一频率正弦稳态的相量、功率、功率因数 → 但电网是三路一起供电、整流波形又不是正弦，"一幅正弦波"的方法不够用了。→ **引入：按"哪一路"或按"哪一种快慢"拆开算再合起来（预测 1）**。
2. **三路相加为零（§12-1、李下 §9-8）**：三路相差 120°，`cos θ+cos(θ−120°)+cos(θ+120°)=0`，所以对任意时刻 `u_A+u_B+u_C=0`、相量 `U̇_A+U̇_B+U̇_C=0`。**【陈述时刻 1】** 这是后面所有简化的总根源；但"和为零"还不能直接告诉我们用户拿到的两根火线之间有多少伏——线值与相值的关系还没算。
3. **线值与相值（§12-2、李下 §9-8）**：由 KVL `U̇_AB=U̇_A−U̇_B=√3 U̇_A∠30°` 可见地推出 Y 形 √3 倍、超前 30°；△ 形线电压即相电压。**预测 2** 问：猜 Y 形线电压与相电压是什么关系？揭晓后给出电流关系与"只在对称+定相序+定参考方向下成立"的边界。**【陈述时刻 2】** 现在能算压/流了——"和为零"还能带来什么计算简化？
4. **归结为一相 + 中性线 + 三相功率（§12-3/§12-4/§12-5、李下 §9-8/§9-9）**：`U̇_A+U̇_B+U̇_C=0` 使 `U̇_N'N=0`、中线电流为零，对称 Y-Y 可只算一相、中线可省；不对称时中性点位移、中线不可省，否则各相电压严重失衡。功率 `p=3 U_p I_p cos φ` 为常量（瞬时功率平衡），`P=√3 U_l I_l cos φ`，二瓦计法测总量。**预测 3** 问：三路一起供电的瞬时功率是不是也随时间脉动？两只功率表能否测出总功率？揭晓后给出功率公式与二瓦计法。**【陈述时刻 3】** 解锁面板 A。
5. **非正弦（§13-2~§13-4、李下 §10-4/§10-5）**：三相再"标准"仍是正弦；整流的方波怎么办？**预测 4** 问：非正弦周期波形怎么用只会算正弦的工具处理？揭晓：傅里叶分解成直流 + 基波 + 各次谐波（频谱离散），有效值平方和、平均功率只有同频配对才贡献，谐波分析法逐频算再时域相加，直流按 ω=0 单独处理。**【陈述时刻 4】** 解锁面板 B。

链条的驱动力始终是"上一步只是表象、这个新现实还没解决"，不是把三相定义、相值关系、功率、傅里叶并列摆出。

## 四、逐环节脚本（教师说什么 / 板书什么 / 问什么 / 何时揭示）

### 环节 0 · 开场核心问题 + 预测 1（约 6′）

- **师**："前几课我们只会对付一幅正弦波。可你家里插座、工厂电机的电，不是一路，是三路错开三分之一周期一起送来的；而充电器把交流整流后的波形，根本不是正弦。今天就把你会的相量工具搬到这两种现实里——做法是同一句话：按'哪一路'或按'哪一种快慢'拆开算，最后合起来。"
- **板书**：核心问题（第一节那句话）；画"三路错开三分之一周期的正弦源 → 拆开算 → 合起来"的流程图（页内自包含 SVG）。**明确：只出现"三路错开三分之一周期/按哪一路分开算/按哪一种快慢分开算/合起来"这类描述词，不出现任何术语符号。**
- **问（预测 1，先想后揭）**："三路正弦彼此错开三分之一周期（也就是 120°），把它们在任意时刻的电压加起来，会得到什么？A 还是同频正弦、幅度更大 / B 恒等于零 / C 一个恒定的数。"（学生先选，此时黑板没有 `cos θ+cos(θ−120°)+cos(θ+120°)=0`，也没有"对称三相/相序"字样）
- **揭示条件**：学生先选后才揭晓；揭到"由恒等式可见三路瞬时和为零、相量和为零，这就是后续所有简化的根源"这一层，陈述时刻 1 才给"对称三相/相序/Y/△/相电压/线电压"的定义名。

### 环节 1 · 三路相加为零 + 陈述时刻 1（约 8′）

- **揭晓（陈述时刻 1，此时才板书推导与定义）**：**板书可见地被推出来**：`cos θ + cos(θ−120°) + cos(θ+120°) = cos θ + 2cos θ cos120° = cos θ + 2cos θ(−1/2) = 0`；所以任意时刻 `u_A(t)+u_B(t)+u_C(t)=0`，相量 `U̇_A+U̇_B+U̇_C=0`（相量线性性质）。三路到达最大值的先后次序叫**相序**。把三个绕组末端连一点叫 **Y 形**（该点=中性点，引出的三根线=相线；每路电压=相电压，两根相线之间=线电压）；始末端顺次相接叫 **△ 形**（无中性点，线电压即相电压，接反会短路）。**【陈述时刻 1】**
- **师**："和为零很漂亮，但用户拿到的是两根火线之间的电压——线电压跟相电压到底差多少？"→ 引出预测 2。

### 环节 2 · 线值相值 + 陈述时刻 2（约 9′）

- **问（预测 2，先想后揭，公式未上黑板时提出）**："Y 形接法里，两根相线之间的电压（线电压）跟你说的每路相电压，幅度是什么关系？相电压 220 V 时线电压大约多少？（A 一样 220 V / B 约 380 V、√3 倍 / C 约 110 V、一半）"（学生先表态，此时黑板没有 `U̇_AB=U̇_A−U̇_B` 的推导）
- **揭晓（陈述时刻 2，此时才板书推导）**：**板书推导**：`U̇_AB = U̇_A − U̇_B = U_p∠0° − U_p∠−120° = √3 U_p∠30°`（画相量图：两相等幅相量相差 120°，其差是 √3 倍且超前 30°）。所以 Y 形 `U_l=√3 U_p`、线电压超前对应相电压 30°；相电压 220 V → 线电压约 380 V。△ 形 `U_l=U_p`。电流：Y 形 `I_l=I_p`，△ 形 `I_l=√3 I_p` 且滞后 30°。**强调边界**：这套 √3/±30° 只在**对称 + 固定相序 + 固定参考方向**下成立，不能任意设定。**【陈述时刻 2】**
- **师**："和为零还能再省一步——既然三路电流加起来也是零，中性线还需要吗？功率又怎么算？"→ 引出预测 3。

### 环节 3 · 一相计算、中性线与三相功率 + 陈述时刻 3（约 10′）

- **问（预测 3，先想后揭）**："三路一起供电的瞬时功率，是不是也像单相那样随时间脉动？如果只知道总线电压和线电流、负载功率因数，一个式子能不能算出总功率？两只功率表够不够？"（学生先表态，此时没有 `P=√3 U_l I_l cos φ`、没有二瓦计结论）
- **揭晓（陈述时刻 3，此时才板书）**：**板书**：① 对称 Y-Y 中 `U̇_N'N=(U̇_A/Z+U̇_B/Z+U̇_C/Z)/(3/Z+1/Z_N)=0`（因和为零），中线电流 `İ_N=İ_A+İ_B+İ_C=0`，所以**对称时只需算一相**，中线可省。② 但**不对称时**中性点位移 `U̇_N'N≠0`，各相互相牵连、电压严重失衡，中线必须保留（例中某相电压低到 60 V）。③ 功率 `p=p_A+p_B+p_C=3 U_p I_p cos φ` 是常量（瞬时功率平衡），`P=√3 U_l I_l cos φ`，**φ 是阻抗角不是线电压电流夹角**。④ 二瓦计法 `P₁=U_l I_l cos(φ−30°)`、`P₂=U_l I_l cos(φ+30°)`，`P₁+P₂=P`；|φ|>60° 时一表可为负，单独一表无意义；三相四线不对称不能用。**【陈述时刻 3】** 解锁面板 A。
- **师**："三相再标准仍是正弦；可整流的方波不是正弦——最后一问。"

### 环节 4 · 非正弦与谐波直觉 + 陈述时刻 4（约 9′）

- **问（预测 4，先想后揭）**："一个非正弦的周期波形（比如方波），怎么用只会算正弦的工具处理？能不能直接把它当成一个相量？（A 直接当一个相量 / B 拆成直流 + 若干正弦分量分别算再叠加 / C 完全没法算）"（学生先选，此时没有"傅里叶/谐波/频谱/有效值平方和/同频配对"字样）
- **揭晓（陈述时刻 4，此时才板书）**：**板书**：傅里叶级数 `f(t)=A₀+Σ A_k cos(kω₁t+φ_k)` = 直流 + 基波 + 各次谐波，频谱离散；收敛快慢看波形光滑程度（方波要很多项，取到 11 次才约 0.95、35 次仍有 2% 误差）。有效值 `U=√(U₀²+U₁²+…)`。平均功率 `P=U₀I₀+ΣU_k I_k cos φ_k`——**不同频率不产生平均功率（正交），只有同频配对才贡献**；例10-9 用这个规则算出 228.8 W。谐波分析法：逐频建相量模型求同频响应，再在时域相加；**不能把不同频率合并成一个相量**；直流分量按 ω=0 单独处理（L 短路、C 开路）。**【陈述时刻 4】** 解锁面板 B。
- **师**："按相拆、按频率拆，拆完再合——这就是今天的两招。"

### 环节 5 · 双实验台 + 独立练习 + 收尾钩子（约 3′）

- 面板 A（三相实验台）：滑块相电压/阻抗角/阻抗模，Y/△ 与"对称/不对称"及"中线接通/断开"开关 → 显示三路相量、线电压 √3 关系、一相电流、三相功率、二瓦计两表读数；**不对称时严格区分两种情形**：① 中线接通（`Z_N≈0`，有电流通路）→ 各相独立、`U̇_N'N≈0`、各相电压仍 220 V，但中线电流非零（`İ_N=−İ_A/2=11∠150° A`），**无中性点位移告警**；② 中线断开（三相三线，无通路）→ `İ_N=0`、`U̇_N'N≠0`、各相电压失衡（书中算得某相低至 60 V），**此时告警"中性点位移"**，且各相电流不能再按 220/Z 简单算（须联立求解，本课只给结论）。两情形互斥，不可绑在一起。
- 面板 B（同频配对实验台）：例10-9 各频率分量的电压/电流/相位 → 逐频功率表，直流与 2 次（无对应电流）不贡献、基波 250 W、3 次 −21.2 W、总 228.8 W；改滑块按同一公式联动。
- 再做 8 题（4 数值/填空 + 2 选择 + 2 辨析），覆盖两形态与边界，强调不是例题近邻复制。
- 收尾回扣核心问题，抛 L3-06 钩子（波形越陡谐波越多 → 高频下导线不再是导线 → SI 触发条件）。

<details><summary>预测 1 揭晓（含陈述时刻 1）</summary>

**B 恒等于零。** 推导：`cos θ + cos(θ−120°) + cos(θ+120°) = cos θ + 2cos θ cos120° = cos θ − cos θ = 0`。所以任意时刻 `u_A(t)+u_B(t)+u_C(t)=0`；由相量线性性质也有 `U̇_A+U̇_B+U̇_C=0`。三路到达最大值的先后次序叫相序。三个绕组末端相连成 Y 形（公共点=中性点，引出三根相线；每路电压=相电压，相线之间=线电压）；始末端顺次相接成 △ 形（无中性点、线电压即相电压，任一相接反会在闭合回路产生极大短路电流）。**"和为零"是后面一相计算、中线可省、瞬时功率恒定的总根源。** 此处不给 √3 关系、不给功率公式。

> **【陈述时刻 1 · 对称三相电源、相序、Y/△ 联结、相电压与线电压】**
> **全称/命名**：对称三相电源（symmetrical three-phase source）、相序（phase sequence）、星形/Y 形联结与三角形/△ 形联结、中性点（neutral point）、相线（火线）、相电压（phase voltage）、线电压（line voltage）。
> **一句定义**：三个幅值相等、频率相同、彼此相差 120° 的正弦电压源构成对称三相电源；若相量为 `U̇_A=U_p∠0°`、`U̇_B=U_p∠−120°`、`U̇_C=U_p∠120°`，则任意时刻 `u_A+u_B+u_C=0`、相量和 `U̇_A+U̇_B+U̇_C=0`（`cos θ+cos(θ−120°)+cos(θ+120°)=0`）。三相到达最大值的先后次序称相序。Y 形把三相末端接一公共点（中性点），引出三根相线，每相电压为相电压、相线间电压为线电压；△ 形始末端顺次相接，无中性点、线电压即相电压。
> **符号式**：`U̇_A=U_p∠0°`、`U̇_B=U_p∠−120°`、`U̇_C=U_p∠120°`；`U̇_A+U̇_B+U̇_C=0`。

〔邱 §12-1 / p.281–282；李下 §9-8 式 9-37~9-39 / PDF 103〕

</details>

<details><summary>预测 2 揭晓（含陈述时刻 2）</summary>

**B 约 380 V、√3 倍。** 由 KVL 可见地推出：`U̇_AB=U̇_A−U̇_B=U_p∠0°−U_p∠−120°=√3 U_p∠30°`（两个等幅相量相差 120°，其差是 √3 倍且超前 30°）。所以 Y 形 `U_l=√3 U_p`、线电压超前对应相电压 30°；相电压 220 V → 线电压 380 V。△ 形 `U̇_AB=U̇_A`，线电压等于相电压。电流：Y 形线电流=相电流；△ 形 `İ_A=İ_AB−İ_CA=√3 İ_AB∠−30°`，线电流是相电流的 √3 倍、滞后 30°。**边界**：这套 √3/±30° 只在对称 + 固定相序 + 固定参考方向下成立，不能任意设定（邱原文明确强调）。

> **【陈述时刻 2 · 线值与相值关系及其适用条件】**
> **全称/命名**：线电压与相电压、线电流与相电流的关系（line/phase quantities）。
> **一句定义**：对称系统中，Y 形联结满足 `U_l=√3 U_p` 且线电压超前对应相电压 30°、`I_l=I_p`；△ 形联结满足 `U_l=U_p`、`I_l=√3 I_p` 且线电流滞后对应相电流 30°。这些关系由 KVL/KCL 在相量图上推出。**适用条件**：只在电源与负载对称、相序确定、参考方向按约定时成立，不能任意设定；非对称时不能套用。
> **符号式**：Y 形 `U̇_AB=√3 U̇_A∠30°`、`U_l=√3 U_p`、`I_l=I_p`；△ 形 `U̇_AB=U̇_A`、`İ_A=√3 İ_AB∠−30°`。

〔邱 §12-2 式 12-1/12-2 / p.283–284；李下 §9-8 式 9-40、例9-16 / PDF 104、109–110〕

</details>

<details><summary>预测 3 揭晓（含陈述时刻 3）</summary>

对称 Y-Y 中 `U̇_N'N=(U̇_A/Z+U̇_B/Z+U̇_C/Z)/(3/Z+1/Z_N)=0`（因 `U̇_A+U̇_B+U̇_C=0`），中线电流 `İ_N=0`，故对称时只需算一相、中线可省。但**不对称**时 `U̇_N'N≠0`（中性点位移），各相互相牵连、电压严重失衡（某相低到 60 V），中线必须保留以强使 `U̇_N'N≈0`。功率：把三路瞬时功率相加，`p=3 U_p I_p cos φ` 是常量（瞬时功率平衡），总有功 `P=√3 U_l I_l cos φ`，**φ 是负载阻抗角（相电压与相电流相位差），不是线电压与线电流夹角**。二瓦计法：三相三线制下 `P₁=U_l I_l cos(φ−30°)`、`P₂=U_l I_l cos(φ+30°)`，`P₁+P₂=P`；|φ|>60° 时一表可为负，单独一表无意义；不对称四线制不能用。例12-4：`P=2.5 kW`、`cos φ=0.866`、`U_l=380 V` → `I_l≈4.386 A`，`P₁≈1666.68 W`、`P₂≈833.34 W`，和为 2500 W。

> **【陈述时刻 3 · 一相计算法、中性线的作用、三相功率与二瓦计法】**
> **全称/命名**：归结为一相的计算（single-phase equivalent calculation）、中性点位移（neutral-point displacement）、瞬时功率平衡（instantaneous power balance）、二瓦计法（two-wattmeter method）。
> **一句定义**：对称 Y-Y 电路因 `U̇_A+U̇_B+U̇_C=0` 有 `U̇_N'N=0`、中线电流为零，可只算一相、中线可省；不对称时中性点位移 `U̇_N'N≠0` 使各相电压失衡、彼此牵连，中性线（阻抗≈0）能强使 `U̇_N'N≈0`、保证各相独立与安全。对称三相瞬时功率 `p=3 U_p I_p cos φ` 为常量、等于平均功率；`P=√3 U_l I_l cos φ`，φ 是负载阻抗角。三相三线制用两只功率表，`P₁=U_l I_l cos(φ−30°)`、`P₂=U_l I_l cos(φ+30°)`、`P₁+P₂=P`，单独一表无意义，不对称四线制不可用。
> **符号式**：`U̇_N'N=(U̇_A Y_A+U̇_B Y_B+U̇_C Y_C)/(Y_A+Y_B+Y_C)`；`P=√3 U_l I_l cos φ`；`P₁+P₂=P`。

〔邱 §12-3 p.285–286、§12-4 p.287–288、§12-5 p.288–290 例12-4；李下 §9-8 式 9-47、§9-9 例9-18 / PDF 106、110–114〕

</details>

<details><summary>预测 4 揭晓（含陈述时刻 4）</summary>

**B 拆成直流 + 若干正弦分量分别算再叠加。** 满足狄里赫利条件的周期函数可展开为傅里叶级数 `f(t)=A₀+Σ A_k cos(kω₁t+φ_k)`：A₀ 直流分量、k=1 基波、k>1 各次谐波，频谱是离散线频谱；方波/脉冲收敛慢（取到 11 次约 0.95、35 次仍约 2% 误差），光滑波形几项就够。有效值 `U=√(U₀²+U₁²+…)`（正交性）。平均功率 `P=U₀I₀+ΣU_kI_k cos φ_k`——不同频率乘积的积分为零，**只有同频配对才贡献**。例10-9：`u=[100+100cos t+50cos2t+30cos3t] V`、`i=[10cos(t−60°)+2cos(3t−135°)] A`，直流与 2 次无对应电流不贡献，基波 250 W、3 次 −21.2 W，总 228.8 W。谐波分析法：逐频建相量模型求同频响应，再时域相加；**不能把不同频率合并成一个相量**；直流按 ω=0 单独处理（L 短路、C 开路）。复杂傅里叶系数手算 P3 了解即可。

> **【陈述时刻 4 · 傅里叶级数、有效值平方和、平均功率同频配对、谐波分析法】**
> **全称/命名**：傅里叶级数（Fourier series）、直流分量/基波/高次谐波、幅度频谱、谐波分析法（harmonic analysis method）。
> **一句定义**：非正弦周期量可分解为 `f(t)=A₀+Σ A_k cos(kω₁t+φ_k)`=直流 + 基波 + 各次谐波，各次频率为基频正整数倍、频谱离散。有效值 `U=√(U₀²+U₁²+…)`。平均功率 `P=U₀I₀+ΣU_kI_k cos φ_k`：不同频率分量乘积的积分为零，只有同频电压电流才产生平均功率。谐波分析法=把激励按傅里叶分解 → 每个频率单独建相量模型求同频响应 → 时域叠加；不同频率不能合并成一个相量，直流按 ω=0 单独处理（电感短路、电容开路）。
> **符号式**：`f(t)=A₀+Σ A_k cos(kω₁t+φ_k)`；`U=√(U₀²+U₁²+…)`；`P=U₀I₀+ΣU_kI_k cos φ_k`。

〔邱 §13-2 p.296–302、§13-3 p.303–305、§13-4 p.305–306；李下 §10-4 PDF 134–140、§10-5 例10-9 PDF 144–145〕

</details>

- **面板 A（三相实验台）**：滑块相电压 `U_p`(V)、阻抗角 `φ`(°)、阻抗模 `|Z|`(Ω)，开关 Y/△、对称/不对称。
  - 默认对称 Y：`U_p=220 V` → 三路相量 `220∠0°/220∠−120°/220∠120°`、`U̇_A+U̇_B+U̇_C=0`；`U_l=√3×220≈381 V`（工程上系统标称取 380 V，面板内部统一用 381 V 计算以保自洽），`U̇_AB=381∠30° V`；`φ=30°`、`|Z|=10 Ω` → `İ_A=220/10∠−30°=22∠−30° A`，Y 形 `I_l=I_p=22 A`。
  - 默认功率（用 `U_l=381 V` 统一口径，`cos φ=cos30°≈0.866`）：`P=√3 U_l I_l cos φ=√3×381×22×0.866≈12573 W`；`P₁=U_l I_l cos(φ−30°)=381×22×cos0°=8382 W`，`P₂=U_l I_l cos(φ+30°)=381×22×cos60°=4191 W`，`P₁+P₂=12573 W=P` ✓（因 `cos(φ−30°)+cos(φ+30°)=2cosφ cos30°=√3 cosφ`）。**实现时用同一 `U_l=√3·U_p` 数值统一显示 P 与两表读数，保证相加一致。**
  - 联动：改 `U_p/φ/|Z|` 按同一公式重算；切 △ 形则 `U_l=U_p`、`I_l=√3 I_p`。不对称令一相阻抗加倍（该相电流由 22 A 减半为 11 A），**必须按中线通断分成两个互斥情形显示，不得同屏给出**：
    - **① 中线接通**（`Z_N≈0`，有回流通路）：各相仍独立、`U̇_N'N≈0`、各相电压仍为 220 V，中线电流 `İ_N=İ_A'+İ_B+İ_C=−İ_A/2=11∠150° A`（模 11 A、非零）；**不显示位移告警**——这恰说明"中线有电流但保住了各相电压对称"。
    - **② 中线断开**（三相三线，无通路）：`İ_N=0`（无中线可流）、`U̇_N'N≠0`、各相电压失衡（书中算得某相低至 60 V、另两相偏高）；此时显示"中性点位移、各相电压不再相等"告警，并标注"各相电流不能再按 220/Z 算，须联立求解（P3 本课不展开，只给定性结论）"。
    - 两情形由"中线 接通/断开"开关切换；切勿把"中线电流非零"与"中性点位移告警"绑在同一状态——那会把中线的作用教反。
- **面板 B（同频配对实验台）**：李下例10-9 默认：`u=[100+100cos t+50cos2t+30cos3t] V`、`i=[10cos(t−60°)+2cos(3t−135°)] A`。
  - 逐频表：k=0 直流 U=100/I=0→P=0；k=1 `U₁=70.71`、`I₁=7.07`、`φ₁=60°`→`P₁=250 W`；k=2 `U₂=35.36`/I=0→0；k=3 `U₃=21.21`、`I₃=1.414`、`φ₃=135°`→`P₃=−21.2 W`；总 `P=228.8 W`。有效值 `U≈129.2 V`、`I≈7.21 A`。
  - 联动：滑块改各分量幅值/相位按同频配对公式重算；直流与无对应电流的谐波恒为 0；负功率项标"该分量端口在送功率"。

### 独立练习答案

1. `U_l=√3×220≈381 V`（工程取 380 V）；`U̇_AB=√3 U̇_A∠30°`，超前 `U̇_A` 30°。
2. `İ_A=220/(4+j3)=220/5∠−36.87°=44∠−36.87° A`；`İ_B=44∠(−36.87°−120°)=44∠−156.87° A`；`İ_C=44∠(−36.87°+120°)=44∠83.13° A`。
3. `P=√3×380×10×cos30°=3800×1.5=5700 W`；`P₁=380×10×cos(30°−30°)=3800 W`；`P₂=380×10×cos(30°+30°)=1900 W`；`P₁+P₂=5700 W`。
4. 对称时 `İ_N=0`、中线可省；不对称且中线断时中性点位移 `U̇_N'N≠0`，各相电压严重失衡、彼此牵连；中线（Z_N≈0）强使 `U̇_N'N≈0`，保证各相独立与安全，故不可省。
5. `U=√(100²+70.71²+35.36²)=√(10000+5000+1250)=√16250≈127.5 V`。
6. 基波 `P₁=(100/√2)(10/√2)cos60°=250 W`；3 次电压无对应电流 → 0；总 250 W。
7. ②。①不同频率不可合成一个相量；③直流分量要计入（ω=0 单独处理）；④傅里叶级数含 cos 与 sin 项、也可只含奇次等，不限于正弦项。
8. 直流按 ω=0 单独处理：电感短路、电容开路，不能用普通相量阻抗（jω=0）；例13-2 电路对 7 次谐波串联谐振、呈带通，响应由网络频率特性决定，故"取几项够"要看网络频率特性，不能只看激励谐波是否按 1/k 衰减。

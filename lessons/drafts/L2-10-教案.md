## 一 · 核心问题（贯穿全篇，只有一个）

**前面九课我们学了两套完全不同的工具：一套是时域暂态（储能、换路定则、τ、三要素），一套是正弦稳态（相量、阻抗、功率、频响、谐振）。可题目把电路摆到面前时，没人告诉我们"这题该用哪一套"——我凭什么判断这是要盯换路后的时间过程、还是盯单一频率下的稳态？更进一步：当电路里 L 和 C 都在、又发生了换路，我能不能不解微分方程，光看 R、L、C 三个参数就预判它会安安静静地单调回落，还是会来回振铃？**

学生学完要能自己复述这句话，并覆盖两种任务形态：

- **形态一（工具选择）**：给一个电路 + 一个问题（如"t=0 合闸后电容电压怎么变"或"正弦稳态下电流与功率因数是多少"），判断该用时域暂态工具、正弦稳态相量工具、还是频响/谐振工具，并说出判断依据（问题问的是时间过程还是稳态？激励是直流/阶跃还是单一频率正弦？），再调出对应工具链求解。
- **形态二（二阶形态预判，本课只针对 RLC 串联）**：给一个 **RLC 串联**电路的 R、L、C，用临界电阻 `R_c=2√(L/C)` 预判零输入响应的形态——过阻尼（不振荡）/ 临界 / 欠阻尼（衰减振铃）/ `R=0` 等幅振荡——不必解出响应表达式。**边界**：并联 GLC 的临界条件与本式不同（本课不展开，也不套用本式），凡形态预判题一律先看清是串联还是并联；本课只练串联。

## 二 · 讲什么 / 不讲什么

**讲（P1 必会）**：两条主线的适用条件与工具链——时域线（换路定则 `u_C`/`i_L` 连续、`τ=RC` 或 `L/R`、三要素 `f(t)=f(∞)+[f(0₊)−f(∞)]e^(−t/τ)`，用于直流/阶跃激励、关注换路后随时间的过程）；相量线（正弦量→相量、`jω` 对应微分、`Z=R/jωL/1/(jωC)`、`S̃=P+jQ`、频响 `H(jω)`、谐振 `ω₀=1/√(LC)`，用于单一频率正弦稳态）。关键判据：**看问题问的是"换路后的时间过程"还是"稳态/频率响应"，看激励是"直流/阶跃"还是"单一频率正弦"**。稳态谐振过压与暂态振铃的分界（复用 L2-09 陈述⑤）。

**讲（P2 应会）**：二阶响应形态分类（**本课只针对 RLC 串联**）——二阶电路由二阶微分方程描述、需两个初始条件；特征根 `p₁,₂=−α±√(α²−ω₀²)`（`α=R/(2L)`、`ω₀=1/√(LC)`）只由结构与参数决定、与激励和初值无关；临界电阻 `R_c=2√(L/C)`：`R>R_c` 过阻尼（两个不等负实根，单调回落）、`R=R_c` 临界（相等负实根，无过冲最快）、`R<R_c` 欠阻尼（共轭复根，衰减振铃）、`R=0` 等幅振荡（共轭虚根）。二阶"零输入/零状态/全响应"的分解结构与一阶相同（全响应＝齐次通解＋特解），只是一阶齐次解是指数、二阶齐次解有四种形态。并联 GLC 的临界判据不同，本课不涉及。

**不讲**：二阶微分方程的具体求解与待定常数 A、β 的定解、欠阻尼阶跃的超调量/调节时间/峰值时间（L3-03 主课）；拉氏变换与复频域系统函数求解（S3）；李上 §7 与 H&H 相关章节（未摘正文，不引章节号）；耦合谐振、高阶滤波器设计、傅里叶多频分解。

**下一课钩子**：本课把"工具选择"练熟，但每课仍是单知识点的小综合；L2-E 将做 S2 阶段综合考核，把 C/L 方程、τ、相量/阻抗、正弦稳态分析、功率、频响/谐振、二阶形态分类放在一起考。之后再进 S3。

## 三 · 因果顺序（不是时间安排）

前九课是"分科"学的：L2-01~03 时域、L2-04~09 正弦稳态。next question：**这些工具散落在九课里，一道新题摆到面前，我怎么知道该掏哪一件？** 推理链：

1. 先立"判据"而非先列公式：把所有问题的第一个分叉口摆出来——**题目问的是"换路以后的时间过程"，还是"正弦源一直开着时的稳态/频率表现"？** 前者属时域线、后者属相量线。此处先提出**预测 1**（一个典型的换路暂态场景该用哪套工具），**不揭晓**；揭晓块内才给出时域线的适用条件与工具链（换路定则、τ、三要素）。陈述时刻 ①。
2. 对称地给出另一条线：再提**预测 2**（一个典型的正弦稳态场景该用哪套工具），**不揭晓**；揭晓块内才给出相量线的适用条件与工具链（相量、`Z`、`S̃`、`H(jω)`、谐振），并把两条线并到一张"工具选择图"上——这是本课的知识图谱。陈述时刻 ②。
3. 交界辨析：两条线都会在"含 L、C 的电路"上出现，最容易被混。提出**预测 3**（同一个 RLC，情形甲正弦源调到 ω₀ 一直开着看稳态、情形乙 t=0 合闸看头几毫秒的过冲，哪种可用相量法），**不揭晓**；揭晓块内收口边界（陈述时刻 ③）：相量法只适用于正弦稳态，换路瞬间必须回时域线；`Q=ω₀L/R` 只描述稳态谐振，不能套到暂态振铃。
4. 补上最后一类认知：如果换路后电路里 L、C 都有（二阶），时域线要解二阶微分方程——形态不止"指数衰减"一种。提出**预测 4**（把 RLC 串联的 R 从很大减到 0，零输入响应形态怎么变），**不揭晓**；揭晓块内才给出特征根四形态、临界电阻 `R_c=2√(L/C)`、判据表与四种波形。陈述时刻 ④。**关键**：形态（振荡与否）由 R、L、C 三个参数就能预判，与激励和初值无关——这是"分类认知"能成立的根据。
5. 收口：给出元认知层的"工具选择总流程"（先问暂态还是稳态 → 再看激励形式与阶次 → 再调工具链），陈述时刻 ⑤。混合型综合练习 + 过关自检，让学生对一个没见过的题独立走完整个判断流程。

**为什么这个顺序**：先立判据再列工具，是因为学生的问题不是"不会用工具"，而是"不知道用哪个"；时域线先讲，因为它承接 L2-01~03 且是换路场景的默认答案；相量线对称给出并立刻并图对照，形成知识图谱；交界辨析放在两条线都讲完之后，才讲得清"为什么这里不能用相量"；二阶形态分类放在最后，因为它要用到"时域线 + 换路 + L/C 储能"的全部前置认知，且是新知；总流程收口把四步压成一句可迁移的口诀。

## 四 · 教学环节（预测先提后揭；每环节写明"提出—推导—揭晓"顺序）

### 环节 0：核心问题与预测 1（约 4′）

- 开场只写核心问题。摆两个"待判断"的场景卡（先不给工具链），让学生意识到"我会用工具，但不知道选哪个"。
- **先预测 1（只收选项，不公布；此时黑板上不出现三要素公式、τ 公式）**：场景——一个 RC 电路，开关在 t=0 闭合接上直流电源，问电容电压 `u_C` 从 0 到稳态**随时间怎么变**。该用哪套工具？① 相量法（转到频域算）② 时域暂态（换路定则 + τ/三要素）③ 只要戴维南等效就够了。选定后才解锁揭晓，现在别翻答案。
- 【QA 锚点】若学生选①，追问"相量法要求单一频率的正弦稳态，可这里是直流电源 + 刚合上的一瞬间，是稳态吗"——真实卡点，不预置。

### 环节 1：时域线工具箱，揭晓预测 1（约 8′）

- 铺垫（无 gate，板书可见）：激励是直流/阶跃、问的是换路后随时间的过程 → 时域线。
- **揭晓 gate（预测 1）块内（选定后才可见）——时域工具链在此首次完整出现**：
  - 换路定则：`u_C(0₊)=u_C(0₋)`、`i_L(0₊)=i_L(0₋)`（储能元件的电压/电流不能突变，L2-03）。
  - 时间常数：RC 电路 `τ=RC`，RL 电路 `τ=L/R`；`3τ~5τ` 进稳态。
  - 三要素公式：`f(t)=f(∞)+[f(0₊)−f(∞)]e^(−t/τ)`（一阶 + 直流激励时，不必解微分方程，找 3 个数即可）。选②；①错在相量法只适用正弦稳态，③戴维南只给等效电路、不会给时间过程。
  - 陈述时刻 ①：**时域暂态分析法（time-domain transient analysis）**——当电路含储能元件、激励为直流/阶跃、且问题关注换路后随时间的响应过程时，用换路定则确定初值、时间常数 τ 定快慢、三要素公式写全响应的方法。条件：一阶（RC/RL）、直流或阶跃激励；三要素公式不适用于二阶或正弦稳态。
  - 页内 SVG ①上半（时域线：RC 电路 + `u_C(t)=U_s(1−e^(−t/τ))` 上升曲线）在此可见。

### 环节 2：相量线工具箱与两线对照图，揭晓预测 2（约 9′）

- **先预测 2（在给出相量工具链与对照图之前提出，不揭晓）**：场景——一个 RLC 串联电路接在 `220 V / 50 Hz` 的正弦电压源上，已通电很久，问稳态电流有效值、各元件电压与电路的功率因数。该用哪套工具？① 时域三要素/微分方程 ② 相量法 + 阻抗 + 功率 ③ 二阶形态分类。选定后才解锁揭晓。
- **揭晓 gate（预测 2）块内（选定后才可见）——相量工具链与知识图谱在此首次完整出现**：
  - 相量线：正弦量 → 相量 `Ū=U∠ψ`（`jω` 对应微分，微分方程变代数方程）；元件 `Z_R=R`、`Z_L=jωL`、`Z_C=1/(jωC)`；`Ū=ZĪ`，KCL/KVL 相量域同形；复功率 `S̃=P+jQ=ŪĪ*`、`λ=cosφ=P/S`；网络函数 `H(jω)=Ū_o/Ū_i`；谐振 `ω₀=1/√(LC)`。选②；①错在相量域电流电压是同频正弦、无需时域微分方程，③只是分类工具、不给出数值。
  - 陈述时刻 ②：**正弦稳态相量法（phasor analysis）**——对单一频率正弦激励、电路已达稳态的线性电路，用相量表示正弦量、用阻抗/导纳表示元件，把时域微分方程化为复系数代数方程来求解电压电流与功率的方法。条件：单一频率、正弦稳态、线性元件；**不能用于换路瞬间或非正弦/多频激励**。
  - 页内 SVG ①（两条主线工具选择图：入口分叉"换路时间过程 / 稳态频率表现" → 时域线工具链 vs 相量线工具链 → 各自适用条件）在此完整可见。这是本课的知识图谱。
  - 【QA 锚点】学生常问"三要素里也有 e^(−t/τ)，相量里也有 e^(jωt)，是不是一回事"——点明一个描述衰减的时间常数、一个是稳态旋转因子，物理与适用条件都不同（真实卡点）。

### 环节 3：两条线的交界，揭晓预测 3（约 7′）

- **先预测 3（在收口边界之前提出，不揭晓）**：同一个 RLC 串联电路。情形甲：正弦源频率调到 `ω₀`、一直开着，观察稳定的 `U_L`。情形乙：t=0 合闸，观察头几毫秒电流有没有过冲。哪一种情形**可以用相量法**？① 只有甲 ② 只有乙 ③ 甲乙都可以。选定后解锁揭晓。
- **揭晓 gate（预测 3）块内（选定后才可见）——边界陈述在此首次出现**：
  - 选①。情形甲是正弦稳态：参数与频率不变时，谐振过压 `U_L=Q·U_s` 持续存在，可用相量/`Q=ω₀L/R` 描述；情形乙是换路暂态：一次会衰减的自由响应（欠阻尼时就是振铃），必须回时域线，`Q=ω₀L/R` 不适用。
  - 陈述时刻 ③：**稳态谐振与暂态振铃的边界**——相量法和谐振 Q 只用于正弦稳态；换路后的过冲/振铃属时域暂态（二阶时见环节 4），两者产生原因、方程、响应表达式都不同。条件：判据是"激励是否为持续正弦 + 是否已进入稳态"，只要问题出现"换路后""t=0 后头几毫秒"就必须用时域线。
  - 页内 SVG ②（稳态谐振 vs 暂态振铃并排对照图：持续正弦源 + 不衰减过压 vs 换路 + 衰减振铃）在此可见。
  - 【QA 锚点】呼应 L2-09 练习 9：学生仍可能把 Q 套到暂态——此处再压一次："暂态振铃的尖锐程度看 R 与临界电阻的关系，不是看稳态 Q 值"（真实卡点）。

### 环节 4：二阶形态分类，揭晓预测 4（约 12′）

- 铺垫（无 gate，板书可见）：时域线遇到 L、C 都在的二阶电路，要解二阶微分方程 `LC·d²u_C/dt²+RC·du_C/dt+u_C=0`，需要两个初始条件。学生已知一阶电路的响应就是一条指数衰减曲线；但二阶电路里有 R、L、C 三个参数，**改一改 R，放电的样子会不会变？** 此处先提出预测 4，**不揭晓**；本阶段**不写出临界电阻公式、四形态表、α/ω₀ 判据，也不出现"特征根"一词**——它们全部留到揭晓块内首次出现。
- **先预测 4（在给出临界电阻判据之前提出，不揭晓）**：把一个 RLC 串联放电电路的电阻 R 从很大慢慢减小到 0，电容放电（零输入响应）的形态会怎样？① 始终是单调衰减、不振荡；② 先单调衰减，R 小过某个临界值后出现衰减振铃，R=0 时变成不衰减的等幅振荡；③ 始终是振铃。选定后才解锁揭晓。
- **揭晓 gate（预测 4）块内（选定后才可见）——特征根四形态、临界电阻、判据表在此首次出现**：
  - 特征方程 `p²+(R/L)p+1/(LC)=0`，令 `α=R/(2L)`、`ω₀=1/√(LC)`，则 `p₁,₂=−α±√(α²−ω₀²)`。临界点是 `α=ω₀`，即 `R_c=2√(L/C)`（由 `R/(2L)=1/√(LC)` 解出，等价于 `R²=4L/C`）。
  - 四种形态（判据表）：`R>R_c` → 两个不等负实根 → **过阻尼**（不振荡、单调回落）；`R=R_c` → 相等负实根 → **临界**（非振荡、无过冲且最快）；`R<R_c` → 共轭复根 → **欠阻尼**（衰减振荡/振铃）；`R=0` → 共轭虚根 → **等幅振荡**（无损耗、持续）。选②。
  - 陈述时刻 ④：**二阶电路的响应形态与临界电阻**——RLC 串联二阶电路零输入响应的形态由特征根决定，而特征根只取决于电路结构与参数（R、L、C）、与激励和初始储能无关；以临界电阻 `R_c=2√(L/C)` 为界，`R>R_c` 过阻尼（不振荡）、`R=R_c` 临界、`R<R_c` 欠阻尼（衰减振铃）、`R=0` 等幅振荡。条件：理想 RLC 串联、线性元件、零输入（或叠加在特解上的齐次解）；并联 GLC 的临界判据不同、本课不展开；本课只做形态预判，不解具体响应、不算超调量（L3-03）。
  - 页内 SVG ③（四种形态波形对照：过阻尼单调、临界最快单调、欠阻尼衰减振铃、等幅正弦）与互动面板 B（二阶形态预判台）在此启用。
  - 【QA 锚点】学生必问"R=0 那不是没有电阻了吗，还能叫电路吗"——点明理想无损 LC 是模型极限，实际线圈总有电阻、振铃总会衰减；R=0 只是帮我们看清"振荡来自 L、C 储能交换，电阻负责耗散"（真实卡点）。

### 环节 5：工具选择总流程与过关（约 5′）

- 收口（元认知，无 gate）：给出可迁移的四步口诀——**① 问时间过程还是稳态表现？② 看激励：直流/阶跃 → 时域；单一频率正弦 → 相量；频率当变量 → 频响/谐振。③ 看阶次：一阶 → 三要素；二阶换路 → 先看临界电阻判形态。④ 调对应工具链求解。** 这是第五个、也是最后一个陈述时刻。
- 陈述时刻 ⑤：**工具选择总流程**——面对任何动态/稳态电路问题，先判"暂态过程 / 稳态表现"，再判激励形式与电路阶次，再选时域三要素、相量/阻抗、频响/谐振或二阶形态预判的工具链；判据来自各工具的适用条件，而非题目表面措辞。条件：本课覆盖的一阶 RC/RL 与二阶 RLC、直流/阶跃与单一频率正弦；多频/非线性/高阶留后续课。
- 互动面板 A（工具选择决策台）在此全面可用：学生逐场景选择工具，选后显示推荐工具链与依据。
- 独立练习 9 题（混合型综合题，覆盖两种任务形态，非例题近邻复制）+ 过关自检收尾。

## 六 · 答案区（默认折叠，不提前泄露后续推导）

- 预测 1：②，直流阶跃 + 换路时间过程 → 时域暂态；①相量法只适用正弦稳态，③戴维南只给等效电路不给时间过程。
- 预测 2：②，单一频率正弦稳态 → 相量 + 阻抗 + 功率；①不需要时域微分方程，③只分类不给数值。
- 预测 3：①，甲是持续正弦稳态（可用相量、`Q=ω₀L/R`），乙是换路暂态（回时域，Q 不适用）。
- 预测 4：②，`R>R_c` 过阻尼单调 → `R<R_c` 欠阻尼振铃 → `R=0` 等幅；①忽略了欠阻尼/等幅，③忽略了过阻尼区间。
- 练习：1 ②；2 ②；3 `500/1200/500/过阻尼`（`R_c=2√(0.5/8µ)=2√62500=500Ω`、`α=1200/(2×0.5)=1200`、`ω₀=1/√(0.5×8µ)=500`、`R>R_c`）；4 `100/500/欠阻尼/小`（`R=100<R_c`、`α=100<ω₀=500`）；5 `2000`（`R_c=2√(1/1µ)=2000Ω`）；6 `甲/R 与临界电阻的关系`；7 `0.1/10/10`（`τ=RC=1000×100µ=0.1s`、`k=1/τ=10`，即 `u_C=10(1−e^(−10t))` V）；8 `5/2/0.6`（`|Z|=√(3²+4²)=5`、`I=10/5=2`、`cosφ=3/5=0.6`）；9 `相量/时域+二阶形态预判`。

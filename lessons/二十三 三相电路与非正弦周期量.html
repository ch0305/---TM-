全课宪法

一个核心问题：能不能把学过的相量工具和功率账，按"哪一路"或按"哪一种快慢"分开算、最后再合起来——既算得清多路供电的电压电流和功率，又看得懂非正弦波里各份贡献，并且说清这些简化在什么条件下才成立？
因果顺序：先判断三路相加会怎样 → 再看两根火线之间有多少伏 → 再算三路一起的功率 → 最后处理不是正弦的波形 → 实验台验证。不是时间安排；结论都在预测揭晓后才上板。
本课是工程认知：只求建立图景与边界。复杂的系数手算与不对称联立求解标为「了解即可」，不要求手算。

多路供电 · 关系速查

Y 形：U_l=√3 U_p（线电压超前对应相电压 30°）、I_l=I_p；△ 形：U_l=U_p、I_l=√3 I_p（滞后 30°）。只在对称 + 定相序 + 定参考方向下成立。
对称时中性线电流为零、可省；不对称断线则中性点位移、各相失衡。功率 P=√3 U_l I_l cos φ（φ=阻抗角）；二瓦计 P₁+P₂=P、单独一表无意义、|φ|>60° 时一表可为负。

波形分解 · 速查

f(t)=A₀+ΣA_k cos(kω₁t+φ_k)：直流 + 基波 + 各次谐波，频谱离散。有效值 U=√(U₀²+U₁²+…)。

三相电路与非正弦周期量

前几课我们只会对付一幅正弦波。可电网是三路错开三分之一周期一起送来供电，充电器整流后的波形又根本不是正弦。这节课要问的是：能不能把已经学会的相量工具和功率账，按"哪一路"或按"哪一种快慢"分开算、最后再合起来——既算得清多路供电的电压电流和功率，又看得懂非正弦波里各份贡献，并且说清这些简化在什么条件下才成立？

0 · 核心问题与预测 1（先别算，先判断三路相加会怎样）
师：前几课我们只会对付一幅正弦波；可你家里插座、工厂电机的电，不是一路，是三路错开三分之一周期一起送来的。今天就把你会的相量工具搬到这个现实里，做法是一句话：按"哪一路"或按"哪一种快慢"拆开算，最后合起来。

图上这条路线是今天全部工作的骨架：三路错开三分之一周期 → 拆开看每路 → 合起来看总量 → 守住简化成立的条件。先只回答一个问题：把这三路在任意时刻的电压加起来，会得到什么？

图① · 今天四步路线（自包含示意，不引用书内图号）。

先预测 1：三路正弦彼此错开三分之一周期（也就是 120°），把它们在任意时刻的电压加起来，会得到什么？选定后才解锁揭晓。

先自己选。公布只到"三路相加的结果与原因"这一层；名字与定义在下一步"继续"里才给。

选 B 恒等于零。可用一个恒等式"可见地"推出来——把三路写成相差 120° 的同一个正弦：

cos θ + cos(θ−120°) + cos(θ+120°) = cos θ + 2cos θ·cos120° = cos θ + 2cos θ·(−1/2) = 0

所以对任意时刻 u_A(t)+u_B(t)+u_C(t)=0；由相量的线性性质，也有三个相量相加为零。这是后面所有简化的总根源——但此刻先别急着用它，名字与联结方式在下一步才给。

图②：三路相差 120° 的正弦，逐点相加恒为零。三条曲线彼此错开三分之一周期；把它们在同一时刻的高度相加，处处得到中间那条零线。这就是"和为零"的图像。

图② · 三路正弦与相加为零（自包含示意，不按精确比例）。
陈述时刻 1 · 对称三相电源、相序、Y/△ 联结、相电压与线电压
全称/命名：对称三相电源（symmetrical three-phase source）、相序（phase sequence）、星形/Y 形联结与三角形/△ 形联结、中性点（neutral point）、相线（火线）、相电压（phase voltage）、线电压（line voltage）。
一句定义：三个幅值相等、频率相同、彼此相差 120° 的正弦电压源构成对称三相电源；若相量为 U̇_A=U_p∠0°、U̇_B=U_p∠−120°、U̇_C=U_p∠120°，则任意时刻 u_A+u_B+u_C=0、相量和 U̇_A+U̇_B+U̇_C=0。三相到达最大值的先后次序称相序。Y 形把三相末端接一公共点（中性点），引出三根相线，每相电压为相电压、相线间电压为线电压；△ 形始末端顺次相接，无中性点、线电压即相电压。
符号式：U̇_A=U_p∠0°、U̇_B=U_p∠−120°、U̇_C=U_p∠120°；U̇_A+U̇_B+U̇_C=0。〔邱 §12-1 / p.281–282；李下 §9-8 / PDF 103〕

图③：两种联结方式。Y 形把三相末端接成一点，这点就是中性点，从它引出的三根线叫相线；△ 形把始末端顺次接成闭合环，没有中性点，两根相线之间的电压就等于一相的电压。任一相接反会在 △ 形闭合回路里造成极大短路电流。

1 · 两根火线之间有多少伏（陈述时刻 2 · 揭晓预测 2）
师："和为零"很漂亮，但用户拿到的是两根火线之间的电压——它跟每一路的电压差多少？先别看推导，猜一猜。

既然三路相量彼此差 120°，两根火线上的电压就是两路电压之差。用已学的 KVL 就能把这个差可见地算出来。

先预测 2：Y 形接法里，两根相线之间的电压与每一路电压，幅度上是什么关系？每一路 220 V 时，两根相线之间大约多少伏？此时黑板上还没有推导，选定后才揭晓。

先表态。推导此时还没上板；选定后才板书。

选 B 约 380 V。由 KVL，两根相线之间的电压是两路电压之差，用相量减法可见地推出：

U̇_AB = U̇_A − U̇_B = U_p∠0° − U_p∠−120° = √3·U_p∠30°

两个等幅相量相差 120°，其差是 √3 倍且超前 30°。所以 Y 形 U_l=√3 U_p、线电压超前对应相电压 30°；相电压 220 V → 线电压约 381 V（工程标称取 380 V）。△ 形线电压等于相电压。电流关系：Y 形线电流=相电流；△ 形 I_l=√3 I_p 且滞后 30°。

边界（务必记住）：这套 √3/±30° 只在对称 + 固定相序 + 固定参考方向下成立，不能任意设定；非对称时不能套用。

图④：线电压为什么是 √3 倍且超前 30°。把 U̇_A 与 U̇_B 画成两根等长相量（相差 120°），从 U̇_B 端点指向 U̇_A 端点的差相量就是 U̇_AB：长度是 √3 倍，方向超前 U̇_A 30°。这就是上式在相量图上的样子。

图④ · Y 形相量差（自包含示意，不按精确比例）。
陈述时刻 2 · 线值与相值关系及其适用条件
全称/命名：线电压与相电压、线电流与相电流的关系（line/phase quantities）。
一句定义：对称系统中，Y 形联结满足 U_l=√3 U_p 且线电压超前对应相电压 30°、I_l=I_p；△ 形联结满足 U_l=U_p、I_l=√3 I_p 且线电流滞后对应相电流 30°。这些关系由 KVL/KCL 在相量图上推出。适用条件：只在电源与负载对称、相序确定、参考方向按约定时成立，不能任意设定；非对称时不能套用。
符号式：Y 形 U̇_AB=√3 U̇_A∠30°、U_l=√3 U_p、I_l=I_p；△ 形 U̇_AB=U̇_A、I_A=√3 I_AB∠−30°。〔邱 §12-2 / p.283–284；李下 §9-8 / PDF 104〕
2 · 三路一起供电的功率与中性线（陈述时刻 3 · 揭晓预测 3）
师：前面看到三路电压相加为零。那三路一起供电时，瞬时功率是不是也像单相那样随时间脉动？只知道两根火线之间的电压、每根线的电流和功率因数，能不能一个式子算出总功率？两只表够不够测总量？先猜。

先预测 3：① 三路一起供电的瞬时功率，是否随时间脉动？② 只知道两根火线之间的电压、每根线的电流和功率因数，能否一个式子算出总功率？③ 两只功率表够不够？此时黑板上没有功率公式，也没有两表结论，选定后才揭晓。

先表态。公式与两表结论此时都没上板；选定后才板书推导。

选第一项。分三步板书：

① 对称时可只算一相、中线可省。对称 Y-Y 中负载中性点电压 U̇_N'N=(U̇_A/Z+U̇_B/Z+U̇_C/Z)/(3/Z+1/Z_N)=0（因三路电压相加为零），中线电流 İ_N=İ_A+İ_B+İ_C=0，所以只需算一相，中线可省。

② 不对称时中线不可省。负载不对称时中性点位移 U̇_N'N≠0，各相互相牵连、电压严重失衡（书中算得某相低到 60 V）。中线阻抗接近零，能强使 U̇_N'N≈0、保证各相独立与安全。注意区分两种情形：中线接通时中线电流非零但各相电压仍对称、无位移告警；中线断开时中线电流为零、才发生中性点位移。

③ 功率与二瓦计法。把三路瞬时功率相加，p=3 U_p I_p cos φ 是常量（瞬时功率平衡），总有功 P=√3 U_l I_l cos φ——φ 是负载阻抗角（相电压与相电流相位差），不是线电压与线电流夹角。三相三线制用两只功率表：P₁=U_l I_l cos(φ−30°)、P₂=U_l I_l cos(φ+30°)，P₁+P₂=P；|φ|>60° 时一表可为负，单独一表无意义；不对称四线制不能用。例12-4：P=2.5 kW、cos φ=0.866、U_l=380 V → I_l≈4.386 A，P₁≈1666.68 W、P₂≈833.34 W。

图⑤：中线接与断的两种情形。左图中线接通，负载中性点 N′ 被钳住在电源中性点 N，各相电压保持相等（220 V），但中线电流非零；右图中线断开，N′ 偏移，一相电压掉到 60 V、另两相偏高——这就是"中性点位移"，此时各相电流不能再按 220/Z 简单算。

图⑤ · 中线通断两种情形（自包含示意，不按精确比例）。
陈述时刻 3 · 一相计算法、中性线的作用、三相功率与二瓦计法
全称/命名：归结为一相的计算、中性点位移（neutral-point displacement）、瞬时功率平衡、二瓦计法（two-wattmeter method）。
一句定义：对称 Y-Y 电路因三路电压相加为零，有 U̇_N'N=0、中线电流为零，可只算一相、中线可省；不对称时中性点位移 U̇_N'N≠0 使各相电压失衡、彼此牵连，中性线能强使 U̇_N'N≈0、保证各相独立与安全（接通时中线电流非零但无位移，断开时电流为零才位移）。对称三相瞬时功率 p=3 U_p I_p cos φ 为常量、等于平均功率；P=√3 U_l I_l cos φ，φ 是负载阻抗角。三相三线制用两只功率表，P₁=U_l I_l cos(φ−30°)、P₂=U_l I_l cos(φ+30°)、P₁+P₂=P，单独一表无意义，不对称四线制不可用。
符号式：U̇_N'N=(U̇_A Y_A+U̇_B Y_B+U̇_C Y_C)/(Y_A+Y_B+Y_C)；P=√3 U_l I_l cos φ；P₁+P₂=P。〔邱 §12-3~§12-5 / p.285–290；李下 §9-8~§9-9 / PDF 106、110–114〕

→ 面板 A（多路供电实验台）已解锁，见第 5 节。

3 · 不是正弦的波形怎么办（陈述时刻 4 · 揭晓预测 4）
师：三路供电再"标准"也还是正弦。可整流的方波、脉冲根本不是正弦——最后一问：怎么用只会算正弦的工具处理它？

先预测 4：一个非正弦的周期波形（比如方波），怎么用只会算正弦的工具处理？能不能直接把它当成一个相量？此时黑板上还没有处理办法，也没有功率规则，选定后才揭晓。

先选。分解式与功率规则此时都不在黑板上；选定后才板书。

选 B。满足条件的周期函数可以展开成傅里叶级数：

f(t) = A₀ + Σ A_k cos(kω₁t + φ_k)　＝ 直流 + 基波 + 各次谐波

A₀ 是直流分量、k=1 是基波、k>1 是各次谐波，各次频率是基频的整数倍，频谱是离散的线频谱。收敛快慢看波形光滑程度：方波/脉冲要很多项（取到 11 次约 0.95、35 次仍约 2% 误差），光滑波形几项就够——复杂系数手算 P3 了解即可。

有效值由正交性得 U=√(U₀²+U₁²+…)；平均功率 P=U₀I₀+ΣU_k I_k cos φ_k——不同频率分量的乘积积分为零，只有同频配对才贡献平均功率。例10-9：u=[100+100cos t+50cos2t+30cos3t] V、i=[10cos(t−60°)+2cos(3t−135°)] A，直流与 2 次电压无对应电流、不贡献，基波 250 W、3 次 −21.2 W，总 228.8 W。谐波分析法：逐频建相量模型求同频响应，再在时域相加；不能把不同频率合并成一个相量；直流按 ω=0 单独处理（电感短路、电容开路）。

图⑥：方波 = 基波 + 3 次 + 5 次…左边把方波写成若干正弦分量之和（取 1、3、5 次已有明显方波模样），右边是离散频谱：只在整数倍频率处有线，幅度随次数下降。这就是"按快慢拆开"的图像。

图⑥ · 非正弦分解与离散频谱（自包含示意，不按精确比例）。
陈述时刻 4 · 傅里叶级数、有效值平方和、平均功率同频配对、谐波分析法
全称/命名：傅里叶级数（Fourier series）、直流分量/基波/高次谐波、幅度频谱、谐波分析法（harmonic analysis method）。
一句定义：非正弦周期量可分解为 f(t)=A₀+ΣA_kcos(kω₁t+φ_k)=直流+基波+各次谐波，各次频率为基频正整数倍、频谱离散。有效值 U=√(U₀²+U₁²+…)。平均功率 P=U₀I₀+ΣU_kI_kcosφ_k：不同频率分量乘积的积分为零，只有同频电压电流才产生平均功率。谐波分析法=按傅里叶分解激励 → 每个频率单独建相量模型求同频响应 → 时域叠加；不同频率不能合并成一个相量，直流按 ω=0 单独处理（电感短路、电容开路）。复杂系数手算 P3 了解即可。
符号式：f(t)=A₀+ΣA_kcos(kω₁t+φ_k)；U=√(U₀²+U₁²+…)；P=U₀I₀+ΣU_kI_kcosφ_k。〔邱 §13-2~§13-4 / p.296–306；李下 §10-4~§10-5 / PDF 134–145〕

6 · 收尾与钩子
师：回扣核心问题——把相量工具和功率账"按哪一路"或"按哪一种快慢"拆开算、最后合起来：多路供电因三路相加为零，可只算一相、线值是相值的 √3 倍、功率 √3·U·I·cos φ；非正弦分解为直流+基波+谐波，只有同频配对才产生平均功率，逐频算完时域相加。但这些简化都有条件——对称、定相序、定参考方向、同频、直流 ω=0，越过边界就不成立。

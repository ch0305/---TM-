全课宪法

一个核心问题：能不能让微分方程直接变成代数方程、初始状态自己带进去，还能让那个"特征根"变成可四则运算的量，从而照搬电阻电路那一整套办法？
因果顺序：旧办法麻烦 → 换个域 → 微分变代数 → 元件新长相 → 解出来读回时域。不是时间安排；公式都在预测揭晓后才上板。
本课是选学强化：只求会换域、会读结构；复杂的展开技巧标为「了解即可」，不要求手算。

换域的定义与微分性质

F(s)=∫₀₋^∞ f(t)e^(−st)dt，s=σ+jω；L[f']=sF(s)−f(0₋)；ΣI(s)=0、ΣU(s)=0。
常用对：ε(t)↔1/s、e^(−at)↔1/(s+a)、sin ωt↔ω/(s²+ω²)、cos ωt↔s/(s²+ω²)。

元件的 s 域长相

Z_R=R、Z_L=sL、Z_C=1/(sC)；非零初值：电感串 −Li(0₋)、电容串 u_C(0₋)/s。
零初始时才可"把 jω 换成 s"；σ=0 时 s 域阻抗退回相量阻抗。

分母的根怎么读

K_i/(s−s_i)↔K_i e^(s_i t)：实部=衰减率、虚部=振荡频率。只有 Z(s)=0 的根才是特征根 p（定瞬态）；激励极点对应稳态（例12-8 的 ±j3）。
全响应 = 瞬态（固有） + 稳态（强迫）。复杂部分分式 P3 了解即可。

拉普拉斯变换与 s 域直觉

上一课我们看一眼特征根就预判了二阶电路的性格。但这节课要解决的是：每次都得先列微分方程、再求根、还要把电感电流与电容电压的初值换算成各阶导数的初值——能不能换一种"运算"方式，让微分方程直接变成代数方程、把初始状态自动带进去，还能让那个特征根变成一个像电阻一样可以做四则运算的量，从而用同一套电阻电路办法系统求解，并从结果里一眼看出响应由哪些指数衰减成分（衰减快慢、振荡频率）组成？

0 · 核心问题与预测 1（先别算，先判断这是不是老朋友）
师：上一课看一眼特征根就知道电路会振铃还是单调——但要先列微分方程、求根，初值还得从电感电流、电容电压换算成各阶导数的初值，又慢又容易错。今天换一种玩法：把整个问题搬到一个新"域"里。

图上这条路线是今天全部工作的骨架：时域里列方程 → 换到新域 → 在新域里解代数方程 → 换回时域读结果。先只回答一个问题：这种"换域简化"的思路，是不是你见过的老朋友？

先预测 1：拉氏变换和我们学过的相量法，是什么关系？选定后才解锁揭晓。

先自己选。公布只到"同属换域方法 + 新域比老朋友多一个实部 + 常用对查表"；名字与定义式在下一步"继续"里才给。

选 B。相量法把正弦量换成复数相量、微分变乘 jω，把正弦稳态问题变成复数代数方程；今天这个变换把任意时间函数换成新域里的函数、微分变乘 s，把动态电路的微分方程变成代数方程。两者都是"换域 → 简化运算 → 换回"的变换域方法。区别在新变量 s=σ+jω 比 jω 多一个实部 σ：于是既能描述等幅正弦（σ=0），也能描述衰减振荡（σ<0）、单调衰减与增长——这正是上一课那些形态在新域里的样子。

常用对应查表即可，少数常用的记住：δ(t)↔1、ε(t)↔1/s、t↔1/s²、e^(−at)↔1/(s+a)、sin ωt↔ω/(s²+ω²)、cos ωt↔s/(s²+ω²)。此处只给"换域 + 查表"，不写微分性质、不写元件的新长相、不提分母里藏着什么。

图②：老朋友与新朋友。相量法只用虚轴上的 jω，所以只能说等幅正弦；新变量 s=σ+jω 在复平面上是个点，实部 σ 告诉你衰减（或增长）快慢，虚部 ω 告诉你振荡频率。上一课的过阻尼、欠阻尼，在新域里就是实部不同的位置。

图② · 相量 jω 与复频率 s 的对照（自包含示意，不按精确比例）。
陈述时刻 1 · 拉普拉斯变换与复频率 s
全称/命名：拉普拉斯变换（Laplace transform）、象函数（image function）、原函数（original function）、复频率（complex frequency）。
一句定义：定义在 [0,∞) 的函数 f(t) 的拉普拉斯变换为 F(s)=∫₀₋^∞ f(t)e^(−st)dt，其中 s=σ+jω 为复数（复频率）；F(s) 叫 f(t) 的象函数，f(t) 叫 F(s) 的原函数。积分下限取 0₋ 可计及 t=0 的冲激。它与相量法同属变换域方法，但 s 的实部 σ 使它可描述衰减/增长，不局限于正弦稳态。
符号式：F(s)=∫₀₋^∞ f(t)e^(−st)dt；s=σ+jω；常用对 ε(t)↔1/s、e^(−at)↔1/(s+a)、sin ωt↔ω/(s²+ω²)。〔邱 §14-1 印刷 p.320–321；李下 §12-1 / PDF 202–204〕
1 · 换域之后，微分会变成什么（陈述时刻 2 · 揭晓预测 2）
师：换域本身不值钱，值钱的是微分在新域里变简单了。先别看公式——猜一猜。

经典法最烦的是"要各阶导数的初值"，而电路实际上只给你电感电流、电容电压这两个初始状态。下面这步就是来看：这个老麻烦在新域里会不会自己消失。

先预测 2：相量法里微分变成乘 jω；猜新域里微分会变成什么运算？经典法最烦的"各阶导数初值"，会不会自动带进来？KCL/KVL 搬到新域会怎样？此时黑板上还没有微分性质公式，选定后才揭晓。

先表态。公式此时还没上板；选定后才板书推导。

选第一项。用分部积分把这条性质"可见地推出来"：

L[f′] = ∫₀₋^∞ f′(t)e^(−st)dt = [f(t)e^(−st)]₀₋^∞ + s∫₀₋^∞ f(t)e^(−st)dt = sF(s) − f(0₋)

关键在最后那一项 −f(0₋)：微分一次，只需要 f 自己在 0₋ 的值，不是它的导数值；微分两次是 s²F−s f(0₋)−f'(0₋)。在随后写出的元件 VCR 里只出现 i_L(0₋)、u_C(0₋)——恰好就是电路给你的初始状态，不必像经典法那样去换算回路电流的各阶导数初值。至于元件到底长什么样、sL 会不会出现，留到下一个预测揭晓，这里不写。

线性性质还让基尔霍夫定律直接搬过来：ΣI(s)=0、ΣU(s)=0，和相量形式一模一样。既然 KCL/KVL 照搬，那电阻电路那套节点/网孔/叠加/戴维南是不是也能照搬？差就差在元件的长相。

陈述时刻 2 · 微分性质、初值自动带入与 KCL/KVL 运算形式
全称/命名：拉氏变换的微分性质（differentiation property）、基尔霍夫定律的运算形式。
一句定义：若 L[f(t)]=F(s)，则 L[df/dt]=sF(s)−f(0₋)——时域微分变成 s 域乘 s 再减去初值 f(0₋)，只需 f 自己在 0₋ 的值；微分两次 s²F−s f(0₋)−f'(0₋) 的高阶初值由低阶初值递推。在后面写出的 s 域元件 VCR 里只出现 i_L(0₋)、u_C(0₋)（电路给的初始状态），不必像经典法那样换算回路电流各阶导数初值。由线性性质，KCL/KVL 在 s 域仍是各支路电流的象函数和为零、各支路电压的象函数和为零：ΣI(s)=0、ΣU(s)=0。
符号式：L[f']=sF(s)−f(0₋)；L[f'']=s²F−s f(0₋)−f'(0₋)；ΣI(s)=0、ΣU(s)=0。（元件 VCR 与 sL、1/sC 留陈述时刻 3。）〔邱 §14-2 印刷 p.322–324；李下 §12-1 / PDF 204–205〕
2 · 元件在新域里的长相（陈述时刻 3 · 揭晓预测 3）
师：电阻 u=Ri 取变换还是 U=RI。电感、电容靠微分/积分性质推出新长相——先猜长相，再对答案。

先预测 3：相量域里 Z_L=jωL、Z_C=1/(jωC)；猜新域里对应的运算阻抗长什么样？如果把新变量取成纯虚数 jω（σ=0），它们会不会退回相量值？此时黑板上还没有 sL / 1/sC 的答案。

选第一项。板书元件的新长相：

Z_R = R　｜　Z_L = sL　｜　Z_C = 1/(sC)　｜　Z(s) = U(s)/I(s)（零状态元件）

电感由 u=L di/dt 得 U(s)=sL·I(s)−L i(0₋)：运算阻抗 sL 之外，还串一个附加电压源 −L i(0₋)。电容由积分关系得 U(s)=(1/sC)I(s)+u_C(0₋)/s：运算阻抗 1/sC 之外，串附加电压源 u_C(0₋)/s。这就是"把 jω 换成 s"：零初始时相量模型直接变成运算电路，电阻电路那套办法可以照搬；非零初始时再加附加电源。

图③：微分性质怎样长出电感的运算模型。乘 s 的部分变成运算阻抗 sL，减掉的初值 −L i(0₋) 变成一个附加电源——初始状态就是这样"自己跳进来"的。

图③ · 电感运算模型（自包含示意）。

图④：把整个 RLC 搬进新域。电阻仍是 R，电感变 sL，电容变 1/sC，初值各带一个附加源；右侧箭头提示"相量法的 jω 直接换成 s"，所以节点法、网孔法、叠加、戴维南都能照搬，只是代数里的量变成了含 s 的分式。

图④ · RLC 运算电路与 jω→s（自包含示意）。
陈述时刻 3 · 运算阻抗、运算电路与"jω→s"
全称/命名：运算阻抗（operational impedance）/广义阻抗（generalized impedance）、运算电路（operational circuit）、拉普拉斯阻抗。
一句定义：由微分/积分性质，元件 VCR 的 s 域形式为 U(s)=Z(s)I(s)+初值源：电阻 Z_R=R，电感 Z_L=sL（附加源 −L i(0₋)），电容 Z_C=1/sC（附加源 u_C(0₋)/s）；零状态时 Z(s)=U(s)/I(s) 称广义阻抗。零初始条件下，把相量模型里的 jω 换成 s 就得到 s 域运算电路，所以相量法的节点/网孔/叠加/戴维南可原样搬到 s 域；非零初始须另加初值电源。
符号式：Z_R=R、Z_L=sL、Z_C=1/(sC)；s=σ+jω，σ=0 时退化为相量阻抗。〔邱 §14-4 印刷 p.331–334；李下 §12-3 / PDF 215–216〕

3 · 解出来之后怎么读回时域（陈述时刻 4 · 揭晓预测 4）
师：现在能照搬整套电阻电路办法列代数方程了。板书写到前两步就停：① 画运算电路（含初值电源）→ ② 用节点/网孔/叠加/戴维南解出 F(s)（s 的有理分式）。解出来是一堆分式——第三步怎么读回时域？它的分母里藏着什么？

先预测 4：例14-6 的 F(s)=(2s+1)/(s³+7s²+10s) 分母根是 0、−2、−5；例12-8 的 I(s)=60/((s²+9)(s+4)) 分母含 −4 与 ±j3。这些分母根，和上一课的特征根 p、和响应里的常数项 / e^(−2t) / 衰减振荡是什么关系？此刻黑板上只写了前两步，第三步还没上板。

题干给分母根只作提问素材，不给"哪些是特征根、哪些是稳态"的结论；选定后才板书第三步。

板书第三步：部分分式展开 + 查表反变换得 f(t)（给常用对；复杂展开 P3「了解即可」，只要求看得懂"根↔成分"的对应，不要求手算）。

选第一项。若分母有单根 s_i，部分分式里就有一项 K_i/(s−s_i)，反变换是 K_i e^(s_i t) 这样一个模态；共轭复根 α±jω 两项合成 e^(αt)(A cos ωt+B sin ωt) 衰减振荡；根 0 对应常数项（不衰减）。所以分母根 s_i 就是响应成分 e^(s_i t) 的指数：实部定衰减率（s=−4 → e^(−4t)，τ=1/4），虚部定振荡频率。

但要分清两类根：只有来自网络自身 Z(s)=0（齐次/无源方程）的根才是上一课的特征根 p，决定瞬态；激励引入的极点不是电路特征根，对应稳态强迫分量。例12-8 的 I(s)=60/((s²+9)(s+4))：s=−4 来自 Z(s)=2s+8=0，给瞬态 2.4e^(−4t)；s=±j3 来自激励 U(s)=120/(s²+9)，给稳态 4sin(3t−37°)（相量法可核对幅值 4A）。全响应 = 瞬态 + 稳态。

图⑤：例12-8 的全响应拆成两块。左边是按 e^(−4t) 衰减的瞬态（时间常数 τ=0.25s，根 s=−4）；右边是正弦稳态 4sin(3t−37°)（由激励的 ±j3 带来）；两块相加才是真实的 i(t)。记住这个对照，就不会把激励极点误认成电路特征根。

图⑤ · 例12-8 全响应分解（自包含示意，不按精确比例）。
陈述时刻 4 · 反变换、分母根=模态（其中 Z(s)=0 的根=特征根 p）、全响应
全称/命名：部分分式展开（partial fraction expansion）、反变换（inverse transform）、模态（mode）、全响应（complete response）= 瞬态响应 + 稳态响应。
一句定义：运算法解 s 域代数方程得象函数 F(s)（s 的有理分式）后，用部分分式展开 + 查表反变换得时域解；F(s) 分母的每个根 s_i 对应一项 K_i e^(s_i t)（共轭复根合成为衰减振荡），即一个响应模态——实部决定衰减率、虚部决定振荡频率。注意适用条件：只有来自网络自身 Z(s)=0（齐次/无源方程）的根才是 L3-03 的特征根 p，决定瞬态（固有）响应；激励引入的极点不是电路特征根，对应稳态（强迫）响应。以例12-8 的 I(s)=60/((s²+9)(s+4)) 为例：s=−4 来自 Z(s)=2s+8=0，是特征根、给瞬态 2.4e^(−4t)；s=±j3 来自激励 U(s)=120/(s²+9)，不是特征根、给稳态 4sin(3t−37°)。电路的全响应 = 瞬态（固有）响应 + 稳态（强迫）响应。
符号式：K_i/(s−s_i) ↔ K_i e^(s_i t)；s=−4 → e^(−4t)、τ=1/4；i(t)=2.4e^(−4t)+4sin(3t−37°)（例12-8）。复杂部分分式展开 P3 了解即可。〔邱 §14-3 印刷 p.327–330、§14-5 p.334–336；李下 §12-2~§12-3 例12-8 / PDF 208–217〕

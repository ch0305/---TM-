全课宪法

一个核心问题：一根导线什么时候还能当成「一根理想的线」，什么时候必须换成「另一种看法」——沿线电压电流随位置变化、有延迟和折返？怎样在布线之前就判断出来？
因果顺序：先审这个默认 → 再看「长短」由什么决定 → 再给导线换模型 → 再看信号走到末端会怎样 → 两实验台验证 → 独立练习。不是时间安排；结论都在预测揭晓后才上板。
本课是工程认知：只求建立判据与边界直觉。方程求解、传播常数、端接网络标为「了解即可」，不要求手算。

一根导线什么时候不再是「一根线」

前面所有课，我们量过电阻、电容、电感，却从来没量过导线有多长，还一直默认「导线两端电压相同、电流处处相同」。今天专门来审这个默认：一根导线什么时候还能当成「一根理想的线」，什么时候必须换成「另一种看法」（沿线电压电流随位置变化、有延迟和折返）？我们怎样在布线之前就判断出来？

师：前面所有课，我们从来没量过导线有多长，却一直默认导线两端电压相同、电流处处相同。今天专门来审这个默认。先别急着判，先回答：它是不是永远成立？

图上这条路线是今天全部工作的骨架：审这个默认 → 看「长短」由什么决定 → 给导线换一种模型 → 看信号走到末端会怎样。先只回答一个问题：导线两端电压相同、电流处处相同——这个默认有没有条件？

图① · 今天四步路线（自包含示意，不引用书内图号）。

先预测 1：「导线两端电压相同、电流处处相同」这个默认：A 永远成立 / B 有条件，取决于信号有多快、电路有多大 / C 只在直流成立。选定后才解锁揭晓。

先自己选。公布只到「这个默认的条件与名字」这一层；完整定义与符号式在下一步「继续」里才给。

选 B：有条件。回扣教材原文：在这种电路里，尺寸是无关紧要的——电流只是时间 t 的函数，谈不上是空间位置 x 的函数；任一时刻从元件一端流入的电流等于另一端流出的电流，才有「支路电流」「支路电压」，才谈得上 VCR、KCL、KVL。采用这个模型的条件是：电路尺寸远小于其正常工作频率所对应的波长、传播推迟可以忽略。

i = i(t)，u = u(t)（与位置无关）；　l ≪ λ ⇒ 可当一根理想的线

其中 λ 读作「信号波长」，是一个长度尺度；它的算法下一步才给。反过来，一旦尺寸和这个长度尺度可比，两端就不再处处相同——这就是今天要认出的边界。

图②：两种看法的对照。左边：导线两端电压、电流处处相同，整根线可以缩成一个点。右边：同一时刻沿线电压高低起伏、随位置而变，导线必须当成一条「有长度的-path」来看。这就是「理想连接」与「另一种看法」的分界。

图② · 两种导线看法对照（自包含示意，不按精确比例）。
陈述时刻 1 · 集总参数电路（集总假设）
全称/命名：集总参数电路（lumped-parameter circuit）与集总假设。
一句定义：当电路的几何尺寸远小于信号波长、电磁作用的传播推迟可忽略时，可把元件视为空间中的点，元件电流只随时间 t 变化、不随位置 x 变化；只有在这种电路里才谈得上支路电流/电压、VCR、KCL 与 KVL。这里 λ 是「信号波长」这个长度尺度，其算法见陈述时刻 2。
符号式：l ≪ λ ⇒ i=i(t), u=u(t)。〔邱 §18-1 / p.450–451；李下 13-1 / PDF 232〕
1 · 长短到底由什么决定（陈述时刻 2 · 揭晓预测 2）
师：既然这个默认有条件，那条件到底怎么量？先看两个真实场景：50 Hz 的电力线跑几百公里，板子上一条 10 cm 走线——谁更「长」？先别看公式，猜一猜。

先预测 2：50 Hz 几百公里的电力线，和板上一条 10 cm 走线，为什么「长」「短」会反过来？A 由绝对长度决定 / B 相对信号本身的变化快慢与几何尺寸而言 / C 由电压高低决定。此时黑板上没有公式，选定后才揭晓。

先表态。公式与数值此时还没上板；选定后才板书。

选 B：「长」是相对量。教材用正弦信号的波长来量它：

λ = v / f （真空 v = c）；　l ≪ λ ⇒ 可当集总；　l 可与 λ 比较 ⇒ 长线

f 是工作频率，v 是传播速度。50 Hz 时 λ=3×10⁸/50=6000 km，一般部件都满足 l≪λ；300 MHz 时 λ=1 m，30 GHz 时 λ=1 cm——此时 10 cm 走线就是长线，再按一根理想的线处理会算出错误结果。

同一判据的时域说法是推出来的，不是背的：把 l ≪ λ 两边同除以速度 v，得 l/v ≪ λ/v；而 λ/v = 1/f = T（周期），所以 Δt = l/v ≪ T。含义是：在电磁作用传过全线的时间内，电源值几乎没变，自然看不到沿线波动。

迁移到数字信号（〔通识〕工程经验，不冒充书中公式）：t_r 是上升沿时间（电平从低跳到高所需的时间），度量信号有多快；边沿主导时把 f_knee≈0.35/t_r 代入上面的 λ=v/f，得到飞行时间 t_d=l/v 与 t_r/6 比较：t_d > t_r/6 ⇒ 启动 SI 思维。正弦题则直接用信号的正弦频率（见练习 2）。

图③：同一条 10 cm 走线，在不同频率下身份不同。上面一条正弦在 50 Hz 下波长极大，走线只占极小一段（短）；下面一条在 30 GHz 下波长仅 1 cm，同样这条走线跨了十个波长（长）。右侧是时域说法：Δt=l/v 是波从一端飞到另一端的时间，与周期（或边沿）比大小。

图③ · 波长的相对性与飞行时间（自包含示意，不按精确比例）。
陈述时刻 2 · 长线、波长判据与飞行时间
全称/命名：长线（electrically long line）、工作波长、飞行时间（flight time）、上升沿时间、膝点频率。
一句定义：线长 l 与工作波长 λ 可相比较的传输线称为长线；λ=v/f（真空 v=c）。l≪λ 可用集总模型；两边同除以 v 得等价时域判据 Δt=l/v≪T；l 可与 λ 比较时沿线电压电流明显波动、必须用分布模型。对边沿主导的数字信号，取 f_knee≈0.35/t_r（t_r 为上升沿时间），若 t_d=l/v>t_r/6 则启动 SI 思维（0.35 与 1/6 都是〔通识〕工程经验，推导留 S13）。
符号式：λ=v/f；l≪λ ⇔ l/v≪T；t_d=l/v，t_d>t_r/6。〔邱 §18-1 / p.452–453；李下 13-1 / PDF 233〕
三条边界（务必记住）：①「长」相对波长而言，同一走线在不同频率下身份不同；②直流/低频若关心沿线电压电流变化，也可能要用分布模型；③两端 T/π 等效的参数是在某一频率下由分布模型求出的，不是集总模型的简单替代。
2 · 导线还能怎么建模（陈述时刻 3 · 揭晓预测 3）
师：当一根线不能再当理想连接，是不是就没办法用电路方法了？先猜：还能不能把导线拆成更小的电路来算？

先预测 3：不能用原来的办法了，导线还能用电路模型来算吗？A 完全不能，只能上电磁场 / B 切成无穷多小段，每段用小电阻、电感、电容、电导 / C 直接把整根线当一个大电阻。此时黑板上没有模型，选定后才揭晓。

先表态。模型的样子此时还没上板；选定后才板书。

选 B。教材的做法是：把导线切成无穷多长度元 dx——每段导线上有电阻 R₀ dx 和电感 L₀ dx，两导线之间有电导 G₀ dx 和电容 C₀ dx。这样构成的模型是「集总参数元件构成的极限情况」：每一小段仍是你会的小集总电路。

在 dx 左端电压为 u、电流为 i，右端为 u+du、i+di；对这一小段写 KVL 与 KCL、略去二阶无穷小量、约去 dx，就可见地推出下面两条偏微分方程——这是从已学工具走过去的桥，不是新定律：

−∂u/∂x = R₀ i + L₀ ∂i/∂t　｜　−∂i/∂x = G₀ u + C₀ ∂u/∂t　（电报方程）

其中 R₀ L₀ C₀ G₀ 是每单位长度的原参数；沿线处处相等就叫均匀传输线。求解方程、传播常数、特性阻抗的严格推导属 P3「了解即可」，本课不展开，留后续深入。

图④：一小段 dx 长什么样。上支路串 R₀dx 与 L₀dx（来线），下支路是回线，两线之间并上 G₀dx 与 C₀dx。左端是 u,i，右端是 u+du, i+di。把无数个这样的小段首尾相接，就得到整根线的分布模型。

图④ · 一小段 dx 的等效（自包含示意，不引用书内图号）。
陈述时刻 3 · 均匀传输线与分布参数模型
全称/命名：原参数（primary constants）、均匀传输线（uniform transmission line）、分布参数模型、电报方程（telegrapher's equations）。
一句定义：每单位长度的电阻 R₀、电感 L₀、电容 C₀、电导 G₀ 称为传输线的原参数；沿线处处相等即均匀传输线。把线切成 dx 小段、每段串 R₀dx+L₀dx、段间并 G₀dx+C₀dx，由已学的 KCL/KVL 略去二阶无穷小量得电报方程；电压电流是位置 x 与时间 t 的二元函数。
符号式：−∂u/∂x=R₀i+L₀∂i/∂t，−∂i/∂x=G₀u+C₀∂u/∂t。〔邱 §18-2 / p.453–455；李下 13-1 / PDF 233〕
边界：方程求解、传播常数、特性阻抗的严格推导标 P3「了解即可」，本课只看到「从集总到分布」这座桥。

3 · 走到末端的信号（陈述时刻 4 · 揭晓预测 4）
师：信号沿线跑到末端，末端接的负载会不会影响它？先猜会发生什么——这也是把 L3-03 见过的振铃现象追到根上的一步。

先预测 4：信号走到线的末端后，末端接的负载会不会影响它？A 原样到达、没有影响 / B 有一部分会折返回来、与后来的波叠加 / C 电流必为零。此时黑板上没有结论，选定后才揭晓。

先选。结论与公式此时都不在黑板上；选定后才板书。

选 B。当负载阻抗与线的特性阻抗不等时，入射波在终端发生反射：一部分能量折返回来，与后来的波叠加，于是在时域看到过冲、振铃——机理是波的折返，不是 L3-03 那种集中 LCR 谐振。反射系数（〔通识〕，推导 P3）：

Γ = (Z_L − Z₀)/(Z_L + Z₀)；　负载端首次阶跃电压 = (1 + Γ) × 入射电压

三种典型情形：Γ=0 匹配（无折返，电压原样到达）；Γ=+1 开路（全部折返且同向叠加，电压翻倍）；Γ=−1 短路（全部折返且反相，电压为零）。这些是现象认知，公式推导与端接设计留后续深入。

图⑤：入射波到达负载后折返。上排箭头向右是入射波，下排箭头向左是折返波；三个小图分别是匹配（无折返）、开路（同向叠加翻倍）、短路（反相抵消为零）。线段高度表示电压大小。

图⑤ · 末端折返与三种情形（自包含示意，不按精确比例）。
陈述时刻 4 · 反射、阻抗失配与现象认知
全称/命名：反射（reflection）、反射系数、阻抗匹配（impedance matching）、过冲与振铃。
一句定义：负载阻抗与特性阻抗不等时，入射波在终端发生反射；Γ=(Z_L−Z₀)/(Z_L+Z₀)（〔通识〕，推导 P3），负载端首次阶跃电压为入射的 1+Γ 倍：匹配 Γ=0、开路 Γ=+1（翻倍）、短路 Γ=−1（为零）。反射与延时在时域表现为过冲/振铃，机理与集中参数谐振不同。
符号式：Γ=(Z_L−Z₀)/(Z_L+Z₀)；u_load首=(1+Γ)u_inc。
边界：公式推导、特性阻抗严格定义、端接网络与 S 参数属 P3，留 S13 深入；本课只做现象认知。

5 · 独立练习（8 题，先作答再判定）与过关
🔒 独立练习在四个预测全部揭晓后出现（题干会用到前面刚揭晓的结论）。

形态一 · 自己判（1–4）；形态二 · 看现象反推（5–8）。都不是前面例题的近邻复制。数值题容差 ±2%，文字按关键词匹配（不区分大小写）。

练习 1（形态一）· t_r=2 ns、l=30 cm、FR4（v=15 cm/ns）。求飞行时间 t_d 多少 ns？判集总还是分布。

6 · 收尾与钩子
师：回扣核心问题——一根导线什么时候还能当理想的线？答案是看尺寸相对信号波长（或边沿快慢）是否足够小：l≪λ（时域 t_d≪T）时可当集总，前面所有工具照用；可与波长比较时就必须按分布域处理，用 R₀ L₀ C₀ G₀ 建模，末端还会出现反射与振铃。三条边界同时成立：「长」是相对量、直流低频也可能分布、两端等效参数只在某一频率下有效。我们不是推翻前 23 课，而是给它们标出适用边界。

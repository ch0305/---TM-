两条更基本的规则：KCL 与 KVL

这一页按教案的揭示顺序制作：先遇到“凭什么”，再要定律；点“继续/公布”才会出现下一段。先把记号认下来——Σ 读作“连加”，Σi=0 就是把支路电流全加起来。

两个凭什么→ 认连接→ KCL→ KVL→ 合用+翻方向→ 迁移自检
上方链条是本课的理解顺序，不是时间安排。每一步都是因为上一步不够用了才出现。
开场 · 两个“凭什么”（4′）

一个节点汇了三条支路，一个回路里串着两个电阻。
为什么我随手把电流箭头、电压极性、绕行方向一标，Σi = 0 和 Σu = 0 就自己成立？

“如果我再问一句：这些箭头和方向若是别人画好贴在题上的，我又该照着它怎么列方程？”

示意图：先不标任何电流箭头、电压极性、绕行方向——问题就是“凭什么随手一标，方程就成立？”

先认记号：Σ 是希腊字母 sigma，读作“连加”；Σi=0＝把所有支路电流加起来等于零，Σu=0 同理；“绕行方向”就是你沿回路走一圈的方向。现在只要认得，不要求会用。

这两个“凭什么”，就是今天要找的东西。先别记定律名——想想：节点上电流“流入＝流出”，凭的是什么？绕回路一圈电压“加起来为零”，又凭的是什么？

1 · 先认清“连在哪里”：支路、节点、回路（6′）〔邱 p.22 / 李 p.12〕

“第一课只盯一个电阻。现在元件接在一起了，每个元件自己的 u=Ri 还是对的，但它管不了‘三条支路在同一个点上碰头’这件事。变量受两类约束：一类来自元件特性，叫 VCR（电压电流关系）；另一类来自连接方式，叫几何约束或拓扑约束——‘拓扑’就是连接关系。”

板书两行：VCR → 管元件自己；KCL / KVL → 管连接方式。

  • 每个二端元件是一条支路；支路的连接点叫节点；由支路构成的闭合路径叫回路。
  • 最常见的坑：a 点和 b 点用理想导线连着，从电的角度看是同一个端点，只能算一个节点。电路图可以改画，只要连接关系不变。
  • 回路内部不包别的回路叫网孔——今天只认个名字，L1-06 再拿它列方程。

即时识别：一个图里 a、b 用一段导线直连，它们算一个节点还是两个？

一个节点。理想导线电阻为零，a、b 电位处处相同，是同一个“电的点”。判据不是“图上画了几条线”，而是“是不是被理想导线连在一起”。

顺手记一个名字：我们讨论的是集总电路——先记住，收尾时讲它成立的前提。

2 · KCL：为什么“流入 = 流出”不是口诀（12′）〔李 p.12–13 / 邱 p.23〕

预测 1（先猜，别算）：节点 O 汇三条支路，统一按流出为正。参考箭头：①号朝内、②号朝外、③号朝外。实际电流是①号 3 A 流入、②号 1 A 流出、③号 2 A 流出——都和各自箭头同向，所以 i₁=+3、i₂=+1、i₃=+2，−i₁+i₂+i₃=−3+1+2=0。
现在把③号的参考箭头改成朝内，其他都不动，照旧写 Σi=0，方程还成立吗？

先说理由，先别算。选完才能公布。

电荷守恒：电荷既不能创造也不能消灭。而节点只是理想导体的汇合点，不可能积累电荷——所以节点上电荷随时间的变化率 dq/dt = 0。

流进节点电荷的速率，就是各支路电流按参考方向带符号相加：dq/dt = i₁ + i₂ − i₃ = 0。

电荷守恒 → 节点不积累电荷 → Σi = 0
基尔霍夫电流定律（Kirchhoff's Current Law，KCL）〔邱 p.22–23〕：在集总电路中，任何时刻，对任一节点，所有支路电流的代数和恒等于零。记作 Σi = 0。

dq/dt 就是“节点上电荷的多少随时间变化的快慢”，今天只要知道它等于 0。Σ 是开场认过的“连加”，这里第一次正式用它。

〔邱 p.23〕“流出节点的电流前取 ‘+’，流入的取 ‘−’；流出还是流入，均按参考方向判断。”这里的 ± 是项前符号，不是电流本身的正负。

两套约定，完全等效：李瀚荪按“流进为正”推得 i₁+i₂−i₃=0，邱关源按“流出为正”写成 Σi=0——两式乘 −1 就互转，书上说“两种说法是等效的”。本课统一用“流出为正”；你用“流进为正”也完全对，只要别中途混。所谓“流入=流出”不是第三套约定，它就是 Σi=0 的口语说法。

成立。③号箭头改朝内后，同一个“2 A 流出”的物理事实，代数值从 i₃=+2 变成 i₃′=−2；方程里那一项也从“+i₃”（箭头朝外）改写成“−i₃′”（箭头朝内），而 −(−2)=+2，与原来一模一样。变的只是标记，物理没变，方程仍成立。

即时检查（口头）：流出为正，求 i₃

已知 i₁=2 A、i₂=3 A，列 Σi=0 求 i₃ 并说实际方向。

自包含示意图：按图中参考箭头与“流出为正”列方程。

−i₁−i₂+i₃=0 ⇒ i₃=5 A。参考箭头朝外、数值为正，所以实际有 5 A 流出节点。

广义节点（只认不练）：KCL 对包围几个节点的闭合面也适用——把几个节点圈成一个“大节点”，内部支路电流一正一负抵消，剩下穿过边界的电流。本质是电荷守恒。

3 · KVL：为什么“绕一圈加起来为零”（14′）〔邱 p.24 / 李 p.15–16〕

预测 2（先猜，别算）：一个矩形回路——左边电压源 U_S（上 + 下 −），上边电阻电压 u₁（左 + 右 −），右边电阻电压 u₂（上 + 下 −），下边是导线。绕行方向＝沿回路走一圈的方向，先选顺时针（从左上角沿上边向右）。
顺时针写 −U_S+u₁+u₂=0；改逆时针写 +U_S−u₁−u₂=0。两式矛盾吗，还是同一件事？

〔邱 p.19〕电压源：两端电压就是给定的 U_S，电流由外电路决定——今天只要这一层。

“第一课用过 u_AB = V_A − V_B：两点间的电压就是两点电位的差。书上说得很直接〔邱 p.24〕：‘④、③两节点之间的电压是单值的，不论沿支路 3 或沿支路 4、1、2 构成的路径，两点的电压值相等。’”

每个节点有确定的电位，两点的电压只由这两个电位决定，与你走哪条路无关。

沿任一回路绕一圈：从某点出发又回到同一个点，电位绕一圈回到原值，净变化只能是 0。把沿途每一小段的电位差带符号加起来，就是：

电位单值 → 路径无关 → 绕一圈回原点 → Σu = 0
基尔霍夫电压定律（Kirchhoff's Voltage Law，KVL）〔邱 p.23–24〕：在集总电路中，任何时刻，沿任一回路，所有支路电压的代数和恒等于零。记作 Σu = 0。

这条公式是从第一课的电位差概念长出来的，不是新背的规定。〔邱 p.24 脚注：“实质上，是能量守恒和转换定律的反映。”能量守恒的完整推导放页尾，主线不借功率。〕

〔邱 p.24〕“沿任一回路，所有支路电压的代数和恒等于零。”绕行方向任意指定；支路电压的参考方向与绕行方向一致取 +，相反取 −。

不矛盾，是同一件事。逆时针绕行时每一项都变号，等于整个方程乘了 −1；电压降的物理事实没变。

第三种“随手标”：翻电压极性。把某个电阻的 +/− 对调，同一物理电压的代数值变号（+3 V 变 −3 V）；而它的参考方向相对绕行方向也反了，项前符号同时变号。两次变号成对出现、互相抵消，方程照旧成立。环节 4 的演示和练习会亲手做。
u₁ + u₂ − u₃ + u₄ = 0　⇒　u₃ = u₁ + u₂ + u₄

点破：③、④两点之间的电压是单值的——走支路 3，还是走支路 1、2、4，算出来一样。这就是 KVL。

两套符号，别混〔李 p.15〕：方程中项前的 ±（由参考方向定） vs 数值本身的 ±（解出来才知道）。今天的独立练习就在考这个区分。
4 · 两定律合用、翻方向演示与独立练习（6′）

教师示范（邱 p.24 例 1-2，跟着走一遍）

两个回路共用一条支路，那条支路电压是 u₆；待求 u_x。已知 u₁=u₃=1 V、u₂=4 V、u₄=u₅=2 V。

第一条回路顺时针：−u₁+u₂+u₆−u₃=0。第二条也顺时针：−u₆+u₄+u₅−u_x=0。

u₆ 在两式里一次是 ‘+’、一次是 ‘−’——不是写错了，是两个回路的绕行方向在 u₆ 这条支路上相反。两式相加消去 u₆：

u_x = −u₁ + u₂ − u₃ + u₄ + u₅ = −1+4−1+2+2 = 6 V

动手翻一翻：变的到底是标记，还是物理？（本课核心难点）

点按钮翻参考方向/极性。看示意图上的箭头与符号如何变化，再盯着“这一项”和“物理描述”——变的是标记，不是电路本身。

A · KCL：翻一支路的电流箭头（流出为正；示例 i₁=4 A 流入、i₂=6 A 流出、i₃=2 A 流入）
→O i₃ 参考：指向 O（流入）
i₃ 代数值+2 A
KCL 项前符号−
i₃ 这一项−(+2 A) = −2 A（始终不变）
−i₁ + i₂ − i₃ = −4 + 6 − 2 = 0
物理描述（不变）：实际仍有 2 A 流入 O。图上只翻了 i₃ 的参考箭头；代数值与项前符号成对变号，这一项仍是 −2 A，方程照旧成立。
B · KVL：翻电压极性 / 翻绕行方向（矩形回路：左 U_S、上 u₁、右 u₂）
u₁：左 + 右 − ↻ 绕行方向：顺时针
u₁ 代数值+3 V

基准状态：U_S = 8 V。

物理描述（不变）：左端比右端高 3 V、右端比下端高 5 V，U_S = 8 V。翻极性：图上 u₁ 的 +/− 对调，代数值与项前符号成对变号，这一项仍是 +3 V；翻绕行：图上绕行箭头反向，整个方程乘 −1（各项都变号）。两种操作后方程和 U_S 都不变。

该你了（本课唯一独立计算题）：照着别人标好的方向列方程

① 节点 O 汇三条支路，参考箭头已标：i₁ 指向 O（流入），i₂ 离开 O（流出），i₃ 指向 O（流入）。已知 i₁=+4 A、i₂=+6 A。
② 矩形回路，四边从左上角起顺时针依次是：上边电阻 R₁（u₁ 左 + 右 −），右边电阻 R₂（u₂ 上 + 下 −），下边导线，左边电压源 U_S（上 + 下 −）；绕行方向已指定为顺时针。已知 u₁=+3 V、u₂=+5 V。

(1) 用流出为正列 KCL 求 i₃，说实际方向。  (2) 列 KVL 求 U_S。  (3) 翻 i₃ 箭头 + 改逆时针，重列两式。  (4) 恢复顺时针，把 u₁ 极性翻成“右 + 左 −”，重列 KVL，U_S 还是 8 V 吗？

(1) 流出为正：−i₁+i₂−i₃=0 ⇒ −4+6−i₃=0 ⇒ i₃=+2 A。箭头指向 O、数值为正，实际是 2 A 流入 O。

(2) 顺时针：−U_S+u₁+u₂=0 ⇒ U_S=3+5=8 V。

(3) i₃ 箭头翻成流出后 i₃′=−2 A，−i₁+i₂+i₃′=−4+6+(−2)=0，仍成立；逆时针 +U_S−u₁−u₂=0 ⇒ U_S=8 V，也成立。i₃ 的数值符号变了（它自己的箭头变了），物理仍是 2 A 流入 O；U_S 没变。

(4) u₁ 翻成右 + 左 − 后同一“左高 3 V”的事实，u₁′=−3 V；顺时针沿上边走变成从 − 端进 + 端出，那一项写成 −u₁′=+3：−U_S−u₁′+u₂=−U_S+3+5=0 ⇒ U_S=8 V。项前与数值成对变号、互相抵消。三种“随手标”（电流箭头、电压极性、绕行方向）全部验证过。

5 · 回答开场问题（3′）
Σi=0、Σu=0 不是“哪个方向算正”的规定，
而是“电荷不积累、电位单值”的事实。
项前的 ± 只是把参考方向翻译成代数语言。

你随手怎么标，物理不变，方程就成立；别人标的方向，照着它的参考方向翻译即可。更深一层，两条定律分别是电荷守恒、能量守恒的运用。

适用前提〔李 p.4–5〕：集总假设——100 MHz 的信号波长 3 m，接一根 1 m 的线就不能当集总电路（S13 再学）。两定律只看“怎么连”〔邱 p.24〕，与元件是线性还是非线性无关，所以换成二极管照样写。

下一课钩子：电流、电压都被方程定下来了。下次该问——谁供能、谁耗能、元件能扛多大？第三课：功率、能量与额定值直觉。

  • 给我一个三条支路汇成的节点，我能按参考方向列出 KCL，并说清“流入=流出”凭什么吗？
  • 看到一个回路，我能用“电位单值、路径无关”解释为什么 Σu=0，而不是背公式吗？
  • 翻电流箭头、翻电压极性、翻绕行方向，我都能说明为什么“项前符号 + 数值符号”成对变、方程和物理都不变吗？
  • 我知道两条定律的适用前提是集总假设，不是无条件成立吗？
讲什么 / 不讲什么（本课边界）

讲：支路/节点/回路识别；VCR 与拓扑约束分工；KCL 从电荷守恒推出、KVL 从“电位单值→路径无关”推出；两套约定与等效；两套符号；绕行方向任意性；广义节点一句；与元件无关；集总假设边界；KCL+KVL+VCR 最小合用。

不讲：功率与额定值（第三课，主线不出现功率记号）；受控源严格处理、独立方程数、节点/网孔法（L1-06）；串并联/分压分流（L1-04）；电源等效（L1-05）；分布参数的严格理论（S13）；图论术语。

学习目标（学完能独立做什么）
  1. 认出支路、节点、回路；知道理想导线相连的点算同一节点。
  2. 说出 KCL 来自电荷守恒、KVL 来自电位单值（路径无关），不是背规则。
  3. 解释为什么任意参考方向下方程仍成立：翻箭头/翻极性/翻绕行都只改符号。
  4. 按给定参考方向列 KCL（流出为正，知道流进为正是等效的）与 KVL，区分项前符号与数值符号。
  5. 说出适用前提集总假设，并知道两定律与元件性质无关。
能量守恒视角的完整 KVL 推导（页尾加分，不进主线）

主线用“电位单值→路径无关”已能推出 Σu=0。教材（李 p.15–17）还可以从能量守恒推出同一结论，这里完整列出供有余力时对照——含功率 p（元件吸收能量的快慢，算法 p=ui），第三课会专门讲功率，本课不要求掌握、不进练习。

能量收支平衡：某段时间一些元件得到的能量增加，另一些必减少 → Σw=0（1-10）→ 微分 → Σp=0（1-11，各元件获得功率总和为零）→ 用 p=ui 写成 −u₁i₁+u₄i₁+u₆i₁+u₂i₂+u₃i₃+u₅i₃=0（1-12）→ 由 KCL 代入 i₂=i₁+i₃（1-13）→ (−u₁+u₄+u₆+u₂)i₁+(u₂+u₃+u₅)i₃=0（1-14）→ 因 i₁、i₃ 线性无关，系数必为零 → −u₁+u₄+u₆+u₂=0、u₂+u₃+u₅=0（1-15a/b）→ 这些式子正对应各回路电压降代数和为零 → Σu=0（1-16）。

李瀚荪原话：KCL 是电荷守恒法则运用于集总电路的结果；KVL 是能量守恒和电荷守恒法则运用于集总电路的结果。

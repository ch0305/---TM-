# 疑问标签工作流：终端问答 → 页面标签

> 状态：已在第一课 `一 参考方向决定了欧姆定律的正负号.html` 试点跑通。
> 目的：你在终端提问 → 我回答 → 回答同时沉淀成页面上的可点击疑问标签。对话不丢，页面也不再是死资料。

## 一次提问的完整流程

1. **你在终端提问**：直接说“我有个疑问：……”，最好点明是哪个环节（不说也行，我判断）。
2. **我回答你**：用课堂口吻答，不只给结论，给推导/直觉。
3. **我追加记录**：把这一问一答写进该课程的 `notes/<课程id>.json`（UTF-8，数组，一条问答一个对象）。
4. **我运行同步脚本**：把标签注入页面对应环节，并在右侧栏“本页疑问”生成索引。
5. **你刷新页面**：在对应环节看到粉色「疑问」按钮；点它或点侧栏索引都会展开答案。若问题挂在尚未揭示的环节，会先把那段展开再跳过去。

## 命令

```bash
cd /home/ch/文档/硬件修炼场

```

**可重复运行**：脚本按标记对整段重写，不会产生重复标签（已验证连跑两次仍为 2 条）。

## 记录格式（`notes/*.json`）

```json
[
  {
    "id": "q-neg-voltage",
    "stage": "stage-2",
    "short": "负电压是不是算错了？",
    "question": "Q：算出 u_AB = −4 V，这个负号是不是说明哪里算错了？",
    "answer": "A：不是。电压永远是“两点之间”的差……",
    "viz": "可选：一句小可视化，出现答案框里的虚线框中"
  }
]
```

- `id`：英文 slug，全页唯一。**追加新问题时只新增对象，不要改已有 `id`**，否则旧标签会失联。
- `stage`：挂到 `stage-0` … `stage-6`。该课程页面里必须已有对应标记对；目前第一课七个环节全都有。
- `short`：侧栏索引显示的短标题（编号由脚本自动加）。
- `question` / `answer`：正文，支持中文标点、公式符号（Unicode 的 `−`、`⇒` 等）；**不要写 HTML 标签**，脚本会做转义。
- `viz`：可选，一句辅助可视化文字。

## 页面里的标记（普通 HTML 注释，不影响渲染）

- 侧栏索引：`<!-- QA-INDEX:BEGIN --> … <!-- QA-INDEX:END -->`
- 每个环节：`<!-- QA:stage-2:BEGIN --> … <!-- QA:stage-2:END -->`

脚本只替换标记之间的内容，标记之外的正文、揭示块、练习都不动。

## 新课程接入

1. 在页面侧栏放一对 `QA-INDEX` 标记。
2. 在需要挂疑问的环节放一对 `QA:stage-N` 标记。
3. 建 `notes/<课程id>.json`（空数组 `[]` 也行）。
4. 让页面加载 `assets/lesson.js`（`flashQA` 在其中；没有这些元素的页面完全不触发）。
5. 运行上面的同步命令。

## 已验证行为

- 侧栏 2 条索引、正文 2 个标签，连跑两次不重复。
- 点侧栏索引 → 对应 popover 打开；打开新答案会关掉旧答案。
- 挂在 `rev-4e`（原本隐藏）里的问题：点击后先展开该揭示块再跳转，主线链条同步高亮到 stage 4。
- 点正文标签本身也能开；× 按钮、点页面空白处都能关。
- 没有疑问标签元素的页面完全不触发相关 JS（做了存在性判断）；新增组件只追加 CSS/JS，不改已有选择器。

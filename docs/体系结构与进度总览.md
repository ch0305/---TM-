# 体系结构与进度总览（硬件工程师路线）

> 状态：**v1.2（清理与重排）** — 样式（方案 A2：黑板课堂·高密度，边缘滑出侧栏+全屏铺满）、体系与考核安排、可视化规范均已确认；**强制走 `docs/课程生产流程.md` 的六步流程**（正文摘录 → 教案 → 独立审核 → 页面 → 学习验证 → 疑问闭环），第一课（L1-01）为首个通过验证的样板课。遗留页面已清理，S1 顺序调整为：参考方向 → KCL/KVL → 功率 → 串并联。  
> 原则：先体系后内容；每课 45 分钟；新课必须按本总览推进；每课编写前先查阅对应书目章节的**正文**（不是只看目录），理解概念引入、推导/例题、常见误区与工程含义；**没有通过独立审核的 Markdown 教案，不得生成 HTML 页面**。

## 0. 使用说明

### 0.1 文档作用
- 给出从零基础到硬件工程师方向的**完整知识体系结构**与**可执行进度安排**（含细粒度知识点、前置依赖、练习与考核）。
- 作为后续生成每一课（HTML+CSS+JS）的唯一进度依据，避免遗漏与跳跃。
- 为每个学习单元提供**书目章节映射**与备课要求，确保内容有据可查。

### 0.2 主要参考书目与分工
| 书目 | 主要作用 | 在体系中的角色 |
|---|---|---|
| 《电路》邱关源 第6版 | 国内经典电路教材，体系严谨、符号规范 | 电路分析主线（KCL/KVL、等效、动态、相量、频响、暂态/复频域等） |
| 《电路分析基础》李瀚荪 第5版 上/下 | 讲解细、例题与复习丰富 | 电路分析第二解释与练习补充，打牢直觉与计算 |
| *The Art of Electronics* 3rd (H&H) | 工程直觉与实用电路 | 器件、模拟/数字/接口/电源/测量等工程化主线 |

> 说明：在 `00-总索引.md` 建议顺序基础上按“硬件工程师岗位能力”融合重排：强调可计算、可验证、可落地；把知识拆为 45 分钟单元并显式标注前置依赖与考核点。

### 0.3 编号、课时与页面规范
- **编号**：`Lx-yy` = 第 x 阶段第 yy 课（45 分钟/1 页面）；`Lx-R` = 阶段复习/综合；`Lx-E` = 阶段考核（测验/考试）。必要时可增补课时，须先更新本总览并保持编号有序。
- **45 分钟建议拆分（可按内容微调）**：导入与目标(3') → 核心概念/推导与直觉(12') → 可视化/交互探究(10') → 例题/工程联系(8') → 练习与自测(10') → 小结与下节衔接(2')。P1 内容必须落在讲解+练习闭环内。
- **每页必须包含**：课号/标题/所属阶段、建议时长、学习目标、前置知识、参考书目章节、正文与可视化、P1/P2/P3 标注知识点、练习/自测（P1 必配）、锚定式疑问标签机制、下节预告与衔接。
- **进度状态**：`未开始` / `排期中` / `页面待验证` / `正式` / `待复习`。只有用户学完并反馈才能标 `正式`；遗留原型已清理，不保留历史版本记录。
- **文件命名（强制）**：页面 = `lessons/<中文大写节数> <教学主题>.html`（如 `lessons/一 参考方向决定了欧姆定律的正负号.html`），疑问笔记同名放 `notes/`；`index.html` 为唯一入口，做成导航栏。

### 0.4 知识优先级（工程师视角）
- **P1 必会**：核心概念/公式/方法，后续高频使用；必须讲透直觉与用法，并配练习/自测与典型例。例：`V=IR`、KCL/KVL、分压分流、戴维南/诺顿、RC 时间常数、阻抗、基本器件与运放用法、去耦/回流等。
- **P2 应会**：常见且重要，需理解原理与适用场景；配少量练习或思考题。
- **P3 了解**：知道存在、用途与边界即可，不深挖不强记；页面明确标注“了解即可”。例：香农公式在本阶段仅作认知边界（通信专题再升优先级）。
- **动态调整**：同一知识点可随阶段升降优先级（如传输线：基础阶段预告 P2/P3，SI 阶段升为 P1）。

### 0.5 每课编写流程（强制）
> 完整规范见 **`docs/课程生产流程.md`**。核心是**教案先行、审核卡关**：旧的“看章节 → 直接出页面”做法已废止——它正是页面沦为信息陈列的原因。

1. **确认排期**：在本总览确认课号、目标、前置、知识点与书目映射（先改总览再动课）。
2. **正文摘录**：把映射章节的**正文**做成 `书籍/摘录/Lx-yy.md`（扫描件 OCR + 校对、标印刷页码、区分原文/校对/摘录者按）；只有目录不算完成。
3. **写 Markdown 教案**：`lessons/drafts/Lx-yy-教案.md`，含核心问题、讲/不讲边界、概念依赖链、逐环节脚本、预测/练习、答案区、来源台账、前端约束。**此时禁止写 HTML。**
4. **独立审核（硬门槛）**：全新会话、只读教案 + 摘录，按固定 5 问审核；结论必须明确“通过 / 退回”，退回则修改重审直到通过。
5. **转页面**：教案通过后按揭示顺序生成 HTML；只做增量组件、不改旧选择器；答案不提前；资料移到页尾；疑问锚真实卡点。
6. **学习验证与疑问闭环**：用户实际走完并反馈；终端提问按 `docs/疑问标签工作流.md` 写回标签。**未拿到反馈前状态只能为“待验证”**，通过后才改“正式”。
7. **更新进度**：同步更新本总览与 `index.html` 的状态与入口。

## 1. 连贯性与顺序设计（回应“章节是否连贯？顺序是否合理？”）

### 1.1 主线依赖链（由浅入深、可验证）
1. **S0 准备**：单位/量纲、参考方向、安全与读图约定 → 为所有计算与测量建立共同语言。  
2. **S1 直流电阻电路**：参考方向与 `u=Ri` 的正负号 → KCL/KVL 与理想源 → 功率/额定值 → 串并联/等效/分压分流 → 电源模型与戴维南/诺顿 → 系统求解（节点/网孔）→ 线性定理 → 综合。*每步以前一步为前置：第一课的符号约定在 KCL/KVL 的代数求和里第一次真正“有用”；功率放到多元件之后，才讲得清谁供能、谁耗能。*  
3. **S2 动态与正弦稳态**：在 S1 基础上引入储能元件（C/L）→ 一阶暂态与时间常数 → 正弦与相量 → 阻抗与稳态分析 → 功率 → 频响/谐振 → 综合。*从时域直觉过渡到频域工具。*  
4. **S3 进阶工具**：耦合/变压器、运放电路模型化、二阶响应、(选学)s 域与拉氏直觉、三相/非正弦认知、传输线边界预告。*为模拟/电源/信号链与 SI 搭桥。*  
5. **S4–S7 模拟与电源**：二极管/晶体管器件 → 运放与构建块 → 滤波/振荡/信号链 → 线性/开关电源与热/保护。*依赖 S1–S3 的电路分析与频响直觉。*  
6. **S8–S11 数字与嵌入式接口**：数字电平与逻辑 → 时序 → 可编程/接口/ADC-DAC → MCU 与总线/系统思维。*与模拟/电源并行需要的接口素养衔接。*  
7. **S12 测量与调试**：深化仪器与方法论（L0-02 已给安全与基本读图/测量意识，S12 系统化）。  
8. **S13 SI/PI/PCB**：在电路+器件+信号+电源基础上进入互连、传输线、串扰、PDN、布局原则。  
9. **S14 综合与专题**：项目闭环与岗位向深化。

### 1.2 顺序合理性说明与权衡
- **“理论先行”与“工程感”平衡**：S0-S3 夯实可计算地基（避免后续器件/PCB 学成黑箱），但每课均含工程联系/量级/选型或安全直觉；S4 起持续引入 datasheet 与实用电路。
- **测量何时深入**：基础测量与安全在 L0-02 前置；系统化仪器/调试在 S12（此时已有足够被测对象与故障模式认知）。*可选调整：若你希望更早动手，可在 S1 后插入“测量实操微专题”（需确认后更新总览）。*
- **S3 中运放提前（L3-02）**：作为“受控源/理想化元件”在电阻电路框架内引入，服务后续 S5 深化，保持连贯。
- **SI/PI 位置**：放在 S13 是因其依赖阻抗/频响/暂态/电源与布局综合认知；L3-06、L7-05 等做前置预告，避免突兀。
- **局部可调**：阶段内细课顺序、实操插入时机、S9-S11 压缩或展开，均可按目标微调，但**必须先更新本总览并检查前置依赖**。

### 1.3 连贯性保障机制
- 每课显式列出**前置课号**与**本课产出对后续的支撑**。
- 每阶段末设**复习与考核课**，未达标项标记 `待复习` 并补弱后再推进。
- 跨书目概念以统一符号与术语表对齐（随模板固化）。

## 2. 考核与反馈体系（回应“是否有考试什么的？”）

### 2.1 多层级考核
| 层级 | 形式 | 时长/频率 | 内容与目的 | 通过建议 |
|---|---|---|---|---|
| L0 课内自测 | 页内练习/选择/填空/小计算 | 每课 8–12'（含在45min内） | 检查当课 P1 掌握与即时纠错 | P1 要点正确率 ≥ 80%，错题能说出原因 |
| L1 阶段小测 | 阶段内穿插 quiz（可嵌入复习课前段） | 每 3–5 课或阶段中点 | 覆盖近期 P1/P2，检验连贯理解 | ≥ 75%，薄弱点记录并补练 |
| L2 阶段综合考核 | `Lx-E` 专用课（45min） | 每阶段末 1 次 | 综合计算/读图/概念辨析/工程判断，覆盖本阶段 P1 全部、P2 抽样 | ≥ 70% 且 P1 关键题无原则性错误 |
| L3 里程碑评审 | 阶段性小项目/设计题复盘（S4+ 逐步引入） | 关键节点 | 从需求到分析/选型/验证的闭环能力 | 方案合理、约束与风险有意识、能自我复盘 |
| L4 综合能力检查 | 跨阶段综合卷/项目答辩（S14） | 终段 | 岗位向综合能力与知识迁移 | 达到个人岗位目标要求 |

### 2.2 补弱与回溯规则
- 任一层级未达标：定位薄弱知识点 → 回看对应课与原著章节 → 完成针对性练习 → 通过补测/补问再推进（避免带病进入强依赖后续课）。
- P1 错误优先于 P2/P3 修复；“了解即可(P3)”内容不纳入通过门槛，但需能识别其边界。

### 2.3 题型建议（按优先级）
- **P1**：概念辨析、单位/数量级计算、公式应用与变形、读图取数、因果判断、典型电路分析、工程约束判断（额定值/方向/极性等）。
- **P2**：原理解释、场景选型/取舍、对比分析。
- **P3**：仅识别题（“这是什么/用于什么/本阶段是否深入”），不设计算与记忆要求。

## 4. 分阶段详细进度

> 下表为“细粒度”教学规格：每课给出前置、45min 拆分、知识点细项（P1/P2/P3）、练习与过关检查。实际授课页可在不破坏前置与 P1 覆盖前提下微调表达顺序。

### S0 导学与工程准备

- **前置**：无（零基础可入）。**后续支撑**：S1–S14 全部。  
- **阶段考核**：以 L0 自测清单 + 进入 S1 前准备度检查（无需单独长考，可并入 L1-01 导入）。

|---|---|---|---|---|---|---|---|

## 零、LC 电路的能量往返与等幅振荡（李上 §7-1 / PDF 300–302，本文件新 OCR）

> 【原文 OCR】上章讨论过的一阶电路中只涉及一种储能——电场能量或磁场能量，如果一个电路既能存储电场能量又能存储磁场能量，这样的电路会有什么特点呢？为了突出问题的实质，我们研究一个只由电容和电感组成的电路的零输入响应。设电容的初始电压为 `u_C0`，电感的初始电流为零。〔李上 §7-1 / PDF 300〕
> 【原文 OCR】在初始时刻，能量全部储于电容中……随着电容放电、电流增长，能量逐渐转移到电感的磁场中。当电容电压下降到零的瞬间，电感电压也为零，电流达到了最大值，此时储能全部转入到电感。电容电压为零但变化率不为零……电流从最大值逐渐减小，电容在这电流作用下又被充电，只是电压的极性与以前不同。〔李上 §7-1 / PDF 300–301〕
> 【原文 OCR】以后，电容又开始放电，只是电流方向和上一次放电方向相反……当电流为零的瞬间，能量全部返回到电容，电容电压的大小和极性又和初始时刻一样……上述过程将不断地重复进行。在由电容和电感两种储能元件构成的电路中，随着储能在电场和磁场之间的往返转移，电路中的电流和电压将不断改变大小和极性，形成周而复始的振荡。这种由初始储能维持的振荡是一种**等幅振荡**。不难想象，如果电路中存在电阻，那么储能终将被电阻消耗殆尽，振荡就不可能是等幅的，而将是减幅的，即幅度逐渐衰减而趋于零，这种振荡称为**阻尼振荡（damped oscillation）**或衰减振荡。〔李上 §7-1 / PDF 301〕
> 【原文 OCR】LC 回路中的储能为 `W(t)=½[Li²(t)+Cu_C²(t)]`……以解答代入并考虑 `L=1H, C=1F`，可得 `W(t)=½[sin²t+cos²t]=½`……储能在任何时刻都为常量……`W(t)=W(0)`。这就表明：储能不断地在电场和磁场之间往返，永不消失。〔李上 §7-1 / 式 7-7、7-8 / PDF 302〕
> 【校对 OCR】等幅振荡时 `u_C=U₀cos(ω₀t)`、`i=−(U₀/(ω₀L))sin(ω₀t)`，`ω₀=1/√(LC)`；`W=½Li²+½Cu²` 在任意时刻为常数。〔李上 §7-1 / 式 7-5~7-8 / PDF 302〕
> 【摘录者按】这段是预测 1 与陈述时刻 1 的权威书证：能量往返 → 等幅振荡、储能恒定 `W=½Li²+½Cu²`；并预告"有电阻则阻尼（减幅）振荡"，正好接下一节 RLC。教案引用 `W=½Li²+½Cu²` 与"等幅振荡"用此处〔李上 §7-1〕，不再只挂在邱 §7-5 名下。〔通识：按语〕

## 一、二阶电路的微分方程与特征根（邱 §7-5 印刷 p.154–156 / PDF 178–180，沿用 L2-10 已校对）

### 【原文】二阶电路与零输入响应

> 【原文 OCR】用二阶微分方程描述的电路称为二阶电路。二阶电路换路后，电路中无外施激励，仅由动态元件的初始储能引起的响应，称为二阶电路的零输入响应。〔邱 §7-5 / p.154〕

### 【原文】特征根只由结构和参数决定

> 【原文 OCR】从式(7-11)可见，特征根 `p₁` 和 `p₂` 仅与电路的结构和参数有关，而与激励和初始储能无关。〔邱 §7-5 / p.155–156〕
> 【校对 OCR】特征方程 `LCp² + RCp + 1 = 0`，即 `p² + (R/L)p + 1/(LC) = 0`。令衰减系数 `α=R/(2L)`（OCR 作 `δ`）、固有角频率 `ω₀=1/√(LC)`，则 `p₁,₂ = −α ± √(α²−ω₀²)`；`p₁p₂=1/(LC)=ω₀²`。〔邱 §7-5 / 式 7-11〕
> 【摘录者按】"与激励、初始储能无关"是理解二阶的关键：**形态（过阻尼还是欠阻尼）由 R、L、C 三个参数就能预判，不用先解方程**；激励和初值只决定振幅与相位（解里的待定常数）。L2-10 已把这条做成定性钩子，本课正式用特征根把它算出来。〔通识〕

### 【原文】RLC 串联零输入响应的方程（李上 §7-2 / PDF 303–304，本文件新 OCR）

> 【原文 OCR】根据 KVL 可得 `LC·d²u_C/dt² + RC·du_C/dt + u_C = u_oc`。本节只研究零输入响应，即 `u_oc=0` 时：`LC·d²u_C/dt² + RC·du_C/dt + u_C = 0`。〔李上 §7-2 / 式 7-10、7-11 / PDF 303〕
> 【原文 OCR】根据对一阶微分方程求解的经验，可假定解答具有 `u_C = Ke^(st)` 的形式……两端均除以 `Ke^(st)`，得 `LCs² + RCs + 1 = 0`。上式称为**特征方程（characteristic equation）**，这一方程有两个根，称为**特征根**，特征根又称**固有频率**。〔李上 §7-2 / 式 7-12~7-14 / PDF 303–304〕
> 【校对 OCR】特征根 `s₁,₂ = −R/(2L) ± √[(R/(2L))² − 1/(LC)] = −α ± √(α²−ω₀²)`，其中 `α=R/(2L)`、`ω₀=1/√(LC)`。〔李上 §7-2 / 式 7-14〕
> 【摘录者按】邱、李两书写的是同一个方程：邱用 `p`、李用 `s`、都得到 `−α±√(α²−ω₀²)`。本教案**统一用 `p`** 记特征根（与 L2-10 一致），`s` 作为"李书也这么写"的一句注，不混用。〔通识〕

## 二、四种特征根 → 四种响应形态（邱 §7-5 印刷 p.156–162，沿用 L2-10 已校对 + 李上例证）

### 【原文】四种通解形式

> 【原文 OCR】针对不同情况的特征根，二阶线性常系数齐次微分方程的通解有如下表达式：(1) `p₁,p₂` 为两个不等的负实根，`u=A₁e^(p₁t)+A₂e^(p₂t)`；(2) 两个相等的负实根 `p₁=p₂=−α`，`u=(A₁+A₂t)e^(−αt)`；(3) 一对共轭复根 `p₁=−α+jω`、`p₂=−α−jω`，`u=A e^(−αt) sin(ωt+β)`；(4) 一对共轭虚数 `p₁=+jω₀`、`p₂=−jω₀`，`u=A sin(ω₀t+β)`。〔邱 §7-5 / p.156〕

### 【原文】临界电阻判据

> 【原文 OCR】当 `R>2√(L/C)` 时，特征根是两个不等的负实数，`u_C` 始终不改变方向，电容在整个过程中一直释放储存的电能，称为**非振荡放电**，又称为**过阻尼放电**。〔邱 §7-5 / p.156–157〕
> 【原文 OCR】当 `R<2√(L/C)` 时，特征根是一对共轭复数，`u_C`、`i`、`u_L` 的波形呈现衰减振荡的状态，又称为**欠阻尼放电**；在整个过程中，它们将周期性地改变方向，储能元件也将周期性地交换能量。〔邱 §7-5 / p.158–159〕
> 【原文 OCR】在 `R=2√(L/C)` 时，特征根 `p₁=p₂=−R/(2L)=−α`，`u_C`、`i`、`u_L` 不做振荡变化，具有非振荡性质；这种过程是振荡与非振荡过程的分界线，这时的电阻称为**临界电阻**，并称电阻大于临界电阻的电路为**过阻尼电路**，小于临界电阻的电路为**欠阻尼电路**。〔邱 §7-5 / p.162〕
> 【原文 OCR】在 `R=0` 时 `α=0`，各量都是正弦函数，它们的振幅并不衰减，是一种**等幅振荡**。〔邱 §7-5 / p.161〕
> 【原文 OCR·李上】在上述特征根的三种表达式中，`R/(2L)` 具有电阻的量纲，称为 RLC 串联电路的**阻尼电阻**，记为 `R_d = 2√(L/C)`；当串联电路的 `R` 大于、等于、小于阻尼电阻 `R_d` 时，分别称为**过阻尼、临界、欠阻尼**情况。〔李上 §7-2 / 式 7-15 / PDF 304〕
> 【校对】判据统一到一个量——临界电阻 `R_c=2√(L/C)`（=李上的阻尼电阻 `R_d`，由 `α=ω₀` 即 `R/(2L)=1/√(LC)` 解出，等价于 `R²=4L/C`）：`R>R_c`→不等负实根→**过阻尼**（单调、不振荡）；`R=R_c`→相等负实根→**临界**（不振荡、最快无过冲）；`R<R_c`→共轭复根→**欠阻尼**（衰减振荡/振铃）；`R=0`→共轭虚根→**等幅振荡**（理想无损耗）。〔通识：判据归并〕

### 【原文·例证】李上三个数值算例（本文件新 OCR，数值逐条核对）

> 【原文 OCR·例7-1】`C=1F, L=1H, R=3Ω, u_C(0)=0, i(0)=1A`，`R>R_d=2Ω` 属**过阻尼**。特征根 `s₁=−0.382, s₂=−2.618`，解 `u_C(t)=0.447e^(−0.382t)−0.447e^(−2.618t) V`；由波形图可知响应是**非振荡性**的。〔李上 §7-2 例7-1 / PDF 304–305〕
> 【校对·验算】`α=R/(2L)=1.5`、`ω₀=1`、`√(α²−ω₀²)=√1.25≈1.118` → `s=−1.5±1.118 = −0.382/−2.618` ✓。〔通识〕
> 【原文 OCR·例7-2】`R=2Ω=R_d` 属**临界阻尼（critically damped）**，解答形式 `i(t)=(K₁+K₂t)e^(−αt)`；本题 `i(0)=0, u_C(0)=−1V`，解得 `i(t)=4t·e^(−t) A`，波形仍为**非振荡性**。〔李上 §7-2 例7-2 / PDF 306–307〕
> 【校对·验算】`α=R/(2L)=1`，`i=4te^(−t)` 在 `t=0` 为 0、先升后降回落 0，始终非负——非振荡 ✓。〔通识〕
> 【原文 OCR·例7-3】`R=1Ω<R_d=2Ω` 属**欠阻尼（under damped）**，特征根为共轭复根，响应是**振荡性**的；实部 `α=R/(2L)` 又称**衰减系数**，虚部 `ω_d` 称**衰减振荡角频率**，响应为振幅按指数规律衰减的振荡。〔李上 §7-2 例7-3 / PDF 307–309〕
> 【原文 OCR·例7-4】`R=0` 属**无阻尼/等幅振荡**，`ω₀` 称为**谐振（resonant）角频率**；`u_C(t)=cos 2t + sin 2t ≈ 1.01cos(2t−π/4) V`，波形为**等幅振荡**。〔李上 §7-2 例7-4 / PDF 309–310〕
> 【摘录者按】李上例7-1~7-4 正好是同一 `L=1H, C=1F`（`R_d=2Ω`）只改 `R=3/2/1/0` 的四个形态，是"只改一个 R，响应从单调变振铃"的完整书证链。教案面板 A 可沿用这组参数让学生亲眼对比。〔通识〕

## 三、二阶零状态响应与阶跃响应（邱 §7-6/§7-7，李上 §7-3）

### 【原文】全响应结构（邱 §7-6 印刷 p.162 / PDF 186，沿用 L2-10）

> 【原文 OCR】二阶电路的初始储能为零（即电容两端的电压和电感中的电流都为零），仅由外施激励引起的响应称为二阶电路的零状态响应。这是二阶线性非齐次方程，它的解答由特解和对应齐次方程的通解组成。〔邱 §7-6 / p.162〕
> 【校对】**全响应 = 特解（强制/稳态分量）+ 齐次通解（自由/暂态分量）**；齐次通解正是上一节那四种形态之一（由特征根定），特解由激励形式定。〔通识〕

### 【原文】单位阶跃函数与阶跃响应（邱 §7-7 印刷 p.166–168 / PDF 190–192，本文件新 OCR）

> 【原文 OCR】电路对于单位阶跃函数激励的零状态响应称为**单位阶跃响应**。单位阶跃函数是一种奇异函数，可定义为 `ε(t)=0 (t<0)`、`ε(t)=1 (t>0)`。值得注意的是单位阶跃函数在 `t=0` 这一点是不连续的；它可以用来描述开关动作，表示在 `t=0` 时把电路接到单位直流电压源上。**阶跃函数可以作为开关的数学模型，所以有时也称为开关函数。**〔邱 §7-7 / p.166〕
> 【原文 OCR】当电路的激励为单位阶跃 `ε(t)` 时，相当于将电路在 `t=0` 时接通电压值为 1 V 的直流电压源或电流值为 1 A 的直流电流源。因此**单位阶跃响应与直流激励响应相同**。〔邱 §7-7 / p.167〕
> 【原文 OCR】矩形脉冲可以看作由两个阶跃函数组成：`ε(t)−ε(t−τ)`。〔邱 §7-7 / p.166–167〕
> 【原文 OCR·例7-12】开关在 `t=0` 接到位置 2、`t=τ=RC` 又返回，`u_C` 在 `0<t<τ` 为零状态响应、`u_C(τ⁻)=0.632U_s`；在 `t>τ` 为零输入响应。也可用阶跃函数把激励写成 `u_s=U_sε(t)−U_sε(t−τ)`，RC 单位阶跃响应 `s(t)=(1−e^(−t/τ))ε(t)`，故 `u_C(t)=U_s(1−e^(−t/τ))ε(t)−U_s(1−e^(−(t−τ)/τ))ε(t−τ)`——第一项为阶跃响应、第二项为**延迟的阶跃响应**。〔邱 §7-7 例7-12 / p.167–168〕
> 【原文 OCR·例7-13（二阶）】`u_C(0₋)=0, i_L(0₋)=0, G=1/6 S, L=1/5 H, C=1 F`（OCR 参数乱，按 `D²+6p+8=0` 反推），列 KCL 得二阶方程；特解 `i_L=1/6` A，特征方程 `p²+6p+8=0`，特征根 `p₁=−2, p₂=−4`，解 `i_L=(1/6 + A₁e^(−2t)+A₂e^(−4t))ε(t)`，代入 `i(0₊)=0` 与 `u_C(0₊)=0` 定常数，得 `i_L=(1/6−(1/2)e^(−2t)+(1/3)e^(−4t))ε(t)`。**电路的过渡过程是过阻尼性质的。**〔邱 §7-7 例7-13 / p.168–169〕
> 【摘录者按】例7-13 是"二阶阶跃响应"的书证：形态由特征根（这里 `−2/−4` 是不等负实根→过阻尼）定，与激励（阶跃）无关；阶跃只提供特解（稳态值 `1/6` A）。这正是 P2"特征根↔响应形式"的直接例证。〔通识〕

### 【原文】"上冲 / overshoot"——过冲的正式名字（李上 §7-3 / PDF 314，本文件新 OCR）

> 【原文 OCR】若此例中无工件与电容并联，`u_C(t)` 是一个最终趋于 300 V 的衰减振荡……**最大值高于稳态值的数值常又称为"上冲"（overshoot）**。〔李上 §7-3 例7-5 后 / PDF 314〕
> 【原文 OCR·例7-5】电火花加工器：`R=50Ω, L=0.06H, C=1µF`，`R_d=2√(L/C)≈447Ω`，`R<R_d` 属**欠阻尼**；`α=417, ω_d≈4060`；`u_C(t)=[−300e^(−417t)cos(4060t) + …sin(4060t) + 300] V`。第一个最大值在 `t=π/ω_d≈77.4 ms`，`u_C≈516 V`（稳态 300 V，**上冲约 216 V**）；加工周期 `T=77.4 ms`、频率 `f≈12.92 Hz`。〔李上 §7-3 例7-5 / PDF 312–314〕
> 【校对·验算】`ω₀=1/√(LC)=1/√(0.06×1e−6)≈4082`、`α=R/(2L)=50/0.12≈416.7`、`ω_d=√(ω₀²−α²)≈4059` ✓；`π/4059≈0.774 ms`？——注意书给 `77.4ms` 对应的是 `π/ω_d` 的**毫秒量级**（`π/0.04059` 若 `ω_d` 以 `rad/ms` 计），即 `ω_d≈0.0406 rad/ms = 40.6 rad/s` 的量纲换算需以教材数值为准；**教案引用时用教材给的 `77.4ms/516V/12.92Hz` 三值，不自行重算该例的 ω 换算**，避免量纲口径争议。〔通识：数值口径说明〕
> 【摘录者按】"上冲（overshoot）"是工程上"过冲"的书本正式名，欠阻尼阶跃响应的标志性现象；李上例7-5 给了"稳态 300V、峰值 516V、上冲 216V"的直观数字，正因为欠阻尼会过冲，电火花加工器才利用这个峰值去击穿间隙。这是 P1"振铃/过冲与阻尼联系"最贴切的书证。〔通识〕

## 四、GCL 并联电路的对偶（李上 §7-4 / PDF 317–318，本文件新 OCR）

> 【原文 OCR】根据 KCL：`i_L(t)+i_C(t)+i_G(t)=i_sc(t)`，以 `u_L=L di/dt`、`i_C=C du/dt`、`i_G=Gu` 代入，得 `GCL` 并联电路的二阶方程。把串联电路方程中的 `u_C` 换以 `i_L`、`L` 换以 `C`、`C` 换以 `G`、`R` 换以 `G`（对偶），就得到并联电路的方程——**RLC 串联电路和 GCL 并联电路具有对偶性质**。〔李上 §7-4 / 式 7-17 / PDF 317〕
> 【原文 OCR·例7-7】并联电路 `10V` 源经 `25Ω` 化为电流源，对并联部分 `G/(2√(CG))` 判据 `=500…` 属**临界阻尼**，补解 `(K₁+K₂t)e^(−500t)`；特解 `i_L=10/25=0.4A`，零状态响应 `i_L=(0.4+200t)e^(−500t) A`。〔李上 §7-4 例7-7 / PDF 318–319〕
> 【校对】并联 GCL 方程 `LC i_L'' + GL i_L' + i_L = i_s`（式 7-17）除以 `LC` 得 `i_L'' + (G/C)i_L' + (1/LC)i_L = …`，故 `α = G/(2C)`、`ω₀ = 1/√(LC)`，临界电导 `G_c = 2√(C/L)`（= `2C/√(LC)`）。于是 `G > G_c` → 过阻尼、`G = G_c` → 临界、`G < G_c` → 欠阻尼。**对偶关系**：串联方程的一阶系数是 `R`（α=R/2L），并联是 `G`（α=G/2C），即**串联电阻 R_s ↔ 并联电导 G**——R_s 越大越阻尼、G 越大也越阻尼；换成并联电阻 `R_p=1/G` 说，则是 **R_p 越小越阻尼**（与串联 R_s 越大越阻尼"方向相反"的说法，指的是电阻本身 R_s 与 R_p，不是电导 G）。〔通识：对偶判据，已从式 7-17 重新推导核对〕
> 【摘录者按】教案**只把对偶作为一句"并联有对偶版本"的边界说明**，不展开并联的数值求解（P3 繁复求解细节不讲）；过关练习可给一个"并联 RLC 增大 G 会怎样"的定性题检验是否真懂对偶方向。〔通识〕

## 五、冲激响应（邱 §7-8 印刷 p.169–172 / PDF 193–196，本文件新 OCR）

> 【原文 OCR】电路对于单位冲激函数激励的零状态响应称为**单位冲激响应**。单位冲激函数定义为 `∫δ(t)dt=1`、`δ(t)=0 (t≠0)`，又称 **δ 函数**；可看作单位脉冲函数的极限（宽度→0、高度→∞、面积恒为 1）。〔邱 §7-8 / p.169〕
> 【原文 OCR】冲激函数有"筛分（取样）"性质 `∫f(t)δ(t−a)dt=f(a)`……当单位冲激电流加到初始电压为零、`C=1F` 的电容上，电容电压瞬时从 0 跳到 1 V（瞬时转移 1 C 电荷）；单位冲激电压加到 `L=1H` 电感上，电感电流瞬时从 0 跳到 1 A。〔邱 §7-8 / p.171〕
> 【原文 OCR】冲激函数作用于零状态一阶电路，在 `0₋` 到 `0₊` 使 `u_C` 或 `i_L` 发生跳变；`t>0₊` 冲激为零，电路产生相当于该初始状态引起的**零输入响应**。所以一阶电路冲激响应的求解关键，是算冲激作用下的 `u_C(0₊)` 或 `i_L(0₊)`。RC 电路 `u_C=(1/RC)e^(−t/RC)ε(t)`。〔邱 §7-8 / p.171–172〕
> 【原文 OCR】零状态 RLC 串联电路在 `t=0` 与冲激电压 `δ(t)` 接通，以 `u_C` 为变量列方程 `LC u_C'' + RC u_C' + u_C = δ(t)`，`u_C(0₋)=0, i(0₋)=0`。〔邱 §7-8 / p.172〕
> 【摘录者按】冲激响应本课**只做边界认知**（知道"冲激让储能瞬时跳变、之后按二阶形态自由响应"），不要求求解；教案放在页尾资料区/一句话带过，避免与核心的"阻尼形态↔工程影响"抢时间。拉氏变换的 δ 处理留 L3-04。〔通识〕

## 一、邱关源《电路》第6版

### 【原文】印刷 p.83 — 第四章导读：定理的作用与叠加定理的地位

第三章介绍的列写电路方程的系统方法奠定了电路分析的基础。在电路公理系统（基尔霍夫两定律以及集总参数的假定）的前提下，本章推导出的电路定理有助于灵活、高效地解决一些特殊的电路问题。其中，叠加定理给出了把电路激励“分而治之”的方法，它是反映线性电路性质的重要定理，是线性方程的齐次性和可加性在电路中的体现；替代定理是一种特殊的等效变换，有时可将电路大大化简；戴维南定理、诺顿定理则是在电路结构上的一种“分和治之”的方法……在戴维南定理基础上推导的最大功率传输定理在实际工程中有广泛的应用。

> 【摘录者按】导读把本章三个定理的关系讲清了：叠加＝对**激励**分而治之；戴维南/诺顿＝对**结构**分而治之；最大功率传输＝建立在戴维南基础上的应用；替代＝特殊的等效变换。这个框架正好是本课主线。

### 【原文】印刷 p.83 — §4-1 叠加定理（引入：两电源电路的响应分解）

作为线性系统（包含线性电路）最基本的性质——线性性质，它包含可加性与齐次性两方面。叠加定理就是可加性的反映，它是线性电路的一个重要定理。

图 4-1(a) 所示电路中有两个独立电源，它们是电路中的激励，现在要求解作为电路响应的电流 *i* 与电压 *u*。

### 【原文】印刷 p.84 — 叠加定理的推导（响应分解为各激励单独作用之和）

根据 KCL、KVL 与 VCR 可列出以 *i* 为未知量的方程……从而解得（式 4-1）。式(4-1) 中，两个响应 *i*、*u* 分别是激励 *i*<sub>s</sub> 和 *u*<sub>s</sub> 的线性组合。

式中 *i*′ 与 *u*′ 为将原电路中电流源置零时的响应，即由 *u*<sub>s</sub> 单独作用的分电路中所产生的电流、电压分响应；*i*″ 与 *u*″ 为将原电路中电压源 *u*<sub>s</sub> 置零后由 *i*<sub>s</sub> 单独作用的分电路中所产生的电流、电压分响应。

原电路的响应则为相应分电路中分响应的和（代数和）：*i* = *i*′ + *i*″，*u* = *u*′ + *u*″。这就是叠加定理。

> 【摘录者按】“置零”的操作规范在印刷 p.85–86 给出（电压源短路、电流源开路，见下）。核心直觉：线性电路的方程是线性方程组，解的线性性保证响应能按激励拆开再相加。

### 【原文】印刷 p.84–85 — 叠加定理的一般证明（线性方程组的线性性）

对于一个具有 *b* 条支路、*n* 个节点的电路，如果用回路电流或节点电压作为变量列出电路方程，此种方程具有以下形式（式 4-3，系数矩阵 × 变量 = 右端向量）：

【校对】
*G*<sub>11</sub>*x*<sub>1</sub> + *G*<sub>12</sub>*x*<sub>2</sub> + … + *G*<sub>1N</sub>*x*<sub>N</sub> = *b*<sub>1</sub>
*G*<sub>21</sub>*x*<sub>1</sub> + *G*<sub>22</sub>*x*<sub>2</sub> + … + *G*<sub>2N</sub>*x*<sub>N</sub> = *b*<sub>2</sub>　……
*G*<sub>N1</sub>*x*<sub>1</sub> + … + *G*<sub>NN</sub>*x*<sub>N</sub> = *b*<sub>N</sub>

当此方程是回路电流方程时，*x*<sub>k</sub> 是回路电流，系数是自阻或互阻，*b*<sub>k</sub> 是回路中独立电压源电压和由独立电流源等效变换后所得电压源电压的线性组合。当此方程是节点电压方程时，*x*<sub>k</sub> 是节点电压，系数是自导或互导，*b*<sub>k</sub> 是节点上的独立电流源的注入电流和独立电压源等效变换后所得电流源的注入电流的线性组合。

式(4-3) 的解的一般形式为 *x*<sub>k</sub> = Σ (Δ<sub>jk</sub>/Δ)·*b*<sub>j</sub>（克莱姆法则）。由于 *b*<sub>j</sub> 都是电路中激励的线性组合，而每个解答 *x*<sub>k</sub> 又是 *b*<sub>j</sub> 的线性组合，故任意一个解（电压或电流）都是电路中所有激励的线性组合。叠加定理于是得证。

> 【摘录者按】这是叠加定理的“根”：第六课学的节点/网孔方程是**线性方程组**，线性方程组的解对右端（激励）是线性的，所以响应必然能按激励拆开相加。不是死记的操作口诀，而是线性代数的直接结论。

### 【原文】印刷 p.85 — 叠加定理的陈述（正式表述）

叠加定理可表述为：**在线性电阻电路中，某处电压或电流都是电路中各个独立电源单独作用时，在该处分别产生的电压或电流的叠加。**线性电路中很多定理都与叠加定理有关，它是分析线性电路的基础。

当电路中存在受控源时，由于受控源的作用反映在回路电流方程或节点电压方程中的自阻和互阻或自导和互导中，所以任一处的电流或电压仍可按照各独立电源分别作用时在该处产生的电流或电压的叠加计算。所以对含有受控源的电路，叠加定理仍然适用，但是在进行各分电路计算时，**应把受控源保留在各分电路之中**。

> 【摘录者按】受控源的处理是核心难点之一：受控源**不是激励、不单独作用**，它属于电路结构，必须始终留在每个分电路里（因为它体现在自阻/互阻、自导/互导里）。李上 §3-2 例 3-4、3-5 有更明确的强调（见后）。

### 【原文】印刷 p.85–86 — 使用叠加定理的四点注意

使用叠加定理时应注意以下几点：
(1) 叠加定理适用于**线性电路，不适用于非线性电路**。
(2) 在叠加的各分电路中，如将不作用的**电压源置零，则在该电压源处用短路线代替**；如将不作用的**电流源置零，则在该电流源处用开路代替**。电路中所有电阻都不予改动，受控源则保留在各分电路中。
(3) 叠加时各分电路中的电压和电流的参考方向可以取为与原电路中的相同。取代数和时，应注意各分量前的“+”“−”号。
(4) **原电路的功率不等于从各分电路计算所得功率的叠加**，这是因为功率是电压和电流的乘积，与激励不呈线性关系，可在求出总响应后再进行功率计算。

> 【摘录者按】第(4)条是本课最重要的“不能做什么”：电压电流能叠加，功率不能。原因一句话——功率含平方/乘积，非线性。李上 §3-3 例 3-8 给出漂亮的数字反例（见后），教案要用它。

### 【原文】印刷 p.86 — 例 4-1：叠加定理简化计算（数值）

例 4-1：试用叠加定理计算图 4-2(a) 所示电路中的 *u* 与 *i*。画出电压源与电流源分别作用时的分电路。

对电压源单独作用的分电路：*u*′ = [20/(20+20)]×20 − [20/(20+30)]×30 = 10 − 12 = −2 V（分压），*i*′ = 20/(20+20) = 0.5 A。
对电流源单独作用的分电路：*u*″ = (20∥30)×... ，*i*″ = 0.25 A。

原电路的总响应：*u* = *u*′ + *u*″ = (−2 + 10) V = 8 V；*i* = *i*′ + *i*″ = (0.5 + 0.25) A = 0.75 A。

> 【摘录者按】OCR 对 *u*″ 的算式识别较乱（20∥30、分流系数），但总响应 u=8V、i=0.75A 清晰。教案若用此例需回看原页核对 *u*″ 细节，或直接用李上例 3-8 的干净数值（36V/9A/12Ω/6Ω→i=8A、P=384W）。

### 【原文】印刷 p.89 — §4-2 替代定理（陈述，含适用范围）

替代定理是一个应用范围极为广泛的定理，**它不仅适用于线性电路，也适用于非线性电路**。它时常用来对局部电路进行简化，从而使电路易于分析或计算。

替代定理的内容可叙述如下：在电路中如已求得 *N*<sub>1</sub> 与 *N*<sub>2</sub> 两个一端口网络连接端口的电压 *u* 与电流 *i*，那么就可用一个 *u*<sub>s</sub>=*u* 的电压源或一个 *i*<sub>s</sub>=*i* 的电流源来替代其中的一个网络，而使另一个网络的内部电压、电流均维持不变。

> 【摘录者按】替代定理的关键：已知某二端网络的端口电压 *u* 和电流 *i*，就能用一个 *u*<sub>s</sub>=*u* 的电压源（或 *i*<sub>s</sub>=*i* 的电流源）替换它，**对外部电路毫无影响**。与戴维南/诺顿的区别：替代用的是**已经求出的实际端口值**，不是等效参数。

### 【原文】印刷 p.89–90 — 替代定理的证明思路与边界

证明（以电压源替代为例）：先在 *N*<sub>2</sub> 的端子间串接两个电压方向相反、但激励电压均为 *u*<sub>s</sub> 的电压源，这不会影响电路内各电压、电流。令 *u*<sub>s</sub>=*u*，由于两点间电压为零，用一条短路线短接后内部电压、电流也不变，即得电压源替代。

**边界**：如果在 *N*<sub>1</sub> 中有 *N*<sub>2</sub> 中受控源的控制量，*N*<sub>2</sub> 被替代后将无法表达这种控制关系，这时 *N*<sub>2</sub> 就不可以被替代。

例 4-7：可求得 *u*=8 V、*i*=1 A。现将支路以 *u*<sub>s</sub>=*u*=8 V 的电压源或 *i*<sub>s</sub>=*i*=1 A 的电流源替代，其他部分的电压和电流均保持不变（*i*=2 A、*u*=1 V 等不变）。支路也可用一个电阻替代，其值为 *R*=*u*/*i*=8 Ω，此时其他部分的电压和电流亦保持不变。

> 【摘录者按】替代定理边界很重要：若被替代部分含有“被外部依赖的受控源控制量”，替代后控制关系丢失，就不能替代。教案作 P2 点思路。例 4-7 的 *u*=8V/*i*=1A/*R*=8Ω 可作最小示例。

### 【原文】印刷 p.97 — §4-4 最大功率传输定理（两类问题与动机）

在分析计算从电源向负载传输功率时，会遇到两种不同类型的问题。第一类型着重于传输功率的**效率**问题，典型的例子就是交、直流电力传输网络，传输的电功率巨大使得损耗、效率问题成为首要考虑。另一类型着重于传输功率的**大小**问题，例如在通信系统和测量系统中，重要问题是如何从给定的信号源取得尽可能大的信号功率，此时传输的功率不大，效率并不是第一位考虑的问题。

图 4-17(a) 中 *u*<sub>s</sub> 为电压源的电压、*R*<sub>s</sub> 为电源的内阻，*R*<sub>L</sub> 是负载……负载 *R*<sub>L</sub> 所获得的功率 *P*<sub>L</sub> 为

【校对】*P*<sub>L</sub> = *i*<sup>2</sup>*R*<sub>L</sub> = [*u*<sub>s</sub>/(R<sub>s</sub>+R<sub>L</sub>)]<sup>2</sup>·*R*<sub>L</sub> = *P*<sub>发出</sub>·*η*，其中 *P*<sub>发出</sub>=*u*<sub>s</sub>*i* 是电源发出功率，*η*=*R*<sub>L</sub>/(R<sub>s</sub>+R<sub>L</sub>) 是传输效率。将 *R*<sub>L</sub> 看为变量，*R*<sub>L</sub> 越小电源发出功率越大，但传输效率则越低。

> 【摘录者按】这段把“功率大小 vs 效率”的张力讲清了，是理解匹配的钥匙：R_L 小→电流大、源发出功率大，但大部分耗在内阻上、效率低；R_L 大→效率高但电流小。存在一个折中的 R_L 使负载功率最大。

### 【原文】印刷 p.97–98 — 最大功率传输条件与最大功率（推导结果）

*P*<sub>L</sub> 取得最大功率的情况发生在 d*P*<sub>L</sub>/d*R*<sub>L</sub>=0 的条件下，即

【校对】d/d*R*<sub>L</sub> { *u*<sub>s</sub><sup>2</sup>*R*<sub>L</sub>/(R<sub>s</sub>+R<sub>L</sub>)<sup>2</sup> } = 0　　→　　*R*<sub>L</sub> = *R*<sub>s</sub>

负载获得的最大功率：

【校对】*P*<sub>Lmax</sub> = *u*<sub>s</sub><sup>2</sup>/(4*R*<sub>s</sub>)。此时，传输效率为 50%。

最大功率问题可推广至可变化的负载 *R*<sub>L</sub> 从含源一端口获得功率的情况。将含源一端口用戴维南等效电路来代替，其参数为 *u*<sub>oc</sub> 与 *R*<sub>eq</sub>，当满足 *R*<sub>L</sub>=*R*<sub>eq</sub> 时，*R*<sub>L</sub> 将获得最大功率 *P*<sub>Lmax</sub> = *u*<sub>oc</sub><sup>2</sup>/(4*R*<sub>eq</sub>)。此时，称负载 *R*<sub>L</sub> 与含源一端口的输入电阻匹配，并取得最大功率。

> 【摘录者按】这正是第五课埋的钩子上并证明：负载等于（戴维南）内阻时功率最大，P_max=u_oc²/(4R_eq)。匹配条件 R_L=R_eq、最大功率公式、效率 50%（对电压源模型）三件都要讲。

### 【原文】印刷 p.98 — 例 4-10：匹配计算与“内外不等效”（效率陷阱）

例 4-10：问 *R*<sub>L</sub> 为何值时可取得最大功率？求此最大功率。电源发出的功率有多少百分比传输给 *R*<sub>L</sub>？

解：先求 *R*<sub>L</sub> 左边含源一端口的戴维南等效电路，可得 *u*<sub>oc</sub>=10 V、*R*<sub>eq</sub>=2.5 Ω。故当 *R*<sub>L</sub>=*R*<sub>eq</sub>=2.5 Ω 时可得最大功率 *P*<sub>Lmax</sub>=*u*<sub>oc</sub><sup>2</sup>/(4*R*<sub>eq</sub>)=10<sup>2</sup>/(4×2.5)=10 W。为求电源发出的功率必须返回原电路，算得电源发出 60 W，此时仅有 16.67% 的电源功率传输给 *R*<sub>L</sub>。该例说明，从戴维南等效电路看传输效率为 50%，但从原电路看只有 16.67% 传输给 *R*<sub>L</sub>。**这进一步说明对内不等效问题。**

> 【摘录者按】这是“50% 效率”最重要的澄清：50% 只对“单个理想电压源串内阻”模型成立；一般含源网络等效后，戴维南等效电阻上“算出来的”损耗不等于原网络内部真实损耗，所以对原电路的电源而言效率未必 50%（例 4-10 只有 16.67%）。教案要把这个当核心难点讲。

## 二、李瀚荪《电路分析基础》第5版（上）

### 【原文】PDF 124（印刷约 p.106）— §3-1 线性电路的比例性（齐次性）

由线性元件及独立电源组成的电路为线性电路。独立电源是电路的输入，对电路起着激励（excitation）的作用……后者只是激励引起的响应（response）。在线性电路中，响应与激励之间存在着线性关系。

若以某支路电流 *i* 为响应，可得 *i* = … （式 3-1，各电阻组成的分式）。由于各电阻为常数，这是一个线性关系，可表示为

【校对】*i* = *K*·*u*<sub>s</sub>　　(3-2)

显然，若 *u*<sub>s</sub> 增大 *n* 倍，*i* 也随之增大 *n* 倍。这样的性质称为“齐次性”（homogeneity）或“比例性”（proportionality），它是“线性”（linearity）的一个表现。

### 【原文】PDF 125（印刷约 p.107）— 网络函数定义

对单一激励的线性时不变电路，指定的响应对激励之比定义为网络函数（network function），记为 *H*，即

【校对】*H* = 响应 / 激励　　(3-3)

激励是指电压源电压 *u*<sub>s</sub> 或电流源电流 *i*<sub>s</sub>，响应可以是任一支路的电压或电流。对电阻电路，*H* 为一实数。若响应与激励在同一对端钮，则属策动点（driving point）函数；若不在同一对端钮，则属转移（transfer）函数。

> 【摘录者按】网络函数是齐次性的“打包”：一个实数 *H* 就把“激励→某响应”的关系表征出来，*H* 只由电路结构与参数决定、与激励无关。这与叠加是同一线性本质的两种表述（齐次性 + 可加性 = 线性）。P1 点到即可，不深挖。

### 【原文】PDF 129–130（印刷约 p.111–112）— §3-2 叠加原理（正式表述与公式）

在含多个激励的线性电路中……式中的第一项就是该电路在 *i*<sub>s</sub>=0、亦即 *u*<sub>s</sub> 单独作用时在电阻中产生的电流，这一项是比例于激励 *u*<sub>s</sub> 的……第二项就是该电路在 *u*<sub>s</sub>=0、亦即 *i*<sub>s</sub> 单独作用时产生的电流……由两个激励产生的响应为每一激励单独作用时产生的响应之和。这是“线性”在多于一个独立源时的表现，称为“可加性”（superposition）。

线性电路的叠加性常上升为电路的一个原理（principle）。表述如下：**由线性电阻、线性受控源及独立源组成的电路中，每一元件的电流或电压可以看成是每一个独立源单独作用于电路时，在该元件上产生的电流或电压的代数和。这就是叠加原理。**当某一独立源单独作用时，其他独立源应为零值，即独立电压源用短路代替；独立电流源用开路代替。

【校对】*y*(*t*) = Σ<sub>k</sub> *H*<sub>k</sub>·*x*<sub>k</sub>(*t*)　　(3-14)

式中 *x*<sub>k</sub>(*t*) 表示电路中的电压源电压或电流源电流，*H*<sub>k</sub> 为相应的网络函数。对线性电路来说，(3-14) 式是一个很重要的公式。叠加性是线性电路的根本属性。

> 【摘录者按】李上的表述与邱一致，且用 *y*=Σ*H*<sub>k</sub>*x*<sub>k</sub> 把“叠加”与“网络函数/齐次性”统一成一个公式——响应是各激励经各自网络函数加权之和。这是本课最漂亮的总结式。

### 【原文】PDF 131（印刷约 p.113）— 例 3-4：含受控源电路的叠加（受控源始终保留）

对含受控源电路运用叠加原理时必须注意：**叠加原理中说的只是独立电源的单独作用，受控源的电压或电流不是电路的输入，不能单独作用。在运用该原理时，受控源应和电阻一样，始终保留在电路内。**

例 3-4：10 V 电压源单独作用……注意此时受控源的电压为 2*i*……解得 *i*′=2 A。3 A 电流源单独作用……解得 *i*″=−0.6 A。电源同时作用：*i*=*i*′+*i*″=(2−0.6) A=1.4 A。

> 【摘录者按】“受控源始终保留”用黑体强调，是最易错点。分响应 *i*″ 为负 → 叠加时按代数和相减，正好教“参考方向一致、取代数和”这条注意(3)。

### 【原文】PDF 133、135（印刷约 p.115、p.117）— §3-3 叠加方法与功率计算（核心反例）

例 3-8：设 *u*<sub>s</sub>=36 V、*i*<sub>s</sub>=9 A、*R*=12 Ω、*R*<sub>L</sub>=6 Ω，用叠加方法求 *R*<sub>L</sub> 的电流 *i* 和功率 *P*。

当 36 V 电压源单独作用：*i*′=36/(12+6)=2 A。当 9 A 电流源单独作用：*i*″=[12/(12+6)]×9=6 A。因此流经 *R*<sub>L</sub> 的电流 *i*=*i*′+*i*″=(2+6) A=8 A，功率 *P*<sub>L</sub>=*R*<sub>L</sub>*i*<sup>2</sup>=(6 Ω)(8 A)<sup>2</sup>=384 W。

如果分别求出每一电源单独作用时 *R*<sub>L</sub> 的功率：*P*′=(6 Ω)(2 A)<sup>2</sup>=24 W，*P*″=(6 Ω)(6 A)<sup>2</sup>=216 W，则 *P*′+*P*″=240 W ≠ 384 W。

原因很简单：尽管由叠加原理可得 2 A+6 A=8 A，但 (2 A)<sup>2</sup>+(6 A)<sup>2</sup> ≠ (8 A)<sup>2</sup>。**电阻的功率不能由叠加原理直接求得，因为功率与电流（压）的二次方有关，不是线性关系。一般来说，功率不服从叠加原理，只有在一些特殊情况下才能例外。通常我们可以用叠加方法求得电流、电压后再去计算功率。**

> 【摘录者按】这是“功率不可叠加”的最佳数值反例：电流 2+6=8 A（√），功率 24+216=240 W ≠ 384 W（✗）。一眼看懂非线性来源。教案/页面直接用这组数。

### 【原文】PDF 136（印刷约 p.118）— 例 3-9：电源提供的总功率却可以叠加（易混淆点辨析）

例 3-9：求两电源对电路提供的总功率，并试由每一电源单独作用时对电路提供功率的代数和求解。

解：(1) 直接算：电压源提供 −36 W（即吸收 36 W），电流源提供 432 W，总提供 396 W。
(2) 分别算：电压源单独作用时提供 72 W，电流源单独作用时提供 324 W，总和 72+324=396 W，与 (1) 一致。

由此可见：**电源对电路提供的总功率等于电压源单独作用时对电路提供的功率和电流源单独作用时对电路提供功率的总和。**这对不含受控源的线性电阻电路是一个普遍规律。

> 【摘录者按】极易混淆：某个**电阻**的功率不可叠加（例3-8），但各**独立电源提供/吸收**的总功率可以按源分别累加（例3-9）。教案要点明这个区别，避免学生把“功率绝对不可叠加”记死。属 P2 辨析。

### 【原文】PDF 184–185（印刷约 p.166–167）— §4-8 最大功率传递定理（匹配条件、公式、两大误区）

给定一含源线性单口网络，接在它两端的负载电阻不同，从单口网络传递给负载的功率也不同。设负载电阻为 *R*<sub>L</sub>，当 *R*<sub>L</sub> 很大时，流过 *R*<sub>L</sub> 的电流很小，因而 *R*<sub>L</sub> 得到的功率很小；如果 *R*<sub>L</sub> 很小，功率同样也是很小的。在 *R*<sub>L</sub>=0 与 *R*<sub>L</sub>=∞ 之间将有一个电阻值可使负载所得功率为最大。

【校对】*P*<sub>L</sub> = *u*<sub>oc</sub><sup>2</sup>*R*<sub>L</sub>/(R<sub>eq</sub>+R<sub>L</sub>)<sup>2</sup>　　(4-32)

要使 *P*<sub>L</sub> 为最大，应使 d*P*<sub>L</sub>/d*R*<sub>L</sub>=0，由此解得

【校对】*R*<sub>L</sub> = *R*<sub>eq</sub>　　(4-34)

满足 *R*<sub>L</sub>=*R*<sub>eq</sub> 时，称为最大功率匹配（match），此时负载得到的最大功率为

【校对】*P*<sub>Lmax</sub> = *u*<sub>oc</sub><sup>2</sup>/(4*R*<sub>eq</sub>)　　(4-35)（诺顿形式：*P*<sub>Lmax</sub>=*i*<sub>sc</sub><sup>2</sup>*R*<sub>eq</sub>/4）

**注意**：最大功率传递定理是在 *R*<sub>L</sub> 可变的情况下得出的。如果 *R*<sub>L</sub> 固定而 *R*<sub>eq</sub> 可变，则应使 *R*<sub>eq</sub> 尽量减小，才能使 *R*<sub>L</sub> 获得的功率增大；当 *R*<sub>eq</sub>=0 时 *R*<sub>L</sub> 获得最大功率。

**另一常易产生的错误概念**：由线性单口网络获得最大功率时，其功率传递效率应为 50%，因为 *R*<sub>L</sub> 与 *R*<sub>eq</sub> 消耗的功率相等。如果负载功率来自一个具有内阻为 *R*<sub>eq</sub> 的电压源，那么负载得到最大功率时效率确实为 50%。但是，单口网络和它的等效电路就其内部功率而言是不等效的，由等效电阻 *R*<sub>eq</sub> 算得的功率一般并不等于网络内部消耗的功率，因此实际上当负载得到最大功率时，其功率传递效率未必是 50%。

> 【摘录者按】李上这段是对邱例 4-10 的理论澄清，两个误区都要讲：① 定理前提“负载可变”；② 50% 效率只对单电压源模型成立，一般网络内部不等效、效率未必 50%。这是工程含义与核心难点。

## 三、摘录者综合笔记（备课用，不是原文）

1. **引入顺序**：第四章导读立框架（叠加对激励、戴维南对结构、最大功率是应用）→ 齐次性/比例性与网络函数（线性的一个表现）→ 叠加原理（线性的另一表现：可加性）→ 受控源处理（保留）→ 功率不可叠加（例3-8 反例）→ 替代定理（特殊的等效，P2）→ 最大功率传输（接第五课钩子，戴维南应用）。**不是**上来就甩三个定理。
2. **叠加定理核心**：线性方程组解的线性性（邱用克莱姆法则证）→ 响应=各独立源单独作用分响应之代数和。适用：线性电路；不适用非线性。置零规则：电压源→短路，电流源→开路，电阻不动，**受控源保留**。参考方向取一致、代数和注意正负。
3. **功率不可叠加**：功率∝电流²（非线性），电阻功率不能叠加（例3-8：2A+6A=8A 但 24+216≠384W）。但可以：先叠加求电流/电压，再算总功率；各独立电源**提供/吸收**的总功率可按源累加（例3-9，P2 辨析）。
4. **替代定理核心（P2）**：已知二端网络端口 u、i，可用 u_s=u 电压源或 i_s=i 电流源（甚至 R=u/i 电阻）替换，外部不变。适用线性+非线性电路。边界：被替代部分若含外部依赖的受控源控制量则不能替代。
5. **最大功率传输核心**：接第五课戴维南钩子。P_L=u_oc²·R_L/(R_eq+R_L)²，dP/dR_L=0 → R_L=R_eq 匹配，P_max=u_oc²/(4R_eq)。效率陷阱：50% 只对单电压源模型成立，一般网络内部不等效、实际效率未必 50%（邱例4-10 仅 16.67%）。前提：负载 R_L 可变。
6. **与前课衔接**：第六课节点/网孔方程（线性方程组）是叠加定理成立的数学基础；第五课戴维南/诺顿是最大功率传输的前置（提供 u_oc、R_eq）；L1-03 功率计算（P=i²R、吸收/发出符号）是功率不可叠加与电源功率辨析的基础。
7. **边界**：邱 §4-3 戴维南/诺顿已摘于 L1-05，本课只引用；§4-5 特勒根、§4-6 互易、对偶原理只作 P3 认知；李上网络函数只点到（齐次性 + 可加性 = 线性）；受控源严格叠加计算、电源功率求和属 P2。H&H 本课未摘正文，不引用。

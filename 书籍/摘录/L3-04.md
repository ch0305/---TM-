## 零、为什么需要复频域法：经典法的困难（邱 导读 p.319 / PDF 344；§14-1 p.320–321 / PDF 344–345）

### 【原文】经典法的困难与积分变换的思路

> 【原文 OCR】第七章介绍了用经典法求解动态电路，其优点是物理概念清楚，但当分析具有多个动态元件及多个激励电源的复杂电路时，则直接求解微分方程会有一定的困难。拉普拉斯变换法是在复频域求解高阶动态电路方程行之有效的方法之一。〔邱 第14章导读 / p.319 / PDF 344〕
> 【原文 OCR】对于一个 n 阶方程，直接求解时需要知道变量及其各阶导数（直到 n−1 阶导数）在 t=0₋ 时刻的值，而电路中给定的初始状态是各电感电流和电容电压在 t=0₋ 时刻的值，从这些值求得所需初始条件的工作量很大。积分变换法是通过积分变换，把已知的时域函数变换为频域函数，从而把时域的微分方程化为频域的代数方程。求出频域函数后，再作反变换，返回时域，可以求得满足电路初始条件的原微分方程的解答，而不需要确定积分常数。拉普拉斯变换是一种重要的积分变换，是求解高阶复杂动态电路的有效而重要的方法之一。〔邱 §14-1 / p.320 / PDF 345〕
> 【摘录者按】这就是本课的"核心问题"书证：微分方程难在**初始条件换算**（要各阶导数的初值），而电路只给 L 电流、C 电压的初值。拉氏变换把微分变成代数、自动带入初值，正是为解决这个痛点。〔通识〕

### 【原文】拉普拉斯变换的定义

> 【原文 OCR】一个定义在 [0,∞) 区间的函数 f(t)，它的拉普拉斯变换式 F(s) 定义为 `F(s)=∫₀₋^∞ f(t)e^(−st) dt`（14-1），式中 s=σ+jω 为复数，F(s) 称为 f(t) 的象函数，f(t) 称为 F(s) 的原函数。拉普拉斯变换简称为拉氏变换。〔邱 §14-1 / 式 14-1 / p.320 / PDF 345〕
> 【校对 OCR】积分下限取 0₋，可计及 t=0 时刻 f(t) 包含的冲激，给存在冲激电压/电流的电路带来方便。变量 s 称为**复频率**；应用拉氏变换法分析电路称为电路的**复频域分析方法**，又称**运算法**。由 F(s) 求 f(t) 的反变换定义为 `f(t)=(1/2πj)∫ F(s)e^(st) ds`，实际计算一般查表 + 部分分式展开，不用这个复变积分。〔邱 §14-1 / 式 14-1、14-2 / p.320–321 / PDF 345〕
> 【摘录者按】定义里 s=σ+jω 是关键：它比相量法的 jω 多了一个实部 σ，因此既能描述衰减（对应 L3-03 的欠阻尼），也能描述稳定与增幅；L3-03 的特征根 p 其实就是这里的复频率 s 在特定位置的取值。〔通识〕

### 【原文】变换域方法：与相量法类比（李下 §12-1 / PDF 202–203）

> 【原文 OCR】时域变量是实际存在的变量，而它们的拉氏变换 U(s)、I(s) 则是一种抽象的变量。之所以把直观的时域变量变为抽象的复频率变量，是为了便于分析和计算电路问题，待得出结果后再反变换为相应的时域变量。这与以前在分析正弦稳态电路时，把直观的正弦量（时域变量）变为抽象的相量（频域变量），以求简化电路的分析、计算，目的完全相同，均属变换（域）方法。〔李下 §12-1 / PDF 203〕
> 【校对 OCR】求激励函数的拉氏变换通常查表（工程技术上激励函数有限），少数常用的记住即可。常用对：δ(t)↔1、ε(t)↔1/s、t↔1/s²、e^(−at)↔1/(s+a)、cos ωt↔s/(s²+ω²)、sin ωt↔ω/(s²+ω²)。〔李下 §12-1 表 12-1 / PDF 203–204〕
> 【摘录者按】"和相量法类比"是本课最省力的认知支点：学生已学过相量法（L2-04），把 jω 换成 s 就从正弦稳态推广到任意激励 + 暂态。教案据此设计预测 1 的类比铺垫。〔通识〕

## 一、基本性质：线性、微分、KCL/KVL 的运算形式（邱 §14-2 p.322–324 / PDF 346–348；李下 §12-1 / PDF 204–205）

### 【原文】线性性质

> 【原文 OCR】设 f₁(t) 和 f₂(t) 是两个任意的时间函数，它们的象函数分别为 F₁(s) 和 F₂(s)，a₁ 和 a₂ 是两个任意实常数，则 `L[a₁f₁(t)+a₂f₂(t)]=a₁F₁(s)+a₂F₂(s)`。〔邱 §14-2 / p.322 / PDF 346〕
> 【校对 OCR】线性性质意味着：求函数乘以常数的象函数、以及求几个函数相加减的象函数时，可以先求各项的象函数再相加减。〔邱 §14-2 例14-2〕

### 【原文】微分性质（把微分变成乘 s，并自动带入初值）

> 【原文 OCR】若 `L[f(t)]=F(s)`，则 `L[df/dt]=sF(s)−f(0₋)`。〔邱 §14-2 / 式 14-2 节 / p.323 / PDF 347〕
> 【校对 OCR】当初始条件均为零时，时域内求一次导数相当于复频域内乘以 s；时域的微分运算相当于复频域的乘法运算，其情况类似于两数相乘经取对数后简化为相加。〔邱 §14-2；李下 §12-1 式 12-6 / PDF 205〕
> 【摘录者按】`sF(s)−f(0₋)` 中的 `−f(0₋)` 就是"自动带入初值"：这正是零对比经典法"要各阶导数初值"的优势——只用到 f 本身在 0₋ 的值，恰是电感电流、电容电压这些电路给的初始状态。教案陈述时刻 2 要显式化这条。〔通识〕

### 【原文】KCL、KVL 的运算形式（李下 §12-1 / PDF 205）

> 【原文 OCR】对集总电路的任一节点，在任一时刻，流出节点的电流代数和为零，即 Σi=0；若 L[Σi]=ΣI(s)，则由线性性质可得 `ΣI(s)=0`，此即 KCL 的拉氏变换形式。类似地可得 KVL 的拉氏变换形式为 `ΣU(s)=0`。〔李下 §12-1 / 式 12-4、12-5 / PDF 205〕
> 【摘录者按】运算形式下 KCL/KVL 与相量形式一模一样，这是"电阻电路的整套方法（节点/网孔/叠加/戴维南）可以原样搬到 s 域"的根基。〔通识〕

## 二、反变换：部分分式展开（邱 §14-3 p.327–330 / PDF 351–354；李下 §12-2 / PDF 208–214）

> 【原文 OCR】用拉氏变换求解线性电路的时域响应时，需要把求得的响应的拉氏变换式反变换为时间函数。拉氏反变换可以用复变积分求得，但一般比较复杂。如果象函数比较简单，往往能从拉氏变换表中查出其原函数；对于不能从表中查出原函数的情况，如果能设法把象函数分解为若干较简单的、能够从表中查到的项，就可查出各项对应的原函数，而它们之和即为所求原函数。电路响应的象函数通常可表示为两个实系数 s 的多项式之比，即 s 的一个有理分式。把 F(s) 分解成若干简单项之和，而这些简单项可以在拉氏变换表中找到，这种方法称为**部分分式展开法**，或称为**分解定理**。〔邱 §14-3 / p.327 / PDF 351〕
> 【校对 OCR】单根：`K_i=[(s−p_i)F(s)]|_{s=p_i}`（留数法）；共轭复根 `p₁,₂=α±jω` 展开后合并成 `2|K|e^(αt)cos(ωt+φ)`（对应欠阻尼衰减振荡，与 L3-03 一致）；重根按重数逐项分离求导。〔邱 §14-3 / 式 14-4~14-9 / p.327–330 / PDF 351–354〕
> 【原文 OCR】例14-6 求 `F(s)=(2s+1)/(s³+7s²+10s)` 的原函数：分母根 p₁=0、p₂=−2、p₃=−5，得 `f(t)=0.1+0.5e^(−2t)−0.6e^(−5t)`。〔邱 §14-3 例14-6 / p.328 / PDF 352〕
> 【校对 OCR】OCR 把分母识为 `s³+5s²+6s`，但原页同时印有 `D'(s)=3s²+14s+10`（导数）且根为 `0/−2/−5`、`0.1/0.5/−0.6` 三系数，反推分母必为 `s³+7s²+10s=s(s+2)(s+5)`：`N(p)/D'(p)=1/10, 1/2, −3/5`，与原页三系数逐项吻合；若取 `s³+5s²+6s=s(s+2)(s+3)` 则根为 0/−2/−3、与 `e^(−5t)` 矛盾。故按导数与根/系数三重证据校为 `s³+7s²+10s`。〔摘录者按〕
> 【校对 OCR】例14-7：`F(s)=s/(s²+2s+5)` 有共轭复根 `p=−1±j2`，反变换为 `f(t)=√5 e^(−t) sin(2t+φ)` 型衰减振荡。〔邱 §14-3 例14-7 / p.329 / PDF 353〕
> 【摘录者按】部分分式的每一项的"分母根"就是响应里的指数衰减率/振荡频率——这正是 L3-03 的特征根 p：s 域分母的根 = 时域响应的模态。教案只要求学生"看得懂对应关系"，不要求手算复杂展开（选学强化、P3 了解即可）。〔通识〕

## 三、运算电路：元件的 s 域模型（邱 §14-4 p.331–333 / PDF 355–357；李下 §12-3 / PDF 215–216）

### 【原文】电阻、电感、电容的运算形式

> 【原文 OCR】基尔霍夫定律的运算形式：对任一节点 `ΣI(s)=0`，对任一回路 `ΣU(s)=0`。电阻元件 `u=Ri` 两边取拉氏变换得 `U(s)=R I(s)`（14-10），称为电阻 VCR 的运算形式。〔邱 §14-4 / p.331 / PDF 355〕
> 【原文 OCR】电感 `u=L di/dt`，取拉氏变换并根据微分性质得 `U(s)=sL I(s) − L i(0₋)`（14-11a），式中 sL 为电感的**运算阻抗**，`L i(0₋)` 反映电感初始电流的作用（附加电压源）。〔邱 §14-4 / p.331–332 / PDF 355–356〕
> 【原文 OCR】电容取拉氏变换并根据积分性质得 `U(s)=(1/sC) I(s) + u_C(0₋)/s`（14-12），其中 `1/sC` 为电容的**运算阻抗**，`u_C(0₋)/s` 反映电容初始电压的作用（附加电压源）。〔邱 §14-4 / p.332 / PDF 356〕
> 【校对 OCR】RLC 串联的运算阻抗 `Z(s)=R+sL+1/(sC)`；零初始条件下 `U(s)=Z(s)I(s)` 即"运算形式的欧姆定律"。非零初值把初始状态看成附加电源后，方程形式仍与相量方程类似。〔邱 §14-4 / p.333–334 / PDF 357–358〕

### 【原文】广义阻抗：把 jω 换成 s（李下 §12-3 / PDF 215–216）

> 【原文 OCR】零状态元件两端电压 U(s) 与电流 I(s) 之比定义为广义阻抗（generalized impedance）或拉普拉斯阻抗，记为 Z(s)，即 `Z(s)=U(s)/I(s)`；三种元件统一用 `U(s)=Z(s)I(s)` 表征，只是 Z(s) 各不相同：电容 `Z(s)=1/sC`、电感 `Z(s)=sL`、电阻 `Z(s)=R`。〔李下 §12-3 / 式 12-23~12-27 / PDF 215–216〕
> 【原文 OCR】新引入的概念更具有普遍性，它把阻抗、导纳考虑为复变量 s 的函数而不是纯虚数变量 jω 的函数……若电路为零初始状态，则处理拉氏变换的规律与处理相量的规律完全相同，只需把 jω 换以 s 即可。相量法中的相量模型在把 jω 换以 s 后即可得到同一电路的 s 域模型，当然这一模型只适用于零状态分析。〔李下 §12-3 / PDF 216〕
> 【摘录者按】这句"把 jω 换成 s"是全课最该抄进笔记的一句：它把 L2-05 的阻抗法（Z_R=R、Z_L=jωL、Z_C=1/jωC）直接升级成 s 域运算阻抗（R、sL、1/sC），因此"电阻电路那套解法原样可用"。教案陈述时刻 3 显式化这条。〔通识〕

## 四、应用：运算法分析线性电路与全响应（邱 §14-5 p.334–336 / PDF 358–360；李下 §12-3 / PDF 216–217）

> 【原文 OCR】运算法与相量法的基本思想类似。相量法把正弦量变换为相量（复数），从而把求解线性电路的正弦稳态问题归结为以相量为变量的线性代数方程；运算法把时间函数变换为对应的象函数，从而把问题归结为求解以象函数为变量的线性代数方程。当电路的所有独立初始条件为零时，电路元件 VCR 的运算形式与相量形式类似，KCL 和 KVL 的运算形式与相量形式也类似，所以对于同一电路列出的零状态下的运算形式方程和相量方程在形式上相似，但这两种方程具有不同的意义。在非零状态条件下，电路方程的运算形式中还应考虑附加电源的作用。可见相量法中各种计算方法和定理在形式上完全可以移用于运算法。在运算法中求得象函数之后，利用拉氏反变换就可以求得对应的时间函数。〔邱 §14-5 / p.334 / PDF 358〕
> 【原文 OCR】例14-9：图14-7 电路原处于稳态，t=0 时开关闭合，用运算法求换路后的电流。解：先求初值（电感电流 i_L(0₋)=0、电容电压 u_C(0₋)=1V），画运算电路，用回路电流法列出 s 域代数方程解出 I(s)，再部分分式反变换得 `i(t)=(1−e^(−t)cos t − e^(−t)sin t)` 型时域解。〔邱 §14-5 例14-9 / p.334–335 / PDF 358–359〕
> 【校对 OCR】李下例12-8 求 i(t)：R=8Ω、L=2H，电源电压 u(t)=40sin3t，零初值作 s 域模型（`Z(s)=2s+8`），`U(s)=120/(s²+9)`，解得 `I(s)=U(s)/Z(s)=120/((s²+9)(2s+8))=60/((s²+9)(s+4))`，部分分式 `I(s)=2.4/(s+4)+(−2.4s+9.6)/(s²+9)`，反变换得 `i(t)=[2.4e^(−4t)+4sin(3t−37°)]ε(t) A`（稳态幅值 4A 由相量法核对：`Z=8+j6=10∠36.87°`、`I=40/10=4∠−36.87°`；瞬态系数 `K₁=60/(16+9)=2.4`）。李下点明：第二项为正弦稳态解、第一项为瞬态解，`Z(s)=2s+8` 为特征多项式、`2s+8=0` 为特征方程（`s=−4`，时间常数 `τ=1/4=0.25s`）——**s 域分析法求得的是全响应**。〔李下 §12-3 例12-8 / PDF 216–217〕
> 【摘录者按】例12-8 是连接 L3-03 的最佳实证：`Z(s)=0` 的根就是 L3-03 讲的"特征根 p"，它同时决定瞬态项 `e^(−4t)` 的衰减快慢；响应第一项瞬态 + 第二项稳态 = 全响应，把 L2-03 的三要素法与 L3-03 的形态统一进一个框架。教案据此设计"预测 4 / 陈述时刻 4：s 域分母的根 = 响应模态 = L3-03 特征根"。〔通识〕

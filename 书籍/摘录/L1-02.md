## 一、邱关源《电路》第6版

### 【原文】印刷 p.10 — 第1章导读（两类约束）

电路中变量（物理量）受到两类约束：一类是元件的特性方程形成的变量的元件约束；另一类是因元件的相互连接而构成的变量的几何约束。变量的几何约束由基尔霍夫定律来表达，基尔霍夫定律是集总参数电路的基本定律。对于给定的电路，可凭借元件特性方程和基尔霍夫定律得到定解；反之，正确的电路解答也一定满足基尔霍夫定律。

> 【摘录者按】这句话是 L1-02 的“地图”：KCL/KVL 不是又一条元件公式，而是**连接关系**带来的约束。第一课解决“一个元件内部 u 和 i 的关系”，这一课解决“多个元件接在一起后，支路量之间被迫满足什么”。

### 【原文】印刷 p.19–20 — §1-6 电压源和电流源（最小引入）

电压源是一个理想电路元件，它的端电压 *u*(*t*) 为

【校对】*u*(*t*) = *u*<sub>S</sub>(*t*)

式中 *u*<sub>S</sub>(*t*) 为给定的时间函数，称为电压源的激励电压。电压源电压 *u*(*t*) 与通过元件的电流无关，总保持为给定的时间函数，而电流的大小则由外电路决定。……

电压源不接外电路时，电流 *i* 为零值，这种情况称为“电压源处于开路”。如果一个电压源的电压 *u*<sub>S</sub> = 0，则此电压源的伏安特性为 *u*-*i* 平面上的电流轴，它相当于短路。……

电流源是一个理想电路元件。它发出的电流 *i*(*t*) 为

【校对】*i*(*t*) = *i*<sub>S</sub>(*t*)

其中 *i*<sub>S</sub>(*t*) 为给定时间函数，称为电流源的激励电流。因而电流源的电流 *i*(*t*) 与元件的端电压无关，并总保持为给定的时间函数。电流源的端电压由外电路决定。……

电流源两端短路时，其端电压 *u* = 0，而 *i* = *i*<sub>S</sub>，短路电流仍是激励电流。如果一个电流源的 *i*<sub>S</sub> = 0，则此电流源的伏安特性为 *u*-*i* 平面上的电压轴，它相当于开路。……

> 【摘录者按】本课只需要“理想源 = 提供已知电压/电流的元件”这一层；受控源（§1-7）是 P3，留到 L1-06。这里特意不摘 §1-7。

### 【原文】印刷 p.22 — §1-8 基尔霍夫定律（支路、节点、回路；两类约束）

集总电路由集总元件相互连接而成。基尔霍夫定律是集总电路的基本定律。为了说明基尔霍夫定律，先介绍支路、节点和回路的概念。为了简化说明，在本节中把组成电路的每一个二端元件称为一条支路，把支路的连接点称为节点。图 1-13 为一个具有六条支路、四个节点的电路，各支路和节点的编号如图所示。由支路所构成的闭合路径称为回路，如图中支路（1，3，4，6）。同理，支路（1，2，4，6）、（1，2，5，6）、（1，3，5，6）、（2，3）、（4，5）等也都分别构成回路。关于支路、节点和回路等概念的进一步介绍见 §3-1。

如果将电路中各个支路的电流和支路的电压（简称支路电流与支路电压）作为变量来看，这些变量受到两类约束。一类是元件的特性造成的约束。例如，线性电阻元件的电压与电流必须满足 *u* = *Ri* 的关系；电流源元件的电压与电流必须满足 *i* = *i*<sub>S</sub>。这种关系称为元件的电压电流关系（VCR），即 VCR 构成了变量的元件约束。另一类约束是由于元件的相互连接赋予支路电流之间或支路电压之间的约束关系，有时称为“几何”约束或“拓扑”约束。这类约束由基尔霍夫定律来体现。

基尔霍夫定律包括电流定律和电压定律。

基尔霍夫电流定律（KCL）指出：“在集总电路中，任何时刻，对任一节点，所有流出节点的支路电流的代数和恒等于零”。

> 【摘录者按】邱关源这里把“支路”简化成“每一个二端元件”。李瀚荪补充了另一种处理：多个元件串联也可以合并成一条支路。两种说法不矛盾，关键是**先把支路划清楚，再谈节点和回路**。

### 【原文】印刷 p.23 — KCL 的符号规则、闭合面；KVL 的表述

此处，电流的“代数和”是根据电流是流出节点还是流入节点来说的。若流出节点的电流前面取“+”号，则流入节点的电流前面取“−”号；电流是流出节点还是流入节点，均根据电流的参考方向判断。所以对任一节点，KCL 表示为

【校对】Σ *i* = 0

上式取和是对连接于该节点的所有支路电流进行的。

例如，以图 1-14 所示电路为例，对节点①应用 KCL，有（各支路电流的参考方向见图）

【校对】*i*<sub>1</sub> + *i*<sub>4</sub> − *i*<sub>6</sub> = 0

上式可写为

【校对】*i*<sub>1</sub> + *i*<sub>4</sub> = *i*<sub>6</sub>

此式表明，流出节点①的支路电流等于流入该节点的支路电流。因此，KCL 也可理解为，任何时刻，流出任一节点的支路电流等于流入该节点的支路电流。

KCL 通常用于节点，但对包围几个节点的闭合面也是适用的。对图 1-14 所示电路，用虚线表示的闭合面 *S* 内有 3 个节点，即节点①、②和③。对这些节点分别有：

【校对】*i*<sub>1</sub> + *i*<sub>4</sub> − *i*<sub>6</sub> = 0

【校对】−*i*<sub>2</sub> − *i*<sub>4</sub> + *i*<sub>5</sub> = 0

【校对】*i*<sub>3</sub> − *i*<sub>5</sub> + *i*<sub>6</sub> = 0

以上 3 式相加后，得到流出闭合面 *S* 的电流代数和为

【校对】*i*<sub>1</sub> − *i*<sub>2</sub> + *i*<sub>3</sub> = 0

其中 *i*<sub>1</sub> 和 *i*<sub>3</sub> 流出闭合面，*i*<sub>2</sub> 流入闭合面。

所以，流出一个闭合面的支路电流的代数和恒等于零；或者说，流出闭合面的支路电流等于流入同一闭合面的支路电流。这称为电流的连续性。KCL 是电荷守恒的体现。

基尔霍夫电压定律（KVL）指出：“在集总电路中，任何时刻，沿任一回路，所有支路电压的代数和恒等于零。”

所以，沿任一回路有

【校对】Σ *u* = 0

上式取和时，需要任意指定一个回路的绕行方向，凡支路电压的参考方向与回路的绕行方向一致时，该电压前面取“+”号；支路电压的参考方向与回路绕行方向相反时，该电压前面取“−”号。

> 【摘录者按】两套符号在这里第一次同时出现：**方程项前的 ±** 由“参考方向对节点/绕行方向”决定；**数值本身的 ±** 由解出来是正是负决定。李瀚荪在 p.15 专门提醒“两者不要混淆”，这是本课的核心难点之一。

### 【原文】印刷 p.24 — KVL 例、适用条件、例 1-2

以图 1-15 所示电路为例，对支路（1，2，3，4）构成的回路列写 KVL 方程时，需要先指定各支路电压的参考方向和回路的绕行方向。绕行方向用虚线上的箭头表示，有关支路电压为 *u*<sub>1</sub>、*u*<sub>2</sub>、*u*<sub>3</sub>、*u*<sub>4</sub>，它们的参考方向如图 1-15 所示。根据 KVL，对指定的回路有

【校对】*u*<sub>1</sub> + *u*<sub>2</sub> − *u*<sub>3</sub> + *u*<sub>4</sub> = 0

由上式也得

【校对】*u*<sub>3</sub> = *u*<sub>1</sub> + *u*<sub>2</sub> + *u*<sub>4</sub>

该式表明，④、③两节点之间的电压是单值的，不论沿支路 3 或沿支路 4、1、2 构成的路径，此两节点间的电压值是相等的。KVL 是电压与路径无关这一性质的反映①。

> 【原文脚注①】实质上，是能量守恒和转换定律的反映。

KCL 在支路电流之间施加线性约束关系；KVL 则对支路电压施加线性约束关系。这两个定律仅与元件的相互连接有关，而与元件的性质无关。不论元件是线性的还是非线性的，时变的还是时不变的，KCL 和 KVL 总是成立的。KCL 和 KVL 是集总电路的两个公设（公理）。

对一个电路应用 KCL 和 KVL 时，应对各节点和支路编号，并指定有关回路的绕行方向，同时指定各支路电流和支路电压的参考方向，一般两者取关联参考方向。

**例 1-2** 图 1-16 所示电路中，已知 *u*<sub>1</sub> = *u*<sub>3</sub> = 1 V，*u*<sub>2</sub> = 4 V，*u*<sub>4</sub> = *u*<sub>5</sub> = 2 V，求电压 *u*<sub>x</sub>。

**解** 对回路Ⅰ和Ⅱ分别列出 KVL 方程（支路的参考方向和回路的绕行方向如图 1-16 所示）：

【校对】−*u*<sub>1</sub> + *u*<sub>2</sub> + *u*<sub>6</sub> − *u*<sub>3</sub> = 0

【校对】−*u*<sub>6</sub> + *u*<sub>4</sub> + *u*<sub>5</sub> − *u*<sub>x</sub> = 0

*u*<sub>6</sub> 在方程中出现二次，一次前面为“+”号（与回路Ⅰ绕行方向相同）、一次前面为“−”号（与回路Ⅱ绕行方向相反）。将两个方程相加消去 *u*<sub>6</sub>，得

【校对】*u*<sub>x</sub> = −*u*<sub>1</sub> + *u*<sub>2</sub> − *u*<sub>3</sub> + *u*<sub>4</sub> + *u*<sub>5</sub> = 6 V

> 【摘录者按】例 1-2 的价值不在算 6 V，而在展示：**同一个 *u*<sub>6</sub>，在两个回路里符号相反**。这不是书在变魔术，而是两个回路绕行方向不同导致的必然结果。学生如果死记“电压降取正”，到这里就会卡住。

### 【原文】印刷 p.24–25 — 例 1-3（KCL + KVL + VCR 合用）

**例 1-3** 图 1-17 所示电路中，电阻 *R*<sub>1</sub> = 1 Ω，*R*<sub>2</sub> = 2 Ω，*R*<sub>3</sub> = 10 Ω，*U*<sub>S1</sub> = 3 V，*U*<sub>S2</sub> = 1 V。求电阻 *R*<sub>1</sub> 两端的电压 *U*<sub>1</sub>。

**解** 这是一个复杂电路。求解本题时，须同时应用 KCL、KVL 以及元件的 VCR。给出各支路电压与电流的参考方向如图所示。可依下列步骤进行：

（1）先将支路电流 *I*<sub>1</sub>、*I*<sub>2</sub> 与 *I*<sub>3</sub> 都以未知量 *U*<sub>1</sub> 来表示。有 *I*<sub>1</sub> = *U*<sub>1</sub>/*R*<sub>1</sub>；对Ⅰ、Ⅱ回路由 KVL 可得 *U*<sub>1</sub> = *U*<sub>S1</sub> − *R*<sub>3</sub>*I*<sub>3</sub> 与 *U*<sub>1</sub> = *R*<sub>2</sub>*I*<sub>2</sub> + *U*<sub>S2</sub>，从而得到

【校对】*I*<sub>3</sub> = (*U*<sub>S1</sub> − *U*<sub>1</sub>)/*R*<sub>3</sub> = (3 − *U*<sub>1</sub>)/10

与

【校对】*I*<sub>2</sub> = (*U*<sub>1</sub> − *U*<sub>S2</sub>)/*R*<sub>2</sub> = (*U*<sub>1</sub> − 1)/2

（2）在节点①使用 KCL，有 *I*<sub>3</sub> = *I*<sub>1</sub> + *I*<sub>2</sub>，即

【校对】(3 − *U*<sub>1</sub>)/10 = *U*<sub>1</sub>/1 + (*U*<sub>1</sub> − 1)/2

从而解得

【校对】*U*<sub>1</sub> = 0.5 V

> 【摘录者按】这道题是本课“两定律合用”的样板：KVL 把电压变成电流（通过 VCR），KCL 再把电流合起来。注意每一步都先写**参考方向**，再写方程；符号不是最后补的。

## 二、李瀚荪《电路分析基础》第5版（上）

### 【原文】印刷 p.4–5 — §1-1 集总假设（KCL/KVL 的适用条件）

当实际电路的尺寸远小于使用时其最高工作频率所对应的波长时，可以用几种“集总参数元件（lumped parameter element）”来构成实际部、器件的模型。……

由集总参数元件组成的电路，称为实际电路的集总电路模型或径称之为集总电路。……

采用集总电路模型意味着不考虑电路中电场与磁场的相互作用，不能考虑电磁波的传播现象，认为电能的传送是瞬间完成的。当电路的尺寸大于最高频率所对应的波长或两者属于同一数量级时，便不能作为集总电路处理，应作为分布（distributed）参数电路处理。例如，对无线电调频接收机来说，若所接收的信号频率为 100 MHz，则对应的波长 *λ* = *c*/*f* = 3 m（传播速度以光速计，即 *c* = 3×10<sup>8</sup> m/s），连接接收天线与接收机之间的传输线即便只有 1 m 长，也不能作为集总电路来处理。又如，我国电力用电的频率为 50 Hz，对应的波长为 6×10<sup>6</sup> m，对以此为工作频率的用电设备来说，其尺寸远小于这一波长，可以按集总电路处理，而对远距离输电线来说，就必须考虑到电场磁场沿线分布的现象，不能按集总电路来处理。

集总假设为本书的基本假设。以后所述的电路基本定律、定理等均是在这一假设的前提下才能成立的。

> 【摘录者按】这是本课必须讲清的“适用条件”：KCL/KVL 不是无条件成立的宇宙真理，它们成立的前提是**集总假设**。页面上要给出 100 MHz/1 m 这个反例，让学生知道边界在哪。

### 【原文】印刷 p.12 — §1-3 基尔霍夫定律（支路、节点、回路、网孔）

在集总电路中，任何时刻流经元件的电流以及元件的端电压都是明确的（well-defined）物理量。集总电路由各种元件通过理想导体连接而成，若将每一个二端元件视为一条支路（branch），这样，流经元件的电流和元件的端电压便分别称之为支路电流和支路电压，它们是集总电路中分析和研究的对象。集总电路的基本规律也将用支路电流和支路电压来表述。

为了表达电路的基本规律，先介绍几个名词。支路的一般含义已如上所述。支路的连接点称为节点（或结点）（node）。在图 1-8 所示电路中共有 5 条支路，3 个节点。显然，节点是两条或两条以上支路的连接点。初学者往往把图中的 a 点与 b 点看成是两个节点，这是不对的，因为 a 点与 b 点是用理想导体相连的，从电的角度来看，它们是相同的端点，可以合并成一点。电路图可以改画，只要保证各元件间的连接关系不变即可。为方便起见，在分析电路时，也可把支路看成是一个具有两个端钮而由多个元件串联而成的组合。例如，把图中的元件 4 和 5 作为一条支路，这样，连接点 3 就不算作节点。在用手算解决电路问题时，常如此处理。电路中的任一闭合路径称为回路（loop），例如，图中元件 1、2，元件 1、4、5，元件 1、3 均构成回路，该电路有 6 个回路。在回路内部不另含有支路的回路称为网孔（mesh），例如，图中元件 1、2，元件 2、3 均构成网孔，该电路有 3 个网孔。……

> 【摘录者按】“a 点与 b 点是一个节点”是零基础学生第一个会错的点。李瀚荪专门用“理想导体相连”解释，比只背“三条支路交点”有用。

### 【原文】印刷 p.12–13 — KCL 从电荷守恒推出来

电荷守恒和能量守恒是自然界的基本法则，把它们运用到集总电路就得到基尔霍夫的两个定律。

电荷守恒的意思是：电荷既不能创造也不能消灭。由此可得基尔霍夫电流定律（Kirchhoff's current law），该定律简写为 KCL。图 1-9 所示为集总电路中的一个节点，与该节点相接各支路的电流分别为 *i*<sub>1</sub>、*i*<sub>2</sub> 和 *i*<sub>3</sub>，参考方向如图中所示。流进该节点的电流的代数和为 *i*<sub>1</sub> + *i*<sub>2</sub> − *i*<sub>3</sub>，故知流进该节点电荷的速率可表示为

【校对】d*q*/d*t* = *i*<sub>1</sub> + *i*<sub>2</sub> − *i*<sub>3</sub>

式中 *q* 为节点处的电荷。但是，节点只是理想导体的汇合点，不可能积累电荷，电荷既不能创造，也不能消灭，因而，节点处 d*q*/d*t* 必须为零，即

【校对】*i*<sub>1</sub> + *i*<sub>2</sub> − *i*<sub>3</sub> = 0

这就是说：流进节点所有电流的代数和为零。流进节点的电流为正，流出节点的电流为负。如以 −1 乘上式两端可得

【校对】−*i*<sub>1</sub> − *i*<sub>2</sub> + *i*<sub>3</sub> = 0

亦即：流出节点所有电流的代数和为零。流出节点的电流为正，流进节点的电流为负。以上两种说法是等效的。

不论节点处有多少条支路，都可得到同样的结论。

综上所述，KCL 可表述为：

对于任一集总电路中的任一节点，在任一时刻，流出（或流进）该节点的所有支路电流的代数和为零。其数学表示式为

【校对】Σ<sub>*k*=1</sub><sup>*K*</sup> *i*<sub>*k*</sub>(*t*) = 0　　(1-6)

式中 *i*<sub>*k*</sub>(*t*) 为流出（或流进）该节点的第 *k* 条支路的电流，*K* 为该节点处的支路数。

在以上的讨论中，对各支路的元件并无要求，这就是说，不论电路中的元件如何，只要是集总电路，KCL 就总是成立的。

把 KCL 运用到节点时，根据各支路电流的参考方向，以流进为准或是以流出为准来列写支路电流的关系式，两种标准可任选一种。

KCL 表达了电路中支路电流间的约束（constraint）关系。以图 1-10 所示电路为例，在节点 1 处运用 KCL 可得

【校对】*i*<sub>1</sub> + *i*<sub>3</sub> − *i*<sub>2</sub> = 0

即

【校对】*i*<sub>3</sub> = *i*<sub>2</sub> − *i*<sub>1</sub>　　(1-7)

> 【摘录者按】这段是本课“为什么方程自己成立”的第一根支柱：KCL 不是规定，而是**电荷守恒 + 节点不积累电荷**的推论。符号规则只是把这个推论写成代数和的方式。

### 【原文】印刷 p.15 — 两套符号不要混淆

通过这个例题可看到，在运用 KCL 时常需和两套符号打交道。其一是方程中各项前的正、负符号，其正、负取决于电流参考方向对节点的相对关系，如以流出为正、流入为负，则如（1-8）式所示。另一是电流本身数值的正、负号，如（1-9）式中各括弧内所示，两者不要混淆。

如以流入为正、流出为负来列 KCL，仍可求得 *i*<sub>4</sub> = −6 A，结果完全一样。

> 【摘录者按】这句话可以直接当课堂语言。学生最常见的错，不是不会列方程，而是把“项前的符号”和“数值的正负”混成一团。

### 【原文】印刷 p.15–17 — KVL 从能量守恒推出来

基尔霍夫定律有两条，上面讲的是基尔霍夫电流定律，它表明了电路中各支路电流之间必须遵守的规律，这一规律体现在电路中的各个节点上。另外一条是基尔霍夫电压定律（Kirchhoff's voltage law），简写为 KVL，它表明电路中各支路电压之间必须遵守的规律，这一规律体现在电路的各个回路中。

在 §1-2 中已指出电路中各元件间有能量交换发生。电路必须遵守能量守恒法则。若在某段时间内电路中某些元件得到的能量有所增加，则其他一些元件的能量必须有所减少，保持能量的“收支”平衡。这一情况对电路中的支路电压间的关系有着重大的影响。……

【校对】*w*<sub>1</sub> + *w*<sub>2</sub> + *w*<sub>3</sub> + *w*<sub>4</sub> + *w*<sub>5</sub> + *w*<sub>6</sub> = 0　　(1-10)

对上式微分，可得

【校对】*p*<sub>1</sub> + *p*<sub>2</sub> + *p*<sub>3</sub> + *p*<sub>4</sub> + *p*<sub>5</sub> + *p*<sub>6</sub> = 0　　(1-11)

式中 *p*<sub>1</sub> = d*w*<sub>1</sub>/d*t*，…。上式表明在每一瞬间电路中所有元件获得功率的总和为零。

如以电压、电流来表示各元件的功率，则得……

【校对】−*u*<sub>1</sub>*i*<sub>1</sub> + *u*<sub>4</sub>*i*<sub>1</sub> + *u*<sub>6</sub>*i*<sub>1</sub> + *u*<sub>2</sub>*i*<sub>2</sub> + *u*<sub>3</sub>*i*<sub>3</sub> + *u*<sub>5</sub>*i*<sub>3</sub> = 0　　(1-12)

但由 KCL 可得

【校对】*i*<sub>2</sub> = *i*<sub>1</sub> + *i*<sub>3</sub>　　(1-13)

以（1-13）式代入（1-12）式可得

【校对】(−*u*<sub>1</sub> + *u*<sub>4</sub> + *u*<sub>6</sub> + *u*<sub>2</sub>)*i*<sub>1</sub> + (*u*<sub>2</sub> + *u*<sub>3</sub> + *u*<sub>5</sub>)*i*<sub>3</sub> = 0　　(1-14)

*i*<sub>1</sub> 和 *i*<sub>3</sub> 不满足 KCL，它们是线性无关的，因而若（1-14）式成立，则式中 *i*<sub>1</sub>、*i*<sub>3</sub> 前的系数必为零，即

【校对】−*u*<sub>1</sub> + *u*<sub>4</sub> + *u*<sub>6</sub> + *u*<sub>2</sub> = 0　　(1-15a)

【校对】*u*<sub>2</sub> + *u*<sub>3</sub> + *u*<sub>5</sub> = 0　　(1-15b)

如以（1-15b）式代入（1-15a）式，可得

【校对】−*u*<sub>1</sub> + *u*<sub>4</sub> + *u*<sub>6</sub> − *u*<sub>5</sub> − *u*<sub>3</sub> = 0　　(1-15c)

从电路图可见：元件 1、4、6、2 形成一个回路；元件 2、3、5 形成一个回路；元件 1、4、6、5、3 也形成一个回路。因此，上列三个式子分别表明了沿这三个回路各支路电压降的代数和为零……

对于任何一个集总电路都可仿照以上步骤得出同样结论。因此，KVL 可表述为：

对于任一集总电路中的任一回路，在任一时刻，沿着该回路的所有支路电压降的代数和为零。其数学表达式为

【校对】Σ<sub>*k*=1</sub><sup>*K*</sup> *u*<sub>*k*</sub>(*t*) = 0　　(1-16)

式中 *u*<sub>*k*</sub>(*t*) 为该回路中的第 *k* 条支路电压，*K* 为该回路中的支路数。

在以上的讨论中，对各支路的元件并无要求，这就是说，不论电路中的元件如何，只要是集总电路，KVL 总是成立的。

KVL 为回路中的支路电压施加了一个约束关系，这是一个线性关系（线性相关）。……

KCL 是电荷守恒法则运用于集总电路的结果；KVL 是能量守恒法则和电荷守恒法则运用于集总电路的结果。前者反映电路中各支路电流间的约束关系；后者反映电路中各支路电压间的约束关系。

> 【摘录者按】李瀚荪的 KVL 推导比邱关源细得多，但 45 分钟里不必完整重演 (1-10)~(1-15c)。页面可以只保留“能量收支平衡 → 沿回路电压降代数和为零”的因果链，把完整推导放页尾折叠区。**不要**把这段推导压成一句“KVL 就是能量守恒”，学生要看到中间那一步。

### 【原文】印刷 p.45–46 — §1-9 两类约束：拓扑约束 vs 元件约束

前面几节讨论了 KCL、KVL 以及电阻元件、电源元件、受控源元件的 VCR，并运用它们计算了一些较简单的电阻电路。以后还将讨论其他一些元件的 VCR。必须指出：

KCL、KVL 和元件的 VCR 是对电路中各电压变量、电流变量施加的全部约束。不论是当前讨论的电阻电路还是以后讨论的动态电路都是如此，是处理集总电路问题的基本依据。这便是本书基本结构中所称的两类约束（constraints）。

当元件相互连接组成具有一定几何结构形式的电路后，电路中出现了节点和回路，其各部分的电压、电流将为两类约束所支配。其一，来自元件的相互连接方式。与一个节点相连接的各支路，其电流必须受到 KCL 的约束；与一个回路相联系的各支路，其电压必须受到 KVL 的约束。例如，一个节点处只有两条支路相汇集，那么，由于这一连接方式，一条支路的电流将被迫与另一条支路的电流相等，别无选择。又如，一个回路只由两条支路组成，那么，由于这一连接方式，一条支路的电压将被迫与另一条支路的电压相等，别无选择。这种只取决于互连形式的约束，称为拓扑约束（topological constraints）。另一类约束，来自元件的性质。每种元件的电压、电流形成一个约束，例如，一个线性时不变电阻将迫使其两端的电压 *u* 和流过的电流 *i* 服从 *u* = *Ri* 的约束关系，别无选择。这种只取决于元件性质的约束，称为元件约束。

【校对】对一个具有 *b* 条支路的电路，可以列出联系 *b* 个支路电流变量和 *b* 个支路电压变量所需的 2*b* 个独立方程式。

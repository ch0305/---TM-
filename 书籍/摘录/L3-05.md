## 零、为什么讲这两件事（邱 第12章导读 p.281 / PDF 305；第13章导读 p.295 / PDF 319）

### 【原文】三相制的地位

> 【原文 OCR】目前，世界各国的电力系统中电能的生产、传输和供电方式绝大多数都采用三相制。它是世界上规模最大的生产系统，系统的结构为适应工业化生产的需要，已经标准化或规范化，它主要是由三相电源、三相负载和三相输电线路三部分组成。三相交流发电机、变压器和三相制的发明是人类社会进入电气化时代的里程碑，至今已有 100 多年的发展史，是当今社会发展的物质基础之一。〔邱 第12章导读 / p.281 / PDF 305〕

### 【原文】非正弦的来源与谐波分析法的思路

> 【原文 OCR】在生产实践和科学实验中，通常会遇到按非正弦规律变化的电源和信号。另外，如果电路存在非线性元件，即使在正弦电源的作用下，电路中也将产生非正弦周期的电压和电流。……首先应用数学中的傅里叶级数展开方法，将非正弦周期电压、电流或信号分解为一系列频率为周期函数频率的正整数倍的正弦量之和表示的无穷级数，再根据线性电路的叠加定理，分别计算每一频率的正弦量单独作用下在电路中产生的同频正弦电流分量和电压分量；把所得分量按时域形式叠加，就可以得到电路在非正弦周期激励下的稳态电流和电压。这种方法称为**谐波分析法**。〔邱 第13章导读 / p.295 / PDF 319〕
> 【摘录者按】这两段就是本课的两个"为什么"：**三相**是输电与电机的现实标准；**非正弦**是整流/信号/非线性的现实结果。两者都不需要新定律——仍用相量法 + 叠加定理，只是要按"相"或按"频率"分开算再合起来。〔通识〕

## 一、对称三相电源：三相差 120°，瞬时和恒为零（邱 §12-1 p.281–282 / PDF 305–306；李下 §9-8 / PDF 103）

### 【原文】对称三相电压

> 【原文 OCR】对称三相电压源是由三相发电机提供的（我国三相系统电源频率 50 Hz，入户电压 220 V；而日美、欧洲等国为 60 Hz、110 V）。三个电压源依次相差 120°，相量可写为 `U̇_A = U_p∠0°`、`U̇_B = U_p∠−120°`、`U̇_C = U_p∠120°`（U_p 为相电压有效值）。〔邱 §12-1 / p.282 / PDF 306；李下 §9-8 式 9-37 / PDF 103〕
> 【校对 OCR】对称三相电压有一重要特点：任一瞬间三者之和恒为零，即 `u_A(t)+u_B(t)+u_C(t)=0`，相量形式为 `U̇_A+U̇_B+U̇_C=0`。这是恒等式 `cos θ + cos(θ−120°) + cos(θ+120°) = 0` 的反映。三个电压到达最大值的先后次序称为**相序**（phase sequence）；图示发电机逆时针旋转时相序为 a—b—c（正相序），顺时针则为 a—c—b。〔李下 §9-8 式 9-38、9-39 / PDF 103〕
> 【原文 OCR】把三个绕组的末端连在一公共点 n，就构成对称 **Y 形联结**的三相发电机，公共点 n 称为**中性点**，a、b、c 三端接出的三根输电线称为**相线（火线）**。每个电源的电压称为**相电压**，相线之间的电压称为**线电压**。把三个绕组始末端顺次相接、从连接点引出相线，则构成 **△形联结**：没有中性点，**线电压即相电压**。必须注意，△ 形中任何一相绕组接反，三个相电压之和将不为零，闭合回路中会产生极大的短路电流。〔李下 §9-8 / PDF 103–104〕
> 【摘录者按】相序与"和为零"是后面所有简化（一相计算法、中性线可省、瞬时功率恒定）的总根源。教案把"三相差 120° → 相加为零"作为第一条可推导结论，而不是让学生背。〔通识〕

## 二、线值与相值：Y 形 √3 倍、△ 形相等（邱 §12-2 p.283–284 / PDF 307–308；李下 §9-8 / PDF 104、109）

### 【原文】Y 形的线电压与相电压

> 【原文 OCR】对于对称星形电源，设线电压为 `U̇_AB、U̇_BC、U̇_CA`，相电压为 `U̇_A、U̇_B、U̇_C`，根据 KVL 有
> `U̇_AB = U̇_A − U̇_B = (1−a²)U̇_A = √3 U̇_A∠30°`
> `U̇_BC = U̇_B − U̇_C = (1−a²)U̇_B = √3 U̇_B∠30°`
> `U̇_CA = U̇_C − U̇_A = (1−a²)U̇_C = √3 U̇_C∠30°`〔邱 §12-2 式 12-1 / p.283 / PDF 307〕
> 【校对 OCR】结论：相电压对称时线电压也依序对称，**线电压是相电压的 √3 倍，并依次超前对应相电压 30°**。李下给出的规律是"线电压超前于其下标第一字母所对应的相电压 30°"（`U̇_AB` 超前 `U̇_A` 30°）。若相电压有效值 220 V，则线电压 `√3×220 = 380 V`。〔李下 §9-8 式 9-40 / PDF 104〕
> 【原文 OCR】对于三角形电源，有 `U̇_AB=U̇_A`、`U̇_BC=U̇_B`、`U̇_CA=U̇_C`，所以**线电压等于相电压**；相电压对称时线电压也一定对称。以上有关线电压和相电压的关系也适用于对称星形负载端和三角形负载端。〔邱 §12-2 / p.284 / PDF 308〕

### 【原文】线电流与相电流

> 【原文 OCR】对于星形联结，线电流显然等于相电流。对三角形联结，以对称 △ 形负载为例，设相电流 `İ_AB、İ_BC、İ_CA`，线电流 `İ_A、İ_B、İ_C`，由 KCL：
> `İ_A = İ_AB − İ_CA = (1−a)İ_AB = √3 İ_AB∠−30°`
> `İ_B = √3 İ_BC∠−30°`，`İ_C = √3 İ_CA∠−30°`〔邱 §12-2 式 12-2 / p.284 / PDF 308〕
> 【校对 OCR】即 △ 形中**线电流是相电流的 √3 倍，依次滞后对应相电流 30°**。李下例 9-16 核对：380 V 线电压下 `U̇_AB=381∠60° V`，`İ_AB=30.43∠22.98° A`，则 `İ_A=√3×30.43∠(22.98°−30°)=52.70∠−7.02° A`。〔李下 §9-8 / PDF 110〕
> 【原文 OCR】最后还必须指出，所有关于电压电流的对称性以及上述对称相值和对称线值之间关系的论述，**只能在指定的顺序和参考方向的条件下**，才能以简单有序的形式表达出来，而不能任意设定。〔邱 §12-2 / p.284 / PDF 308〕
> 【摘录者按】这一句是重要的适用条件：√3 与 ±30° 只在"对称 + 固定相序 + 固定参考方向"下成立；教案把它显式列为边界，防止学生把这个关系当成无条件真理。〔通识〕

## 三、对称三相电路的计算：归结为一相（邱 §12-3 p.285–286 / PDF 309–310；李下 §9-8 / PDF 105–107）

### 【原文】一相计算法

> 【原文 OCR】对称三相电路是一类特殊类型的正弦电流电路，分析正弦电流电路的相量法对它完全适用。以对称三相四线制电路为例，用节点法先求中性点之间的电压：`U̇_N'N = (U̇_A/Z + U̇_B/Z + U̇_C/Z)/(3/Z + 1/Z_N) = 0`（因 `U̇_A+U̇_B+U̇_C=0`）。各相（线）电流独立，`U̇_N'N=0` 是各相电流独立的必要和充分条件。所以对称的 Y-Y 电路可**分列为三个独立的单相电路**；又因三相电源、负载对称，只需分析计算任一相，其他两相按对称顺序写出。这就是对称 Y-Y 三相电路**归结为一相的计算**。〔邱 §12-3 / p.285 / PDF 309〕
> 【校对 OCR】一相计算电路中连接 N、N′ 的是等效线，与中性线阻抗 `Z_N` 无关；中线电流 `İ_N=İ_A+İ_B+İ_C=0`，故对称 Y-Y 电路理论上不需要中性线，可以移去。其他连接方式可先经 Y-△ 等效化成对称 Y-Y，再用一相计算法。〔邱 §12-3 / p.285 / PDF 309；李下 §9-8 式 9-43~9-45 / PDF 106〕

### 【原文】例12-1（邱 §12-3 / p.286 / PDF 310）

> 【原文 OCR】对称三相电路如 Y-Y 四线制，已知线路阻抗 `Z_l=(1+j2) Ω`、负载 `Z=(5+j6) Ω`、线电压 `u_AB=380√2 cos(ωt+30°) V`。求负载各电流相量。
> 【校对 OCR】由线相关系得相电压 `U̇_A = 380/√3 ∠(30°−30°) = 220∠0° V`。一相计算：`İ_A = U̇_A/(Z_l+Z) = 220∠0°/(1+j2+5+j6) = 220/(6+j8) = 22∠−53.1° A`。由对称性 `İ_B=a²İ_A=22∠−173.1° A`，`İ_C=aİ_A=22∠66.9° A`。
> 【摘录者按】数值独立复核：`|6+j8|=10`，`220/10=22`；`−arctan(8/6)=−53.13°`；再分别 ±120° 得 −173.1°、66.9°，与书上一致。〔通识〕

### 【原文】例12-2（△ 负载化 Y，邱 §12-3 / p.286 / PDF 310）

> 【原文 OCR】对称三相电路如 Y-△，已知 △ 负载每相 `Z=(19.2+j14.4) Ω`、线路阻抗 `Z_l=(3+j4) Ω`，线电压 380 V。求负载端线电压和线电流。
> 【校对 OCR】△→Y：`Z′=Z/3=(6.4+j4.8) Ω`，`U̇_A=220∠0° V`。一相计算：`İ_A=220/(3+j4+6.4+j4.8)=220/(9.4+j8.8)=17.1∠−43.1° A`，`İ_B=17.1∠−163.1° A`（OCR −163.2°，按 ±120° 应为 −163.1°，属印刷/OCR 舍入差），`İ_C=17.1∠16.9° A`。负载端相电压 `U̇_A′=İ_A Z′=136.8∠−6.3° V`，线电压 `U̇_AB′=√3×136.8∠(−6.3°+30°)=236.9∠23.7° V`。负载相电流 `İ_AB=İ_A/√3 ∠(∠İ_A+30°)=9.9∠−13.1° A`。〔邱 §12-3 例12-2 / p.286 / PDF 310〕

## 四、不对称与中性点位移：中性线为什么重要（邱 §12-4 p.287–288 / PDF 311–312；李下 §9-9 / PDF 112–115）

### 【原文】中性点位移

> 【原文 OCR】在三相电路中，只要有一部分不对称就称为不对称三相电路，例如某一条端线断开，或某一相负载短路、开路，就失去对称性。一般情况下**不能引用一相计算方法**。以 Y-Y 联结、电源对称而负载不对称为例，开关 S 打开（不接中性线）时，用节点电压法求得 `U̇_N'N = (U̇_A Y_A + U̇_B Y_B + U̇_C Y_C)/(Y_A+Y_B+Y_C)`。由于负载不对称，此值不为零，N′ 点和 N 点不重合，这一现象称为**中性点位移**。当中性点位移较大时，会造成负载端电压严重不对称，可能使负载工作不正常；且各相工作相互关联、彼此影响。〔邱 §12-4 / p.287 / PDF 311〕
> 【原文 OCR】合上开关 S（接上中性线），如果 `Z_N≈0`，则可强使 `U̇_N'N=0`。尽管电路不对称，各相仍保持独立性、互不影响，可分别独立计算，确保各相负载在相电压下安全工作。**在负载不对称的情况下中性线的存在非常重要，它能起到保证安全供电的作用。** 由于线（相）电流不对称，中性线电流一般不为零。〔邱 §12-4 / p.287 / PDF 311–312〕
> 【校对 OCR】李下 §9-9 例 9-18 核对（负相序、线电压 440 V → 相电压 254 V，不对称 Y 形负载 `Z_a=10∠30° Ω`、`Z_b=20∠60° Ω`、`Z_c=15∠−45° Ω`）：接中线时 `İ_a=25.4/10∠−30°=2.54∠−30° A`（按相序调整后得 `12.7∠60° A` 等），中线电流 `İ_N=İ_a+İ_b+İ_c=37.38∠−28.88° A ≠ 0`；取消中线后各相互相耦合，须用节点法/网孔法解联立方程，书中算得 `U̇_N'N` 使某相电压低至 60 V、另两相过高。〔李下 §9-9 例9-18 / PDF 112–114〕
> 【摘录者按】李下例 9-18 的相序/初相 OCR 错乱较多，教案只取定性结论 + 中线电流非零、某相电压 60 V 这些可复核数值，不引用其有争议的相角细节。〔通识〕

## 五、三相功率：对称时瞬时功率恒定、二瓦计法（邱 §12-5 p.288–290 / PDF 312–314；李下 §9-8 / PDF 106、110–111）

### 【原文】三相功率与瞬时功率平衡

> 【原文 OCR】三相负载吸收的复功率等于各相复功率之和：`S̃=S̃_A+S̃_B+S̃_C`；对称时 `S̃=3S̃_A`。对称三相电路的瞬时功率为各相瞬时功率之和，展开后 `p=p_A+p_B+p_C=3U_A I_A cos φ = 3P_A`。**这表明对称三相电路的瞬时功率是一个常量，其值等于平均功率**，这一性能习惯上称为**瞬时功率平衡**。〔邱 §12-5 / p.288–289 / PDF 312–313〕
> 【校对 OCR】李下给出常用式：对称三相平均功率 `P=3U_p I_p cos φ = √3 U_l I_l cos φ`，无功 `Q=√3 U_l I_l sin φ`。**必须再次指出：公式中的 φ 是负载的阻抗角（相电压与相电流的相位差），不是线电压与线电流的相位差！**〔李下 §9-8 式 9-47、9-51、9-52 / PDF 106、110〕

### 【原文】二瓦计法

> 【原文 OCR】在三相三线制电路中，不论对称与否，都可以使用两个功率表的方法测量三相功率（称为**二瓦计法**）。使线电流从 * 端分别流入两个功率表的电流线圈，电压线圈的非 * 端共同接到第 3 条端线。可以证明两表读数代数和为三相电路吸收的平均功率：`P₁=Re[U̇_AB İ_A*]`、`P₂=Re[U̇_CB İ_C*]`，`P₁+P₂=Re[S̃]=P`。对称三相制中 `P₁=U_l I_l cos(φ−30°)`、`P₂=U_l I_l cos(φ+30°)`。**在一定条件下（如 |φ|>60°），其中一个读数可能为负，求代数和时应取负值；单独一个功率表的读数没有意义。** 不对称的三相四线制不能用二瓦计法，因为一般 `İ_A+İ_B+İ_C≠0`。〔邱 §12-5 / p.289 / PDF 313〕
> 【原文 OCR】例12-4：对称三相负载吸收功率 2.5 kW，功率因数 λ=cos φ=0.866（感性），线电压 380 V，求两功率表读数。
> 【校对 OCR】`I_l = P/(√3 U_l cos φ) = 2500/(√3×380×0.866) ≈ 4.386 A`；`φ=arccos 0.866=30°`。`P₁=380×4.386×cos(30°−30°)=1666.68 W`，`P₂=380×4.386×cos(30°+30°)=833.34 W`，和为 2500 W。〔邱 §12-5 例12-4 / p.290 / PDF 314〕
> 【摘录者按】例12-4 是很好的"工程 × 理论"接口：两表读数一个 2/3、一个 1/3，和才是总有功。教案把 `φ` 是阻抗角这一句作为陈述时刻的适用条件。〔通识〕

## 六、非正弦周期量：傅里叶级数与频谱（邱 §13-2 p.296–302 / PDF 320–326）

### 【原文】傅里叶级数

> 【原文 OCR】满足狄里赫利条件的周期函数 `f(t)=f(t+kT)` 可展开为
> `f(t) = A₀ + Σ[k=1→∞] A_k cos(kω₁t+φ_k)`
> 其中第一项 `A₀` 为**恒定分量（直流分量）**，k=1 项 `A₁cos(ω₁t+φ₁)` 为**基波**（周期、频率与原函数相同），k>1 各项统称**高次谐波**（2 次、3 次……）。这种分解称为**谐波分析**。系数也可写成 `a_k=A_k cos φ_k`、`b_k=−A_k sin φ_k`、`A_k=√(a_k²+b_k²)`。〔邱 §13-2 式 13-1、13-2 / p.296–297 / PDF 320–321〕
> 【校对 OCR】系数由积分给出：`a_k=(2/T)∫₀ᵀ f(t)cos(kω₁t)dt`、`b_k=(2/T)∫₀ᵀ f(t)sin(kω₁t)dt`。以线段高度表示各次谐波振幅画出的 `A_k–kω₁` 图称为**幅度频谱**；各次谐波频率都是 ω₁ 的正整数倍，故频谱是**离散的线频谱**。〔邱 §13-2 式 13-3 / p.297 / PDF 321〕
> 【原文 OCR】例13-1：周期性矩形信号（幅值 ±E_m、占空比 1/2）的傅里叶级数为 `f(t)=(4E_m/π)[sin(ω₁t) + (1/3)sin(3ω₁t) + (1/5)sin(5ω₁t) + …]`，只含奇次谐波。取到 5 次、11 次的合成曲线逐步逼近方波；矩形波收敛较慢，取到 11 次谐波时合成值约为准确值的 0.95 倍，取到 35 次仍有约 2% 误差。〔邱 §13-2 例13-1 / p.298–299、§13-3 p.303 / PDF 322–323、327〕
> 【摘录者按】这条"收敛快慢取决于波形光滑程度"是工程取舍的直觉来源：方波/脉冲需要很多谐波，光滑波形几项就够；教案据此设"截取项数的边界" prediction 与练习。〔通识〕

## 七、非正弦的有效值与平均功率：只有同频分量产生平均功率（邱 §13-3 p.303–304 / PDF 327–328；李下 §10-5 / PDF 141–145）

### 【原文】有效值

> 【原文 OCR】非正弦周期电流有效值定义为 `I=√[(1/T)∫₀ᵀ i²(t)dt]`。把 `i(t)=I₀+Σ√2 I_k cos(kω₁t+φ_k)` 代入并利用正交性（不同频率乘积积分为零）可得
> `I = √(I₀² + I₁² + I₂² + …)`。
> 即**非正弦周期电流的有效值等于恒定分量的平方与各次谐波有效值平方之和的平方根**。此结论可推广到其他非正弦周期量：`U=√(U₀²+U₁²+…)`。〔邱 §13-3 / p.303–304 / PDF 327–328；李下 §10-5 式 10-29、10-30 / PDF 143〕
> 【校对 OCR】平均值（均值绝对值）`I_av=(1/T)∫₀ᵀ |i|dt`，正弦波 `I_av=(2/π)I_m=0.637I_m=0.898I`。磁电系（直流）仪表读恒定分量、电磁系仪表读有效值、全波整流仪表读平均值——测量非正弦量要注意仪表类型。〔邱 §13-3 / p.304 / PDF 328〕

### 【原文】平均功率

> 【原文 OCR】任意一端口的瞬时功率 `p=ui`，平均功率 `P=(1/T)∫₀ᵀ p dt`。**不同频率的正弦电压与电流乘积的积分为零（不产生平均功率）；同频的正弦电压、电流乘积积分不为零**。因此
> `P = U₀I₀ + U₁I₁cos φ₁ + U₂I₂cos φ₂ + …`
> 即平均功率等于恒定分量构成的功率和各次谐波平均功率的代数和。〔邱 §13-3 / p.305 / PDF 329；李下 §10-5 式 10-31 / PDF 145〕
> 【原文 OCR】李下例10-9：单口端口 `u(t)=[100+100cos t+50cos(2t)+30cos(3t)] V`，`i(t)=[10cos(t−60°)+2cos(3t−135°)] A`，求平均功率。
> 【校对 OCR】按频率配对（功率公式用有效值）：直流与 2 次电压无对应电流 → 不贡献；基波 `U₁=100/√2`、`I₁=10/√2`、`φ₁=0−(−60°)=60°` → `P₁=(100/√2)(10/√2)cos60°=500×0.5=250 W`；3 次 `U₃=30/√2`、`I₃=2/√2`、`φ₃=0−(−135°)=135°` → `P₃=(30/√2)(2/√2)cos135°=30×(−0.707)=−21.2 W`。总 `P=250−21.2=228.8 W`。〔李下 §10-5 例10-9 / PDF 144–145〕
> 【摘录者按】独立复核：基波 `(100×10)/2×cos60°=500×0.5=250 W`；3 次 `(30×2)/2×cos135°=30×(−0.7071)=−21.21 W`；合计 228.8 W，与书上一致。OCR 中一处误读的"50 W"已按有效值口径与总和校为 250 W。〔通识〕
> 【摘录者按】这是本课形态二的核心例子：功率要"按频率配对"，**不同频率互补相干**；负号代表 3 次谐波在送功率（端口在该分量上是发出而非吸收）。教案把"只有同频配对才产生平均功率"设为陈述时刻，并把这个例子做成实验台。〔通识〕

## 八、非正弦电路的计算：谐波分析法（邱 §13-4 p.305–306 / PDF 329–330；李下 §10-4 / PDF 134–140）

### 【原文】逐次谐波分别算，再在时域相加

> 【原文 OCR】谐波分析法的计算原则：把非正弦周期激励分解为傅里叶级数后，对每个频率分量分别建立相量模型、用相量法求出同频响应分量，再在时域把各分量相加。**不能把不同频率的分量合并成一个相量**——相量法只适用于单一频率。李下思考题 10-4 正是对此的反例：有人把 `i₁(t)` 中 ω、3ω、5ω 分量直接写成相量相加，这是错误的。〔李下 §10-4 / PDF 134、140〕
> 【原文 OCR】例13-2：电路 `R=3 Ω`、`ωL=0.429 Ω`、`1/(ωC)=21 Ω`，输入矩形波电压 `u_s=[280.11cos(ω₁t)+93.37cos(3ω₁t)+56.02cos(5ω₁t)+40.03cos(7ω₁t)+31.12cos(9ω₁t)+…] V`，求电流与各谐波功率。
> 【校对 OCR】`Z(kω₁)=3+j(0.429k−21/k)`。k=7 时 `0.429×7−21/7≈0`，串联谐振、Q≈1。逐次解得：`İ₁=13.47∠81.70° A`（容性）、`P₁≈272.33 W`；`İ₃=14.47∠62.30° A`、`P₃≈314.06 W`；`İ₅=15.41∠34.41° A`、`P₅≈356.00 W`；`İ₇=13.34∠0° A`、`P₇≈267.07 W`；`İ₉=9.24∠−26.99° A`、`P₉≈128.17 W`。总 `P≈1337.63 W`。电流振幅并未按 1/k 衰减（电路对 7 次谐振，呈带通），说明"取几项够"必须结合**网络频率特性**判断，不能只看激励谐波的衰减。〔邱 §13-4 例13-2 / p.305–306 / PDF 329–330〕
> 【原文 OCR】李下例10-6：方波电压经 RL 电路，直流分量单独作用（ω=0，电感短路、电容开路）得输出直流；基波与各次谐波分别经网络函数 `H(jω)=jωL/(R+jωL)` 求得输出谐波：`u₀(t)=[121.28cos(ω₁t+17.66°) −42.10cos(3ω₁t+6.05°)+25.35cos(5ω₁t+3.66°)−…] V`。〔李下 §10-4 / PDF 138–140〕
> 【摘录者按】例10-6 同时说明"直流分量也要单独算"：ω=0 时 L 短路、C 开路，不能用普通相量阻抗（jω=0）。教案把这一条列为谐波分析法的适用边界。〔通识〕

## 九、本摘录可供教案直接引用的"可推导结论"清单

1. 对称三相电压相量和为零（邱 §12-1；李下 §9-8 式 9-38/9-39）——一切的起点。
2. Y 形 `U_l=√3 U_p` 且线电压超前对应相电压 30°；△ 形 `U_l=U_p`；Y 形 `I_l=I_p`，△ 形 `I_l=√3 I_p` 且滞后 30°（邱 §12-2；李下 §9-8）——**只在对称+定相序+定参考方向下成立**。
3. 对称 Y-Y 归结为一相，`U̇_N'N=0`、中线电流为零、中线可省（邱 §12-3）。
4. 不对称时中性点位移，中性线保证各相独立与安全（邱 §12-4；李下 §9-9）。
5. 对称三相瞬时功率恒定 = 平均功率；`P=√3 U_l I_l cos φ`（φ 是阻抗角）；二瓦计法 `P₁+P₂=P`（邱 §12-5；李下 §9-8/§10-5）。
6. 非正弦周期量可分解直流 + 基波 + 各次谐波（傅里叶级数），频谱离散（邱 §13-2）。
7. 有效值平方等于直流与各次谐波有效值平方和（邱 §13-3；李下 §10-5）。
8. 平均功率只有同频配对才贡献：`P=U₀I₀+ΣU_k I_k cos φ_k`（邱 §13-3；李下 §10-5 例10-9）。
9. 谐波分析法：逐频相量求解 + 时域叠加；不同频率不可合并相量；直流分量按 ω=0 单独处理（邱 §13-4；李下 §10-4）。

> **留白**：邱 §13-5~§13-7（对称三相高次谐波、指数形式、傅里叶积分）与复杂傅里叶系数手算，本课不摘、不引章节号，标为 P3「了解即可」。

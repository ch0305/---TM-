## 一、邱 §9-4 正弦稳态电路的功率（印刷 p.222–225 / PDF 246–249）

### 【原文】瞬时功率的分解（印刷 p.222–224）

> 【原文 OCR】设图 9-12(a) 所示一端口 N 吸收的瞬时功率等于端口电压 u 和电流 i 的乘积。当一端口 N 处于正弦稳态时，端口的电压电流是同频正弦量，瞬时功率是两个同频正弦量的乘积……整个 RLC 串联电路吸收的瞬时功率为上述三项之和，即
> p = p_R + p_L + p_C = RI²[1+cos(2ωt)] − (ωL − 1/ωC)I² sin(2ωt)
> 根据一端口的阻抗三角形可做如下变换：有 R=|Z|cosφ_z，(ωL−1/ωC)=|Z|sinφ_z，V=|Z|I，代入后有
> p = UI cosφ_z [1+cos(2ωt)] − UI sinφ_z sin(2ωt)
>
> 【校对】瞬时功率 `p(t)` 的频率是电压/电流的 **2 倍**，且不是纯正弦量：第一项 `UIcosφ[1+cos2ωt]` 始终 ≥ 0，是不可逆部分（真正被电阻消耗）；第二项 `−UIsinφ·sin2ωt` 是可逆部分（储能元件与外电路往返交换）。φ_z 为一端口阻抗角，也即电压超前电流的相位差。
> 【摘录者按】这条分解是本课全部概念的源头：`P` 取第一项的恒定分量，`Q` 取第二项的振幅，`S` 是两者合成容量。学生先看见"功率里有一半在往返"，才有动机区分三种功率。

### 【原文】三个功率与功率因数的定义（印刷 p.224–225）

> 【原文 OCR】1. 有功功率 P（即平均功率）定义为 P=(1/T)∫₀ᵀ p dt = UI cosφ_z。它是瞬时功率不可逆部分的恒定分量，也是其变动部分的振幅，它是衡量一端口实际所吸收的功率，其单位用 W（瓦）表示。
> 2. 无功功率 Q 定义为 Q = UI sinφ_z。它是瞬时功率可逆部分的振幅，是衡量由储能元件引起的与外部电路交换的功率，这里"无功"的意思是指这部分能量在往复交换的过程中，没有"消耗"掉。其单位用 var（乏）表示。
> 3. 视在功率 S 定义为 S = UI。它是满足一端口电路有功功率和无功功率两者的需要时，要求外部提供的功率容量。显然有 S≥P 和 S≥Q，P、Q 及 S 三者的关系为
> P = S cosφ_z，Q = S sinφ_z，S = √(P²+Q²)
> 这是一个直角三角形关系（S 是斜边）。工程上常用视在功率衡量电气设备在额定的电压、电流条件下最大的负荷能力，或承载能力。视在功率的单位常用 V·A（伏安）表示。
> 上面所用单位 W、var 和 V·A，其量纲相同，目的是区分三种不同的功率。
> 工程中通常用到功率因数 λ 的概念，其定义为 λ = cosφ_z = P/S。φ_z 称为功率因数角（不含独立源的一端口的阻抗角）。它是衡量传输电能效果的一个非常重要的指标，表示传输系统有功功率所占的比例，即 P/S。
>
> 【校对】三种功率用**同一个量纲、不同单位**加以区分：P→W、Q→var、S→V·A。功率三角形直角边为 P、Q，斜边为 S，夹角为 φ_z；`λ=cosφ=P/S` 恒为非负，因此工程上必须补注"感性（滞后）/容性（超前）"才能确定电路性质。理想状态 λ=1、Q=0。
> 【摘录者按】邱本此处 φ 一律指 `φ_z = φ_u − φ_i`（电压超前电流）。容性时 φ_z<0、Q<0，`cosφ_z` 仍 >0。

### 【原文】单个 R/L/C 元件的功率（印刷 p.225）

> 【原文 OCR】对于不含独立源的一端口，可以用等效阻抗 Z=R+jX=|Z|∠φ_z 替代，端电压 U 被分解为两个分量 U_R 和 U_X，其中 U_R 产生有功功率 P，U_X 产生无功功率 Q，即为
> P = UI cosφ_z = U U_R = RI²，Q = UI sinφ_z = U U_X = XI²
> 对于电阻 R，由于 φ_z=0、λ=1：P_R = UI = I²R = U²/R，Q_R = 0。
> 对于电感 L，由于 φ_z=90°、λ=0：P_L = 0，Q_L = S sinφ_z = ωLI² = U²/(ωL)。
> 对于电容 C，由于 φ_z=−90°、λ=0：P_C = 0，Q_C = S sinφ_z = −S = −U²/X_C = −I²/(ωC) = −ωCI²。
> 在电路系统中，电感和电容的无功功率有互补作用，工程上认为电感吸收无功功率，而认为电容发出无功功率，将两者加以区别。
>
> 【校对】记忆抓手：**电阻只吃 P，电感吃正 Q，电容"吐"负 Q**；电感与电容的 Q 符号相反，因此可以互相补偿——这是后面"并联电容提高功率因数"的物理根据。
> 【校对补正】电容无功的三种等价写法是 `Q_C=−S=−U²/X_C=−I²/(ωC)=−ωCU²`（因 `X_C=1/(ωC)`、`U=I X_C`，故 `−I²/(ωC)=−ωCU²=−I·U`）。OCR 末项识作 `−ωCI²` 系误识（应为 `−ωCU²`），量纲与数值均不对；教案与页面统一采用 `Q_C=−ωCU²`，与李下 §9-3 式 9-17 一致。

### 【原文】功率守恒（印刷 p.226）

> 【原文 OCR】整个电路遵守功率守恒原理，有 ΣP=0，ΣQ=0；一般情况下不存在 ΣS=0。
>
> 【校对】**有功守恒、无功守恒，但视在功率一般不守恒**（因为 S 是模，不是线性量）。这条与本课复功率守恒呼应：ΣS̃=0 同时给出 ΣP=0 和 ΣQ=0。

### 【原文】例 9-9 求电源发出的三种功率（印刷 p.226）

> 【原文 OCR】求图所示电路中电源发出的有功功率 P、无功功率 Q、视在功率 S 和电路的功率因数。解：求功率必先解电路……视在功率 S = UI = 100×0.6 V·A = 60 V·A；电压与电流的相位差 φ = 0 − 52.3° = −52.3°（容性），λ = cosφ = 0.612；P = Sλ = 60×0.612 W = 36.72 W；Q = S sinφ = −47.47 var。
>
> 【校对】书中先取 λ≈0.612 再乘 S 得 36.72 W；若直接用 `60cos52.3°` 约为 36.7 W，微差来自中间舍入。关键结论：容性电路 φ<0、Q<0，但 λ 仍为正值。
> 【摘录者按】教案把此题改造为**整比 3-4-5 参数**（U=100 V、I=0.6 A、φ=−53.13°）用于面板默认与陈述，得 P=36 W、Q=−48 var、S=60 V·A、λ=0.6（容性），数值干净且自洽；原书数值仍保留在本段原文中。

## 二、邱 §9-5 复功率（印刷 p.226–228 / PDF 250–252）

### 【原文】复功率定义与"四归一"（印刷 p.226–227）

> 【原文 OCR】正弦电流电路的有功功率、无功功率和视在功率三者之间是一个直角三角形的关系，可以通过"复功率"表述。设一端口的电压相量为 Ū，电流相量为 İ，复功率 S̃ 定义为
> S̃ = Ū İ* = UI∠(φ_u − φ_i) = UI cosφ + j UI sinφ = P + jQ
> 式中 İ* 是 İ 的共轭复数。复功率的吸收或发出同样根据端口电压和电流的参考方向来判断。复功率是一个辅助计算功率的复数，它将正弦稳态电路的 3 种功率和功率因数统一为一个公式表示，是一个"四归一"公式。
> 最后，应当注意，复功率 S̃ 不代表正弦量，乘积 Ūİ 是没有意义的。
>
> 【校对】`S̃=Ūİ*` 中**必须取电流共轭**，否则辐角变成 `φ_u+φ_i`（错）。复功率不是相量、不对应时域正弦量，只是把 P、Q 打包成一个复数的计算工具；单位 V·A，实部单位 W、虚部单位 var。
> 【摘录者按】"为什么取共轭"可用极坐标一句话说明：`Ū=U∠φ_u`、`İ=I∠φ_i`，则 `İ*=I∠−φ_i`，相乘得 `UI∠(φ_u−φ_i)=UI∠φ`，实部正是 `UIcosφ=P`，虚部正是 `UIsinφ=Q`。

### 【原文】复功率的等效参数表达与守恒（印刷 p.227）

> 【原文 OCR】对于不含独立源的一端口可以用等效阻抗 Z 或等效导纳 Y 替代，则复功率 S̃ 又可写成
> S̃ = İ* 的变形：S̃ = Z İ² = (U Y*) 的变形……
> 由 SP、Q 形成的三角形是一个与阻抗三角形相似的直角三角形。可以证明，对整个电路复功率守恒，即有 ΣS̃=0，ΣP=0，ΣQ=0。
>
> 【校对】三种等价写法：`S̃=Ūİ* = Z|İ|² = |Ū|²Y*`（其中 `Y*=G−jB`）。`Z|İ|²` 最适合串联、`|Ū|²Y*` 最适合并联。复功率守恒 `ΣS̃=0` 是 KCL/KVL 在功率域的推论，它**同时**保证有功与无功分别守恒。

### 【原文】例 9-10 并联电容提高功率因数（印刷 p.227–228）

> 【原文 OCR】图 9-13(a) 所示电路外加 50 Hz、380 V 的正弦电压，感性负载吸收的功率 P₁=20 kW，功率因数 λ₁=0.6。若要使电路的功率因数提高到 λ=0.9，求在负载的两端并接的电容值。
> 解：工程上常利用电感、电容无功功率的互补特性，通过在感性的负载端并联电容来提高电路的功率因数。接入电容后，不会改变原负载的工作状态，而利用电容发出的无功功率，部分（或全部）补偿感性负载所吸收的无功功率，从而减轻了电源和传输系统的无功功率的负担。
> 解法一：根据复功率守恒原理求解。接入电容 C 后，S = S₁ + S_C，其中 S 为并联电容后电源发出的复功率，S₁ 为支路吸收的复功率，S_C = −jωC U² 为电容吸收的复功率。分列为
> S cosφ = S₁ cosφ₁ = P（有功功率）
> S sinφ = S₁ sinφ₁ − ωC U²
> 解得 C = P/(ω U²) (tanφ₁ − tanφ)
> 式中 φ = arccos λ = 25.84°（感性），φ₁ = arccos λ₁ = 53.13°（感性）。最后有 C = 374.51 μF。
>
> 【校对】电容**并联**在负载两端（端电压 U 不变），所以负载自身 P₁、Q₁ 都不变，只是电源少送了一部分无功。`φ₁=arccos0.6=53.13°`、`φ=arccos0.9=25.84°`，代入 `C=P(tanφ₁−tanφ)/(ωU²)`，ω=2π×50≈314.16 rad/s、U=380 V，约得 374 μF（书中 374.51 μF 与 tan 取值舍入有关）。
> 【摘录者按】邱本虽写 S，上下文实为复功率守恒（式中有 `−jωCU²`）；教案统一记为 `S̃`，避免与视在功率 S 混淆。书中还提醒另一组容性解 `φ=−25.84°` 需更大电容、经济上不可取。

## 三、邱 §9-6 最大功率传输（印刷 p.229–230 / PDF 253–254）

### 【原文】共轭匹配条件（印刷 p.229–230）

> 【原文 OCR】图 9-14(a) 所示电路为含源一端口 Ns 向终端负载 Z 传输功率，当传输的功率较小（如通信系统电子电路中），而不必计较传输效率时，常常要研究使负载获得最大功率（有功）的条件。根据戴维南定理，该问题可以简化为等效电路进行研究。设 Z_o=R_o+jX_o，Z=R+jX，则负载吸收的有功功率为
> P = U_oc² R / [(R_o+R)² + (X_o+X)²]
> 在内部不便变动的情况下（且 R_o>0），负载 Z 必须根据 Z_o 进行配置（匹配），才可能获得最大功率。如果 R 和 X 可以任意变动，而其他参数不变时，则获得最大功率的条件为
> X + X_o = 0，R = R_o，即 Z = R_o − jX_o = Z_o*。
> 此时获得的最大功率为 P_max = U_oc² / (4R_o)。当用诺顿等效电路时，获最大功率的条件可表示为 Y = Y_o*。上述获最大功率的条件称为最佳匹配（共轭匹配）。
>
> 【校对】两个独立条件：`X=−X_o`（把总电抗抵消成纯电阻，分母只剩 `(R_o+R)²`）与 `R=R_o`（对 `R/(R_o+R)²` 求极值得 R=R_o）。合起来 `Z=Z_o*`（共轭匹配）。`U_oc` 为有效值。此时负载与内阻各分一半电压、效率 50%——所以只适合"小功率、不计效率"的通信/信号场景。
> 【摘录者按】注意与直流最大功率 `R=R_o` 的区别：交流多了一条 `X=−X_o`，因为电抗不耗能却进分母、必须抵消掉。

## 四、李下 §9-2~§9-7 正弦稳态功率与能量（PDF 075–101，印刷页码按 PDF−7 推算、以原书为准故用章节号）

### 【原文】§9-2 电阻的平均功率（PDF 075–077）

> 【原文 OCR】由表 9-1 可知电阻元件吸收的功率为 p_R(t)=R i²(t)，上式适用于任何波形。设电路已进入正弦稳态，i(t)=I sin(ωt)，瞬时功率 p_R(t)=R I² sin²(ωt)=RI²/2·[1−cos(2ωt)]，始终非负……平均功率 P=(1/T)∫₀ᵀ p dt = R I² = U²/R。上述结果与直流电阻电路计算电阻元件消耗功率的公式完全相同，但需使用有效值。通常所说的功率，都是指平均功率而言。平均功率又叫有功功率（active power）。
>
> 【校对】`P=RI²=U²/R` 与直流同形，**但 U、I 必须是有效值**；平均功率与频率、初相无关（李下例 9-2：20 Ω 电阻通 `8cos(314t+60°) A`，P=I²R=(8/√2)²×20=640 W）。

### 【原文】§9-3 电感、电容的平均储能与无功功率（PDF 079–082）

> 【原文 OCR】储能的平均值应为 W̄_L = (1/2)(W_max+0) = (1/2)(L I_m²/2) = LI²/2。功率是能量的变化率……P_L=(1/T)∫₀ᵀ p_L dt=0。单看 P_L=0 不足以表明电感在正弦稳态时能量的往返情况。在电工技术中，把瞬时功率 p_L 的振幅定义为电感的无功功率，记为 Q_L，即 Q_L = ω L I² = U I。联系前式可得 Q_L = 2ω W̄_L。上式表明：电感的无功功率等于其储能平均值的 2ω 倍……无功功率的单位为乏（var），由 volt ampere reactive 三个首字母组成。类似地，电容的无功功率为 Q_C = −ω C U² = −2ω W̄_C，其值为负。
>
> 【校对】`Q_L=+ωLI²=+2ωW̄_L`、`Q_C=−ωCU²=−2ωW̄_C`：**无功功率 = 2ω × 储能平均值**（符号按吸/放区分）。这给出 Q 的物理意义——它衡量储能元件与电源之间能量往返的规模，不是"白做功"。能量平均值与时间无关，可以直接相加；无功功率满足守恒 ΣQ=0（电感取正、电容取负）。
> 【校对补正】本小节 OCR 把电容无功识作 `−ωCI²`，系误识；正确为 `Q_C=−ωCU²=−I²/(ωC)`（见本节原文式 9-17 及 §9-4【校对补正】），教案与页面统一用正确式。

### 【原文】§9-4 单口网络的平均功率与视在功率（PDF 085）

> 【原文 OCR】在一般情况下，若单口网络端口电压与电流的相位差角为 φ，则电阻部分的电压应为 U cosφ，计算平均功率的公式应为 P = UI cosφ，这是正弦稳态电路的一个重要公式。电压分量 U cosφ 称为电压的有功分量。若单口网络只含电阻，φ=0、cosφ=1；若只含电感和电容，φ=±90°、cosφ=0。如果含受控源，φ 可能大于 90°，此时平均功率为负值，说明该网络对外提供能量。
> 在电工技术中，把 UI 即 |Ū||İ| 称为视在功率，记作 S=UI，为与平均功率区别，视在功率不用瓦特为单位，而用伏安（V·A）。……平均功率一般是小于视在功率的，也就是说要在视在功率上打一个折扣才能等于平均功率，这折扣就是 cosφ，称为功率因数，记为 λ=P/S=cosφ，因此阻抗角 φ 也称为功率因数角。不论 φ 正还是负，cosφ 总为正值，单给出 λ 值不能体现电路性质，习惯上同时加上"感性""容性"或"滞后""超前"字样。
>
> 【校对】与邱 §9-4 完全一致，补充两点：① 含受控源时 `|φ|>90°`、`P<0`，单口**发出**有功；② 电气设备按**额定视在功率**标容量（发电机按额定电压/电流设计），所以 S 虽不守恒却 engineering 有用。

### 【原文】§9-5~§9-6 无功功率守恒与复功率守恒（PDF 091、095–098）

> 【原文 OCR】若单口网络包含多个电感和电容，不论如何连接，Q=2ω(W̄_L−W̄_C)，Q_x 为第 x 个电感或电容的无功功率，电感取正、电容取负。上式称为无功功率守恒，与有功（平均）功率守恒同为正弦交流电路功率分析的重要关系。视在功率 S、平均功率 P 与无功功率 Q 三者在数值上 S=√(P²+Q²)，这一关系由功率三角形表明。需注意单口网络的视在功率 S ≠ Σ S_x。
> 把节点方程乘以对应节点电压后相加，可得 Σ Ū_k İ_k* = 0（9-31）……即复功率守恒 Σ S̃ = 0，其中 P=ΣP_k，Q=ΣQ_x=ΣQ_L−ΣQ_C。
>
> 【校对】李下从 KCL/KVL 直接证出 `ΣŪ_k İ_k*=0`（非关联参考方向时取负号），这是复功率守恒的严格出处。再次强调 **S≠ΣS_k**（视在功率不守恒）而 `ΣS̃=0`（复功率守恒）。

### 【原文】例 9-12 两负载的总复功率（PDF 097–098）

> 【原文 OCR】电路如图，求两负载吸收的总复功率，并求输入电流（有效值）和总功率因数。2300 V，负载 1：10 kW、λ=0.8（电容性）；负载 2：15 kW、λ=0.6（电感性）。解：S̃₁ = (10000 − j7500) V·A；S̃₂ = (15000 + j20000) V·A；S̃ = S̃₁ + S̃₂ = (25000 + j12500) V·A = 27951∠26.56° V·A；S = 27951 V·A = UI，得 I = 27951/2300 A = 12.2 A；λ = cos26.56° ≈ 0.894（电感性）。在处理多负载的功率分析问题时，复功率守恒是很有用的。
>
> 【校对】核算：`S₁=10/0.8=12.5 kV·A`、`Q₁=12.5 sin(−36.87°)=−7.5 kvar`；`S₂=15/0.6=25 kV·A`、`Q₂=25 sin53.13°=20 kvar`；总有功 25 kW、总无功 +12.5 kvar，故总功率因数 `λ=25/√(25²+12.5²)=0.894`（感性）。**总视在功率 27.95 kV·A ≠ 12.5+25=37.5 kV·A**，正是"视在功率不守恒"的实例。

### 【原文】§9-7 正弦稳态最大功率传递定理（PDF 098–101）

> 【原文 OCR】交流电源的电压为 U_s，其内阻抗为 Z_i=R_i+jX_i，负载阻抗 Z_L=R_L+jX_L。负载电阻获得最大功率的条件取决于电路中何者为定值、何者为变量。设给定电源及其内阻抗……电流有效值 I=U_s/√[(R_i+R_L)²+(X_i+X_L)²]，负载电阻的功率 P=I²R_L……由于 X_L 只出现在分母中，显然对任何 R_L 值，当 X_L=−X_i 时分母最小……再令 dP/dR_L=0 得 R_L=R_i。因此第一种情况下负载获得最大功率的条件是 X_L=−X_i 且 R_L=R_i，即 Z_L=Z_i*（最大功率匹配或共轭匹配）。满足此条件时最大功率为 P_max=U_s²/(4R_i)。
>
> 【校对】与邱 §9-6 一致：`Z_L=Z_i*`（共轭匹配），`P_max=U_s²/(4R_i)`，U_s 为有效值。李下补充说明若负载阻抗角固定、仅模可变，则只能达到"尽可能好"而非极值；本课只讲第一种（R、X 均可独立变）的共轭匹配。

## 一、邱关源《电路》第6版 · 第八章导读与 §8-1 复数（印刷 p.192–196）

### 【原文】第八章导读（印刷 p.192）——正弦稳态与"为什么需要相量法"

> 【校对 OCR】对线性电路施加激励（独立电源）均为同频率的正弦时间函数，在电路达到稳态时，线性电路的所有响应（电压和电流）均为与激励具有相同频率的正弦时间函数，称电路为正弦稳态电路。
>
> 由第七章获知，含有储能元件的线性电路用线性常微分方程描述。施加正弦激励的线性电路的稳态响应，是线性常微分方程的特解，它是与激励具有相同频率的正弦时间函数。显然，对正弦稳态电路，采用微分方程求特解将非常困难。
>
> 1893 年，工程师 C.P.施泰因梅茨率先用约定的"符号"将正弦稳态电路的微（积）分方程的特解问题变换为复代数方程的求解问题，这种方法就是本章介绍的相量法。相量法将正弦稳态电路中的电压和电流（正弦时间函数）变换为用复数表示的电压相量和电流相量，将电路元件用复阻抗或复导纳表示，从而将时域的微分方程变换为复代数方程。显然，用相量法分析正弦稳态电路比用微分方程要容易得多。

> 【摘录者按】这就是本课的核心动机：李上/L2-03 已经看到"换路 → 微分方程 → 特解"，而正弦激励的特解靠三角函数硬算很繁；相量法是一次**换语言**，把"求微分方程特解"换成"解复数代数方程"。注意书里明说"激励均为同频率"——这是整个方法的前提，不是可有可无的注脚。

### 【原文】§8-1 复数的表示（印刷 p.192–194）

> 【校对 OCR】复数及其运算是应用相量法的数学基础。一个复数有多种表示形式。复数 *F* 的代数形式为
>
> 【校对】*F* = *a* + j*b*，式中 j = √(−1) 为虚单位。
>
> 复数 *F* 在复平面上是一个坐标点，常用原点至该点的向量表示。可得三角形式
>
> 【校对】*F* = |*F*|(cos *φ* + j sin *φ*)
>
> 而指数形式或极坐标形式为
>
> 【校对】*F* = |*F*| e<sup>jφ</sup> = |*F*|∠*φ*
>
> 式中 |*F*| 为复数的模，*φ* 为复数的辐角，即 *φ* = arg *F*。|*F*| 和 *φ* 与 *a*、*b* 之间的关系为
>
> 【校对】|*F*| = √(*a*² + *b*²)，*φ* = arctan(*b*/*a*)；*a* = |*F*| cos *φ*，*b* = |*F*| sin *φ*。

> 【校对 OCR】本书还常用到如下概念：Re[*F*] 表示取复数 *F* 的实部，即 Re[*F*] = *a*；Im[*F*] 表示取虚部，即 Im[*F*] = *b*；*F*\* 表示复数 *F* 的共轭复数，即 *F*\* = *a* − j*b* 或 *F*\* = |*F*|e<sup>−jφ</sup>。

### 【原文】§8-1 复数的四则运算与旋转因子（印刷 p.194–196）

> 【校对 OCR】复数的相加和相减必须用代数形式进行。设有 *F*₁ = *a*₁ + j*b*₁，*F*₂ = *a*₂ + j*b*₂，则
>
> 【校对】*F*₁ ± *F*₂ = (*a*₁ ± *a*₂) + j(*b*₁ ± *b*₂)
>
> 也可以在复平面上按平行四边形法则用向量的相加和相减求得。
>
> 复数相乘用指数形式比较方便：
>
> 【校对】*F*₁*F*₂ = |*F*₁||*F*₂| e<sup>j(φ₁+φ₂)</sup>　，　arg(*F*₁*F*₂) = arg *F*₁ + arg *F*₂
>
> 用代数形式有
>
> 【校对】*F*₁*F*₂ = (*a*₁+j*b*₁)(*a*₂+j*b*₂) = (*a*₁*a*₂ − *b*₁*b*₂) + j(*a*₁*b*₂ + *a*₂*b*₁)
>
> 复数相除：
>
> 【校对】*F*₁/*F*₂ = (|*F*₁|/|*F*₂|) e<sup>j(φ₁−φ₂)</sup>
>
> 代数形式相除要给分子分母同乘 *F*₂\*（有理化），使分母成为实数。乘除的图解意义是：模的放大/缩小与辐角的旋转。

> 【校对 OCR】*F* = 1∠*θ* = e<sup>jθ</sup> 是一个模等于 1、辐角为 *θ* 的复数。任意复数 *A* = |*A*|e<sup>jφ</sup> 乘以 e<sup>jθ</sup> 等于把 *A* 逆时针旋转一个角度 *θ*，而模值不变，所以 e<sup>jθ</sup> 称为旋转因子。根据欧拉公式，e<sup>jπ/2</sup> = j，e<sup>jπ</sup> = −1。因此 j 和 −1 都可以看成旋转因子：一个复数乘以 j，等于把它在复平面上逆时针旋转 π/2；除以 j 等于乘以 −j，即顺时针旋转 π/2。
>
> 两个复数相等必须满足 *a*₁ = *a*₂ 且 *b*₁ = *b*₂，或者模相等且辐角（相差 2π 的整数倍时）相等；一个复数方程可以分解为两个实数方程。

> 【摘录者按】"加减用直角坐标、乘除用极坐标"不是死记的口诀：加减来自向量合成（实部虚部分别相加），乘除来自模相乘/相除、角相加/相减（旋转因子 e<sup>jθ</sup>）。后面微分 `jω` 的本质正是"模乘 ω、角加 90°"，与这里的旋转因子是同一件事。

### 【原文】§8-1 例8-1（印刷 p.196）——复数四则运算示例

> 【校对 OCR】设 *F*₁ = 3 − j4，*F*₂ = 10∠135°。求 *F*₁ + *F*₂ 和 *F*₁/*F*₂。
>
> 解：*F*₂ = 10(cos135° + j sin135°) = −7.07 + j7.07，
> *F*₁ + *F*₂ = (3−j4) + (−7.07+j7.07) = −4.07 + j3.07 = 5.1∠143°。
> *F*₁/*F*₂ = (3−j4)/(10∠135°) = 0.5∠(−53.1°−135°) = 0.5∠171.9°。

## 二、邱关源《电路》第6版 · §8-2 正弦量（印刷 p.196–198）

### 【原文】§8-2 正弦量的数学描述与三要素（印刷 p.196–197，式 8-1）

> 【校对 OCR】电路中按正弦规律变化的电压或电流，统称为正弦量。本书采用 cosine 函数。图 8-4 表示一段电路中有正弦电流 *i* 在图示参考方向下，其数学表达式定义如下：
>
> 【校对】*i*(*t*) = *I*<sub>m</sub> cos(ω*t* + *ψ*<sub>i</sub>)　　(8-1)
>
> 式中的 3 个常数 *I*<sub>m</sub>、ω 和 *ψ*<sub>i</sub> 称为正弦量的三要素。
>
> *I*<sub>m</sub> 称为正弦量的振幅，它是正弦量在整个振荡过程中达到的最大值；当 cos(ω*t*+*ψ*)=−1 时有最小值 −*I*<sub>m</sub>，峰—峰值为 2*I*<sub>m</sub>。

> 【校对 OCR】随时间变化的角度（ω*t* + *ψ*）称为正弦量的相位（相角）；ω 称为角频率，是相位随时间变化的角速度：
>
> 【校对】ω = d(ω*t* + *ψ*)/d*t*，单位 rad/s；ω*T* = 2π，ω = 2π/*T* = 2π*f*，*f* = 1/*T*。
>
> *f* 的单位为 1/s，称 Hz（赫兹）。我国工业化生产的电能为正弦电压源，频率为 50 Hz，称工频。

> 【校对 OCR】*ψ* 是正弦量在 *t*=0 时刻的相位，称为初相位（角），简称初相：(*ωt*+*ψ*)|<sub>t=0</sub> = *ψ*。初相通常在主值范围内取值，即 |*ψ*| ≤ 180°。初相与计时零点的选择有关。对同一电路系统中的许多相关正弦量，只能相对于一个共同的计时零点确定各自的相位。

> 【摘录者按】三要素是"区分两个正弦波"的完整信息：振幅管大小、ω 管快慢、初相管起点。参考方向反转会让初相改变 180°（邱 §8-2 后文），所以谈相位必须先谈参考方向——这与第一课"参考方向决定正负号"是同一条纪律。

### 【原文】§8-2 正弦量的运算封闭性（印刷 p.197）

> 【校对 OCR】正弦量随时间变化的图形称为正弦波。正弦量乘以常数、正弦量的微分、积分，同频正弦量的代数和等运算，其结果仍为一个同频率的正弦量。正弦量的这个性质十分重要。

> 【摘录者按】这句话是相量法能成立的**第一块基石**：运算不产生新频率，才有"把正弦量换成复数、在复数域做完再换回来"的可能。不同频率相加不会得到单一正弦量，相量代数不适用（本课 P3 边界）。

### 【原文】§8-2 有效值（印刷 p.198，式 8-2）

> 【校对 OCR】工程中常将周期电流或电压在一个周期内产生的平均效应换算为等效的直流量，以衡量和比较周期电流或电压的效应，这一等效的直流量就称为周期量的有效值，用相对应的大写字母表示。周期量有效值 *I* 定义如下：
>
> 【校对】*I* = √[ (1/*T*) ∫<sub>0</sub><sup>*T*</sup> *i*²(*t*) d*t* ]　　(8-2)
>
> 即有效值等于瞬时值平方在一个周期内积分的平均值的平方根，因此又称均方根值（root-mean-square，rms）。上式对周期量普遍适用。
>
> 当 *i* 是正弦量时，利用 cos²*θ* = (1 + cos2*θ*)/2 可推出
>
> 【校对】*I* = *I*<sub>m</sub>/√2 ≈ 0.707 *I*<sub>m</sub>
>
> 所以常把正弦量改写为 *i* = √2 *I* cos(ω*t* + *ψ*)。正弦量的有效值与频率和初相无关。工程中交流电气设备铭牌上的额定电流、电压，交流电压表、电流表的读数都是有效值。

### 【原文】§8-2 相位差（印刷 p.198–199）

> 【校对 OCR】设两个同频正弦量 *i* = √2 *I* cos(ω*t*+*ψ*<sub>i</sub>)、*u* = √2 *U* cos(ω*t*+*ψ*<sub>u</sub>)，相位差等于相位相减：
>
> 【校对】*φ* = (ω*t*+*ψ*<sub>i</sub>) − (ω*t*+*ψ*<sub>u</sub>) = *ψ*<sub>i</sub> − *ψ*<sub>u</sub>
>
> 同频正弦量的相位差等于初相之差，为与时间无关的常数，也在主值范围内取值。*φ*>0 称 *i* 超前 *u*；*φ*<0 称 *i* 滞后 *u*；*φ*=0 同相；|*φ*|=π/2 正交；|*φ*|=π 反相。相位差与计时零点的选择无关；改设某正弦量的参考方向，其初相改变 π，与其他正弦量的相位差也相应改变 π。

> 【摘录者按】"相位差 = 初相之差"只在**同频**时成立；频率不同时相位差随时间变，没有固定的超前/滞后。有效值的 √2 关系也只对正弦波成立（对方波、三角波不成立，均方根定义式(8-2)才普适）。

## 三、邱关源《电路》第6版 · §8-3 相量法的基础（印刷 p.199–202）

### 【原文】§8-3 从微分方程到复代数方程（印刷 p.199–200，式 8-3~8-5）

> 【校对 OCR】根据 VCR、KCL 和 KVL 编写 RLC 串联电路的 KVL 方程，代入元件 VCR 得
>
> 【校对】*R i* + *L* d*i*/d*t* + (1/*C*) ∫ *i* d*t* = *u*<sub>s</sub>　　(8-3)
>
> 当 *u*<sub>s</sub>（激励）为正弦量时，电流 *i* 的特解一定是与 *u*<sub>s</sub> 同一频率的正弦量。设 *u*<sub>s</sub> = √2 *U* cos(ω*t*+*ψ*<sub>u</sub>)，*i* = √2 *I* cos(ω*t*+*ψ*<sub>i</sub>)，代入后得一组同频正弦函数描述的代数方程：
>
> 【校对】√2 *RI* cos(ω*t*+*ψ*) − √2 ω*LI* sin(ω*t*+*ψ*) + √2 (*I*/ω*C*) sin(ω*t*+*ψ*) = √2 *U* cos(ω*t*+*ψ*<sub>u</sub>)　　(8-4)
>
> 正弦量乘常数、微分、积分、同频正弦量的代数和，结果仍是同频正弦量；各正弦量之间只在有效值（振幅）和初相上有"差异和联系"。求解这类同频正弦函数方程非常繁琐。根据欧拉公式，可将正弦函数用复指数函数表示：
>
> 【校对】*u*<sub>s</sub>(*t*) = Re[ √2 *U* e<sup>j*ψ*<sub>u</sub></sup> e<sup>jω*t*</sup> ]，　*i*(*t*) = Re[ √2 *I* e<sup>j*ψ*<sub>i</sub></sup> e<sup>jω*t*</sup> ]
>
> 取其中一个分量代入式(8-3)，整理得
>
> 【校对】*R* √2 *I* e<sup>j*ψ*</sup> + jω*L* √2 *I* e<sup>j*ψ*</sup> + (√2 *I* e<sup>j*ψ*</sup>)/(jω*C*) = √2 *U* e<sup>j*ψ*<sub>u</sub></sup>　　(8-5)
>
> 该复代数方程的结果用复数形式表述了正弦量除频率 ω 外的另两个要素：有效值 *I* 和初相 *ψ*，据此即可写出正弦量 *i* 的表达式。

> 【摘录者按】注意式(8-4)→(8-5) 发生了什么：`d/dt → jω`，`(1/C)∫dt → 1/(jωC)`，原来的微分方程变成"√2 I e^{jψ} 乘一个复数 = √2 U e^{jφ}"。这不是近似，是同频正弦量在复指数表示下的严格对应。**ω 被藏在 e^{jωt} 里没有消失**：相量里没有频率，回到时域必须知道 ω。

### 【原文】§8-3 相量的定义与相量图（印刷 p.201，例8-2）

> 【校对 OCR】电路理论中将与正弦量 *u*<sub>s</sub>、*i* 关联的复数 √2 *U* e<sup>j*ψ*<sub>u</sub></sup> 和 √2 *I* e<sup>j*ψ*<sub>i</sub></sup> 前面的有效值部分定义为正弦量对应的相量，用带"·"的大写字母表示：
>
> 【校对】**相量（phasor）**：*Ū* = *U*∠*ψ*<sub>u</sub>，*Ī* = *I*∠*ψ*<sub>i</sub>；即正弦量的对应相量是一个复数，**它的模为正弦量的有效值，它的辐角为正弦量的初相**。
>
> 相量在复平面上表示的图形称为相量图。电路中有时也用正弦量的振幅表示相量的模，称为振幅相量 *Ū*<sub>m</sub> = *U*<sub>m</sub>∠*ψ*<sub>u</sub>。学习时要注意两者区别。

> 【校对 OCR】例8-2 写出正弦电流 *i* = 14.14 cos(314*t*+30°) A 对应的相量。解：*Ī* = 14.14/√2 ∠30° = 10∠30° A。相量与正弦量之间**不是相等关系**，写成"*i* = 10∠30° A"是错误的。

> 【摘录者按】"-point 记号"只是身份标签：提醒读者这个复数代表一个正弦波，而不是普通复数，也不是有效值这个实数。用有效值相量时，时域写法固定为 √2 *U* cos(ω*t*+*ψ*)；换回时必须补 `√2` 和 `ω`。

### 【原文】§8-3 相量与频率、微分的关系（印刷 p.202，例8-3）

> 【校对 OCR】相量与频率无关。由相量反求正弦量的表达式时必须知道 ω 才能写出。相量之间所表示的运算关系只能在**同频**的正弦量中使用。
>
> 例8-3 表明：正弦量的微分是与原正弦量同频率的正弦量，其对应的相量等于原正弦量对应相量乘以 jω（积分则除以 jω）。

> 【摘录者按】"相量与频率无关"与"微分 ↔ jω"并不矛盾：相量本身只装（有效值, 初相）两个数，ω 是转换时另存的公共参数；一旦做微分/积分，ω 就通过 jω 进入相量的模与角。这是下一课 `Z_L = jωL`、`Z_C = 1/(jωC)` 的直接来源。

### 【原文】§8-4（截取）KCL、KVL 的相量形式（印刷 p.202）

> 【校对 OCR】KCL 的相量形式：任一节点上同频正弦电流对应相量的代数和为零，即
>
> 【校对】*Ī*₁ + *Ī*₂ + … + *Ī<sub>k</sub>* + … = 0　或　Σ*Ī* = 0
>
> KVL 的相量形式：任一回路中同频正弦电压对应相量的代数和为零，即
>
> 【校对】*Ū*₁ + *Ū*₂ + … + *Ū<sub>k</sub>* + … = 0　或　Σ*Ū* = 0
>
> 应用相量法时，其电路方程的相量形式与电阻电路相似，线性电阻电路的各种分析方法和电路定理可推广用于正弦稳态分析，差别在于计算为复数运算。

> 【摘录者按】本课只取这两条"定律换语言"的结论句（与李下 §8-5 完全一致），正负号仍按原正弦量的参考方向决定；元件 VCR 相量形式（R、L、C 的相量模型）留下一课 L2-05，不在本课展开。

## 四、李瀚荪《电路分析基础》第5版（下册）· §8-1 正弦激励的过渡过程和稳态

### 【原文】§8-1 三特征（PDF 8–10）

> 【校对 OCR】随时间按正弦规律变化的电压和电流称为正弦（sinusoidal）交流电压和电流。正弦波是周期波形的基本形式。本书采用 cos 函数。设正弦电压瞬时值为
>
> 【校对】*u*(*t*) = *U*<sub>m</sub> cos ω*t*　　(8-1)
>
> 其中 *U*<sub>m</sub> 为振幅（最大值）；ω = 2π/*T* = 2π*f* 为角频率（rad/s），*f* 单位 Hz。我国电力系统提供的正弦电压为 50 Hz，ω = 100π rad/s。理论分析中常把角频率简称为频率，实际计算时必须注意 2π 这一乘数。
>
> 在一般情况下，时间的起点不一定恰好选在正弦波为正最大值的瞬间，此时
>
> 【校对】*u*(*t*) = *U*<sub>m</sub> cos(ω*t* + *ψ*)　　(8-3)
>
> *ψ* 称为初相角，反映初始值 *u*(0) = *U*<sub>m</sub> cos *ψ*。一个正弦波可由三个参数完全确定：**振幅、频率（或角频率或周期）、初相**，这三者称为正弦波的三特征。

### 【原文】§8-1 正弦稳态响应的由来（PDF 10–13，式 8-7~8-15）

> 【校对 OCR】设 RC 电路在 *t*=0 与正弦电压源 *u*<sub>s</sub>(*t*) = *U*<sub>sm</sub> cos(ω*t*+*ψ*) 接通，微分方程为 *RC* d*u*<sub>C</sub>/d*t* + *u*<sub>C</sub> = *u*<sub>s</sub>。解答由稳态解和瞬态解组成。稳态解设为同频正弦 *u*<sub>Cs</sub> = *U*<sub>Cm</sub> cos(ω*t*+*ψ*<sub>C</sub>)，代入后靠待定系数法得到
>
> 【校对】*U*<sub>Cm</sub> = *U*<sub>sm</sub>/√(1+ω²*R*²*C*²)，　*ψ*<sub>C</sub> = *ψ* − arctan(ω*RC*)
>
> 接通瞬间为满足 *u*<sub>C</sub>(0)=0 还需叠加瞬态项 *K*e<sup>−*t*/τ</sup>，*K* = *u*<sub>C</sub>(0) − *U*<sub>Cm</sub> cos *ψ*<sub>C</sub>，τ = *RC*。
>
> 在 *t*=(4~5)τ 期间电路处于过渡过程，响应不是按正弦方式变化；当电路进入稳态后，响应以与外施激励频率一致的正弦方式变化，这一响应特称为**正弦稳态响应**（sinusoidal steady state，SSS）。若 *u*<sub>C</sub>(0) 恰与 *U*<sub>Cm</sub> cos *ψ*<sub>C</sub> 相等，则无瞬态分量，换路后立即进入正弦稳态。

> 【摘录者按】这段把 L2-03 与本课缝合起来：暂态项 *K*e<sup>−t/τ</sup> 几毫秒到几秒后消失，留下来的稳态响应仍有"频率不变、幅度和起点被电路改掉"两个待求量——相量正是为装这两个量而生。原文用振幅相量口径（*U*<sub>Cm</sub>），邱用有效值口径，两种口径差 √2，不能混用。

### 【原文】§8-1 思考题 8-2（PDF 13）

> 【校对 OCR】求解线性时不变动态电路的某一正弦稳态响应，实际上需求解的未知量只有一个、两个还是三个？你是否感到正文中求解这一响应并非轻松之事，是否渴望有更简便的方法？

> 【摘录者按】书里自己把矛盾摆出来了：频率 ω 已知，只剩"幅度、初相"两个未知量，用微分方程+待定系数求解却要展开三角函数。这就是下一节"变换方法"的引子。

## 五、李瀚荪《电路分析基础》第5版（下册）· §8-2 变换方法的概念

### 【原文】§8-2 变换三步（PDF 13–15，图 8-8/8-9）

> 【校对 OCR】科学技术领域常使用变换方法。所有变换方法的基本思路都可分为三个步骤：
> (1) 把原来的问题变换为一个较容易处理的问题；
> (2) 在变换域中求解问题；
> (3) 把变换域中求得的解答反变换为原来问题的解答。
>
> 例如求解 *x*<sup>2.35</sup> = 5：对两端取对数得 2.35 lg *x* = lg 5，故 lg *x* = 0.2974，解得 *x* = 10<sup>0.2974</sup> = 1.983。取对数是变换，求反对数是反变换。变换不仅改变数值（lg 5 当然与 5 不同），还改变数值间的运算方式：指数运算变成乘法运算。由正实数域变换而来的对数域是一个"虚拟世界"，在那里"相乘"叫作"相加"、"乘方"叫作"相乘"；对数表是现实世界语言和这个虚拟世界语言间的字典。

> 【摘录者按】这段是全书最适合零基础的类比：相量法也是"换到虚拟世界 → 做简单运算 → 换回来"。**变换域里的量不等于原量**（lg5 ≠ 5；相量 ≠ 正弦波）；忘记反变换、或在两个世界里混用规则，是最常见的错。

## 六、李瀚荪《电路分析基础》第5版（下册）· §8-3 复数与 §8-4 振幅相量

### 【原文】§8-3 复数（PDF 15–18，式 8-20~8-23）

> 【校对 OCR】在相量分析法中需运用复数。设 *A* 为一复数，*a*₁ 及 *a*₂ 分别为实部及虚部，则
>
> 【校对】*A* = *a*₁ + j*a*₂　　(8-20)
>
> j = √(−1) 为虚数单位。Re[*A*] = *a*₁，Im[*A*] = *a*₂（注意虚部是 *a*₂ 而不是 j*a*₂）。复数在复平面上用有方向的线段表示：长度为模 *a*，与实轴正方向夹角为辐角 *θ*，于是
>
> 【校对】*A* = *a* cos *θ* + j*a* sin *θ* = *a* e<sup>jθ</sup> = *a*∠*θ*　　(8-21~8-23)
>
> 工程上常把 *a* e<sup>jθ</sup> 简写为 *a*∠*θ*。

> 【校对 OCR】相等：实部、虚部分别相等（极坐标下模、辐角分别相等）。加减：实部与虚部分别相加减，**必须用直角坐标形式**。乘除：极坐标下模相乘/相除、辐角相加/相减；直角坐标下要用到共轭复数做分母有理化。复数加减在复平面上 obey 平行四边形法则；乘除则表现为模的缩放与辐角的旋转。

> 【校对 OCR】例8-1：已知 *A* = 6+j8 = 10∠53.1°，*B* = −4.33+j2.5 = 5∠150°，则
> *A*+*B* = 1.67+j10.5；*A*−*B* = 10.33+j5.5；
> *A·B* = 50∠203.1° = 50∠−156.9°；*A/B* = 2∠−96.9°。

### 【原文】§8-4 振幅相量（PDF 18–21，式 8-24~8-26）

> 【校对 OCR】欧拉恒等式 e<sup>jθ</sup> = cos *θ* + j sin *θ*，令 *θ* = ω*t* 得
>
> 【校对】e<sup>jωt</sup> = cos ω*t* + j sin ω*t*；cos ω*t* = Re[e<sup>jωt</sup>]　　(8-24)
>
> 设 *u*(*t*) = *U*<sub>m</sub> cos(ω*t*+*ψ*)，则
>
> 【校对】*u*(*t*) = Re[ *U*<sub>m</sub> e<sup>jψ</sup> e<sup>jωt</sup> ] = Re[ *Ū*<sub>m</sub> e<sup>jωt</sup> ]，　*Ū*<sub>m</sub> = *U*<sub>m</sub>∠*ψ*　　(8-25~8-26)
>
> *Ū*<sub>m</sub> 是一个与时间无关的复值常数，其模为振幅、辐角为初相，称为**振幅相量**。相量只是一个复数，但具有代表正弦波的特殊意义，故字母上端加点。初学者常把 *u*(*t*) 与 *Ū*<sub>m</sub> 画等号，这是错误的：**振幅相量是正弦波的变换式，并非正弦波本身**，完整关系由式(8-25)给出（可记作双箭头对应）。相量与 e<sup>jωt</sup> 相乘得到时间 *t* 的复值函数，可在复平面上看作以角速度 ω 逆时针旋转的相量。
>
> 例8-2：*i*₁(*t*) = 5cos(314*t*+60°) A，*i*₂(*t*) = −10sin(314*t*+60°) A，*i*₃(*t*) = −4cos(314*t*+60°) A。先统一成 cos 形式：*i*₂ = 10cos(314*t*+150°) A，*i*₃ = 4cos(314*t*−120°) A；振幅相量分别为 5∠60°、10∠150°、4∠−120° A。因三者同频，相量图里的夹角在任何瞬间不变，可由静止相量图判断超前/滞后（*i*₁ 超前 *i*₂ 90°）。

> 【摘录者按】李下用**振幅相量**（模 = 振幅），邱用**有效值相量**（模 = 有效值）：同一正弦波两者的模差 √2。本课教案统一采用邱/工程口径的有效值相量，遇到李下例题的数值需先除以 √2 再比较。无论哪种口径，"相量 ≠ 时间函数"这条纪律完全一致。

## 七、李瀚荪《电路分析基础》第5版（下册）· §8-5 线性性质与 KCL/KVL 相量形式

### 【原文】§8-5 例8-4：同频正弦相加，三角法 vs 相量法（PDF 22–23）

> 【校对 OCR】已知 *u*₁(*t*) = 20cos(ω*t*−30°)，*u*₂(*t*) = 40cos(ω*t*+60°)，求 *u*₁+*u*₂。
>
> 解一（三角法）：展开为 37.32cos ω*t* − 24.64sin ω*t*，作辅助三角形得斜边 44.72、夹角 33.43°，故
> *u*₁(*t*)+*u*₂(*t*) = 44.72cos(ω*t*+33.43°)。
>
> 解二（相量法）：三步——
> 第一步变换：*u*₁ ↔ 20∠−30°，*u*₂ ↔ 40∠60°（振幅相量）；
> 第二步在变换域相加：(17.32−j10)+(20+j34.64) = 37.32+j24.64 = 44.72∠33.43°；
> 第三步反变换：*u*₁+*u*₂ = 44.72cos(ω*t*+33.43°)。
>
> 显然解二比解一方便得多，代数运算代替了繁琐的三角运算；相加的正弦量更多时优越性更突出。

> 【摘录者按】这个例子就是"同频相加 → 相量复数加法 → 反变换"的完整三段式，教案可以把它作为预测题的揭晓依据：先让学生猜"和还是不是正弦、幅度是多少"，再用相量三步验证。

### 【原文】§8-5 相量的线性性质（PDF 23）

> 【校对 OCR】表示若干个同频率正弦量（可带实系数）线性组合的相量，等于表示各正弦量的相量的同一线性组合。若 *u*(*t*) = Re[ *A* e<sup>jωt</sup> ]、*v*(*t*) = Re[ *B* e<sup>jωt</sup> ]，*α*、*β* 为实数，则 *αu*(*t*)+*βv*(*t*) 的相量为 *αA* + *βB*。

> 【摘录者按】"线性性质"是 KCL/KVL 相量形式成立的数学原因：时域的加、减、乘以实常数，在相量域原样保留为复数加、减、乘以实常数。注意系数必须是实数；乘以 j 对应的是微分，不是简单的实系数缩放。

### 【原文】§8-5 KCL 的相量形式与例8-5（PDF 23–24，式 8-27~8-28）

> 【校对 OCR】由 KCL：任一时刻流出节点电流的代数和为零。正弦稳态下各支路电流都是同频正弦波 *i*<sub>k</sub>(*t*) = Re[ *Ī*<sub>k</sub> e<sup>jωt</sup> ]，故 Σ Re[ *Ī*<sub>k</sub> e<sup>jωt</sup> ] = 0 (8-27)，由线性性质得
>
> 【校对】**Σ*Ī* = 0**　　(8-28)
>
> 例8-5：节点上 *i*₁(*t*) = 10cos(ω*t*+60°) A、*i*₂(*t*) = 5sin ω*t* A 流入节点，*i*₃ 流出节点，求 *i*₃。先把 *i*₂ 改写成 5cos(ω*t*−90°) A，故 *Ī*<sub>1m</sub> = 10∠60°，*Ī*<sub>2m</sub> = 5∠−90°（注意不是 5∠0°）。由 Σ*Ī* = 0 且正负号按参考方向定：
>
> 【校对】*Ī*<sub>3m</sub> = *Ī*<sub>1m</sub> + *Ī*<sub>2m</sub> = (5+j8.66−j5) A = (5+j3.66) A = 6.2∠36.2° A
> *i*₃(*t*) = 6.2cos(ω*t*+36.2°) A
>
> 相量图中 *Ī*<sub>1m</sub>、*Ī*<sub>2m</sub> 构成平行四边形两边，*Ī*<sub>3m</sub> 是对角线；由相量图可读出相位关系，不必再画波形图。

### 【原文】§8-5 KVL 的相量形式（PDF 23）

> 【校对 OCR】同理，在正弦稳态电路中沿任一回路，KVL 可表示为
>
> 【校对】**Σ*Ū* = 0**　　(8-29)
>
> 若汇集于某节点的三个同频正弦电流的振幅分别为 *I*<sub>1m</sub>、*I*<sub>2m</sub>、*I*<sub>3m</sub>，则不能仅由振幅满足"加法"就断定满足 KCL；振幅之间必须按相量（含初相）相加才对。若把例8-5 中 *i*₂ 改为 5sin(2ω*t*)，则因频率不同，例题中的相量计算无效。

> 【摘录者按】这两段正好给出本课 P1 与 P3 的判定题：①同频才能用 ΣĪ=0 / ΣŪ=0，参考方向的正负号仍按时域那套；②**振幅（有效值）不能直接加减**，必须带相位做复数加法；③频率不同时相量图无法静止，方法失效。

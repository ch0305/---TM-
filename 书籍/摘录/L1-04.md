## 一、邱关源《电路》第6版

### 【原文】印刷 p.34 — §2-1 电路的等效变换：什么叫“等效”

由时不变线性无源元件、线性受控源和独立电源组成的电路，称为时不变线性电路，本书简称线性电路。如果构成电路的无源元件均为线性电阻，则称该电路为线性电阻性电路（或简称电阻电路）。当电路中的独立电源都是恒定电源时，这类电路简称为直流电路。

对电路进行分析和计算时，有时可以把电路中某一部分简化，即用一个较为简单或另一种结构形式的电路代替该部分电路，以使整个电路便于计算。在图 2-1(a) 中，右方虚线框中由几个电阻构成的电路可以用一个电阻 *R*<sub>eq</sub>〔书中下标 eq〕〔见图 2-1(b)〕来代替，使整个电路得以简化。进行代替的条件是使图 2-1(a)、(b) 中端子 1-1′ 以右的部分有相同的**伏安特性**。电阻 *R*<sub>eq</sub> 称为**等效电阻**，其值决定于被代替的原电路中各电阻的值以及它们的连接方式。

另一方面，当图 2-1(a) 中端子 1-1′ 以右电路被 *R*<sub>eq</sub> 代替后，1-1′ 以左部分电路的任何电压和电流都将维持与原电路相同。这就是电路的“等效概念”。更一般地说，当电路中某一部分用其等效电路代替后，未被代替部分的电压和电流均应保持不变。

> 【摘录者按】这是全课的“核心概念锚点”：等效不是“看起来像”，而是**对外伏安特性相同**（接同样的电压，流入同样的电流）。书里明确说下标 eq 是 equivalent（等效）的简写。教案要在开场就立这个判据，后面串、并联公式都从它推出来。

### 【原文】印刷 p.35 — “对外等效”：内部并不等效；图 2-2 串联

〔接上页〕也就是说，用等效电路的方法求解电路时，电压和电流保持不变的部分**仅限于等效电路以外**，这就是“**对外等效**”的概念。等效电路是被代替部分的简化或结构变形，因此，**内部并不等效**。例如，把图 2-1(a) 所示电路简化后，不难求得端子 1-1′ 以左部分的电流和端子 1-1′ 的电压，它们分别等于原电路中的电流和电压。但如果还要求图 2-1(a) 虚线框内部各电阻的电流，就必须**回到原电路**，利用已求得的电流和电压来求解。可见，“对外等效”也就是其外部特性等效。

§2-2 电阻的串联和并联：等效电路是电路结构的一种变形（或变换），本节先讨论最简单的电阻串联和并联的情况。

图 2-2(a) 所示电路为 *n* 个电阻 *R*<sub>1</sub>、*R*<sub>2</sub>…*R*<sub>n</sub> 的串联组合。**电阻串联时，每个电阻中的电流为同一电流。** 应用 KVL，有

【校对】*u* = *u*<sub>1</sub> + *u*<sub>2</sub> + … + *u*<sub>n</sub>

即总电压为各串联电阻分电压之和。由于每个电阻的电流均为同一电流 *i*，有 *u*<sub>k</sub> = *R*<sub>k</sub> *i*，代入上式得

【校对】*u* = (*R*<sub>1</sub> + *R*<sub>2</sub> + … + *R*<sub>n</sub>) *i*

> 【摘录者按】串联推导三步：串联同电流（结构事实）→ KVL 得总电压是分电压和 → 代入 *u*<sub>k</sub>=*R*<sub>k</sub>*i* 得等效电阻是各电阻之和。每一步都是前两课已有的 KVL + 欧姆定律，不是新规定。

### 【原文】印刷 p.36 — 串联等效电阻、分压公式(2-2)；并联与等效电导(2-3)

〔串联〕其中

【校对】*R*<sub>eq</sub> = *R*<sub>1</sub> + *R*<sub>2</sub> + … + *R*<sub>n</sub> = Σ<sub>k=1</sub><sup>n</sup> *R*<sub>k</sub>

电阻 *R*<sub>eq</sub> 是这些串联电阻的等效电阻。显然，当各电阻均为正值时，**等效电阻必大于任一个参与串联的电阻**。

电阻串联时，各电阻上的分电压为

【校对】*u*<sub>k</sub> = (*R*<sub>k</sub> / Σ<sub>i=1</sub><sup>n</sup> *R*<sub>i</sub>) *u*　　(2-2)

或 *u*<sub>k</sub> = *R*<sub>k</sub> *i*（*k* = 1, 2, …, n）。可见，各个串联电阻的电压与电阻值成正比，亦即总电压根据各个串联电阻的电阻值进行分配。式(2-2)称为**电压分配公式，或称分压公式**。

〔并联〕图 2-3(a) 示出 *n* 个电阻的并联组合。**电阻并联时，各电阻的电压为同一电压。** 总电流 *i* 可根据 KCL 写作

【校对】*i* = *i*<sub>1</sub> + *i*<sub>2</sub> + … + *i*<sub>n</sub> = (*G*<sub>1</sub> + *G*<sub>2</sub> + … + *G*<sub>n</sub>) *u*

即总电流为各并联电阻分电流之和，式中 *G*<sub>1</sub>、*G*<sub>2</sub>…*G*<sub>n</sub> 为电阻 *R*<sub>1</sub>、*R*<sub>2</sub>…*R*<sub>n</sub> 的电导，而

【校对】*G*<sub>eq</sub> = *G*<sub>1</sub> + *G*<sub>2</sub> + … + *G*<sub>n</sub> = Σ<sub>k=1</sub><sup>n</sup> *G*<sub>k</sub> = Σ<sub>k=1</sub><sup>n</sup> 1/*R*<sub>k</sub>　　(2-3)

*G*<sub>eq</sub> 是 *n* 个电阻并联后的等效电导。并联后的等效电阻 *R*<sub>eq</sub> 为

【校对】*R*<sub>eq</sub> = 1/*G*<sub>eq</sub> = 1 / Σ<sub>k=1</sub><sup>n</sup> (1/*R*<sub>k</sub>)

或

【校对】1/*R*<sub>eq</sub> = 1/*R*<sub>1</sub> + 1/*R*<sub>2</sub> + … + 1/*R*<sub>n</sub>

不难看出，当各电阻均为正值时，**等效电阻小于任一个参与并联的电阻**。

> 【摘录者按】并联推导与串联对偶：并联同电压（结构事实）→ KCL 得分电流和 → 用电导 *G*=1/*R* 写成 *i*=*G*<sub>eq</sub>*u*。**书特意改用“电导”来写并联**，于是并联公式和串联公式形式对称（都是“和”），这是理解对偶关系的钥匙。教案要讲清“为什么并联忽然用电导”：不是为了难，是为了让 *i*=*G u* 与串联的 *u*=*R i* 对上。等效电阻“串大任一个、并小任一个”是学生做数值题时的 sanity check。

### 【原文】印刷 p.37 — 分流公式(2-4)、两电阻并联特例、例 2-1、混联

电阻并联时，各电阻中的电流为

【校对】*i*<sub>k</sub> = (*G*<sub>k</sub> / *G*<sub>eq</sub>) *i*　（*k* = 1, 2, …, n）　　(2-4)

可见，每个并联电阻中的电流与它们各自的**电导值成正比**。上式称为**电流分配公式，或称分流公式**。

当 *n* = 2 时，即 2 个电阻并联，等效电阻为

【校对】*R*<sub>eq</sub> = *R*<sub>1</sub> *R*<sub>2</sub> / (*R*<sub>1</sub> + *R*<sub>2</sub>)

两并联电阻的电流分别为

【校对】*i*<sub>1</sub> = *G*<sub>1</sub>/(*G*<sub>1</sub>+*G*<sub>2</sub>) · *i* = *R*<sub>2</sub>/(*R*<sub>1</sub>+*R*<sub>2</sub>) · *i*
【校对】*i*<sub>2</sub> = *G*<sub>2</sub>/(*G*<sub>1</sub>+*G*<sub>2</sub>) · *i* = *R*<sub>1</sub>/(*R*<sub>1</sub>+*R*<sub>2</sub>) · *i*

**例 2-1** 电路中总电流 *i* = 16.5 mA，三个并联电阻 *R*<sub>b</sub>=40 kΩ、*R*<sub>c</sub>=10 kΩ、*R*<sub>d</sub>=25 kΩ（另有一个串联电阻不影响并联组内的电流分配），求各并联支路电流。解：*G*<sub>b</sub>=1/40 kΩ=0.025 mS、*G*<sub>c</sub>=1/10 kΩ=0.1 mS、*G*<sub>d</sub>=1/25 kΩ=0.04 mS，总分流电导 0.165 mS。按分流公式：

【校对】*i*<sub>b</sub> = 0.025/0.165 × 16.5 mA = 2.5 mA
【校对】*i*<sub>c</sub> = 0.1/0.165 × 16.5 mA = 10 mA
【校对】*i*<sub>d</sub> = 0.04/0.165 × 16.5 mA = 4 mA

（三支路电流之和 = 16.5 mA，与总电流相符。OCR 把 *i*<sub>b</sub> 识别成“2.3 mA”，按分流公式与电流守恒校对为 2.5 mA。）

〔混联〕当电阻的连接中既有串联又有并联时，称为电阻的串、并联，或简称**混联**。图 2-6(a) 中，*R*<sub>1</sub> 与 *R*<sub>2</sub> 串联后与 *R*<sub>3</sub> 并联，再与 *R*<sub>4</sub> 串联，故

【校对】*R*<sub>eq</sub> = *R*<sub>4</sub> + (*R*<sub>1</sub>+*R*<sub>2</sub>)*R*<sub>3</sub> / (*R*<sub>1</sub>+*R*<sub>2</sub>+*R*<sub>3</sub>)

图 2-6(b) 电路，读者可自行求得 *R*<sub>eq</sub> = 12 Ω。

> 【摘录者按】两电阻并联的 *R*<sub>1</sub>*R*<sub>2</sub>/( *R*<sub>1</sub>+*R*<sub>2</sub> ) 与分流“*i*<sub>1</sub> 配 *R*<sub>2</sub>、*i*<sub>2</sub> 配 *R*<sub>1</sub>”是**交叉**的——学生最爱记成“*i*<sub>1</sub> 配 *R*<sub>1</sub>”。教案要现场用电导比推一遍，并点明“电流走电阻小的那条路”。例 2-1 的“串联电阻不影响并联组内分配”也是易错点：分的是并联组内那股电流。

### 【原文】印刷 p.38 — 桥形连接（点到即止，本课的边界）

除了串联、并联以外，还有一种特殊的连接形式是桥形连接。图 2-7(a) 所示桥形结构电路中各电阻既不是串联也不是并联，因此无法根据电阻的串联、并联变换规律将电路结构加以变动。如果在任一桥支路中加入一个电压源，即得到惠斯通电桥。不难证明，当满足条件

【校对】*R*<sub>1</sub> *R*<sub>4</sub> = *R*<sub>2</sub> *R*<sub>3</sub>

时，对角线支路中电流为零、二端电压也为零，此时认为电桥处于平衡状态，这一条件也称为电桥的平衡条件。电桥平衡时对角线支路可看作开路（因 *i*=0）或短路（因 *u*=0），电路就可按串、并联规律计算。但当电桥不满足平衡条件时，就无法应用串、并联变换，而要用下一节电阻的 Y-Δ 等效变换。

> 【摘录者按】这里是本课的**天然边界**：桥路（不平衡时）“不能用串并联化简”，正好用来回答学生“是不是所有电路都能化简”的疑问。平衡条件与 Y-Δ 变换只点到，留到 L1-05 之后；教案可把它放进“讲什么/不讲什么”。

## 二、李瀚荪《电路分析基础》第5版（上）

### 【原文】印刷 p.41（PDF 59）— §1-8 分压公式和分流公式：分压的引入与推导

在电路分析中，电阻串联电路的分压公式和电阻并联电路的分流公式是两个很有用的公式。在电子电路中常需多种不同数值及极性的直流工作电压，对信号电压的大小也常需加以控制（如录音机、电视机的音量控制），运用分压电路可解决这类问题，并可用分压公式来进行计算。

在图 1-58 所示电路中，两个串联电阻的总电压为 *u*，流过同一电流 *i*。显然，每个电阻的电压只是总电压的一部分。串联电阻电路具备对总电压的**分压作用**，作这一用途时又常称为分压电路。分压关系可推导如下。由 KVL 及欧姆定律得

【校对】*u* = *u*<sub>1</sub> + *u*<sub>2</sub> = *R*<sub>1</sub> *i* + *R*<sub>2</sub> *i* = (*R*<sub>1</sub>+*R*<sub>2</sub>) *i*

【校对】故　*u*<sub>1</sub> = *R*<sub>1</sub>/(*R*<sub>1</sub>+*R*<sub>2</sub>) · *u*，　*u*<sub>2</sub> = *R*<sub>2</sub>/(*R*<sub>1</sub>+*R*<sub>2</sub>) · *u*

（书后式 1-29、1-30 给出 *n* 个电阻串联的一般形式：*u*<sub>k</sub> = *R*<sub>k</sub>/Σ*R*<sub>i</sub> · *u*。）

> 【摘录者按】李瀚荪从“音量控制”“多种直流工作电压”这样的真实需求切入，比邱的纯电路叙述更贴近学生经验，可作开场情境。两电阻分压公式与邱式(2-2)完全一致。

### 【原文】印刷 p.42（PDF 60）— 节点电压、电子电路习惯画法、电位器、例 1-16

〔节点电压〕机壳往往也称为“地”（ground），虽然它并不与大地相连接。在电子电路中常把电压表的“−”端接机壳，而以“+”端依次接触电路中各节点，测得各节点与机壳间的电压（仪表反向偏转记为负值）。因此机壳又称为电路的**参考节点**，各节点至参考节点间的电压降定义为该点的**节点电压**（node voltage）。参考节点的电压为零，故参考节点又称为“零点”或“零电位点”。对节点电压，通常毋需标示参考极性，参考点被认为是节点电压的“−”端。

电子电路有一种简化的习惯画法：电源不用图形符号表示而改为只标出其极性及电压值。分压电路也可用一个具有滑动接触端的三端电阻器来组成，这种可变电阻器又称为**电位器**（potentiometer）。电压施加于电阻器的两端，随着滑动端的滑动，在滑动端与一端之间可得到从零到连续可变而极性不变的电压。

**例 1-16** 空载直流分压电路如图 1-61 所示，*R*<sub>1</sub>=*R*<sub>2</sub>=*R*<sub>3</sub>=100 Ω，电源 150 V，求节点电压 *U*<sub>1</sub>、*U*<sub>2</sub>。解：注意 *U*<sub>1</sub>、*U*<sub>2</sub> 系指自节点 1、2 分别至参考点的电压，*U*<sub>1</sub> 并非是 *R*<sub>3</sub> 两端的电压，而是 *R*<sub>3</sub>+*R*<sub>2</sub> 两端的电压。因此

【校对】*U*<sub>1</sub> = 150 × (*R*<sub>2</sub>+*R*<sub>3</sub>)/(*R*<sub>1</sub>+*R*<sub>2</sub>+*R*<sub>3</sub>) = 150 × 200/300 = 100 V
【校对】*U*<sub>2</sub> = 150 × *R*<sub>3</sub>/(*R*<sub>1</sub>+*R*<sub>2</sub>+*R*<sub>3</sub>) = 150 × 100/300 = 50 V

> 【摘录者按】例 1-16 是分压公式的直接应用，且点破一个真陷阱：节点电压是“该点到参考点”的电压，不是某个元件两端的电压。电位器是分压的实时版——教案的可调交互可以直接做成“滑动分压”的直觉来源（本课页面用两个电阻的滑块即可，不必引入第三端）。

### 【原文】印刷 p.43（PDF 61）— 例 1-17：双电源分压，输出在正负压间连续变化

**例 1-17** 电路为双电源直流分压电路，试说明输出 *U*<sub>1</sub> 可在 +15 V 至 −15 V 间连续变化。电位器电阻为 *R*，*α* 表示 1-3 间的电阻在电位器总电阻 *R* 中所占比例的数值，0≤*α*≤1。

解：初学者往往对这种形式的电路不习惯，不妨把它改画成另一种画法，其中 4 为电源公共端，是电路的参考点。由该图可知：当滑动端 1 移至 b 时，*α*=1，*U*<sub>1</sub>=15 V；当滑动端 1 移至 c 时，*α*=0，*U*<sub>1</sub>=−15 V。设电流 *i* 的参考方向如图，由 KVL 及欧姆定律可得

【校对】*i* = 30 V / *R*

故得（沿 1-3-4 路径）

【校对】*U*<sub>1</sub> = *α*R·*i* − 15 V = (30*α* − 15) V

当滑动端移动时，*α* 随之而变，*U*<sub>1</sub> 亦随之而变：*α*=1 时 *U*<sub>1</sub>=15 V；*α*=0.5 时 *U*<sub>1</sub>=0；*α*=0 时 *U*<sub>1</sub>=−15 V，在 +15 V 与 −15 V 间连续可变。

> 【摘录者按】这个例子给出分压的一个重要工程形象：分压不仅能“分小电压”，还能在**正负电源之间连续调出任意电压**。它是电位器/音量控制的定量版。教案可作“分压能做什么”的佐证，但双电源细节不列为必会。

### 【原文】印刷 p.44（PDF 62）— 分流公式推导、一般形式、练习 1-12

串联电阻电路可起分压作用；**并联电阻电路则可起分流作用**。在图 1-63 所示电路中，两个并联电阻的总电流为 *i*，两端的电压同为 *u*。显然，每个电阻的电流只是总电流的一部分，并联电阻电路具备对总电流的**分流作用**，作这一用途时常又称为分流电路。分流关系可推导如下。用电导表示电阻元件，则由 KCL 及欧姆定律可得

【校对】*i* = *i*<sub>1</sub> + *i*<sub>2</sub> = *G*<sub>1</sub> *u* + *G*<sub>2</sub> *u* = (*G*<sub>1</sub>+*G*<sub>2</sub>) *u*

因而

【校对】*i*<sub>1</sub> = *G*<sub>1</sub>/(*G*<sub>1</sub>+*G*<sub>2</sub>) · *i*　　(1-39a)
【校对】*i*<sub>2</sub> = *G*<sub>2</sub>/(*G*<sub>1</sub>+*G*<sub>2</sub>) · *i*　　(1-39b)

以上两式表明：并联电导中的任一电导的电流等于总电流乘以该电导对总电导的比值。显然，**电导值大的分配到的电流也大**。(1-38) 式便是两电导并联电路的分流公式。若有 *n* 个电导并联，不难得出第 *k* 个电导的电流为

【校对】*i*<sub>k</sub> = *G*<sub>k</sub>/Σ<sub>j=1</sub><sup>n</sup> *G*<sub>j</sub> · *i*　　(1-40)

这就是分流公式的一般形式，式中分母即为并联电路的总（等效）电导。

**练习题 1-12** *R*<sub>1</sub> 与 *R*<sub>2</sub> 并联，若总电流为 *i*，则用 *R*<sub>1</sub> 和 *R*<sub>2</sub> 表示的分流公式是怎样的？若与分压公式作比较，你将得出什么规律？

> 【摘录者按】练习 1-12 是**本课对偶关系的点睛题**：把 *G*=1/*R* 代入分流式，得 *i*<sub>1</sub>=*R*<sub>2</sub>/( *R*<sub>1</sub>+*R*<sub>2</sub> )·*i*——分子换成“对方电阻”，正好与分压 *u*<sub>1</sub>=*R*<sub>1</sub>/( *R*<sub>1</sub>+*R*<sub>2</sub> )·*u* 对照：**分压按本电阻正比、分流按本电阻反比（按电导正比）**。教案的独立练习应让学生自己推出并说出这条规律，而不是背两个公式。书里“电导大的分到电流大”与“电阻大的分到电压大”是对偶的口头版。

## 备课可用的原书要点（我整理，非原文）

4. **书埋的坑**：
   - “等效”被误解成“内部也一样”：书明确只对外部成立，内部各电阻电流要回原电路算。
   - 并联为什么用电导：为了让 *i*=*G u* 与串联 *u*=*R i* 对上；学生若死记“1/R 求和”易乱。
   - 两电阻分流“交叉”：*i*<sub>1</sub> 分子是 *R*<sub>2</sub>，不是 *R*<sub>1</sub>。
   - 等效电阻串大于任一、并小于任一：是数值 sanity check，也能反推“并联越并越小”。
   - 分压按电阻正比、分流按电阻反比（电导正比）：练习 1-12 的对偶规律，学生常混。
   - 分压电路“空载”假设：接上负载后分压比会变（本课空载，负载效应留到 L1-05）。
5. **与上一课（L1-03 功率）的衔接（我补，书中无此对比段）**：串联同电流 → 各电阻 *P*=*i*²*R*，**阻值大的功耗大**；并联同电压 → 各电阻 *P*=*u*²/*R*，**阻值小的功耗大**。这是第三课的功率直觉第一次真正用来比较“谁发热多”，也是排第四课的理由。属通识推导，教案须标清“我补充”，不冒充书中原话。

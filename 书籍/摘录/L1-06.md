## 一、邱关源《电路》第6版

### 【原文】印刷 p.59 — §3-3 支路电流法（引子：2b 法与支路电流法）

对一个具有 *b* 条支路和 *n* 个节点的电路，当以支路电压和支路电流为电路变量列写方程时，总计有 2*b* 个未知量。根据 KCL 可以列出 (*n*−1) 个独立方程，根据 KVL 可以列出 (*b*−*n*+1) 个独立方程，根据元件的 VCR 又可列出 *b* 个方程。总计方程数为 2*b*，与未知量数相等。因此，可由 2*b* 个方程解出 2*b* 个支路电压和支路电流。这种方法称为 2*b* 法。

为了减少求解的方程数，可以利用元件的 VCR 先将每条支路的电压以支路电流来表示，然后代入 KVL 方程，这样，支路电压就不出现在 KVL 方程中，可得到以 *b* 个支路电流为未知量的 (*n*−1) 个 KCL 和 (*b*−*n*+1) 个 KVL 方程。变量数和方程数从 2*b* 个减少至 *b* 个。这种方法称为支路电流法。

> 【摘录者按】支路电流法是“最直接但方程多”的方法，可作本课开场对比：未知量多时想省力，就要选更聪明的变量（网孔电流 / 节点电压），让一部分定律“自动满足”。

### 【原文】印刷 p.60 — 支路电流法示例要点

以图 3-8(a) 所示电路为例说明支路电流法。把电压源 *u*<sub>s1</sub> 和电阻 *R*<sub>1</sub> 的串联组合作为一条支路；把电流源 *i*<sub>s5</sub> 和电阻 *R*<sub>5</sub> 的并联组合作为一条支路……电路的图如图 3-8(b) 所示，其节点数 *n*=4，支路数 *b*=6，各支路的方向和编号也示于图中。

先利用元件的 VCR，将支路电压 *u*<sub>1</sub>、*u*<sub>2</sub>、…、*u*<sub>6</sub> 以支路电流 *i*<sub>1</sub>、*i*<sub>2</sub>、…、*i*<sub>6</sub> 表示：

【校对】*u*<sub>1</sub> = −*u*<sub>s1</sub> + *R*<sub>1</sub>*i*<sub>1</sub>，*u*<sub>2</sub> = *R*<sub>2</sub>*i*<sub>2</sub>，*u*<sub>3</sub> = *R*<sub>3</sub>*i*<sub>3</sub>，*u*<sub>4</sub> = *R*<sub>4</sub>*i*<sub>4</sub>，*u*<sub>5</sub> = *R*<sub>5</sub>*i*<sub>5</sub> + *R*<sub>5</sub>*i*<sub>s5</sub>，*u*<sub>6</sub> = *R*<sub>6</sub>*i*<sub>6</sub>。

选择网孔作为独立回路，按图 3-8(b) 所示回路绕行方向列出 KVL 方程：

【校对】*u*<sub>1</sub> + *u*<sub>2</sub> + *u*<sub>3</sub> = 0；−*u*<sub>3</sub> + *u*<sub>4</sub> + *u*<sub>6</sub> = 0；−*u*<sub>1</sub> − *u*<sub>4</sub> + *u*<sub>5</sub> = 0。

将支路 VCR 代入 KVL 方程，得以支路电流表示的 KVL 方程（式 3-3）；再与 (*n*−1) 个 KCL 方程联立，即得支路电流法全部方程（式 3-4）。

### 【原文】印刷 p.61 — KVL 的“电阻压降和 = 电压源电压和”形式、支路电流法步骤

式(3-4) 中的 KVL 方程可归纳为

【校对】Σ *R*<sub>k</sub>*i*<sub>k</sub> = Σ *u*<sub>sk</sub>　　(3-5)

此式须对所有的独立回路写出。式中 *R*<sub>k</sub>*i*<sub>k</sub> 是回路中第 *k* 个支路中电阻上的电压，当 *i*<sub>k</sub> 的参考方向与回路的方向一致时，该项在和式中取“+”号；不一致时，则取“−”号；式中右方 *u*<sub>sk</sub> 是回路中第 *k* 个支路的电源电压……当 *u*<sub>sk</sub> 与回路方向一致时前面取“−”号（因移在等号右侧），*u*<sub>sk</sub> 与回路方向不一致时，前面取“+”号。式(3-5)实际上是 KVL 的另一种表达式，即任一回路中，电阻电压的代数和等于电压源电压的代数和（也可看作，任一回路中，电阻上电压降的代数和等于电压源上电压升的代数和）。

列出支路电流法的电路方程的步骤如下：

(1) 选定各支路电流的参考方向。
(2) 对 (*n*−1) 个独立节点列出 KCL 方程。
(3) 选取 (*b*−*n*+1) 个独立回路，指定回路的绕行方向，按照式(3-5)列出 KVL 方程。

支路电流法要求 *b* 个支路电压均能以支路电流表示，即存在式(3-1)形式的关系。当一条支路仅含电流源而不存在与之并联的电阻时，就无法将支路电压以支路电流表示。这种无并联电阻的电流源称为无伴电流源。当电路中存在这类支路时，必须加以处理后才能应用支路电流法。

> 【摘录者按】“电阻压降代数和 = 电压源电压升代数和”是后面网孔法/回路法列方程时最顺手的口语化 KVL，符号规则和 L1-02 一致（参考方向决定符号）。

### 【原文】印刷 p.62 — 网孔电流的定义与关键思想

以下通过图 3-9(a) 所示电路说明。图 3-9(b) 是此电路的图，该电路共有 3 条支路……

在节点①应用 KCL，有

【校对】−*i*<sub>1</sub> − *i*<sub>2</sub> + *i*<sub>3</sub> = 0　或　*i*<sub>2</sub> = −*i*<sub>1</sub> + *i*<sub>3</sub>

可见，*i*<sub>2</sub> 不是独立的，它由 *i*<sub>1</sub>、*i*<sub>3</sub> 决定。*i*<sub>2</sub> 分为两部分，即图 3-9(b) 中向下方向的 *i*<sub>1</sub> 以及向上方向的 *i*<sub>3</sub>。这两个电流可以看成是支路 1 与支路 3 中的电流 *i*<sub>1</sub> 与 *i*<sub>3</sub> 各自经过节点①后的延续，也就是将图中所有的电流归结为由两个沿网孔连续流动的假想电流 *i*<sub>m1</sub> 与 *i*<sub>m2</sub> 产生，这两个假想的电流称之为**网孔电流**。根据给定的网孔电流和支路电流的参考方向，可以得出其间的关系：支路 1 只有电流 *i*<sub>m1</sub> 流过，支路电流 *i*<sub>1</sub> = *i*<sub>m1</sub>；支路 3 只有电流 *i*<sub>m2</sub> 流过，支路电流 *i*<sub>3</sub> = *i*<sub>m2</sub>；但是支路 2 有两个网孔电流同时流过，在给定的参考方向下支路电流将是网孔电流的代数和，即 *i*<sub>2</sub> = *i*<sub>m2</sub> − *i*<sub>m1</sub>。

由于网孔电流已经体现了电流连续即 KCL 的制约关系（换言之，根据网孔电流而计算的支路电流一定满足 KCL 方程，或称为自动满足 KCL），所以用网孔电流作为电路变量求解时只需列出 KVL 方程。全部网孔是一组独立回路，因而对应的 KVL 方程将是独立的，且独立方程个数与电路变量数均为全部网孔数，足以解出网孔电流，从而求得全部支路电流。这种方法称为网孔电流法。

> 【摘录者按】这是网孔法的核心直觉：选“沿网孔连续流的假想电流”为变量，节点处进出自动相等 → KCL 不用再单独列，只剩每个网孔一条 KVL。

【校对】*R*<sub>3</sub>*i*<sub>m2</sub> + *u*<sub>s3</sub> − *u*<sub>s2</sub> + *R*<sub>2</sub>(*i*<sub>m2</sub> − *i*<sub>m1</sub>) = 0

### 【原文】印刷 p.63 — 网孔电流方程的一般形式（自阻、互阻）

经整理后，有

【校对】(*R*<sub>1</sub>+*R*<sub>2</sub>)*i*<sub>m1</sub> − *R*<sub>2</sub>*i*<sub>m2</sub> = *u*<sub>s1</sub> − *u*<sub>s2</sub>
【校对】−*R*<sub>2</sub>*i*<sub>m1</sub> + (*R*<sub>2</sub>+*R*<sub>3</sub>)*i*<sub>m2</sub> = *u*<sub>s2</sub> − *u*<sub>s3</sub>　　(3-6)

现在用 *R*<sub>11</sub> 和 *R*<sub>22</sub> 分别代表网孔 1 和网孔 2 的**自阻**，它们分别是网孔 1 和网孔 2 中所有电阻之和，即 *R*<sub>11</sub>=*R*<sub>1</sub>+*R*<sub>2</sub>，*R*<sub>22</sub>=*R*<sub>2</sub>+*R*<sub>3</sub>；用 *R*<sub>12</sub> 和 *R*<sub>21</sub> 代表网孔 1 和网孔 2 的**互阻**，即两个网孔的共有电阻，本例中 *R*<sub>12</sub>=*R*<sub>21</sub>=−*R*<sub>2</sub>。上式可改写为

【校对】*R*<sub>11</sub>*i*<sub>m1</sub> + *R*<sub>12</sub>*i*<sub>m2</sub> = *u*<sub>s11</sub>
【校对】*R*<sub>21</sub>*i*<sub>m1</sub> + *R*<sub>22</sub>*i*<sub>m2</sub> = *u*<sub>s22</sub>　　(3-7)

方程可理解为：*R*<sub>11</sub>*i*<sub>m1</sub> 项代表网孔电流 *i*<sub>m1</sub> 在网孔 1 内各电阻上引起的电压之和……由于网孔绕行方向和网孔电流方向取为一致，故 *R*<sub>11</sub> 和 *R*<sub>22</sub> 总为正值。*R*<sub>12</sub>*i*<sub>m2</sub> 项代表网孔电流 *i*<sub>m2</sub> 在网孔 1 中引起的电压……当两个网孔电流在共有电阻上的参考方向相同时，互阻取正；反之则取负。为了使方程形式整齐，把这类电压前的“+”号或“−”号包括在有关的互阻中。……在不含受控源的电阻电路的情况下，*R*<sub>12</sub> = *R*<sub>21</sub>。方程右方 *u*<sub>s11</sub>、*u*<sub>s22</sub>、…分别为网孔 1、网孔 2、…中所有电压源电压的代数和，各电压源的电压方向与网孔电流一致时，前面取“−”号，反之取“+”号。

对具有 *m* 个网孔的平面电路，网孔电流方程的一般形式可以由式(3-7)推广而得：

【校对】
*R*<sub>11</sub>*i*<sub>m1</sub> + *R*<sub>12</sub>*i*<sub>m2</sub> + … + *R*<sub>1m</sub>*i*<sub>mm</sub> = *u*<sub>s11</sub>
*R*<sub>21</sub>*i*<sub>m1</sub> + *R*<sub>22</sub>*i*<sub>m2</sub> + … + *R*<sub>2m</sub>*i*<sub>mm</sub> = *u*<sub>s22</sub>
……
*R*<sub>m1</sub>*i*<sub>m1</sub> + *R*<sub>m2</sub>*i*<sub>m2</sub> + … + *R*<sub>mm</sub>*i*<sub>mm</sub> = *u*<sub>smm</sub>　　(3-8)

式中具有相同双下标的电阻 *R*<sub>11</sub>、*R*<sub>22</sub>、*R*<sub>33</sub> 等是各网孔的自阻；有不同下标的电阻 *R*<sub>12</sub>、*R*<sub>21</sub>、*R*<sub>13</sub> 等是网孔间的互阻。自阻总是正的，互阻的正、负则视两网孔电流在共有支路上参考方向是否相同而定。方向相同时为正，方向相反时为负。显然，如果两个网孔之间没有共有支路，或者有共有支路但其电阻为零（例如共有支路上仅有电压源），则互阻为零。如果将所有网孔电流都取为顺（或逆）时钟方向，则所有互阻总是负的。

> 【摘录者按】“所有网孔电流同向（都顺时针或都逆时针）→ 互阻总为负”是极实用的口诀，可减少符号错误；本课 P1 采用这一约定。

### 【原文】印刷 p.69 — §3-6 节点电压法（引入）

在电路中任意选择一个节点作为**参考节点**，其他节点称为**独立节点**，这些节点与此参考节点之间的电压称为**节点电压**。节点电压的参考极性是以参考节点为负，其余独立节点为正。由于每一支路都连接在两个节点上，根据 KVL，该支路电压就是这两个节点电压之差。如果每一个支路电流都可由支路电压来表示，那么它一定也可以用节点电压来表示。在具有 *n* 个节点的电路中写出其中 (*n*−1) 个独立节点的 KCL 方程，而 KCL 方程中的各个支路电流都以节点电压来表示，这样，就能得到变量为 (*n*−1) 个节点电压的共 (*n*−1) 个独立方程，称之为**节点电压方程**。最后由这些方程解出节点电压，再求出所需的支路电压、电流。这就是节点电压法。

> 【摘录者按】节点法核心直觉与网孔法对偶：选节点电压为变量，沿任意回路绕一圈电压和自动为零（支路电压 = 节点电压之差）→ KVL 自动满足，只剩每个独立节点一条 KCL。

### 【原文】印刷 p.70 — 节点电压法示例

### 【原文】印刷 p.71 — 节点电压方程的一般形式（自导、互导、注入电流）

……可令 *G*<sub>11</sub> = *G*<sub>1</sub>+*G*<sub>4</sub>+*G*<sub>6</sub>，*G*<sub>22</sub> = *G*<sub>2</sub>+*G*<sub>4</sub>+*G*<sub>5</sub>，*G*<sub>33</sub> = *G*<sub>3</sub>+*G*<sub>5</sub>+*G*<sub>6</sub> 分别为节点①、②、③的**自导**，自导总是正的，它等于连于各节点支路电导之和；令 *G*<sub>12</sub>=*G*<sub>21</sub>=−*G*<sub>4</sub>，*G*<sub>13</sub>=*G*<sub>31</sub>=−*G*<sub>6</sub>，*G*<sub>23</sub>=*G*<sub>32</sub>=−*G*<sub>5</sub> 分别为①-②、①-③和②-③这 3 对节点间的**互导**，互导总是负的，它们等于连接于两节点间支路电导的负值。方程右方写为 *i*<sub>s11</sub>、*i*<sub>s22</sub>、*i*<sub>s33</sub>，分别表示节点①、②、③的**注入电流**。注入电流等于流入节点的电流源电流的代数和，流入节点者前面取“+”号，流出节点者前面取“−”号。注入电流源还应包括电压源和电阻串联组合经等效变换形成的电流源。

> 【摘录者按】节点法的“自导/互导/注入电流”与网孔法的“自阻/互阻/电压源代数和”形成对偶；符号规则：自导恒正、互导恒负（连接两节点的电导取负）、注入电流流入为正流出为负。本课 P1 采用此套规则。

### 【原文】印刷 p.73 — 无伴电压源与超节点（P2 思路）

无电阻与之串联的电压源称为无伴电压源。当无伴电压源作为一条支路连接于两个节点之间时，该支路的电阻为零，即电导等于无限大，支路电流不能通过支路电压表示，按一般公式来列写节点电压方程就遇到困难。当电路中存在这类支路时，有几种方法可以处理。第一种方法是把无伴电压源的电流作为附加变量列入 KCL 方程，每引入这样的一个变量，同时也增加了一个节点电压与无伴电压源电压之间的一个约束关系，成为节点电压法中的约束方程。把这些约束方程和节点电压方程合并成一组联立方程，其方程数仍将与变量数相同。另一种方法是将连接无伴电压源的两个节点的节点电压方程合为一个，即取一个包含这两节点的封闭面来写 KCL 方程，此时，整个电路的独立 KCL 方程就少了一个，同时还应添加节点电压与无伴电压源的约束方程。

> 【摘录者按】“超节点”是 P2 思路：含无伴电压源时把两节点包成一个广义节点列 KCL，再补一条电压约束。教案可点到思路，不必展开例 3-7/3-8 的完整计算。

## 三、摘录者综合笔记（备课用，不是原文）

1. **引入顺序**：支路电流法（直接但方程多，*b* 个方程）→ 选更聪明的变量让部分定律自动满足：网孔电流使 KCL 自动满足（只列 *b−n+1* 个 KVL），节点电压使 KVL 自动满足（只列 *n−1* 个 KCL）。**不是**上来背两套公式。
2. **网孔法核心**：假想沿网孔连续流动的电流 → 支路电流是相关网孔电流的代数和 → KCL 自动满足；列 KVL 得自阻/互阻方程。自阻恒正；所有网孔电流同向时互阻恒负；右端=电压源电压代数和（与绕行方向一致取负、相反取正，移项后）。
3. **节点法核心**：选参考节点，独立节点对参考节点电压为变量 → 支路电压=节点电压之差 → KVL 自动满足；列 KCL 得自导/互导方程。自导恒正；互导恒负（公共支路电导负值）；右端=注入电流代数和（流入为正）。
4. **方法选择直觉（P1）**：独立节点少倾向节点法，网孔少倾向网孔法；含电流源多常用节点法较顺手，含电压源多常用网孔法较顺手（P2 思路，不绝对）。
5. **自检**：求得变量后回代检验 KCL/KVL 与量级是否合理；支路电流可由网孔电流合成或由节点电压差/电阻求得。
6. **P2 边界**：无伴电流源（网孔法需辅助方程/约束）、无伴电压源与超节点（节点法）、含受控源——本课只点思路，不展开计算。回路电流法（邱 §3-5）是网孔法向非平面电路的推广，不讲。
7. **与前课衔接**：KCL/KVL（L1-02）是列方程的两条定律；参考方向/符号约定（L1-01）决定互阻/互导与右端项的正负；戴维南/诺顿（L1-05）解决“单负载看黑箱”，本课解决“系统里多点多回路求解”。
8. **OCR 已知风险**：邱为扫描件，公式字符与下标识别错误较多（如 *i*<sub>m1</sub> 识别成 im1/imi 变体、Σ 与下标丢失、例题数值错读）。以上公式与符号已按电路方程标准形式与原页语义校对；若需精确引用排版/数值，应回看原页图像。李上 §2-1/§2-2 的原文摘录与印刷页码待补充确认。

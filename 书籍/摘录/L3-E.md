## C1 · 耦合电感与理想变压器（摘自 L3-01）

> 【校对】磁耦合：载流线圈通过彼此磁场相互联系；`M` 互感、`M₁₂=M₂₁=M`；同名端决定互感项符号。耦合因数 `k=M/√(L₁L₂)`，`0≤k≤1`，`k=1` 为全耦合。〔邱 §10-1 / p.238–240〕
> 【校对】两线圈串联等效电感 `L=L₁+L₂±2M`（同向取 +、反向取 −）；同名端接错（反向串联却按同向设计）会导致电流过大、有烧毁危险。〔邱 §10-2 / p.242；李下 §11-2 交叉佐证〕
> 【校对】理想变压器三条件：① 无损耗（R=0）；② 全耦合 `k=1`；③ `L₁,L₂→∞`（比值 `n=N₁/N₂` 保持有限）。VCR：`u₁=n·u₂`、`i₁=−(1/n)·i₂`（式 10-7）。电压比与电流无关、电流比与电压无关，**两条是独立关系，不是联立方程**；负号来自两电流都取流入同名端。〔邱 §10-5 / p.251–253〕
> 【校对】功率守恒 `u₁i₁+u₂i₂=0`：输入功率全部传到输出，自身不耗能、不储能（区别于电感/电容）。阻抗变换 `Z_in=n²·Z_L`（二次负载折算到一次侧，乘 `n²`；`n=N₁/N₂`）。〔邱 §10-5 / p.253–254〕

**要点〔通识，据上〕**：本课**统一用邱口径 `n=N₁/N₂`（一次:二次匝数比）**：`n>1` 为降压、`Z_in=n²Z_L` 增大；李下用倒数口径 `n=N₂/N₁`，两者是同一物理规律、**绝不混用**。理想变压器是"k=1 且 L→∞ 的耦合电感极限"，是**非动态、无损耗、无记忆**元件。

## C2 · 运放虚短虚断与四种基本组态（摘自 L3-02）

> 【校对】理想运放三条件 `A→∞`、`R_i→∞`、`R_o→0`，且运放工作在**线性区**（输出不饱和、`|u_o|<U_sat`）；闭环负反馈是常见前提。差分输入 `u_d=u_+−u_-`。〔邱 §5-1；李上 §2-3〕
> 【校对】两条规则：**虚断** `i_+=i_-=0`（因 `R_i→∞`，输入端不吸收电流，但仍不是开路）；**虚短** `u_+=u_-`（因 `A→∞` 且 `u_o` 有限、线性区，两端电压相等但仍不是短路）。虚地是虚短特例：一端真接地 → 另一端 ≈0。〔邱 §5-3 / p.118–119〕
> 【校对】四种组态增益：反相比例器 `u_o=−(R₂/R₁)u_i`；同相（非倒向）比例器 `u_o=(1+R₂/R₁)u_i`（恒 >1、为正）；电压跟随器 `u_o=u_i`（增益 1、隔离负载效应）；加法器（各输入电阻与反馈电阻相等）`u_o=−(u₁+u₂+u₃)`。〔邱 §5-2/§5-3；李上 §2-3〕
> 【校对】操作纪律：只在**输入节点**列 KCL，**不在运放输出节点列 KCL**（输出电流未知）；虚短虚断 + 节点法即可求解，不用受控源模型硬算。〔邱 §5-3；李上 §2-3〕

**要点〔通识〕**：两个"虚"字必须连同**来源（A→∞ / R_i→∞）与前提（线性区 + 负反馈）**一起记——**饱和或正反馈时虚短不成立**。"输出端不列方程"是与 L1-06 节点法一脉相承的操作纪律。

## C3 · 二阶响应形态预判（摘自 L3-03）

> 【原文 OCR / 已校对】特征根 `p₁`、`p₂` 仅与电路的结构和参数有关，而与激励和初始储能无关。〔邱 §7-5 / p.155–156〕
> 【校对】RLC 串联特征方程 `p²+(R/L)p+1/(LC)=0`，令 `α=R/(2L)`、`ω₀=1/√(LC)`，则 `p₁,₂=−α±√(α²−ω₀²)`；临界电阻 `R_c=2√(L/C)`（等价于 `R²=4L/C`，即 `α=ω₀`）。〔邱 §7-5 / 式 7-11；李上 §7-2〕
> 【校对】`R>R_c` → 两个不等负实根 → **过阻尼**（单调、不振荡）；`R=R_c` → 相等负实根 → **临界**（无过冲最快）；`R<R_c` → 共轭复根 → **欠阻尼**（衰减振铃）；`R=0` → 共轭虚根 → **等幅振荡**。〔邱 §7-5 / p.156–162〕
> 【校对】欠阻尼有过冲：阻尼比 `ζ=α/ω₀`，过冲量 `σ%=e^(−πζ/√(1−ζ²))×100%`、`t_p=π/(ω₀√(1−ζ²))`；峰值 `=U∞(1+σ/100)`。〔L3-03 教案/页面口径〕
> 【校对】二阶全响应 = 特解（强制/稳态分量）+ 齐次通解（自由/暂态分量）；齐次通解正是四形态之一，分解结构与一阶相同。〔邱 §7-6 / p.162〕

**要点〔通识〕**：形态（振荡与否）**只由 R、L、C 参数决定，与激励和初值无关**——这是"不解方程就能预判形态"的根据。临界电阻判据**只针对 RLC 串联**；并联 GLC 的判据对偶（用 `G_c=2√(C/L)` 或 `R_p` 越小越阻尼），不能直接套串联式。

## C4 · 拉普拉斯变换与 s 域直觉（摘自 L3-04）

> 【校对】拉氏变换定义 `F(s)=∫₀₋^∞ f(t)e^(−st)dt`，`s=σ+jω` 为**复频率**；比相量的 `jω` 多一个实部 `σ`，故能同时描述衰减（欠阻尼）、稳定与增幅。常用对：`ε(t)↔1/s`、`e^(−at)↔1/(s+a)`、`cos ωt↔s/(s²+ω²)`、`sin ωt↔ω/(s²+ω²)`。〔邱 §14-1；李下 §12-1〕
> 【校对】微分性质 `L[df/dt]=sF(s)−f(0₋)`：`−f(0₋)` 就是"自动带入初值"，只用到 f 本身在 `0₋` 的值（恰是电感电流、电容电压这些电路给的初始状态），不需各阶导数初值。〔邱 §14-2；李下 §12-1〕
> 【校对】运算阻抗：电阻 `R`、电感 `Z_L=sL`、电容 `Z_C=1/sC`；零初值下 `U(s)=Z(s)I(s)`。**"把 jω 换成 s"** 即从相量模型得到 s 域模型（零状态）。〔邱 §14-4；李下 §12-3〕
> 【校对】s 域分母的根（极点）＝响应里的指数衰减率/振荡频率＝L3-03 的特征根 p。例12-8：`Z(s)=2s+8`，根 `s=−4`，响应 `i(t)=[2.4e^(−4t)+4sin(3t−37°)]ε(t) A`（瞬态 + 稳态 = 全响应，稳态幅值 4 A 由相量法核对）。〔邱 §14-3/§14-5；李下 §12-3 例12-8〕

**要点〔通识〕**：s 域法是**变换域方法**，与相量法类比（相量把 jω 当变量、s 域把 s 当变量）。本课只做方法论直觉 + s 域阻抗 + 系统求解流程；**复杂部分分式展开、网络函数零极点/频响不要求手算**（P3 了解即可）。非零初值把初始状态看成**附加电源**后方程形式仍与相量方程类似。

## C5 · 三相电路与非正弦周期量（摘自 L3-05）

> 【校对】对称三相电压 `U̇_A=U_p∠0°`、`U̇_B=U_p∠−120°`、`U̇_C=U_p∠120°`，相量和恒为零。Y 形 `U_l=√3U_p` 且线电压超前对应相电压 30°、`I_l=I_p`；△ 形 `U_l=U_p`、`I_l=√3I_p` 且滞后 30°。〔邱 §12-1/§12-2；李下 §9-8〕
> 【校对】对称三相平均功率 `P=3U_pI_pcosφ=√3U_lI_lcosφ`，无功 `Q=√3U_lI_lsinφ`；**φ 是负载阻抗角（相电压与相电流的相位差），不是线电压与线电流的相位差**。对称时瞬时功率恒定 = 平均功率。二瓦计法 `P₁+P₂=P`，对称时 `P₁=U_lI_lcos(φ−30°)`、`P₂=U_lI_lcos(φ+30°)`；`|φ|>60°` 时某表读数可能为负，取代数和。〔邱 §12-5；李下 §9-8〕
> 【校对】非正弦傅里叶分解 `f(t)=A₀+ΣA_kcos(kω₁t+φ_k)`：直流分量 + 基波（k=1）+ 高次谐波（k>1），频谱离散。有效值 `I=√(I₀²+I₁²+I₂²+…)`（各次有效值平方和开方）。〔邱 §13-2/§13-3；李下 §10-5〕
> 【校对】平均功率 `P=U₀I₀+U₁I₁cosφ₁+U₂I₂cosφ₂+…`：**只有同频的电压、电流配对才产生平均功率，不同频率乘积积分为零**。例10-9：`u=[100+100cos t+50cos2t+30cos3t] V`、`i=[10cos(t−60°)+2cos(3t−135°)] A`，`P₁=250 W`、`P₃=−21.2 W`，总 `P=228.8 W`。〔邱 §13-3；李下 §10-5 例10-9〕
> 【校对】谐波分析法：把非正弦激励分解后**逐频**建相量模型、求同频响应，再在时域相加；**不同频率不可合并成一个相量**；直流分量按 `ω=0` 单独处理（L 短路、C 开路）。〔邱 §13-4；李下 §10-4〕

**要点〔通识〕**：三相 `√3` 与 `±30°`、`P=√3U_lI_lcosφ` **只在对称 + 定相序 + 定参考方向下成立**；不对称时中性点位移，中线保证各相独立。非正弦功率"按频率配对"，负号代表该谐波分量在送功率。

## C6 · 传输线边界：集总 vs 分布（摘自 L3-06）

> 【原文 OCR / 已校对】只有在器件的尺寸远小于其正常工作频率所对应的波长、波的传递现象可以忽略时，才可以采用集总概念。〔李下 13-1 / PDF 232〕
> 【校对】集总假设成立条件：频域 `l≪λ`、时域 `Δt=l/v≪T`（`λ=v/f`，真空 `v=c=3×10⁸ m/s`）。`l` 可与 `λ` 比较即"长线"，必须改用分布模型。"长"是**相对的**：同一 10 cm 走线，50 Hz（λ=6000 km）下是短线，30 GHz（λ=1 cm）下是长线。〔邱 §18-1 / p.452 / PDF 476；李下 13-1 / PDF 233〕
> 【校对】分布参数模型四个原参数：每单位长度电阻 `R₀`（Ω/m）、电感 `L₀`（H/m）、电容 `C₀`（F/m）、电导 `G₀`（S/m）。沿线取长度元 dx，用 KCL/KVL + 略去二阶无穷小量得电报方程 `-∂u/∂x=R₀i+L₀∂i/∂t`、`-∂i/∂x=G₀u+C₀∂u/∂t`（式 18-1）——**不是新定律**。〔邱 §18-2 / p.454–455 / PDF 478–479；李下 13-1〕
> 【校对】两端等效 T/π 电路是集总形式，但其 Z、Y 是在**某一频率下由分布模型求出**的，不能理解为分布模型可由集总模型简单替代。〔邱 §18-1 / p.453 / PDF 477〕

**要点〔通识，据上〕**：数字电路把"信号有多快"用上升沿 `t_r` 度量，`f_knee≈0.35/t_r`；**飞行时间 `t_d=l/v` 与 `t_r/6` 比较**（工程经验，非书中原文）：`t_d≪t_r/6` → 集总，`t_d` 可与 `t_r/6` 相比 → 必须启动 SI 思维。反射系数 `Γ=(Z_L−Z₀)/(Z_L+Z₀)`：开路 `Γ=+1`（末端电压约 2 倍）、短路 `Γ=−1`（末端 0）、匹配 `Z_L=Z₀` 时 `Γ=0`（无折返）。反射/传播常数/特性阻抗的正式推导属 P3「了解即可」，留后续 S13（Bogatin 未摘正文不引章节号）。
